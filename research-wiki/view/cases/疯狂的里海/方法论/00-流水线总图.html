里海方法论流水线总图

Wiki2026-09-24research/疯狂的里海/方法论

里海方法论流水线总图：① 初筛 → ② 解构·建模·跟踪 → ③ 共振

一句话结论：里海从"知道一家公司"到"敢重锤一家公司"，走的是三段动作链，不是一次深度研究——① 决定值不值得花时间；② 决定靠什么赚钱、每天盯什么数；③ 决定什么时候扣扳机、下多重。90-横切 里的两页不占工序，是认识论与行业实例，随时读、不在流水线上执行。

本页是 方法论/ 的唯一入口。归入 00- 前缀但放在目录根部，因此在组页里就是「方法论」这个标签本身。

总思想是弱者体系（见 §〇）：劣势在研究、在信息，所以不靠深研赢，靠买得低 + 看错了也不亏钱 + 只做简单公司 + 不绝对集中赢；散户的灵活与时间则用来"等"。

〇、总思想：弱者体系 —— 这条流水线为什么是这样排的

一句话：承认劣势在研究、在信息（这两项散户永远拼不过机构），于是放弃"看得更深"，改用四件自己能掌控的事取胜——买得低、看错了也不亏钱、只做简单公司、不绝对集中；而散户真正的优势（灵活、时间、没有外部考核压力）拿来"等"，等到能看懂、赢面大、敢重仓才出手。

⚠️ 本句系 AI 归纳，不是作者原话；下面每一条都给出原话出处，请以原话为准。

作者原话（体系命名）：「弱者思维体系下的强者突破是现阶段我的打法的精炼总结……我知道自己不知道」（2022.1.2《2021年投资总结~轻舟已过万重山!》）；「弱者体系下的提前价值发现，再加上不绝对集中，可能是个人投资者能够在市场长期生存并获得超额收益的很好的路径」（2022.1.17《一直在市场里玩下去》；同句更早见于 2022.1.12《幸福与投资！》）

1. 先按作者自己的二分：劣在哪、优在哪

「我想了下，散户的优势在于灵活，在于时间，没有外部给的投资压力，而劣势在于研究，在于信息。」 —— 2026.3.25《散户的赚钱之道》

项 作者定位 落到哪道工序
信息 劣势 只做变量可公开跟踪的公司 → ① 里海-简单论 / ② 建模卡口（跟踪不到即出局）
研究 劣势 不深研，用"紧盯一个主要因子"替代"把公司看透" → ② 建模只留 1-2 个变量
灵活 优势 资金小、没有条条框框（2025.12.9《看了胡猛的〈风和投资随笔〉……》）→ 战术股轮动 / 道·频率
时间 优势 "只输时间不输钱""等得起" → ③ 共振：三信号同亮才扣扳机
无外部考核压力 优势 敢熬潜伏期、不做排名驱动的换股 → 全三段

⚠️ 更正（2026-09-25）：上一版把资金、情绪也列为劣势，方向错了——作者把资金规模小算作灵活的来源（2025.12.9），心态/情绪则归入 2444 的修行层（里海-2444投资体系），与弱者体系不在同一层。

2. 四条自己能掌控的打法（每条皆为原话）

  1. 以防守为基准，第一目的是"不亏"：「绝大部分人进来的第一目的是赚钱！而我不是，我是不亏钱……就算看错了也亏不了几个钱」（2020.12.29《唉，人气新低了》）；「以防守为基准……站在弱者角度，寻找就算看错了也不会亏多少钱的机会」（2021.6.18《完了，暴露实力了》）。→ 先算最坏亏多少（② 底价），再谈能赚多少（② 弹性）。
  2. 买得低是保护本金最有效的措施：「买得低一定是保护自己的本金不受损的最有效的措施」（2022.5.17《我家领导是股神！》）。买得低 → 看错了也能小赚：秦安（2020.11.10）、新希望（2021.4.6）。
  3. 不深研，只在简单公司里找：「我不深研，只在简单公司中找机会」（2022.12.30《2022年投资总结——困难的一年！》）——研究劣势的解法不是补研究，是换赛道。
  4. 提前价值发现 + 不绝对集中（2022.1.17）。分仓是弱者的保险，不是收益最大化手段；它与"重仓集中"不矛盾，边界在"看错了也亏得起"。

3. 扬长避短是双向的，弱者体系不是只防不攻

「我们可以扬长避短，把研究的劣势变为相对的优势，例如，我的基于弱者视角的投资体系，就算是在看错了的情况下，在没有办法完全了解公司的情况下也能够赚钱。」 —— 2021.1.19《资金到处窜！》

弱者的那一半＝赔率与防守；强者的那一半＝提前价值发现（2021.1.31）。强者那一半有前提：案例/里海案例-新希望 是突破失败的记录——变量从外部周期数据变成公司内部执行数据，强者视角所需的信息精度 > 公开披露能提供的精度。

4. 边界（不得外推）

  • ⚠️ "劣势 → 工序"的对应是本页归纳：作者只做了"优势/劣势"的二分，并没有把三段工序一一挂到劣势上。不要把卡口说成"劣势的止损线"——卡口的直接来源是"看不懂就绕开""变量要能跟踪""三信号要同亮"，属于操作纪律，不是劣势推演。
  • ⚠️ 弱者 ≠ 不研究：本体系仍有一条研究驱动的腿（见 里海体系vs巴菲特三好-方法论对比），只是研究的目的是收敛出 1-2 个变量，不是得出精确预测——后者是强者视角，正是再升与新希望两次栽倒的地方。
  • ⚠️ "弱者体系"不是里海独创的术语：语料中读者留言直接把它与冯柳并列讨论（2021.6.1《投资体系要具备反脆弱性！——2021年5月读者留言精选》）。里海的用法是「弱者思维体系下的强者突破」——多了"强者突破"那一腿，与"只靠赔率与分散"的纯弱者版本不同，两者不可混为一谈。
  • ⚠️ "看错了也不亏钱"的直接理论来源是冯柳的三阶段划分：「低风险阶段就是看错了也不会亏钱，潜在风险阶段就是必须判断对，绝对风险状态就是判断对了也会亏钱」（2019.3.25《冯柳影响我投资观的几句话！》）。本体系只在低风险阶段下注。

一、流水线总览

【第 ① 段】30 分钟初筛 ── 值不值得花时间？
     穷举圈层 → 三板斧（简单 / 变化 / 财报）→ 两把尺子落档 → 60/25/15 精力分配
        ↓  1-2 类才继续
【第 ② 段】解构 · 建模 · 跟踪 ── 靠什么赚钱？最坏亏多少？每天盯什么？
     解构：拆板块 → 找托底 → 找弹性 → 横向淘汰 → 主逻辑 + 底价 + 变量清单
     建模：变量 → 每天/每季要盯的数 → 日频 / 季频持续跟踪（变量会换轨）
        ↓  跟踪模型亮灯
【第 ③ 段】共振 ── 什么时候扣扳机？
     基本面 ✓ ＋ 位置（走出阶段底）✓ ＋ 资金面（看基本面的资金进场）✓
        ↓
     买入（仓位来自第 ② 段的赔率判断）
        ↓
     继续用同一套模型盯「主逻辑走完没有」＝卖点
段 输入 动作 产出 卡口（不满足即出局）
① 初筛 能力圈名单 / 财务反筛 / 外部推荐 三板斧 + 两把尺子 跟踪力度分配表（≠ 买入清单） 不简单 / 无大变化 → 3-4 类，只给 15% 精力
② 解构建模跟踪 1-2 类标的 500 字主逻辑 → 变量 → 跟踪模型 一句话主逻辑 + 底价 + 1-2 个可跟踪变量 500 字讲不清 / 变量无法公开跟踪 → 出局
③ 共振 亮灯的跟踪模型 等三个信号同时亮 买点与仓位 只有价格动、基本面没动 → 不买；判定双左侧 → 一票否决

二、各组提炼

10-初筛 — 决定"值不值得花时间"

页 一句话提炼
里海-四类跟踪分档法（本段总图） 三步动作链 + 一条精力纪律。产出的不是买入清单，是跟踪力度分配表：1 类 60% / 2 类 25% / 3+4 类 15%；原文硬约束「1 类跟踪可能就几家」，早期口径上限约 10 家——超了就是尺子放水。分档之后还要二次梳理才谈得上抉择。
里海-简单论 第一道闸门，功能是把"看不懂"前置到选股阶段：术四字里"简单决定能不能看，底部决定亏不亏，变化决定涨不涨"；原话"复杂的公司，其业绩释放路径上的可变因子太多"（2020.5.2）。它的动作是绕开，不是挑出。
里海-变化论 第二道闸门，也是三板斧的核心：低估不是底，变化才是底。语料中的变化归纳为六类（治理股权 / 业绩拐点 / 行业景气·第二曲线 / 预期估值 / 筹码 / 无变化反例）。捕获的正确姿势不是预测，是跟踪，"低位信其有"。⚠️ 六类划分系 AI 归纳，非作者原话的分法。

本段出口：落 1-2 类 → 进第 ② 段；落 3-4 类 → 只保留定期浏览，不做解构。

20-解构建模跟踪 — 决定"靠什么赚钱、最坏亏多少、每天盯什么"

页 一句话提炼
里海-解构法 目的不是"搞懂公司"，而是收敛出三样东西：一句话主逻辑 + 1-2 个业绩变量 + 一个"全搞砸也亏不了"的底价。500 字原则：讲不清就出局。四步＝拆板块 / 找托底 / 找弹性 / 横向淘汰。层次边界：生意模式层必答，专业层刻意不钻（"很多化工产品的名字我都叫不来，我就是个门外汉"）。唯一全程数字示范＝新希望（民生银行托底 → 底价 170-180 亿；2500 万头产能储备 vs 250 万头出栏 vs 猪收入仅占 5%；不选纯猪股＝"如果猪周期晚两年，有些养猪的公司说不定撑不住"）。
里海-建模与跟踪 把变量变成"每天/每季要盯的数"。每段模型只盯 1-2 个变量——正因为单只变量少，才跟得起上百家池子。示范：鲁西（双氧水·PC 价格，日频，盯 8 个月）、榨菜（县城渠道数 + 恢复发货）、再升（短中长资金共振）。变量会随阶段换轨（榨菜从"提价"换成"渠道"），所以建模不是一劳永逸的活。⚠️ 换轨分两种，新希望是反面那一半：被下跌逼出来的被动换轨（出栏量+猪价 → 自有育肥出栏+完全成本），换轨后的变量作者自认"就算是董秘也不一定知道全貌"——过不了"可公开跟踪"这道卡口，见该页 §三.2（案例/里海案例-新希望）。

本段出口：跟踪模型亮灯 → 交棒第 ③ 段。亮灯 ≠ 买入（鲁西第一波因"逻辑不硬 + 我没钱"没买）。

30-共振 — 决定"什么时候扣扳机、下多重"

页 一句话提炼
里海-四段式工作流 第 ④ 段＝基本面 × 位置 × 资金面三者同亮才介入。原话"低位的共振点，即使判断错了，也不会怎么亏钱，大不了就是亏时间而已"。两个反面：
① 只有价格动、基本面没动（纯情绪）→ 不买；
② 基本面动了但满仓没钱 → 买不了（鲁西"没买够"是结构性代价，不是失误）。
里海-双左侧 买卖两端总开关，共用一条信念——市场先生的表态比我个人研究可信。
卖出端：基本面预期往下 + 股价大走势往下 → "怎么也要把筹码砍掉"，不幻想不抄底。
买入端：重锤前提＝股价趋势与基本面预期至少一端在右侧，"最好股价先到右侧"。

90-横切 — 不占工序，随时读

页 一句话提炼 什么时候读
里海体系vs巴菲特三好-方法论对比 两套推理结构之差：正向演绎 + 优质样本归纳（巴菲特）vs 反向证伪 + 错误样本归纳（里海）；分歧不在"要不要价值"，而在远见型推理 vs 位置型推理。⚠️ 若只讲差异而丢掉"研究驱动"那一腿，就会误读成"反研究"。 校准"为什么可以这样干"时；引用"门外汉/不深研"之前必读
里海-储能与新能源链观察法 储能/新能源在语料里从来不是可配置的赛道，而是"变化因子"的行业实例：它能不能让一只已跌到位、业务看得懂的公司顶破原有天花板，才是关心的全部；且都按战术股处理，赚一波就走。闸门随时会关（阳光电源从"隐形冠军正面案例"转为"根本看不明白"的回避样本）。 遇到"热门赛道 + 低估值传统公司"组合时，作为第 ① 段第二板的行业层参照
引用纪律-行业规模与市占率分母三检 ⚠️ 非里海原文（本项目引用纪律）。市占率 = 分子 ÷ 分母，而分母几乎从不被审计——引用行业规模/份额前先验三检：时间粒度（官方只发规上年度，出现"行业中期收入"必是上市公司加总）／量级对照（与官方口径差 ≥3 倍即截断）／成分覆盖（异种混入 + 行业龙头不在分母）。达意隆样本：伪口径 19.4% → 真口径 5.9%，投资含义从"龙头抢份额"翻成"低份额替代（慢变量，"变化"关不认）"。 引用任何"行业规模 / 市占率"数字之前；做第 ② 段横向淘汰时

三、跨段三条纪律

  1. 顺序不可颠倒（概率·赔率 → 频率）：原文"千万不能搞错顺序，如果抛弃'概率和赔率'，盲目来搞频率，就成了普通散户的追涨杀跌"。→ 跳过 ①② 直接照搬"共振"或照搬 1-4 类编号，方向恰好相反。
  2. 每张图的产出都不是买入信号：初筛产出的是精力分配表；解构产出的是底价与变量；建模产出的是亮灯。作者自己说分档"完全还没有达到可以抉择的那个阶段"。唯一产生买入动作的是第 ③ 段。
  3. 双左侧一票否决：任何阶段一旦判定双左侧，后续全部中止——"不管你觉得多么的便宜，都不要锤进去"。

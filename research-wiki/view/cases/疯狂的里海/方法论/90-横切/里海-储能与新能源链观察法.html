里海储能与新能源链观察法

Wiki2026-09-17research/疯狂的里海/方法论/90-横切

里海体系中的「储能 / 新能源链」观察法：储能是变化因子，不是买入理由

一句话结论：语料里里海从未把"储能"当作一个可以配置的赛道，而是把它当变化因子使用——它能不能让一只已经跌到位、业务看得懂的公司"顶破原有天花板预期"，才是他关心的全部。

本页为分析整理层（非里海原文）。"变化因子""四种切入形态"等提法系本文归纳，作者本人用的词是"变化 / 变量 / 第二增长曲线 / 巨大市场"。所有引号内文字均出自本仓库 raw 年度合集，路径与行号在文末索引中给出，可逐条回查。

〇、结论速览

  1. 他不买赛道：2026 年他把"最近的储能锂产业链"与创新药、算力并列为"无一不是资金猛干"的热门赛道（合集至2026-06-09 line 2167）——赛道越热，越不在他的买点上。
  2. 他买变化：储能作为"一个新的巨大的市场，这市场足够大"，能让一家"本来已经赚钱但不值钱的老登股"重新变成成长股（宁德时代案例，2026-05-11）。
  3. 他买形态：真正下手的是两类形态——传统公司切入储能/新能源（云南能投）与跌不动但基本面在好转的储能标的（华宝新能），且都按战术股处理：赚一波（几十个点）就走。
  4. 闸门随时会关：同一家公司，只要"业绩算不出来"（阳光电源 2022）或"位置被资金猛干过"，立刻从可看变成回避。

2026.04.20 宁德时代（储能第二曲线） 作为"变化 → 预期修复"的方法论案例 "就说目前正是如日中天的宁德时代，目前因为储能第二增长曲线放量了，所以又来了一波新的行情""其业绩下滑是在 2024 年……但股价却在 2024 年 1 月份到底了""涨回来了是因为公司基本面预期又发生了向上的变化"（合集至2026-06-09 line 658-665）
2026.05.11 宁德时代 + 储能 把"足够大的新市场"写成机制 "本来经过了 2019-2021 年的突飞猛进期，公司已经成为了……能赚钱，但二级市场不给好定价了……两年内公司股价跌了 70%""结果这两年又遇到一个新的巨大的市场，那就是储能，这市场足够大，因此市场马上就看到了公司能够顶破原有天花板预期的确定性，所以这么大体量的公司，居然两年内涨了 3 倍了"（合集至2026-06-09 line 871-873）
2026 对行情的定性 把储能链归入"资金猛干" "这一轮的上涨行情……例如上半年的创新药，算力，最近的储能锂产业链等，无一不是资金猛干"（合集至2026-06-09 line 2167）

二、四种切入形态（按他的偏好排序）

形态一：传统公司切入储能 / 新能源（乌鸦变凤凰）——最偏好

  • 判据：原主业"成熟、垄断毛利、但缺乏增量" → 新业务打开空间 → "是巨大的变量"
  • 原文实证：云南能投（盐+天然气 → 风光储，装机从 100 万千瓦到 513 万千瓦）
  • 同类模型：法拉电子"传统衰退行业进新兴行业"（2022.4.11，里海年度时间线-2022年）
  • 他的动作特征：在放量前介入，赚边际变化的一波（战术性），而不是长期持有

形态二：第二增长曲线顶破天花板（已验证的大公司）

  • 判据："本来能赚钱但不值钱（老登股）" + "遇到一个足够大的新市场" → 市场重估预期
  • 原文实证：宁德时代（2024.01 股价见底 → 储能放量 → 两年 3 倍）
  • 关键：他讲的是"预期修复的机制"，落点仍是"变化大到能顶破原天花板"（与 里海-变化论 第 3 类"行业景气/第二曲线"一致）

形态三：储能标的自身的"底部 + 边际改善"

  • 判据：跌不动（筹码层面）+ 基本面在好转（业绩层面）+ 估值有净资产托底
  • 原文实证：华宝新能（"跌不动了""半年报营收 +24%、净利润扭亏为盈"、PB 1.4）
  • 他的附加检查：募资是否被浪费（超募 50 亿 → "被钱噎住" → 战略属性降为战术机会）

形态四：纯赛道股 / 高估值高波动 → 回避

  • 原文实证：阳光电源 2022（"根本看不明白"）、2026 年对储能锂产业链"资金猛干"的定性
  • 机理：属于简单论闸门中的"连业绩都算不出来（机构也是糊涂账）"一类（里海-简单论）

三、把标准翻成检查表（本页归纳，非作者原话）

步骤 问什么 语料中的判据来源
① 位置 是否"跌不动了 / 长期横住"？还是已被资金猛干？ 华宝新能"跌不动"；2026 储能锂链"资金猛干"
② 简单 业务能否一两句话说清？ 华宝新能"大号充电宝+太阳能充电板"；再升"工业消费品公司，没法建模型"（复杂反例）
③ 变化 切入是否"足够大"（空间大、确定性高、市场未定价）？ 云南能投"5 倍扩产=巨大变量"；宁德"市场足够大→顶破天花板"
④ 财务 负债/净资产实不实？募资有没有被浪费？ 云南能投（30 年长贷、利率约 3%、国资委大股东）；华宝新能（60 亿现金"被钱噎住"）
⑤ 定性与卖点 是战略股还是战术股？兑现即走？ 云南能投"涨六七十点""这波战术性行情差不多结束了"；华宝新能"只有战术机会的股"

四、什么情况下他会关掉闸门（反向证据）

情形 原文 结果
业绩算不出来 "根本看不明白企业的基本面的"（阳光电源 2022） 从隐形冠军模型样本 → 直接回避
位置被资金猛干 "最近的储能锂产业链……无一不是资金猛干"（2026） 不参与，等待
募资被噎住 "公司被这笔钱噎住了"（华宝新能） 战略股 → 只剩战术机会
高位透支 "一波流两年就把未来七八年的业绩都透支完了"（宁德 2023 语境） 业绩好也不买
变化不够大 腾讯"经营很稳定，但没啥大变化 → 赚钱但不值钱的股"（2026.5.11） 只当分红资产，不赚价差

五、边界与不确定（务必注意）

  1. "变化因子"是本文的归纳词，作者没有用过；他讲的是"变化 / 变量 / 第二增长曲线"。
  2. 语料中没有他对储能行业本身的系统论述——没有储能技术路线、锂价周期、装机数据、政策机制的分析。本页只能还原"他怎么用这条链选股"，不能还原"他怎么看储能行业"。
  3. 他的储能相关操作以战术股为主（云南能投、华宝新能），唯一被当作"战略级变化"讨论的是宁德时代，但那是方法论举例，语料中未见其持仓自述。
  4. 因果需谨慎：本页所列"买入—卖出"因果关系中，只有云南能投一篇是他自己完整复盘的操作，其余（华宝新能、涪陵电力、鹏辉能源）为观察/跟踪表述，不能等同于实际持仓。

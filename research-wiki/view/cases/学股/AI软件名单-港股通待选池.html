三、逐类判读（初筛看法，全部待中报原文验证）

① 开发端（AI Coding 降本 → 人效提升）

逻辑：收入按人头计费的 IT 服务/软件外包**——AI Coding 省的是自己的成本，理论上直接落到毛利。

代码 名称 初筛看法 待核（按优先级）
00354 中国软件国际 本类唯一正经标的，PB 0.75 接近破净，但营收仅 +5.2%——降本的受益还没体现在报表 ① 中报人均创收/人均毛利是否真提升（需员工人数 + 营业成本附注）；② AI Coding 工具是自用还是给客户交付（后者会变成收入不增反降单价）；③ PB 0.75 隐含市场认为人效提升会被客户压价吃掉，这个定价对不对
01675 亚信科技 营收 -15.4%，先把"-15.4%"解释清楚再谈受益 ① 收入下滑是丢失订单还是项目验收节奏；② PB 0.56 已接近清算价，是否隐含盈利能力永久下台阶

④ 竞争端（供给出清 → 龙头受益）

落在同一批名字上：00268 金蝶、03888 金山软件、00696 中民航信、02013 微盟。

🔴 这一类的证据是最弱的。原文判断"中国 SaaS 经历两轮融资热潮后低谷期本身的供给出清，行业龙头面临前所未有的大好局面"——本库没有任何 CR / 退出家数 / 招投标价格数据可以佐证。当前只能标记为「逻辑成立，证据为零」。要验证必须去找：中国 SaaS 行业投融资总额、同业家数变化、以及上述公司自身的客单价是否止跌（客单价止跌＝价格战出清的直接证据）。

⑤ 商业模式（订阅制 → 积分/token 消耗：毛利率下降但营收暴涨）

营收增速最高的集中在这一类（迅策 +388.8% / 迈富时 +111.2% / 滴普 +115.0% / 云知声 +38.7% / 金山云 +33.7% / 范式智能 +43.4%）。

🔴 判据需要两个数同时成立：营收暴涨 ＋ 毛利率下降。 目前只有营收侧可证，毛利率侧完全不可证（TDX 损益表无销售成本科目）。这是本池当前最大的结构性证据缺口，也是已下载中报最需要优先做的事：把每家的毛利率/毛利额拉出来，看 2026H1 vs 2025H1 是升是降。

  • 若营收暴涨 + 毛利率下降 → 原文第 5 类在本地得到证实（token 化真实发生）；
  • 若营收暴涨 + 毛利率也升 → 说明不是 token 化，只是正常的规模效应，原文的"全栈 Token 工厂"在本池不成立。

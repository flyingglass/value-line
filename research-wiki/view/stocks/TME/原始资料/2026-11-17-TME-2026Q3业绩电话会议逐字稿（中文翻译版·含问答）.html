摘要

核心话题：喜马拉雅首个完整并表季度 · 泛IP第二增长曲线 · SVIP与长音频 · 广告逆风 · 微信视频号协同 · 2027展望

一句话核心：2026Q3 是喜马拉雅并入 TME 后首个完整季度，总收入 89亿元（+6%）、音乐相关服务收入 77亿元（+10%）；以周边商品与线下演出为核心的泛IP消费成为最亮眼的第二增长曲线（营销及消费服务收入 27亿元，+12%），管理层称 IP 业务"好于预期"、Q4 将进一步加速。但毛利率因收入结构变化降至 42.8%（去年 43.5%）、运营费用率升至 17.1%（去年 15.5%，喜马拉雅并表含无形资产摊销），归母净利润 22亿元基本持平、Non-IFRS 净利 25亿元（+2%）。管理层对 2027 年 IP 与 SVIP 展望积极，广告仍承压。

关键数据（2026Q3）：

  • 总收入 89亿元（+6%）；音乐相关服务收入 77亿元（+10%）
  • 会员服务收入 50亿元（+9%）；营销及消费服务收入 27亿元（+12%）
  • 毛利率 42.8%（去年同期 43.5%，收入结构变化所致）
  • 运营开支 15亿元，费用率 17.1%（去年同期 15.5%，喜马拉雅并表+无形资产摊销）
  • 归母净利润 22亿元（与去年同期基本持平）；Non-IFRS 归母净利润 25亿元（+2%）；调整后 EBITDA 30亿元（+3%）
  • 现金、现金等价物、定期存款及短期投资合计 515亿元（6月30日为 442亿元）
  • 2026年9月发行本金总额 10亿美元高级无担保票据（2031年到期 5亿 + 2036年到期 5亿）
  • Q3 回购 3470万份 ADS，总现金对价 3亿美元（2025年3月回购计划推进中）
  • GAI 4 场体育场级演唱会吸引超 12万名观众；喜马拉雅动态漫画等新型音视频超 1万部
  • AI 生成内容播放量"仍然微不足道"，收听份额呈下降趋势（管理层多次强调）

核心矛盾：

  1. 毛利率下滑（43.5%→42.8%）与费用率上升（15.5%→17.1%），主因收入结构向周边/演出倾斜 + 喜马拉雅并表摊销；IP 业务利润率低于集团平均，管理层预计占比提升会带来"小幅波动"
  2. 广告业务在宏观走弱与流量竞争下承压，但喜马拉雅并表对广告为正向贡献、IP/线下演出赞助打开新增量——广告何时企稳待观察
  3. 泛IP（周边+演出）增长强劲但利润率偏低，与第二增长曲线的"高质量增长"目标存在张力；管理层以"一体化飞轮"（内容+平台+端到端IP）与精细化运营回应
  4. AI 生成内容冲击订阅变现，管理层以版权保护（法律行动+内容管理）应对，称 AI 歌曲播放量极低且下降

跟踪要点：

  1. 2027 年 IP 业务项目储备：Q4 环比加速、海外艺人（K-pop 顶级厂牌）演出落地、长青 IP 策略
  2. 喜马拉雅整合协同：付费用户留存、广告商业化率、激励广告点击率、组织架构调整
  3. 广告能否企稳（曝光量、入口率、eCPM + 宏观预算 + 流量竞争 + 创新广告形态）
  4. SVIP 付费用户/ARPPU/渗透率，票务、周边券捆绑、个性化装扮等 IP 权益的转化
  5. 微信视频号协同：视频号→QQ音乐/酷狗跳转、TME 作为视频号音乐内容主要运营方、音乐 VV 增长
  6. 10 亿美元票据发行后的资金用途与回购计划完成进度

Cussion Pang / 彭迦信（执行董事长）：开场与战略概览

谢谢 Millicent。大家好，感谢各位今天参加电话会议。

第三季度，我们持续巩固音乐与音频生态系统，展现了业务的韧性，以及随着音乐消费向流媒体之外拓展而把握机遇的能力。

与喜马拉雅的整合进展顺利。他们为我们更广阔的音频生态系统带来的机遇，以及未来的增长空间，令我们倍感振奋。

今天，我想分享我们对优质 IP 持久价值的看法、使 TME 脱颖而出的核心优势，以及我们如何依托这些优势把握未来的增长机遇。

首先，谈谈我们在内容消费领域观察到的一个重要趋势。

尽管技术进步使内容供给更加丰富，但用户对所消费的内容正变得更加挑剔。因此，AI 生成内容的播放量仍然微不足道，收听份额呈下降趋势，而高质量、差异化的内容持续获得青睐。

这一趋势进一步印证了我们的信念：能够建立情感连接并经得起时间考验的音乐具有真正的价值。当内容持续与用户产生共鸣，它便能成长为优质 IP，创造新的互动与消费机会。

事实上，我们已在业务中看到这一动态的体现。用户对我们泛 IP（pan-IP）体验的反响非常热烈，这一势头持续超出我们的预期。

这就引出了我们泛 IP 战略的第一大支柱：强化差异化的内容库。在这方面，我想深入探讨两个领域。

一、巩固我们的优质音乐与音频内容优势

本季度，我们继续开发自制内容，并在两个重点领域进一步丰富供给。

首先，我们扩充了 K-pop、华语流行（Mandopop）和影视原声带等高需求音乐曲库，深化与行业领军者的合作。

在 K-pop 领域，我们与 HYBE 续签了合作协议，获得了新曲 30 天的抢先发行窗口，其中包括 JISOO 的最新单曲。我们与 JISOO 的合作也为内容开发、联合推广和粉丝相关商业化创造了机会。

同样，在作为音乐消费核心驱动力的华语流行领域，我们与乐华娱乐集团（YH Entertainment Group）续签了合作协议，获得新歌首发权，并为未来的周边商品合作奠定了基础。

我们还丰富了影视原声带曲库，收录了热门剧集《兰香如故》（Against the Current）和《早春晴朗》（The Early Spring）的音乐，以及为腾讯视频剧集《百花杀》（Blossoms of Power）和《这一秒过火》（Overdo）制作的原创原声带。

其次，我们拓宽了音频内容供给，以满足更多兴趣和收听场景。

喜马拉雅凭借其庞大的文学、教育和娱乐音频库，以及不断扩充的自制内容组合，为我们的生态系统增添了显著的深度。他们与阅文集团、七猫和纵横文学等头部版权方的长期合作关系，为我们带来了丰富的文学 IP 资源。

官方逐字稿第2/9页

本季度，我们与多家工作室合作开发了多部《盗墓笔记》有声书改编作品，重新激发了用户对这一经典 IP 的兴趣，推动了播放量提升。

我们还在历史、儿童等热门品类扩展了原创节目，吸引多元受众并助力会员转化。

二、通过我们的综合能力延伸 IP 价值

我们的综合能力涵盖艺人培养、推广、现场娱乐演出制作和周边商品开发，并持续增强。通过打通这些环节，我们在艺人的整个职业生涯中为其赋能，并为粉丝创造更多与喜爱艺人互动的方式。

下面重点介绍三个方面的进展。

第一，我们帮助艺人在更大的舞台上获得更高曝光，组织有影响力的活动和行业颁奖礼，扩大音乐的传播力，释放音乐价值。

例如，我们将林俊杰（JJ Lin）、小鬼王琳凯（Lil Ghost）和袁娅维（TIA RAY）带到 F1 新加坡大奖赛这一全球文化盛事，提升了他们的国际知名度，并为粉丝带来难忘的现场体验。

针对 BIGBANG 成立 20 周年，我们将线上周年活动与在中国 19 个城市主要购物中心举办的周边主题展览相结合。这一联动活动引发了强烈的粉丝互动，提升了 BIGBANG 曲库在我们平台上的播放份额，并促进了会员增长和周边销售。

今年我们还扩大了第四届浪潮音乐大赏的规模。这一音乐盛典成功吸引了超过 80 位华语艺人和创作者参与，同时也欢迎粉丝到场。

第二，我们正通过现场娱乐和艺人周边扩大 IP 消费。

我们的演唱会业务持续保持势头。本季度，我们为说唱歌手 GAI（周延）举办了 4 场体育场级演唱会，吸引超过 12 万名观众。

我们还为潘玮柏（Will Pan）、单依纯（Shan Yichun）、张新成（Steven Zhang）和 TREASURE 等艺人成功举办了演出，推动现场演出业务稳健增长。

我们在助力华语艺人走向全球方面取得更多成功，支持了袁娅维横跨澳大利亚、加拿大、马来西亚和美国的首次世界巡演，以及她在格莱美博物馆的专场演出。

官方逐字稿第3/9页

我们与百事可乐合作举办其年度音乐节，由五月天阿信、王嘉尔和登陆少年组合（TOP）等知名艺人领衔，这也展示了我们通过音乐提升品牌影响力、实现广告收入多元化的能力。

除现场活动外，我们还开发了独具特色的周边商品，延伸演唱会体验并加强艺人与粉丝的连接。

针对易烊千玺（Jackson Yee）的 Que Xue 巡演，我们推出了纪念周边，庆祝巡演一周年。梓渝（Zi Yu）的首张个人同名实体专辑及配套收藏品也均由我们制作。这两款产品都受到粉丝热烈追捧，迅速登顶 2026 年畅销榜。

上述所有举措使我们的 IP 消费服务本季度再次实现强劲的同比和环比增长，并转化为市场份额的持续提升。随着我们在 IP 价值链上的布局不断深入，我们看到 IP 相关业务仍具备大规模持续增长的空间。

我们的信心源于我们的核心差异化优势——一体化飞轮。它将优质内容、充满活力的平台生态系统和端到端的 IP 能力融为一体。通过打通音乐流媒体、艺人推广、现场娱乐和周边商品，我们为粉丝创造更丰富的体验，同时开辟新的 IP 消费机会。反过来，这又吸引更多顶级 IP 入驻平台，形成良性循环。

最后，在结束发言并交给 Ross 之前，谈一下 ESG：随着我们扩大实体音乐和周边商品供给，我们始终致力于推行更可持续的生产实践。通过使用环保材料、节约资源的包装以及可回收再利用的生产材料，我们力求减少环境影响，同时继续为粉丝提供优质产品。

官方逐字稿第4/9页

Ross Liang / 梁柱（首席执行官）：谢谢 Cussion。大家好。

第三季度是喜马拉雅并入 TME 后的首个完整季度。过去六个月，我们专注于整合两个团队、理顺运营并发挥互补优势。我们在内容供给、会员和广告业务以及成本管理方面都看到令人鼓舞的进展。这些努力进一步巩固了我们作为一站式音乐与音频服务平台的地位。

在这一更广泛的生态系统中，尽管竞争压力持续存在，我们的音乐业务本季度仍取得稳步进展。多年来对优质内容和用户体验的投入，帮助我们建立了忠诚、高度活跃且付费意愿强的用户群。

我们的核心业务依然极具韧性。用户留存率和使用时长同比改善，而对更丰富 IP 体验的需求增长，推动了 SVIP 及其他付费层级的消费提升。这依然是我们业务的核心优势。

虽然部分举措需要时间才能充分释放财务潜力，但它们正在增强用户参与度、扩大商业化机会，并使我们得以逐步切入新的垂直行业。

我们的战略很清晰：通过针对不同受众定制的产品扩大覆盖面，强化核心用户体验，并将 IP 消费向流媒体之外多元化延伸。

先从产品升级谈起。

我们的重点是在改善核心用户体验的同时，通过差异化产品触达新受众。

一方面，我们持续优化 QQ 音乐和酷狗音乐，我们最活跃的用户在这些平台上积累了个人音乐收藏、歌单和收听习惯。这些宝贵资产随着时间推移不断增强用户忠诚度。

本季度，我们升级了个性化推荐和滑动发现功能，让用户更容易找到喜爱的音乐。我们看到人均听歌时长同比增长。

我们率先针对新款 iPhone Duo 优化了应用，现已获得苹果 App Store 推荐。我们还升级了鸿蒙系统（HarmonyOS）体验，改进了基于滑动的发现功能并推出可自定义应用主题；同时拓展至华为穿戴设备，推出跑步、睡眠和放松专属模式。所有这些都推动了用户采用和增长。

官方逐字稿第5/9页

另一方面，我们拓展了轻量级应用，以触达轻度听众和更广泛的人群。凭借更小的安装包、更简洁的界面和更个性化的推荐，这些产品为核心应用提供了易于上手的替代选择。这一互补的产品策略使我们能够满足不同用户需求，在更广阔的市场中竞争。

接下来，我将深入探讨会员增长以及我们如何持续保持 SVIP 增长。

对优质内容和丰富体验的需求依然强劲，支撑着各项付费业务持续增长。

SVIP 在付费用户数和 ARPPU（每付费用户平均收益）方面均实现了又一个季度的强劲增长，留存率也环比改善。更丰富的粉丝权益、臻品音质、不断扩充的长音频库以及 IP 相关实物特权，持续增强其吸引力并支撑会员收入增长。

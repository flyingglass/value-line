环节细化卡

① 设计/IP — 花钱买"内容"

机制：三种 IP 供给（签约分成 / 内部 PDC / 联名）。授权费按销量提成（费用化）；买断授权金资本化为无形资产再摊销；保底款形成应付授权费负债（98.5% 一年内到期）→ 几乎不签长期刚性保底，成本随销量浮动。

维度 2026H1 2025H1 说明
授权费（损益） 376,247 451,171 按销量提成；同比 -16.6%；占营收 2.19%（2025H1 3.25%）——LABUBU 热度回落、高费率授权 IP 占比下降
设计服务费（损益） 未单列 — 2025 年报拆分科目（86,446），2026H1 中报并入"其他"
雇员福利开支（损益） 1,405,025 992,685 含内部设计师薪酬（PDC），不走授权费（Note 4 全公司口径）
无形-授权IP（资产） ⊂ 236,368（无形总额） 208,665（2025年末） 中报未拆分授权IP；2025 年报口径授权IP 122,284
应付授权费（负债） 518,858 442,772（2025年末） 欠艺术家；即期 513,583 / 非即期 5,275；98.5% 一年内
购建无形资产（现金） 50,579 20,900 资本开支中无形资产部分（买断授权+软件）

口径注意：2020–2024 是合并科目"设计及授权费"，2025 拆分为"授权费 + 设计服务费"；2026H1 中报为简式报告，设计服务费未单列（并入"其他"345,273）。授权费是附注级科目，data/09992.db 无此拆分，只能从中报/年报附注提取（历史序列见 03-环节演变时序（2020-2026H1） §②）。

② OEM 制造 — 花钱买"货"

机制：全外包 + 模具所有权在公司。外包货款赊购（信用期即期至 180 天）→ 先进存货、卖出转成本；模具双轨制（>1 年资本化 / ≤1 年费用化）。

维度 2026H1 2025H1 说明
销售成本（损益） 5,207,181 4,115,212 制造环节总成本，同比 +26.5%
├ 计入销售成本的存货成本 4,303,215 3,272,871 外包货款→存货→成本（占销售成本 83%）
存货（资产） 6,101,530 5,472,839（2025年末） 周转 201 天（2025 全年 123 天）——海外前置备货 + 销售预测偏差
贸易应付款（负债） 905,150 1,858,216（2025年末） 欠代工厂；周转 48 天；30 天内账龄 86%
存货（环比增加） +628,691 — 6,101,530 − 5,472,839；中报无营运资本变动附表，以环比代替

口径注意：2026H1 中报为简式报告，无现金流量表营运资本变动附注，存货/应收/应付现金流以资产负债表环比增量代替。贸易应付款 905,150 与 AKShare"应付账款"口径已核对一致（中报 Note 16 商品应付款项）。

③ 质控 — 省钱(0.37%)

机制：横贯制造全程的三层体系（工厂内控 → 公司介入：飞行检查/KPI/罚单 → 第三方检测），无独立科目。

维度 2026H1 2025H1 说明
存货减值（损益） 22,806 4,302 计入销售成本；减值率 0.37%（对存货 6,101,530）；期末减值拨备 75,509
质控团队薪酬 ⊂雇员福利开支 — 无独立科目
2 年以上库龄 2026H1 起上升 — 见 存货跟踪

④ 仓储物流 — 花钱运"货"

机制：三类钱、三条入表路径——运费/海外仓操作费直接费用化；自营仓租金资本化（使用权资产）；存货=营运资金。47,000㎡ 海外仓是第三方资产，不入表。

维度 2026H1 2025H1 说明
运输及物流开支（损益） 754,346 784,667 同比 -3.9%；占营收 4.4%（2025H1 5.7%）——海外收入下降、国际物流费减少
使用权折旧-办公室及仓库 69,344 26,831 自营仓租金摊销
短期租赁开支 673,120 513,331 门店+仓库短期/可变租约（与渠道合并，不拆分）
使用权资产-办公室及仓库（资产） 224,464 237,223（2025年末） 自营仓/办公室资本化租金
租赁负债 3,727,572 2,861,575（2025年末） 仓库+门店合并（流动 665,736 / 非流动 3,061,836）

MDA 口径差异：管理层讨论称运输及物流开支 644.7 百万（同比 -4.8%），为经销及销售开支内的口径；Note 4 附注口径 754,346 为全部费用化运输物流（含计入销售成本部分）。以 Note 4 附注数为准。 理解要点："看起来轻、实际重"——轻在资产端（无大型自有仓网），重在运营性现金流出（运费直接吃毛利 + 存货吃现金）。

⑤ 渠道销售 — 赚钱＋收钱

机制：按收钱时点分三类——零售店/机器人即时收款（无应收）；线上预收（合约负债，免息资金）；批发赊销（贸易应收）。DTC 占 94.8%（零售+线上+机器人 16,275/17,173），唯一资金占用来自批发赊销。

维度 2026H1 2025H1 说明
收益（损益） 17,172,921 13,876,276 全集团渠道：零售店 53.1%（9,112） / 线上 36.2%（6,212） / 机器人商店 5.5%（951） / 批发及其他 5.2%（898）（中报 Note 5：中国 122.01 + 海外 49.72）
经销及销售开支（损益） 3,931,123 3,192,590 占营收 22.9%；佣金 561,961 + 广告 444,073 + 短期/可变租赁 673,120（Note 4）
使用权折旧-零售店 377,819 222,582 门店租金摊销
贸易应收（资产） 627,306 921,240（2025年末） 批发赊销；3–6 月账龄 72,394（从 206,148 大幅回落）；周转 8 天
合约负债（负债） 513,419 393,119（2025年末） 线上预收 + 积分；环比 +120,300
使用权资产-零售店（资产） 3,312,197 2,483,182（2025年末） 全链条最大资产（门店租金资本化）；2026H1 添置使用权资产 1,373,884
经营现金流净额 3,637,300 5,977,473 同比 -39.1%；2025H1 高基数（爆款预收）+ 2026 存货备货

横切：这条链在报表上的三条主线

  1. 费用化主线（授权费 3.76 亿 / 运费 7.54 亿 / 渠道费 39.31 亿）→ 直接吃毛利、净利——链条上"看不见资产"的部分；授权费同比 -16.6%（IP 结构变化）、运费同比 -3.9%（海外收入下降）
  2. 资本化主线（模具 / 使用权资产 / 买断 IP）→ 形成资产 + 逐期折旧摊销——2026H1 使用权资产净添置 13.74 亿（门店扩张），零售店 33.12 亿 > 仓库 2.24 亿
  3. 营运资金主线（存货 61.02 亿 / 应收 6.27 亿 / 应付 9.05 亿 / 合约负债 5.13 亿）→ 吃现金 or 给资金——上游账期 > 下游账期，唯一大额占用是存货（周转 201 天，2025 全年仅 123 天）

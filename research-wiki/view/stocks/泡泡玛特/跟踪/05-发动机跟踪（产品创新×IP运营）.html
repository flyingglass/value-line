泡泡玛特 (09992) — 发动机跟踪：产品创新 × IP 运营

定位：把「产品创意设计 + IP 运营」这个发动机，转成可跟踪、可判真伪、可定介入时点的操作体系。 方法：以招股书（唯一系统披露单位经济体效率的文件）+ 2020–2026 全序列业绩会/财报为一手证据；每一个论断标注出处，凡推论逐条标注。 关联：六变量（库存/杠杆/人/租金/物流/营运资本）见 横切变量跟踪；单位产出序列见 ../渠道单店产出时间线；业绩会全序列见 ../业绩/业绩会纪要索引（2020-2026）。

速读摘要

一句话结论：发动机本身无法从财报跟踪（上市后即停披单位经济体指标、年报正文只在首发期写新品），只能从**「业绩会问答 + 财报首次披露 + 投入端附注」三级梯度间接跟踪；三级梯度的时间差约 2–3 年 / 1.5 年 / 同步，而可辨识性最早在 2024-03-20（23A）出现**。

四条硬事实

  1. 招股书是唯一的「经营温度计」：单店年化收益（2017 421 万 → 2019 841 万 → 2020H1 501 万）、同店销售增长（2018 +59.6% / 2019 +63.1% / 2020H1 -23.1%）、亏损店占比（2019 2.3% → 2020H1 11.2%）——上市后 20年报/21中报/21年报/22中报 全部零命中（本次程序化核查）。
  2. 单店模型极轻：每间新零售店平均初始投资约 230 万港元，开业后 1–2 个月收支平衡，现金回收期 3–6 个月（招股书「未來計劃」）→ 这门生意可以「用开店试错」；反过来说，单店产出跌破盈亏线就是扩张的自动刹车。
  3. 财报正文只在「首次发布」写新品：22 年报（2023-03）LABUBU 出现 13 次（首次书面披露搪胶毛绒）；而 23 中报 0 次、23 年报 LABUBU 0 次 / 毛绒 1 次——同一时间点的业绩会却在讲"LABUBU +40% 验证毛绒"。
  4. 23A（2024-03-20）是四判据第一次同时齐备：早于 Lisa 引爆（2024-04-16，据公开报道）约 4 周、早于财报确认（24H1）5 个月、早于峰值（2025-08-26）17 个月。

三条跟踪判据（本页产出）：① 四判据齐备度（数据/品类匹配/市场验证/供应链跟进，缺一不算）；② 业绩会主动表述 > 财报正文（正文滞后一个周期）；③ 终端"断货 + 产能扩张"双向确认（比收入早）。

一条最需要警惕的边界：23A 的兑现依赖外生流量事件（Lisa），公司可控的只有"泰国样本已自验"——能预判"公司在押什么"，预判不了"会不会有人替它引爆"。

一、发动机的解构：为什么「产品创新 × IP 运营」是核心

招股书开篇即定性："IP 是我們業務的核心"，且以「覆蓋潮流玩具全產業鏈的一體化平台」定义自身（藝術家發掘 → IP 運營 → 消費者觸達 → 潮流玩具文化推廣）。

但把发动机拆开后，两半的可预测性完全不同：

半台发动机 本质 可预测性 证据
IP 运营 把已有 IP 商业化（系列节奏、品类匹配、区域落地） ⚠️ 部分可辨（方法论可复制） 王宁 24-03："找到了不同 IP 擅长的点……有效地避免了 IP 之间的竞争"
产品创意设计 找出下一个能爆的 IP ❌ 不可预测（管理层自认） Pucky：20A 业绩会预期"小幅增长"，实际 2021 -39.3%；LABUBU 是"意外"而非规划产物

关键推论：可跟踪的是**「IP 运营」这一半**（因为它有方法论、有可验证的输出），而「创造爆款」这一半只能事后确认。因此跟踪体系的设计目标不是"预测下一个 LABUBU"，而是"尽早识别公司在下注什么，并跟踪这个下注的验证进度"。

二、渠道的双重身份：放大器 + 测试仪

招股书/业绩会里，四条渠道的定位是明写的分工（20A 业绩会司德原话）：

渠道 定位（原话）
线下门店 销售 + 品牌宣传 + 会员拉新
机器人商店 便利购买 + 拉新 + "雷达作用，根据销售表现考虑是否新增门店"
天猫/电商 以拉新为核心目标（团队 KPI 含"新会员销售业务占比"）
微信抽盒机 核心用户聚集，玩法驱动

"机器人商店＝雷达"是渠道即测试仪的书面证据。

2.1 渠道数据的正确用法：预判、确认、证伪三分

用途 看什么 时点
预判 渠道的新形态试点决策（快闪转正、主题店、雷达点位升格） 最早
确认 渠道的单店/单台产出倍数异常（不是总量） 中
证伪 单店产出/同店转负 最灵敏，但最易被开店摊薄污染

2.2 两个必须区分的方向（逻辑不对称）

"真有好产品 → 会在渠道显现"基本成立（必要性）。 "渠道数据好 → 说明产品好"不成立（充分性）。

渠道数据是复合信号，至少混四种成分：真产品力 / 渠道扩张摊薄 / 运营改善 / 投机需求。

  • 招股书自证摊薄：门店 114 → 187 家时，零售店单店年化从 841 万掉到 501 万
  • 运营改善 ≠ 产品力：24A 门店同店 +28%，归因是"提升陈列、精细化运营、奖励机制"
  • 投机需求：25A 管理层自陈"做好产品，不做理财产品"；26H1 海外线上随即 -39.8% / -45.6%

→ 渠道更适合当"证伪工具"，不适合当"证实工具"。

三、信号的三级梯度（本页核心方法）

引擎的声音有明确的传导顺序，且每一级的时间差可以量化。

以「毛绒」这条线完整复盘（含精确到日的时点）：

级 载体 信号原文 距放量
一级：业绩会口头方向 21H1 业绩会（2021-08） 司德：衍生品三方向，"会推出一些可能从毛绒到徽章，再到数码周边相关的产品"，"今年下半年衍生品重点" 3 年
二级：财报首披 22 年报（2023-03） 首次书面："LABUBU 搪膠毛絨公仔……突破傳統品類的定義與設計模式，未來該產品線將進行長線開發" 1.5 年
— 23 中报 / 23 年报 几乎消失（LABUBU 0 次、毛绒 1 次）——正文只在首发期写新品 —
三级：业绩会量化确认 23A 业绩会（2024-03-20） LABUBU "+40%，头部最快"、"成功验证毛绒品类"、"重点投入毛绒"、"断货" 5 个月
收入可量化 24H1 财报（2024-08） 毛绒 4.5 亿（+993%）、The Monsters 6.27 亿（+292.2%） 放量起点
登顶 25A 财报（2026-03） 毛绒 187 亿、占营收 50.4% —

三条操作含义：

  1. 业绩会问答的权重必须高于财报正文（正文滞后一个报告期，且首发期后即沉默）。
  2. "品类收入未单列"≠"看不见"——22 年报的定性好评就是先行读数；等收入单列（24H1）时价格已 +89%。
  3. ⚠️ 一级信号不等于可信：21H1 的"毛绒"当时是衍生品三方向之一（且招股书里第三方产品早已含毛绒玩具）。真正的新东西是 "自有 IP × 毛绒"这个组合——方向对了，形态不同。引用一级信号时必须区分"方向"与"具体形态"。

3.1 同一逻辑线的另一条（海外 DTC）

级 载体 原文 距放量
一级 21A 业绩会（2022-03） 文德一："今年的主要发展方向是 DTC（直接面向消费者）和本土化零售为重点" —
二级 22 中报（2022-08） 首次书面："港澳台地區及海外業務從以 To B 為主轉型為以 DTC 為主導的模式" —
三级 24A（2025-03） 海外 50.7 亿（+375.2%），单店店效 +160% —

业绩会同样早于财报正文一个报告期——这是重复出现的模式，不是孤立现象。

四、四判据：如何区分"真信号"与"管理层主推"

⚠️ 这是本页最重要的一节。 因为管理层每年都会点名新方向，多数无声消失。

4.1 反例：KUBO（23H1，2023-08）

管理层"新 IP KUBO 主推" → 未兑现（2024–2025 未进头部，此后星星人反而跑出）。

4.2 正例：LABUBU × 毛绒（23A，2024-03-20）

判据 KUBO（2023-08） LABUBU × 毛绒（2024-03）
① 是否已有实际增长数据 新 IP，无 +40%，10 个破亿 IP 中增速最快
② 是否找到专属品类 未提 "发现更适合做毛绒玩具"
③ 是否已有市场验证 未提 "成功验证毛绒品类" + 泰国 6 家店（首店首日 500 万）
④ 是否有供应链跟进动作 未提 "成立专门的团队"，解决断货

判据：四者同时出现才算信号；只有"管理层主推"这一条，零预测力。

4.3 与六变量体系的关系

四判据是发动机层的判读；横切变量跟踪 的六变量是财务层的落点。两者的接口是：

发动机点火（四判据齐备）→ 财务上是"断货 + 产能追赶 + 品类收入爬坡"三件套同步出现。

24H1 即标准样本：毛绒 +993% / 产能 2 月 40 万只 → 7 月 300 万只/月 / 返修率 2% → 0.005%。

5.1 那天同场出现的五条信号

"从前一个时点是空的、到后一个时点已经太贵"——这就是"唯一可辨识窗口"的含义。

六、为什么"证据最薄的下注点"是特征而非缺陷

方法论来源：../../疯狂的里海/案例/里海案例-涪陵榨菜-提价发现与跟踪决策时间线——该页的加粗判语是："证据最薄的时点＝下注的时点，证据最硬的时点＝已经不需要它了。"

6.1 三个可分离的命题

命题 说的是什么 23A 那天的所指
证据最薄 每条证据的强度（数字大小、硬度） LABUBU 仅 +40%、约 3 亿体量；毛绒收入未单列；产能无数字；泰国是单点
判据齐备 证据的来源是否独立、方向是否一致 四条独立来源（IP 增速 / IP×品类方法论 / 终端断货 / 供应链动作）同向
必须下注 决策依据不在证据，在位置 离年内低点仅 +46%、约 27 倍 PE、派息率 35%、累计回购 11.9 亿（占总股本 4.21%）

6.2 为什么"每条都弱"是内生的

如果每条证据都强，价格就不会是 24 港元。

证据强度 时点 股价
毛绒收入单列 +993% 2024-08 45.3
产能数字（40 万 → 300 万只/月） 2024-08 45.3
LABUBU 收入 141 亿 2026-03 137.7

证据强度与市场定价是同一枚硬币的两面——强证据出现的时点，就是市场也看得见的时点。所以"薄"不是选择，是只剩。榨菜完全对称：严格量价拆分（2018-03-23）晚建仓 14 个月，而 2017 全年股价已 +85.81%。

6.3 为什么"齐备"能部分弥补"弱"

一条强证据可能是偶然；四条来源独立、方向一致的弱证据，同时错的可能性低一个量级。其中价值最高的是第 2 条——它不是"LABUBU 好"，而是"我们学会了给 IP 找它擅长的品类"。这是能力，不是状态。

6.4 "必须下注"的依据不在证据里

不是"证据够所以必须下注"，而是"位置提供了容错，所以敢于在证据不足时下注"。

榨菜 2017.1 的实际驱动（该页 §五 原文）："业绩预告大幅增长 + 市值 70 亿 / 业绩 2.5 亿 / PE<30 + 提价已知"。泡泡玛特 2024-03-20 的结构相同：低估值 + 底部 + 变化，三者齐备。

6.5 收口

证据薄（必然）＋ 多源同向（可辨识）＋ 价格低（有容错）＝ 超额收益的唯一入口。 卖出的对称结构同样成立：榨菜 2019-03-22 年报披露销量增速从 +17.26% 掉到 +10.65%——证据变强、方向变差，那才是该走的时候。

七、边界与待验证

  1. 🔴 这套结构提高的是赔率，不是胜率。 里海对榨菜四年的自评是"运气多"（2023-06-20 复盘）。四判据齐备而每条弱，同样可能什么都没发生——弱者体系的承诺只是"看错了亏不了多少"。
  2. 🔴 23A 的兑现依赖外生变量。 LABUBU 全球引爆踩在 Lisa 2024-04-16 的 Instagram 上（二手报道：搜狐、泰国头条新闻；日期未获一手确认）。管理层在泰国已自我验证（首日 500 万），但泰国能否扩散成全球，公司不可控。
  3. 🔴 "读法 B"未排除：LABUBU 的全球爆红含较大社交货币/投机成分（管理层自陈"不做理财产品"）。在中国/亚洲这种收藏文化成熟市场，新 IP 可靠收藏需求接棒；西方市场缺那波社交流量则可能接不上。 26H1 海外线上 -39.8%～-59.0% 已在显示该风险；26H1 星星人虽成"现象级"，但司德自陈"目前在西方热度跟亚洲地区有差距"。
  4. ⚠️ "断货"证据链在 2023 年不完整：本次检索未找到 2023 年下半年 LABUBU 毛绒断货的可靠当时报道（命中的多为 2025 年 LABUBU 3.0 爆红期）。23A 的"断货"是公司单方面口径，未获第三方印证。
  5. ⚠️ PE 27 倍为粗算（EPS 0.80 元来自 23A 业绩会原文；港元/人民币折算未精确核实）。
  6. ⚠️ 模具成本口径需区分：年报为"使用年限为一年内的模具成本"（4,565 / 7,460 / 17,155 / 18,135 / 26,138 千元，2019–2023），中报用另一个科目（"模具成本"，21 中报 10,881），不可混用。

泡泡玛特如何抵御IP与品类的周期性——代际转化的本质

追问：IP有生命周期，品类有潮起潮落。泡泡玛特用什么对抗？还是说本质不是周期，是代际？

一、两个需要区分的"周期"

泡泡玛特面临两种完全不同性质的"周期性"，许多人混为一谈：

IP周期 品类周期
驱动机制 单个IP的流行→过气 "潮玩"这个品类整体是否过时
时间尺度 2-10年 10-50年
类比 一首歌会过气 "音乐"这个品类不会消失
防御手段 IP矩阵（多IP轮换） 形态转换（满足同一需求的载体变了）

关键区分：IP周期是企业可以管理的（多IP储备、推新节奏），品类周期是宏观的、几乎不可逆的。

二、抵御IP周期：泡泡玛特的多IP工厂模型

2.1 模型类比：唱片公司，不是乐队

单一IP依赖（高风险）：     多IP矩阵（低风险）：
   Molly → 收入100%        Molly 25% + Dimoo 18% + Skullpanda 15%
      |                         + CRYBABY 12% + 小野 10% + ...
   Molly过气 → 收入归零        任一IP过气 → 收入-15%，下一个IP顶上

泡泡玛特的核心能力不是"创造一个超级IP"（那是迪士尼的模型），而是批量制造中等IP——像唱片公司签约歌手，不是赌一个超级明星。

2.2 为什么"批量制造IP"是可行的？

泡泡玛特的IP孵化有三条逻辑支撑：

  1. 设计师签约 → 内部孵化：不依赖外部IP授权（减少了版权方拿走利润的问题），自建设计师生态
  2. 产品化能力：设计师画图 ≠ 造出受欢迎的盲盒。泡泡玛特的核心壁垒在"把2D设计变成3D潮玩"的工业能力（建模、开模、涂装、量产）
  3. 渠道触达：抽盒机 + 门店 + 抖音 = 新品触达用户的效率，决定了新IP的"冷启动"速度

类比：Netflix 不赌一部剧爆火，而是批量制作中等质量的内容，靠算法推荐精准分发。泡泡玛特的"设计师签约+3D工业+渠道分发"就是潮玩界的 Netflix 模型。

2.3 芒格检查：这个模型能否持续？

反过来想：什么情况下"多IP工厂"模型会失效？

  1. 签约的设计师越来越差——但这不符合"回归均值"，因为泡泡玛特的渠道优势会吸引更多设计师
  2. 消费者不再接受新IP——但这不符合Z世代的消费特征（他们恰恰是最愿意尝试新品牌、新IP的一代）
  3. 工业化产能被复制——生产盲盒的技术壁垒不高，但"签约-孵化-渠道-数据反馈"的闭环需要多年构建

结论：IP周期是泡泡玛特可以管理的风险。不是消除周期，而是在单个IP的周期中，把整体增长曲线熨平。

三、品类周期是否致命？——代际转化的视角

3.1 "潮玩会不会过时"的错位类比

常见的担忧：呼啦圈、宠物石、电子鸡……都是红极一时然后消失。

但这些类比犯了一个错误：混淆了具体的产品形态（呼啦圈）和满足的需求（运动/娱乐/社交）。

泡泡玛特满足的需求是什么？

需求 上一代满足方式 Z世代满足方式
身份表达 穿什么品牌的衣服 桌上摆什么潮玩
社交货币 聊昨晚的电视剧 小红书晒拆盒
小确幸/自我奖励 买杯奶茶、买本杂志 买一个盲盒（59-79元）
收藏满足 集邮、集球星卡 集全套盲盒
情感陪伴 养宠物 拥有毛绒版 Molly

3.2 代际转化的本质

泡泡玛特不是创造了一个新需求，而是用一个新形态满足了代际更替后的旧需求。

身份表达的需求一直存在：
  1970s: 集邮
  1980s: 收集磁带/CD
  1990s: 买球鞋
  2000s: 买手办/动漫周边
  2010s: 社交网络上的头像/签名
  2020s: 泡泡玛特盲盒 + 小红书晒盒

每一代人都会有"花小钱表达我是谁"的需求。泡泡玛特刚好占据了Z世代这个需求载体的中心位置。

3.3 芒格"反过来想"：什么会让这个代际逻辑失效？

泡泡玛特的品类风险不是"盲盒过时了"，而是下一代人找到了表达身份的新方式，而泡泡玛特没有抓住。

当前：Z世代 → 泡泡玛特 = 身份表达
风险：α世代 → 某新品类 = 身份表达（泡泡玛特不在其中）

如果10年后14-20岁的年轻人觉得"泡泡玛特是我妈/我姐玩的"，那才是真正的品类危机。这就像 Facebook 在青少年中变成了"爸妈的社交网络"。

但泡泡玛特有一个对冲机制：它的IP迭代速度。每一代新IP都可以重新定义目标人群——Molly 的第一批粉丝是90后，Skullpanda 吸引了00后，下一个IP可以瞄准α世代。

四、与茅台的代际对比

茅台 泡泡玛特
需求本质 社交润滑剂（宴请/送礼） 身份表达（我是谁）
载体是否可变 不可变——白酒就是白酒 可变——IP可以换，形态可以换
代际传承压力 年轻人不喝白酒了？ 下一代不玩"这个"了？
应对代际风险的能力 低——产品形态固定 中—高——IP可迭代、品类可拓展
最坏情况 白酒消费萎缩，茅台不是例外 盲盒过气，但"年轻人收集小东西"不会消失

核心差异：茅台的产品是固定的（茅台酒），泡泡玛特的产品是可变的（IP内容）。茅台面对代际变迁几乎没有调整空间；泡泡玛特可以自我迭代。

五、框架总结：三种风险的层次

第一层：IP周期（单个IP过气）
  风险：可管理
  工具：多IP矩阵 + 签约-孵化-分发闭环
  类比：唱片公司

第二层：品类周期（"盲盒"形态过时）
  风险：中等，但可以转换
  工具：从盲盒 → 毛绒 → MEGA → 下一个形态
  本质：形态可变，需求不变（身份表达）

第三层：代际转化失败（下一代不认泡泡玛特）
  风险：真实但远期的威胁
  对冲：IP迭代自然覆盖代际更替
  威胁来源：不是盲盒过时，是出现了完全不同的身份表达载体

芒格的结论框架：

"优秀的公司拥有很深的护城河，这些护城河不断加宽。"

泡泡玛特的护城河不是单个IP（那会在周期中消退），而是**"批量孵化IP + 将IP产品化 + 精准分发到Z世代手中"的工业能力**。

这个能力是否能"不断加宽"？取决于两个变量：

  1. Z世代是否有下一代更愿意花钱的人（长期看是肯定的——人的可支配收入随年龄增长）
  2. 泡泡玛特是否能在下一代人成年时，准备好属于他们的IP（需要在IP储备上持续投入）

茅台的困境是"产品不变，用户变了"；泡泡玛特的优势是"用户可以变，产品也可以跟着变"。

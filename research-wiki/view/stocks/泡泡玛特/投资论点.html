泡泡玛特 (09992) — 投资论点

一句话总结

泡泡玛特是全球最大的潮流玩具 IP 运营平台，核心赚钱模式是签约/孵化艺术家 IP → 产品化（盲盒/毛绒/MEGA/衍生品）→ 全球多渠道分发。2025 年营收 371 亿（+185%），海外占比 43.8%，毛利率 72%。核心超额收益（alpha）在于 IP 矩阵成功熨平个体 IP 周期 + 品类形态转换（盲盒→毛绒→MEGA）持续打开新需求。当前市盈率约 25 倍（2026 年预测），处于消费成长股合理区间。

（来源：data/09992.db、Chason《泡泡的过去现在未来》、wiki synthesis 系列分析）

一、怎么赚钱：四维收入模型（FY2025）

维度 结构 驱动因素
IP 矩阵 Labubu(150亿+)、SKULLPANDA(60亿)、Crybaby(50亿)、Molly(40亿)、Dimoo(40亿) 签约/孵化效率，IP 生命周期管理
品类形态 毛绒(核心)、手办(基础)、MEGA(高端)、衍生品(长尾) 品类创新 → 打开新用户群和场景
渠道 零售店 + 线上(抽盒机/抖音/天猫) + 机器人商店 抽盒机微信小程序是核心壁垒（2025 年 34.2 亿）
地理 中国 56.2% / 海外 43.8%（亚太/美洲/欧洲） 全球扩张是未来 3-5 年最大增长引擎

抽盒机占线上 40.2%，是"过程消费"（拆盒体验）的原生载体，竞争对手难以复制。

二、护城河：四条防线

1. IP 矩阵 → 熨平个体 IP 周期

Molly 占比从 2019 年的 40%+ 降至 2025 年的约 10%，SKULLPANDA + Labubu + Crybaby 矩阵承接。单个 IP 有生命周期，但 IP 矩阵整体可持续。

2. 品类形态转换 → IP 不变，载体变

盲盒→毛绒(2023)→MEGA→衍生品的形态创新，本质是：同一个 IP 以不同载体卖给不同场景的用户。这是 Hello Kitty 52 年不衰的核心逻辑。

3. 平台化引擎 → 签约-孵化-分发

连接全球艺术家 → 商品化 → 多渠道分发。签约效率（每年新增 N 个 IP）和孵化成功率是关键。Chason 称之为"创意发现效率 + 商品化效率 + 市场验证效率"。

4. 全球地理对冲 → 周期空间分散

2025 年海外收入从几乎为零到占比 43.8%，不同市场处于不同的成长阶段，互相缓冲。

三、风险：三个慢变量

风险 概率 影响 缓解
断代风险 中 高 三丽鸥 51 年/迪士尼 100 年证明：IP 公司跨越代际的核心是"IP 先行、品类跟随"。泡泡玛特需证明能带动 2030 年 20 岁的年轻人
Labubu 集中度 中 高 Labubu 已突破 150 亿，需要更多 IP 分担。The Monster 化（电影/游戏/乐园）是实验性路径
毛绒退烧 低-中 中 品类会转换（盲盒已不是主力），关键是下一个形态能否及时补上

（详细分析见 ../articles/synthesis/generational-risk-sanrio-disney-popmart）

四、催化剂

  1. 海外持续超预期：2025 海外 +185% 证明产品市场契合（Product-Market Fit），亚太/美洲深耕 + 欧洲新开
  2. Labubu 内容化破圈：若电影/游戏/乐园成功，打开千亿级 IP 天花板
  3. 新 IP 爆发：每年签约 5-10 个新艺术家，出现下一个 Labubu 级别 IP 的概率
  4. 抽盒机壁垒：微信小程序 34.2 亿成交额（GMV），私域+过程消费的独特生态

五、核心命题

泡泡玛特不是卖玩具的公司，是管理"IP 生命周期 × 品类形态 × 地理区域"三维矩阵的平台。

验证信号：

  • 海外单市场能否复现中国的爆发曲线（东南亚已验证，看欧洲/北美）
  • Labubu 之后，下一个 100 亿+ IP 何时出现
  • 毛绒之后，下一个品类形态是什么

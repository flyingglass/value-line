《泡泡玛特2021年中期业绩发布会纪要》— 艾德勒四级阅读法摘要

摘要

核心话题：IPO 首份半年报 · MEGA 大娃 · 唱片公司定级 · 京东分流天猫 · 存货 74 天 · 经营质量顶部

一句话核心：IPO 后首份答卷——收入 17.73 亿元（+116.8%）、经调整净利润 4.35 亿元（+144.1%），MEGA 1000% 大娃（100 万人次抽签）让王宁重申 "不是盲盒公司，是 IP 公司" 并推出 IP 流动性定级（S/A/B/C）；但这是经营质量的顶部：存货周转 74 天为全序列最优、毛利率却首降（65.2% → 63.0%），半年后库存周期掉头。

关键数据（2021H1）：

  • 收入 17.73 亿元（+116.8%）；毛利率 63.0%（65.2% → 63.0%）；经营利润 4.87 亿元（+133.6%）
  • 经调整净利润 4.35 亿元（+144.1%，24.6%）
  • IP：6 个破亿；Molly 2.04 亿（+81.9%）、Dimoo 2.05 亿（+74.5%）、Skullpanda 1.83 亿（半年即近 2020 全年 3.9 亿的一半）、The Monsters 1.4 亿（翻倍）、Pucky 1.07 亿（下滑）
  • 渠道：门店 215 家（+79）、机器人 1,477 台；线上 6.78 亿（+102.9%），京东 +480%
  • 会员 1,100 万、贡献 91.8%、复购率 49%；存货周转 74 天（从 78 天下降，全序列最优）

核心矛盾：

  1. "IP 公司"叙事 vs 盲盒仍是绝对主力 —— MEGA 被用来证明 IP 价值，但 MEGA 收入体量尚小，盲盒占比仍超 8 成
  2. 高增长 vs 毛利率首降 —— 归因工艺复杂化+原材料上涨，市场当时解读为"品牌升级代价"，实为成本周期起点
  3. "唱片公司"定级 vs Pucky 连续走弱 —— S/A/B/C 流动性管理看似科学，但未阻止独家 IP 收入放缓
  4. 线下高增 vs 疫情反复 —— 半年后（22H1）线下与库存同时恶化

管理层应对：供应链"产能、质量、速度、成本、工艺"五关键词+优质产能整合；海外放缓开店、基建先行（ERP/海外仓）、欧美快闪轻资产试水；下半年试水抖音/得物/小红书；门店标准店 100 → 150-200 平、一楼占比超 80%。

跟踪要点：

  1. MEGA 明年毛利率能否"明显增长"（后验证：2022 年 MEGA 4.67 亿，但毛利率整体破位）
  2. Skullpanda 全年头部化（兑现：2021 全年 5.95 亿，+1423.8%）
  3. 存货周期能否维持 74 天（证伪：半年后 160 天）
  4. 海外"放缓开店"的执行（2022 年实际 43 家门店，DTC 转向）

王宁原话：泡泡玛特的成功也不是盲盒的成功，是 IP 的成功，是潮玩的成功。……我们更像是一个唱片公司。

第一级 · 检视阅读

  • 文件性质：业绩发布会要点纪要（公众号「永恒的价值」，问答含原话），非官方逐字稿
  • 发言人：王宁、司德（COO）、杨镜冰（CFO）、文德一（海外总裁）
  • 一句话定位：战略升级场——"从卖盲盒到做 IP"的官方定性 + IP 定级体系首次公开
  • 是否值得精读：是。经营质量顶部与战略叙事高点同时出现，是理解"顶部管理层在说什么"的样本

第二级 · 通读全书

结构骨架：王宁开场（人才/健康/MEGA）→ 杨镜冰财务（核心数据/IP/渠道/费用）→ 司德业务（IP/MEGA/渠道/海外/文化推广）→ 5 组问答（季节性与毛利率/渠道与人才/海外与 IP 定级/衍生品与门店/大娃与稳态毛利率）

主线（一句话因果链）： IPO 热度+低基数 → 收入翻倍、MEGA 爆发 → 管理层用"唱片公司/定级/大娃"强化 IP 叙事 → 但毛利率、人力、原材料同步上行 → 供应链五关键词埋下"大扩张"伏笔 → 存货 74 天的顶点无人警报

第三级 · 分析阅读

核心论点（管理层立场）：

  1. 泡泡玛特不是盲盒公司，MEGA 证明 IP 价值
  2. IP 定级 S/A/B/C 流动性配置资源
  3. 毛利率下滑是工艺+原材料，属"品牌升级代价"
  4. 头部 IP 每年 3-4 系列、销售周期 12-18 个月
  5. 海外放缓开店、基建先行；京东分流天猫是主动为之（1+1>2）
  6. 供应链五关键词，优质产能整合

逐条检验：

  1. "毛利率下滑是升级代价"——部分成立但掩盖了成本周期：2022 年毛利率再降至 57.5%（含促销），"升级代价"叙事下原材料+15%、人工+10% 的量级（22A 会才披露）当时未量化，属于信息不完整
  2. "京东 1+1>2"——数据支持（京东带来新客），但天猫增速从 100%+ 掉到 49% 的结构性放缓被轻描淡写，22H1 天猫仅 +11.8% 证实放缓是真趋势
  3. "海外放缓开店"——执行到位（2021 年底 7 家），且 2022-2023 年确实基建先行（ERP、区域总部），此承诺可信
  4. "IP 定级流动性"——机制存在，但 Pucky（独家 IP）收入 1.07 亿且系列减少，定级体系未能阻止独家 IP 掉队；-39.3% 发生在定级体系运转之下
  5. "下半年销售约等于上半年两倍"（王宁）——2021 全年 44.9 亿 ≈ 17.73×2.53，当时准确；该季节性规律在 2022 年失效（下半年受疫情冲击）

坦承无法回答的问题：未给全年指引；未披露原材料/人工涨幅量化；Pucky 下滑仅归因"系列数量减少"，未讨论 IP 生命周期。

第四级 · 比较阅读

  • 与 20A 对照：会员 740 万→1,100 万、复购 46%→49%，"拉新+质量并重"承诺开始兑现；但毛利率 63.4%→63.0% 的下滑斜率与 20A 会"提升产品质量"的说法形成张力——质量投入与毛利率的负相关被确认
  • 与 22H1 对照：本场"供应链五关键词""优质产能整合"在半年后变成"库存 9.57 亿/160 天"——产能整合完成后需求端断崖，是典型的"扩产撞上衰退"剧本
  • 与投资论点对照：IP 定级+唱片公司类比支持"平台化"论点；但存货 74 天的顶点说明运营效率护城河当时最强也最脆弱
  • 被忽略的信号：司德披露"上半年涨价的系列只有 11 款"——提价周期刚开始（69/79 元价格带），是 2022 年毛利率结构变化的先导；王宁"1000% 产品出现在客厅"的表述预示品类扩张，但本场品类收入结构未单列

四个基本问题的回答

问题 回答
整体讲了什么 IPO 首份答卷翻倍增长，MEGA+IP 定级完成战略叙事升级；但毛利率首降、存货 74 天是全序列经营质量顶点
细部是怎样的 财务（翻倍+毛利率首降）→ IP 六强+定级 → 渠道（京东+480%）→ 海外基建先行 → 5 组问答（季节性/人才/供应链五关键词/门店升级/大娃）
有道理吗 IP 叙事与海外基建承诺基本兑现；但"毛利率=升级代价"掩盖成本周期，IP 定级未能阻止 Pucky 掉队，季节性规律随后失效
读它干什么 样本价值：顶部场次的管理层叙事结构（新概念+定级体系+长期承诺）；校准"74 天"为运营效率的天花板基准

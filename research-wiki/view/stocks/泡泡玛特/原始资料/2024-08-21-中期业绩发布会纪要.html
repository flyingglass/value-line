摘要

核心话题：业绩爆发 · 毛绒+993% · 海外+259.6%占比近30% · 指引上调至+60%/+200% · 百亿品牌 · "大潮玩时代"

一句话核心：全面爆发期——收入 45.58亿元（+62%）、净利润 9.64亿元（+102%）、毛利率升至 64%；毛绒品类 +993%（LABUBU 现象）、海外 +259.6% 占比近 30%；管理层当场上调全年指引：集团收入 +60%以上、海外 +200%以上，首破 100亿 成百亿消费品牌。

关键数据（2024H1）：

  • 收入 45.58亿元（+62%）；毛利 29.19亿元（+71.9%），毛利率 60.4% → 64%（海外占比+2.2pct、采购成本+1.3pct）
  • 净利润 9.64亿元（+102%，净利率 17% → 21.2%）；经调整净利润 10.18亿元（+90.1%）
  • 中国内地 32.06亿（+31.5%）；港澳台及海外 13.5亿（+259.6%），占比 13.4% → 29.7%
  • 海外细分：东南亚 5.56亿（+478.3%，占海外41.1%）、北美 1.78亿（+377.7%）；泰国不满一年 6 家店、单店产出为平均数倍至十几倍；曼谷 LABUBU 主题店首日破1000万
  • IP（上半年 7 个破亿）：Molly 7.82亿（+90.1%）、The Monsters 6.27亿（+292.2%）、Skullpanda 5.75亿（+9.2%）
  • 品类：手办占比 58.3%（高基数仍+30%+，Skullpanda"温度"系列累计 68万套/5.4亿）；毛绒 +993% 至 4.5亿（占10%）；MEGA 近6亿（+140%，占13%）；积木 6 月上线即断货
  • 自主产品占比 96.2%（+69.5%）；艺术家 IP 36.88亿（+70.4%）、授权 IP 6.95亿（+6.9%）
  • 新业务：乐园开业近一年上半年数千万盈利；游戏《梦想家园》6-27 上线，月度运营盈利
  • 供应链：毛绒产能 2月 40万只 → 7月 300万只；自动化 10% → 近40%；返修率 1.8-2% → 0.0055-0.0057%；"3A"供应链（敏捷/协同/适应）
  • 海外电商 2.47亿（+335.4%）：Shopee+Lazada 1亿、官网 5600万、TikTok 3500万；海外团队超 1000人、95%外籍

指引更新（本场最重要动作）：

  • 原指引：集团 +30%、海外 +100% → 上调至：集团收入不低于 60%、海外不低于 200%
  • 全年销售额首次突破 100亿；海外占比 Q4 超 40%，圣诞月单月或超 50%
  • 下半年新开海外门店 30-40 家，北美年底达 20 家

问答要点：

  1. "大潮玩时代"：商品部一拆六，手办占比降至 60% 以下；"占领办公桌→柜子→客厅→书包"；下半年推全新饰品品牌（IP 项链戒指）
  2. 泰国经验复制到印尼、越南；本土化营销（IP 主题店+当地网红明星联动）是关键
  3. 国内韧性："抚慰人心"属性=口红效应；坚持品牌向上不降价；泡泡玛特成了海外游客来华的"土特产"
  4. "线上线下一盘货"、按天动态流转；爆品拉新→毛绒/衍生品入坑→盲盒
  5. 积木目标"两年后品质公认"；卡牌定位"讲故事"媒介，年底推出面向成年人的产品
  6. IP 分层运营：Molly 多形态（Space/Royal/Baby/小画家）、小野走生活方式品牌、Labubu 探索年龄感突破；新 IP 星星人被点名"很快成为头部"（后验证：2026H1 达 26.5亿）
  7. 供应链不建自有工厂，越南合作生产约 10%；东南亚、北美保税仓已布局

  1. 百亿目标与 Q4 海外占比 40%+ 兑现度
  2. 毛绒供应链产能瓶颈缓解
  3. 全年毛利率 +3pct（至 64%+）达成
  4. 星星人、饰品品牌等新种子

开场致辞

王宁：

公司正在进入一个"大潮玩时代"，业务不再局限于简单的手办，而是扩展到更多领域和品类。这预示着公司业务发展和健康度将迈上新台阶。

"向上努力，向外看"，这是公司内部和对外的核心理念。

  • "向上努力"：即使公司规模不断扩大，也始终坚持"品牌向上"的理念，提升品牌感受和产品品质。
  • "向外看"：海外业务是目前的核心增长点，其增长速度和受欢迎程度都超出了预期。公司提前几个月实现了在海外再造一个泡泡玛特的目标。

财务回顾

杨镜冰：

整体财务表现：

  • 营收与利润：
    • 总营收：45.58 亿人民币，同比增长 62%。
    • 毛利：29.19 亿人民币，同比增长 71.9%，毛利率从 60.4% 提升至 64%。
    • 净利润：9.64 亿人民币，同比增长 102%。净利润率从 17% 提升至 21.2%。
    • 经调整净利润：10.18 亿人民币，同比增长 90.1%。
  • 毛利率提升原因：
    • 海外销售占比提升：海外销售占比达到 29.7%，海外毛利率 70.1% 高于中国内地，整体提升了 2.2 个百分点。
    • 采购成本下降：供应商及订单规模化管理、精细化生产和自动化作业，使毛利率提升了 1.3 个百分点。
  • 净利润增长原因：
    • 毛利增加：贡献了大部分利润提升（12.21 亿人民币）。
    • 费用上升：销售费用和管理费用共增加 5.78 亿人民币，抵消部分净利润的增长。销售费用增长主要来自全球新开门店、线上多平台入驻（如抖音）、广告和物流费用。管理费用增长主要来自职工薪酬增加。

渠道与 IP 收入分析：

  • 渠道表现：
    • 中国内地：营收 32.06 亿人民币，同比增长 31.5%。线下门店和机器人商店通过坪效提升、场景拓展实现增长。线上渠道中，抖音平台增长 90.7%。
    • 港澳台及海外：营收 13.5 亿人民币，同比增长 259.6%。营收占比从去年同期的 13.4% 大幅提升至 29.7%。
  • 海外市场细分：
    • 东南亚：营收 5.56 亿人民币，同比增长 478.3%，占海外总收入的 41.1%。
    • 北美：营收 1.78 亿人民币，同比增长 377.7%。
  • IP 表现：
    • Molly：营收 7.82 亿人民币，同比增长 90.1%。
    • The Monsters：营收 6.27 亿人民币，同比增长 292.2%。
    • Skullpanda：营收 5.75 亿人民币，同比增长 9.2%。
  • 自主产品：营收 43.83 亿人民币，同比增长 69.5%。自主产品收入占比从 91.9% 提升至 96.2%。其中：
    • 艺术家 IP：营收 36.88 亿人民币，同比增长 70.4%。
    • 授权 IP：营收 6.95 亿人民币，同比增长 6.9%。

业务回顾

司德：

公司的 IP 矩阵更加均衡，目前已有 7 个 IP 在上半年的销售额超过 1 亿人民币。

  • Molly：我们合作的第一个 IP，也是合作最久的 IP。Molly 在今年又持续展现出了非常蓬勃的生命力，凭借 MEGA 产品线和 Baby Molly 等新形态，持续保持强劲生命力。
  • The Monsters：通过丰富的产品品类和乐园偶装表现，迅速发展，特别是在毛绒玩具品类实现大幅增长。
  • 新 IP：PDC（设计师团队）的 IP 如小野、Zsiga 表现亮眼。新签约的 IP 也取得了不错的市场反响。
  • 授权 IP：持续深化与迪士尼等国际版权方的合作，并取得了更多海外地区的授权。

产品类别分析：

  • 手办：作为核心品类，手办上半年在高基数的情况下仍保持了超过 30% 的增长，销售占比为 58.3%。其中，SKULLPANDA是品类的绝对领先者，今年推出的"漫相集系列"是上半年单系列销量最佳的产品，截止目前，累计销售超过 19.6 万套，销售额超过 1.6 亿元人民币。2022 年 11 月推出的《温度》系列至今累计销量已超过 68 万套，销售额超过 5.4 亿元人民币，其长久的生命周期令人印象深刻。
  • 毛绒玩具：上半年增速最快的品类，同比增长 993%，销售额达到近 4.5 亿元，占比 10%。特别是拉布布和 Crybaby 的搪胶毛绒产品，已成为中国及海外市场的热门话题。我们将持续优化供应链以解决产能问题，并推出更多新产品。
  • MEGA 产品线：推出第四年，该产品线已进入成熟阶段，上半年收入将近 6 亿元人民币，同比增长近 140%，占比 13%。MEGA 系列在海外市场同样火爆，它不仅带来了销售增长，也提升了品牌艺术调性。Space Molly作为其核心，我们发现其用户与传统 Molly 的受众已开始分化，并产生了新的情感连接，这对我们是一个宝贵的经验。
  • 积木：今年 6 月推出的首款积木产品销售表现良好，许多产品都出现了断货。我们相信积木能让用户更深入地体验 IP 的世界观，未来将是品类矩阵中非常重要的一环。
  • 乐园与游戏：
    • 乐园（POPLAND）：开业近一年，上半年实现数千万盈利。乐园的最大意义在于为用户提供 IP 沉浸感，增强情感连接。正在进行一楼甜品店改造和二期项目推进。
    • 游戏：首款游戏《梦想家园》于 6 月 27 日上线，公测两个月，每月运营层面实现盈利，但数额不大。游戏的核心初衷是为用户提供沉浸式陪伴，加深 IP 与用户的连接。

中国内地业务回顾

褚音：

  • 销售表现：收入 32.1 亿，同比增长 32%。
  • 线下渠道：门店作为拉新渠道，通过优化品类结构、提升连带销售率等措施，实现 24.7% 的增长。机器人商店通过拓展应用场景和中台技术支持，单机生产力提升 15%。
  • 线上渠道：
    • 抽盒机：从第二季度开始恢复双位数增长。
    • 天猫：通过获取优质客户和减少低价促销，实现双位数增长，并在 618 回到双榜第一。
    • 抖音：持续高速增长，通过优化直播内容和矩阵，增强用户互动。
  • 会员数据：上半年会员数量和 ARPU 均有增长。会员贡献占比和复购率基本与去年持平，整体保持稳定。

海外业务回顾

文德一：

  • 业绩：2024 年上半年海外及港澳台地区营业收入达 13.51 亿人民币，同比增长 259.6%。上半年收入已超过 2023 年全年，证明了 DTC（直面消费者）战略的有效性。
  • 线下渠道：上半年海外线下门店（不包括机器人商店）营收 8.9 亿人民币，同比增长 441.5%。其中，泰国曼谷 LABUBU 主题店开业首日营收突破 1000 万人民币。
  • 线上渠道：上半年线上电商收入 2.47 亿，同比增长 335.4%，占海外总收入的 18.3%。
  • 品牌建设：
    • 在伦敦牛津街开设地标性门店，扩大品牌影响力。
    • 在泰国开设小野快闪店，通过多样的互动形式加深 IP 形象。
    • 与明星和网红合作（如明星青睐的 LABUBU），扩大品牌曝光，增强用户情感连接。

海外业务占比上半年达到近 30%。我们在不同国家举办了大量粉丝活动，如：拉布布和 Crybaby 在泰国；Peach Riot 在美国；SKULLPANDA 在欧洲；DIMOO 在澳洲。

这些活动加深了不同 IP 在不同地区的热度。随着海外业务的增长，我们积累了宝贵的数据，可以看到不同 IP、不同品类在不同国家的销售走势，这为我们未来制定 IP 孵化和产品开发策略提供了重要的参考。

  • 未来计划：下半年计划新开 30 至 40 家海外门店，重点布局北美和东南亚等高潜力市场。

供应链回顾

袁俊杰：

  • 新品类拓展：
    • 积木：成功掌握了精密制造和一体化供应链整合能力，为进入其他品类积累了经验。
    • 毛绒：在发现市场商机后，产能迅速提升，从 2 月的 40 万只增至 7 月的 300 万只，满足市场需求。
  • 核心业务优化：
    • 潮玩公仔：围绕工艺科技改造和成本建设开展工作，牵头制定了行业标准。
    • 精益生产：自动化生产水平从不到 10% 提升至近 40%。
    • 敏捷性：提高了返单时效和库存周转效率。
    • 品质提升：产品返修率从去年的 1.8% 至 2% 之间，降至现在的 0.0055% 至 0.0057% 之间。
  • 全球化供应链布局：
    • 致力于打造"3A"供应链：敏捷性（Agility）、大力协同（Alignment）和因地制宜的适应性（Adaptability）。
    • 未来将更多地"走出去"，结合当地市场需求，更敏捷地触达消费者。

问答环节

Q1 全年指引上调与海外战略借鉴

分析师提问：

第一个问题是关于业绩指引。上半年业绩非常好，二季度也在加速，如何看待下半年国内外经营状况，能否给一些展望？

第二个问题是关于海外战略。泰国和东南亚市场的蓬勃发展，是否给公司在海外布局上提供了新的借鉴？未来开店速度会加速吗？海外发展是否仍以门店为核心，还是会有其他举措？

王宁：今年初，我们给出的指引是集团收入增长不低于 30%，海外增长不低于 100%。但上半年业绩超出了预期，集团增长超过 60%，海外增长超过 200%。

因此，我们更新指引，预计全年集团收入增长不低于 60%，海外增长不低于 200%。我们有信心今年销售额能首次突破 100 亿人民币，成为一个百亿消费品牌。

随着海外业务占比越来越大，从去年的 10% 多到上半年的近 30%，我们预计第四季度将超过 40%，甚至在圣诞月可能单月超过 50%。海外的快速增长将带动整个集团进入新的增长阶段。

在海外战略上，我们主要采取**直营（DTC）**模式，不依赖分销或加盟。这证明了我们的产品在全球范围内的受欢迎程度。

数字背后是我们运营能力的积累，海外团队已超过 1000 人，95% 以上是外籍员工，如何管理不同文化背景的同事，是挑战也是能力的提升。海外业务目前才刚过 100 家店，我们认为这只是个开始，未来将持续拓展新品类。

文德一：我们从当初海外业务开始的那一天，就关注到东南亚地区。我们从新加坡开始，然后到马来西亚，第三站是泰国的。我们通过电商和社媒的数据，抓到一些信号，泰国那边的市场比较火爆。

在泰国，我们去年 9 月份开业，不满一年的时间，我们已经开出了六家门店，单店产出是平均水平的数倍甚至是十几倍，这超过了我们的预期。泰国市场的成功给了我们很好的借鉴，我们正将这些成功经验复制到印尼、越南等市场。

成功的关键在于本土化营销，例如设置不同 IP 主题的门店并与当地网红和明星联动。除了在曼谷、新加坡等热门旅游地开设地标性门店，我们也会以快闪店等更敏捷的方式进入新市场。

电商也是非常重要的渠道，目前占海外业务的 18%，未来将持续发力，特别是在东南亚。我们也会加强与当地艺术家和明星的合作，例如最近 Crybaby 与三星的联名，来提升品牌影响力。

Q2 品类拓展与供应链优化

分析师提问：

第一个问题关于品类拓展。在大潮玩战略下，如何评价毛绒、积木、卡牌等新品类的表现？哪些有惊喜，哪些还需要优化？

第二个问题是关于供应链。随着全球化和品类多元化，公司在供应链方面做了哪些优化？未来有什么计划？比如越南工厂的时间表、欧美仓库的布局等。

王宁：两年前我们将商品部拆分，从一个商品部拆到六个商品部，增加了内部和外部工作室，极大地丰富了产品供给。现在，传统手办类产品占比已降到 60% 以下，毛绒、积木等新品类表现非常好。当然，不同品类对供应链是新的挑战。产品开发周期通常长达 10 到 13 个月，我们已经为未来准备了更多惊喜产品。可以透露的是，下半年将推出一个全新的饰品品牌，将 IP 形象融入项链、戒指等产品，希望给消费者带来不一样的体验。

司德：我们自己开玩笑，最早我们就要占领大家的办公桌，后来占领大家的柜子、客厅，我们现在又占领大家的书包。我们过去看到很多年轻人可能通过线上去晒自己的喜好，大家还可能通过自己的包，自己的衣服，自己的身上的饰品项链等等这种东西去把自己的喜好晒出来，通过晒出来之后，然后去展现自己的个性，自己的喜好，去吸引他同好的朋友。

我觉得这个其实是一个非常重要的一个发展的趋势，品类拓展的核心是对消费者的洞察，始终是IP 本身的内涵挖掘。毛绒玩具增速最快，挑战在于供应链产能提升。积木方面，我们深知目前仍有提升空间，已组建专项团队，目标是两年后让泡泡玛特的积木品质得到公认。卡牌品类则被视为"讲故事"的媒介，我们正在开发面向成年受众、更具故事性的卡牌产品，预计年底前推出。

袁俊杰：对于供应链，我们有三个主要改善方向：

第一，增加协同性。通过产品、销售、供应链等部门的集体智慧，减少对未来预测的偏差。

第二，增加后端敏捷性。提升供应链弹性，即使短时断货也能迅速补上。

第三，全球化布局。已经在东南亚和北美布局保税仓，以便更快地触达海外消费者。今年内部目标是越南工厂能提供接近 10% 的产品供应，但强调是合作生产，目前没有自建工厂的计划。

Q3 国内市场恢复与海外重点市场策略

分析师提问：

第一个问题是关于国内市场。体感上今年上半年国内市场持续变好，原因是什么？下半年预期如何？

第二个问题是关于海外市场，特别是北美和东南亚，下半年的运营策略和长期的优化方向。

王宁：尽管今年消费市场面临压力，我们的产品表现相对较好。一方面，潮玩有"抚慰人心"的属性，可以理解为一种"口红效应"。另一方面，我们坚持"品牌向上"的理念，不靠降价，而是通过提供更好的产品和服务来增长。

此外，海外业务的发展也重新为国内市场带来了动力，泡泡玛特成了海外游客来中国旅游时购买的"土特产"，这促进了国内业务的增长。

褚音：我们采取"线上线下一盘货"的策略，实现了货品流转的动态化，可以按天快速响应消费者需求。在运营上，我们把爆品作为吸引新客的工具，通过持续的曝光来增加品牌池的用户。我们发现，现在很多消费者是从毛绒或衍生品开始了解品牌，然后才"入坑"盲盒。所以我们的门店陈列也做了相应调整。下半年我们将继续保持增长，但重点是提高运营效率，并持续优化消费者体验。

文德一：北美和东南亚是重点市场。在北美，预计年底门店数量将达到 20 家，明年会继续加速。我们将与当地艺术家合作，举办签售会等活动。在东南亚，我们尤其关注旅游地点，例如越南的岘港，新加坡的樟宜机场，游客消费意愿很强。

我们将对早期在日韩等东亚地区开业的门店进行升级改造，并在快速扩张的同时，更注重精细化运营，包括人才培养和本地化管理。

Q4 利润率展望与线上渠道协同

分析师提问：

第一个问题是关于利润率。如何展望今年和未来的毛利率和净利率？第二个问题是关于线上渠道，特别是抽盒机和抖音的表现。公司在这些渠道的运营策略是什么？线上线下渠道之间如何协同？

杨镜冰：毛利率的提升主要来自供应链优化和海外业务占比的提高。下半年随着海外销售占比的继续提升，预计全年毛利率将比去年提升 3 个百分点。下半年的净利率也会有提升，但海外费用率相对高一些，净利率的提升会低于毛利率的提升幅度。

展望未来，我们预计接下来几年毛利率将保持稳定，净利率则会随着海外规模效应而相应提升。

褚音：线上渠道方面，抽盒机上半年效能提升，主要是通过线下门店联动和差异化的产品运营策略，第二季恢复两位数增长。抖音的业绩从去年 5 月开始大幅增长，上半年增长超过 90%。下半年我们将重点在抖音的公域流量上发力，获取更多新用户。天猫等平台则定位为"品牌人群入口"，我们不盲目追求 ROI，而是采取**"用产品找人"的策略，大胆尝试破圈，这使得新会员和整体流量都实现了两位数增长。

王宁：抖音是我们所有线上渠道中增长最快的。我们采取完全自营的模式，不依赖其他主播带货。我们发现不同人群喜好不同，一个直播间无法满足不同人群的需求，因此未来将在国内开设更多不同品类和 IP 的直播间，以满足更多元化的需求。

Q5 IP 运营策略与海外电商布局

分析师提问：

首先恭喜公司取得了很好的业绩，提前实现了"再造一个泡泡玛特"的目标，也成功打造了自有 IP 的国际影响力。我有两个问题：

第一个问题是关于 IP 的运营。我们看到 Crybaby 很好地走出了第二增长曲线，整体的品牌运营非常成功。管理层能否透露一下，我们其他的头部 IP 后续是否有进一步的针对性运营计划，以及会采取哪些措施持续提高 IP 和产品的吸引力？

第二个问题是关于海外电商。海外电商在尚未完全发力的情况下，取得了亮眼的增速。公司是否考虑加速海外电商的布局？从中长期看，我们将重点在哪些平台发力？如何提高与海外电商合作伙伴的合作效率？另外，海外电商与国内电商在哪些方面可以更好地协同？

王宁：首先，从财报数据中可以看到，我们的 IP 矩阵正变得越来越分散，不再特别依赖于某个单一 IP。每年都有非常有活力的新 IP 出现，比如最近上线的星星人。我们有信心它会很快成为头部 IP。

同时，随着海外本土团队和渠道的增加，我们挖掘海外 IP 的能力也越来越强，如泰国的 Crybaby，美国的 Peach Riot。

今年表现非常好的两个 IP 是 Molly 和 Labubu。这背后体现了我们的运营能力。一个优秀的 IP 能够持续创造价值，核心是对其进行持续的投入和运营。我们通过市场、渠道、产品、乐园和游戏等构成的综合商业框架，不断孵化新 IP，吸引优秀 IP 加入，并为老 IP 注入新的活力，从而持续获得商业价值。这是数字背后的核心能力。

司德：我简单介绍一下各个 IP 的具体情况：

  • Molly：通过与创作者的共创，Molly 有了不同的形态，例如 Space Molly、Royal Molly、Baby Molly 和小画家 Molly。虽然底色一样，但每一个形态都代表着不同的情感和寓意，我们会进行更精细化的运营和产品开发。
  • Labubu：我们正在开发新的品类，并探索 IP 年龄感的突破。
  • SKULLPANDA：其手办设计和艺术性在所有 IP 中都非常领先。它的设计不只在中国，也在全球范围内广受欢迎，因为它跨越了不同的文化和审美。
  • 小野：我们正尝试将其打造成一个生活方式品牌，例如在上海、杭州和曼谷开设生活方式快闪店。

我们对每一个 IP 都有大致的运营想法，并会通过数据积累和不断尝试来逐步实现。我们拥有非常优秀的 IP 产品开发团队，相信能持续为 IP 注入生命力。

文德一：海外电商是海外业务的重要渠道，它不仅带来了销售，也帮助我们触达了 100 多个国家和地区，为我们探索线下门店无法覆盖的市场提供了重要参考。

上半年海外电商的营收突破 2 亿元人民币，同比增长 335.4%。一般来说，下半年海外电商的收入比上半年高，主要是下半年有更多营销的节点。

我们运营第三方平台和自营官网，其中 Shopee 和 Lazada 占比最高，上半年收入达 1 亿元。内容电商（如 TikTok）增长迅速，上半年收入为 3500 万元。我们的官网也实现了 5600 万元的收入。

在海外电商和国内电商的协同方面，我们可以借鉴国内成熟的经验，在供应链和客服等方面实现集团层面的资源共享，但在营销策略和平台运营上，海外团队会自主进行。

Q6 会员行为变化与库存管理

分析师提问：

关于国内会员，上半年会员增长情况如何？新老会员的购买行为有何变化？在快速增长的背后，国内会员的消费行为有何变化？

第二个问题是关于库存管理。爆款当天售罄、补货也很快卖完，加上海外布局和海运时效的挑战，公司如何应对供应链和库存管理的挑战？

褚音：在国内庞大的会员基础上，复购率和留存率保持稳定，但新增消费会员数有两位数增长。我们不再追求低权益拉新，而是通过互动吸引真正有价值的消费者。

上半年，老会员的单次消费金额提升，购买行为也更加多元化，不再局限于盲盒，而是更多地购买毛绒、积木等新品类；新会员的购买次数和单次购买金额也有显著提升，表明我们吸引了更多优质新客；购买两个及两个以上 IP 的会员比例也在明显上升，高价值会员层级的人数和消费增长表现突出。

袁俊杰：在库存管理上，我们主要通过三方面来应对挑战：

  1. 增加协同性：通过产品、销售和供应链部门的集体智慧，减少对未来预测的偏差。
  2. 增加后端敏捷性：提升供应链弹性，即使短时断货也能迅速补上。
  3. 全球化布局：已在东南亚和北美布局保税仓，加快物流时效。

至于是采取激进或稳健的库存策略，这需要与商务团队一起决策。

司德：补充一点，我们对整个供应链、海运和物流的问题理解得非常深入，并正在通过一点一滴的细节改进来优化，例如加快几天运输时间或降低零点几个百分点的成本。我们相信，只要对问题有足够深的理解，情况就会持续变好。

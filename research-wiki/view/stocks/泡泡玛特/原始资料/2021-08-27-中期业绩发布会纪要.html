摘要

核心话题：MEGA大娃 · IP矩阵均衡化 · 京东分流天猫 · 供应链五关键词 · IP定级SABC · 门店升级

一句话核心：IPO 后首份半年报，收入 17.73亿元（+116.8%）、经调整净利润 4.35亿元（+144.1%）；最大亮点是 MEGA 1000% 大娃爆火（100万人次抽签），王宁借此重申 "泡泡玛特不是盲盒公司，是 IP 公司"，并提出 IP 流动性定级（S/A/B/C）。

关键数据（2021H1）：

  • 收入 17.73亿元（+116.8%）；毛利 11.17亿元（+109.4%），毛利率 65.2% → 63%
  • 经营利润 4.87亿元（+133.6%，净利率 27.5%）；经调整净利润 4.35亿元（+144.1%，利润率 24.6%）
  • 自主产品占比 89.3%；6个 IP 销售额超 1亿元，头部占比均在 10% 左右
  • IP：Molly 2.04亿（+81.9%）、Dimoo 2.05亿（+74.5%）、Skullpanda 1.83亿（熊猫热潮单系列 9200万）、The Monsters 1.4亿（翻倍）、Pucky 1.07亿（系列减少略降）
  • 渠道：门店 215家（+79）、机器人商店 1,477台（+476）；线上 6.78亿（+102.9%）——抽盒机 3.25亿（+101%）、天猫 2.19亿（+49%）、京东 0.47亿（+480%）
  • 海外收入 +105.6%，覆盖 23个 国家地区；会员 1,100万，贡献 91.8%，复购率 49%
  • 存货周转天数 74天（从78天下降）；无银行借款

问答要点：

  1. 季节性：下半年销售约等于上半年 2倍；8月已创历史最佳单月销售，宏观放缓不改信心
  2. 毛利率：上半年新品仅占收入 30-40%、老品未提价压制毛利；下半年新品放量+仅11款涨价，毛利率有望回升
  3. 渠道：京东分流天猫是主动为之（带来大量新客，1+1>2）；下半年试水抖音、得物、小红书
  4. 海外：放缓开店速度，重心转跨境电商+ERP/海外仓等基建，欧美用快闪店轻资产试水
  5. IP 定级：S/A/B/C 级流动性管理，表现好迅速加资源、不及预期迅速收缩；签约到新品推出需 8-12个月
  6. 供应链五关键词：产能、质量、速度、成本、工艺；2-3年供应链信息化建设项目
  7. 门店：新开门店超 80% 在一楼，标准店面积从 100平 提到 150-200平
  8. 毛利率结构：盲盒毛利率高于 MEGA（工艺还在优化），预期明年 MEGA 毛利率明显增长

王宁金句：泡泡玛特的成功不是盲盒的成功，是 IP 的成功、潮玩的成功；我们更像一个 唱片公司。

跟踪要点：

  1. MEGA 明年毛利率能否兑现明显增长
  2. Skullpanda 全年能否站稳头部（上半年已 1.83亿）
  3. 海外"放缓开店、基建先行"策略的落地效果
  4. Pucky 连续走弱（系列减少）是否延续

开场致辞与业绩回顾

王宁：

大家好，非常开心参加这次业绩发布会。2021 年上半年，我们的营收和利润其实都有一个非常好的增长。我想简单总结并分享一下我对上半年业绩的理解。

我们之前一直强调，泡泡玛特是一家非常强调团队、强调人的企业。这次是我们 IPO 之后第一次交出半年报的答卷。上半年，我觉得我们在人才密度方面有了非常好的增长，吸引了非常多优秀的同事加入，并不断优化了我们的团队，使我们对整个管理充满信心。

这半年，我们在很多环节都取得了非常好的进步：

  • 包括我们的供应链、内控、信息化建设；
  • 包括渠道的优化、品牌的建设；
  • 以及授权业务和海外业务的积极发展。

值得一提的是，我们是一家关于 IP 运营的企业。这半年大家从数据上可以看到我们在 IP 方面的优势，包括新 IP 的孵化和成长。从这个角度来看，我们整个平台的 IP 孵化能力得到了进一步提升，同时我们的头部 IP 也依旧保持了非常好的生命力。我对 IP 端的整体结构优化表示非常满意。

我们这半年推出了非常多的新产品线，其中表现非常好的是 MEGA 系列。我们推出了 400% 和 1000% 尺寸的新产品线。从市场反应来看，推出是非常成功的，一定程度上超出了我们的预期。不论是市场的喜爱程度、热度，还是综合增长表现，都让我们充满信心。

这从另一个角度证明了大家对我们 IP 的喜爱，而不仅仅是对盲盒模式的喜爱。

MEGA 系列是对 IP 的一种 1000% 比例的产品呈现。我觉得这对整个公司来讲非常有意义，证明了我们是一家有 IP 价值的公司，而不仅是一个模式。我们相信 MEGA 这条线未来也会成为我们下一步非常重要的业务，并有信心它将进一步快速增长。

对于未来的一些布局，我们也在进行很好的投入。这半年我们增加了许多内部认为有价值的业务布局，包括我们新的乐园业务，目前正在积极准备和逐步规划中。同时，我们也在积极探索对外投资，无论是年轻人喜欢的球鞋还是"三坑"，我们都在进行投资探索，并获得了满意的综合协同效应。

总的来讲，这半年虽然我们 IPO 后面临许多行业竞争，但从内部的增长和团队的成长来看，我们相信公司在进一步提升竞争门槛，扩大市场份额，并增强优势。我们在面对竞争时，表现出了非常强的竞争力和卓越的运营能力。

我们一直追求企业是相对"长青"的，因此内部追求的核心词汇是健康。大家从财报中也可以看到，我们是一家相对尊重经营的企业，一直在认真地做运营工作。

从增长数字可以看到，我们从 IP 的分布、收入占比分布都变得越来越健康；对供应链、人才梯队的建设也变得越来越健康；包括产品规划、业务规划、费用管理、内控管理等都表现出色。我相信整个公司正处于一个非常好的上升阶段。

总体来讲，我们对上半年非常满意，也感谢同事们的付出。整个公司朝气蓬勃，业务得到了快速发展，我们对未来充满信心。谢谢大家。

杨镜冰（首席财务官）财务回顾

杨镜冰：

大家好，由我代表公司向大家汇报 2021 年上半年的财务业绩。

核心财务数据与盈利能力：

  • 收入：从 2020 年上半年的 8.18 亿人民币增长至 2021 年上半年的 17.73 亿人民币，增长了 116.8%。
  • 自主产品占比：由 2020 年上半年的 84.1% 上升到 89.3%（15.82 亿人民币）。未来自主产品的销售占比将继续维持在这一水平。
  • 毛利：由 5.33 亿人民币上升至 11.17 亿人民币，增长了 109.4%。
  • 毛利率：略微下降至 63%（2020 年上半年为 65.2%）。主要由于提高了产品的工艺质量和设计精细度，以及原材料和供应链人工成本上涨所致。
  • 经营性利润：达到 4.87 亿人民币，比 2020 年上半年增长了 133.6%，净利润率为 27.5%。
  • 经调整后净利润：达到 4.35 亿人民币，增长了 144.1%，利润率为 24.6%。（主要调整项目为股份支付）
  • 每股收益：基本每股收益由 12.07 分人民币增加至 26.04 分人民币。摊薄每股收益为 26.02 分人民币。

按 IP 划分的销售增长驱动因素：

公司持续增加泡泡玛特自主产品的销售占比，从 2020 年上半年的 80.1% 上升到 2021 年上半年的 89.3%。

  • 自有 IP 收入：从 2.8 亿人民币增加到 9 亿人民币。
    • Molly：收入贡献从 1.12 亿人民币增加到 2.04 亿人民币。
    • Dimoo：收入贡献从 1.17 亿人民币增加到 2.05 亿人民币。
    • Skullpanda：收入贡献达到 1.83 亿人民币。
    • PDC 内部设计师团队：推出的小甜豆、Bobo&Coco 等表现强劲。
  • 独家 IP 收入：从 2.73 亿人民币增加到 3.94 亿人民币。
    • The Monsters (Labubu)：收入贡献从 0.7 亿人民币增加到 1.4 亿人民币。
    • Pucky (毕奇)：收入贡献为 1.07 亿人民币。（略低于 2020 年上半年，主要由于系列数量减少）
  • 非独家 IP 收入：从 1.33 亿人民币增加到 2.88 亿人民币。
    • 主要原因：长期合作的迪士尼、哈利波特等系列产品的发售，以及新合作 IP 数量的增加。

按渠道划分的销售增长情况：

公司各主要销售渠道均实现了高速增长。

  • 线下零售店：
    • 收入达到 6.75 亿人民币，增长了 115.5%。
    • 门店数量从 136 家增加到 215 家，新增 79 家。
  • 机器人商店：
    • 收入达到 2.28 亿人民币，增长了 115.7%。
    • 机器数量从 1,001 台增加到 1,477 台，新增 476 台。
  • 2021 年上半年国内疫情有效控制，线下门店和机器人商店均正常营业，而 2020 年同期疫情影响较大。
  • 线上渠道：
    • 总收入达到 6.78 亿人民币，增长了 102.9%。
    • 泡泡玛特抽盒机收入达到 3.25 亿人民币，增长了 101%。
    • 天猫旗舰店收入达到 2.19 亿人民币，增长了 49.11%。
    • 大力发展京东渠道，收入贡献为 0.47 亿人民币。（该渠道 2020 年 4 月开始运营）
  • 批发及其他收入：
    • 总收入达到 1.91 亿人民币，增长了 195.9%。
    • 中国大陆批发及其他收入主要来自南京金鹰泡泡玛特商贸有限公司的收入增长（占比 50.8%）及个别大宗团购（占比 24.4%）。
    • 中国大陆以外的批发及其他收入从 0.2 亿人民币上升到了 0.45 亿人民币，主要由于海外市场扩张。

费用开支及运营指标：

  • 经销及销售开支：
    • 总额上升至 4.2 亿人民币，但占收入比重从 27.2% 下降到 23.7%。
    • 雇员福利开支增加，主要是销售员工人数增加（1,071 名增至 1,909 名）以支持渠道扩张。
  • 一般及行政开支：
    • 总额上升至 2.4 亿人民币，但占收入比重从 15.3% 下降到 13.5%。
    • 雇员福利开支增加，主要是行政及设计开发人员人数增加（617 名增至 1,211 名）以支持产品开发及未来业务扩张。
  • 存货：存货周转天数从 78 天下降到 74 天，维持稳定。
  • 资本结构：截至目前，公司并无任何银行借款。

司德（首席运营官）业务回顾

司德：

大家好，我简单介绍一下我们上半年业务的表现和未来的展望。2021 年上半年，我们的主营业务依然围绕着：全球艺术家挖掘、IP 孵化运营、消费者触达、潮流玩具文化推广这四个方面展开。我们继续在全球范围挖掘和培养最顶级、最有潜力的潮流艺术家，并帮助他们进行 IP 的孵化和运营。

IP 孵化与运营成果：

  • 头部 IP 强劲增长：
    • Molly：销售额超过 2 亿人民币，同比增长 81.9%。
    • Dimoo：销售额超过 2 亿人民币，同比增长 74.5%。
    • The Monsters (Labubu)：销售额实现了超过一倍的增长。

    • IP 收入占比变得更加均衡，前几名的 IP 占比均在 10% 左右。
  • 新 IP 爆发式增长：
    • Skullpanda：上半年收入达到 1.83 亿人民币，其第二款系列"熊猫热潮系列"单系列销售额达到 9200 万人民币。
  • 版权 IP 合作深化：
    • 推出了与宝可梦、小猪佩奇等首次合作的 IP 产品。

  • PDC 团队原创能力：内部设计师团队 PDC 推出的原创 IP 产品，上半年销售额整体超过 1 亿人民币，下半年将有更多优秀 IP 和新系列推出。

MEGA 系列产品线（艺术收藏）：

  • 产品定位：推出 MEGA 艺术收藏类新产品线，尺寸分为 400% 和 1000% 两种形式，未来会有其他尺寸推出。
  • 市场热度超预期：
    • MEGA Space Molly x 海绵宝宝联名款 1000% 在发售期间有超过 100 万人次参与抽签。
    • 8 月 18 日天猫超级品牌日活动中，西瓜和太妃糖两款 1000% 产品有超过 98 万人次参与抽签。
  • 战略重点：MEGA 产品线将是接下来非常重点的发展方向。

消费者触达（渠道表现）：

  • 线下加密布局：
    • 中国大陆地区新增 32 家门店，南京分公司新增 10 家。
    • 持续优化门店位置和体验，更多门店出现在购物中心一层，面积更大。
    • 上半年门店和机器人的业务分别取得了同比超过 110% 的增长。
  • 线上渠道爆发：
    • 线上收入增长超过 100%。
    • 自主研发的泡泡玛特抽盒机（小程序）收入达 3.3 亿人民币。
    • 电商渠道（天猫为主）收入达 3.5 亿人民币。
    • 京东平台实现了超过 480% 的同比增长。
  • 电商营销成果：
    • 天猫 618 总销售额达 6100 万人民币，位列天猫潮流玩具类目排名第一。
    • 8 月 18 日天猫超级品牌日，实现了超过 9000 万 GMV，创造了行业记录。

海外业务与会员体系：

  • 海外快速增长：同比增长达到 105.6%。
  • 在 23 个国家和地区建立了销售网络。
  • 在新加坡、韩国、加拿大等国家开设了门店；在 7 个国家和地区铺设了超过 55 台机器人商店。
  • 开设了亚马逊、速卖通以及官网等跨境电商业务。
  • 会员人数与贡献：
    • 截至 6 月 30 日，注册会员人数超过 1100 万人。
    • 上半年会员的销售贡献达到 91.8%，会员复购率达到 49%。

潮流玩具文化推广：

  • 学术合作：与北京大学光华管理学院共同成立北京大学商业与艺术研究中心，推动潮流文化研究。
  • 品牌活动：举办多场 IP 展览和粉丝活动，推出品牌播客。
  • PTS 线上展会：原定 8 月的北京国际潮流玩具展因疫情改为线上直播，三天吸引超过 130 万人次观看，直播 GMV 超过 2500 万人民币。

展望未来：

我们将继续坚持以 IP 为核心，围绕四个主要业务板块进行发展：

  • IP 与品类拓宽：
    • 继续全球发掘、孵化、运营最优秀的 IP。
    • 除了 MEGA 系列，将加速衍生品、BJD和手办等品类的开发。
  • 供应链优化：整合优质产能，优化全链路供应链流程，推动信息化建设，确保满足公司持续快速发展。
  • 消费者触达：
    • 加快门店和机器人商店在一、二线以及部分三线城市的布局。
    • 线上将积极探索更多新兴平台的销售机会。
  • 海外业务重点布局：更积极地布局跨境电商、线下门店、机器人商店以及第三方合作伙伴，将 IP 和产品推广给全世界更多的粉丝。
  • 文化推广：通过更丰富多元化的方式持续推广潮流玩具文化。

问答环节

Q1 上下半年季节特性、宏观需求与供应链毛利率（摩根士丹利）

Morgan Stanley 分析师提问：

第一个问题想请教公司上下半年季节特性，过去有三七开到四六开的特点，下半年会安排更多产品发售、门店开设和展会营销。在这个宏观环境和公司发展规律下，三七开到四六开的上下半年拆分是否仍然适用？

首先，之前我们反复说过，泡泡玛特不是一家盲盒公司，我们的本质是一家基于 IP 的潮玩公司。泡泡玛特的成功也不是盲盒的成功，是 IP 的成功，是潮玩的成功。我们的增长和发展，其实一定程度上也是关于潮玩的发展，以及我们认为有价值的 IP、设计和艺术的发展。

大家也可以看到，这半年以来，随着我们 IPO 的热度，各行各业都在学习我们的方式方法。我们最早说过，盲盒只是一个非常锦上添花的、简单的营销方式而已，它非常简单，所有人都可以去学习和参考。但你会发现，并没有看到更多只依靠这样一个模式而诞生新的成功企业。所以一定程度上验证了我们的核心一定不是只是简简单单的这样一个营销方式而已，更核心的还是我们的 IP 和我们的团队，以及整个潮流文化和潮流玩具这个行业。

我们大娃（MEGA）的成功，其实是让不太了解这个行业的人，更好地理解我们的核心价值，即 IP 的价值。因为我们这么多年的发展，积累了非常多头部的、我们认为非常有价值的 IP 和艺术家。所以第一款 1000% 推出就获得这么多的成功，我们认为还是在我们的预期之内。我们未来会推出更多艺术家的 1000% 和 400% 的作品。我们相信这个将来会有一个更好的发展，也会让更多的人去了解潮流玩具的文化，也让更多的人真正理解我们公司最有价值的核心还是我们 IP 的价值。

司德（补充稳态毛利率）：

我补充一下毛利率问题。目前从品类结构上面的话，盲盒的毛利率还是比大娃 MEGA 要稍微相对高一点。当然这也是因为 MEGA 系列刚刚推出，目前从工艺流程本身，我们还在重新梳理和优化的过程。但我们预期到了明年整个 MEGA 系列它的毛利率会比今年有一个明显的增长。

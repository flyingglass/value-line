摘要

核心话题：中国大店模型（Land / Super MINISO）· 自有 IP（UU / Chocho）· 会员战略 · 海外盘整与分销收缩 · 利润率下调指引

一句话核心：中国区以「大店 + 自有 IP + 会员」跑出近三年最快 H1 增速（收入 +26.2%），但海外分销下滑与北美直营投入拖累利润，管理层主动降速将海外定调为「盘整期（holding stage）」，并把全年调整后经营利润率指引从「-1~2pp」下调到 -3~-4pp，同时明确 2027 年才是利润率改善拐点。

关键数据：

  • 集团收入 115 亿元（+22.4%），EPS +8.2%，经营现金流 +46%，全球门店 8,674 家
  • 中国收入 +26.2%（Q2 +23%，远超原预期低双位数），同店中高个位数；门店 4,665 家（H1 净增 97：Land +59 / 旗舰 +159 / 常规 -121）
  • 会员销售贡献 77%（去年同期 57%、去年全年 60%、Q1 63%），会员数 1.3 亿（+31%），客单价 +5%
  • 自有 IP：H1 收入近 5 亿元，集团 10 亿元年度目标 7 月底提前达成；利润率高于公司平均，库存周转 30–40 天
  • 海外收入 40.6 亿元（+40.9%），但终端 GMV 82.9 亿元（+40%） 与收入背离；海外利润贡献占比从 2023 年的 35–40% 降至 H1 的 10–15%
  • 调整后经营利润 14.9 亿元（-6%），剔除汇兑 16.3 亿元（+5%）；调整后净利率 -2.6pp
  • 毛利率 H1 44.3%（持平，含关税退税 +0.6pp），Q2 45.3%（+1.0pp，含退税 +1.2pp）
  • 库存周转：整体 102 天（97）、中国 67 天（73）、海外 273 天（240）
  • 不派中期股息；H1 股东回报 13.1 亿元（回购 5.2 亿元），全年政策为回购+分红 ≥ 剔汇兑调整净利的 50%

核心矛盾：

  1. 中国超预期 vs 海外不及预期：中国「大店驱动」被验证（Land 坪效为常规店 2 倍、H1 净开 72 家），海外却因分销商去库存 + 北美以外直营未盈利，把集团利润率拖低 3–4pp
  2. 自有 IP 的高增长 vs 高投入：UU 单月销售连续破 1 亿、Chocho 首发售罄，但广告、IP 授权费、销售人工合计推高销售费用率 2.6pp，「战略投入期」尚未进入利润收获期
  3. 规模 vs 渠道健康：管理层主动关店（海外 H2 净减 50–70 家、分销全年净减 100–110 家）、主动放慢开店（"除非有 100% 信心"），以短期收入换长期单店模型
  4. 北美目标 vs 现实：全年 40 亿元收入 / 10% 净利率目标不变，但 Q2 增速从 37% 放缓至 25%，断货、关税调整、新店前置费用三重压制

跟踪要点：

  1. 海外 800 家直营店的单店模型是否在 2027 年前跑通（管理层自认「盘整期」）
  2. 分销库存去化：亚洲分销 H2 收入仍将 -10% 左右，低效店清理「还将持续两个季度」
  3. 北美 9 月断货缓解是否兑现，Q4 旺季能否支撑 40 亿收入 / 10% 净利率目标
  4. Chocho 能否成为第二个年销 10 亿的自有 IP，以及 UU 与 Disney 级别以上的合作落地
  5. 7–8 月中国 GMV 仍 +20%、同店中个位数，H2 中双位数收入指引的达成度（去年 11–12 月 Zuntopia 高基数）
  6. 回购力度：管理层称当前估值「极具吸引力」，将以大规模回购替代中期股息

二、CEO 叶国富：整体表现与中国业务

叶国富（创始人兼 CEO）：大家好。上半年名创优品集团收入达到 115 亿元，同比增长 22.4%；每股收益增长 8.2%，经营现金流增长 46%。全球门店数量达到 8,674 家。

名创优品今天正处在一个关键节点：我们在经营更大、更好的门店，在建设自有 IP，在发展海外组织能力。机遇与挑战并存。我坚信，这些战略方向和它们的阶段性意义，远比短期数字更重要。

我将按三大板块向大家介绍本季度业务表现：名创优品中国、名创优品海外，以及 TOP TOY。

官方数据显示，今年上半年中国社会消费品零售总额同比增长 1.3%。在这一宏观背景下，名创优品中国上半年收入增长 26.2%，不仅大幅跑赢社零大盘，也超出了我们此前的指引。这是我们近三年最快的上半年增速。

更重要的是，增长质量确实很高，主要由同店中高个位数增长驱动。截至 2026 年第二季度末，名创优品中国门店数达到 4,665 家，上半年净增 97 家，其中 Land 业态净增 59 家，旗舰业态净增 159 家，常规店净关 121 家。8 月 22 日，名创优品 Land 成都东郊记忆店正式开业，成为中国第 100 家 Land 门店。

门店数量在稳步增长，但质量更重要。6 月末我们的中国门店数同比增长 8%，而收入增长 26%，反映出单店产出大幅提升、整体坪效健康增长。我想展示三组数据。

第一，关于坪效与租售比。逐月看，Land 业态门店的坪效约为常规店的两倍。与存量门店相比，2026 年新开门店面积显著更大，但坪效保持稳定，其中租售比改善最为明显。我们的新店不再只是一个租户，而是客流引擎。

第二，门店翻新节奏继续加快。上半年我们完成了 189 家门店翻新，翻新后门店表现几乎翻倍。全年翻新目标 355 家，我们完全有信心在年底前超额完成。

第三，加盟商回报持续改善。无论以回本周期、利润率还是盈利门店占比衡量，上半年全国名创优品 Land 门店及全国名创门店的盈利水平都达到了 2019 年以来的最佳。加盟商越来越愿意开更大、更好的店，这是对我们渠道战略最直接的认可。从「腾笼换鸟」到大店驱动增长，我们的渠道升级战略已经推进两年，并且对未来依然意义重大。

这一点可以从两个事实来评估：第一，中国翻新门店的占比仍然很低；第二，我们在店型上持续创新。今年我们为店型矩阵增加了一个新成员——Super MINISO，这是 2026 年最重要的创新。回顾过去两年渠道升级的演进：2024 年，MINISO Land 验证了 IP 沉浸式旗舰店；2025 年，名创进入中高端商圈，定位「轻奢」；2026 年，Super MINISO 把 IP 体验带给更广泛的大众客群。它的商品结构是 50% IP 商品 + 50% 通用生活用品。自推出以来，它已成为最受消费者欢迎的店型之一。

Super MINISO 的巧妙之处在于，它并不推翻消费者既有的品牌认知，而是在此基础上叠加：它保留了消费者对名创优品「高性价比商品」的熟悉感，同时通过 IP 注入潮流与体验感。其他业态如 Friends、Land、Space 则逐级加深 IP 商品占比，帮助消费者从生活杂货走向 IP wonderland，这也是品牌升级的一部分。

我想说，大店的成功不仅仅是渠道创新，而是内容 + 空间 + 运营的系统性创新。门店是空间，IP 是填充它的灵魂。大店的势能与 IP 的价值相互强化，形成一个不断加速的飞轮。

去年 6 月，我们推出了第一个自有 IP UU。仅仅一年时间，UU 已进入全球 53 个国家，上半年相关收入接近 5 亿元。最具标志性的里程碑是 UU × Disney Toy Story 5 系列：Woody、Buzz Lightyear、Slinky Dog 的 UU 版本在多个国家的门店热销。仅仅一年，UU 的成功就把我们的自有 IP 推进到一个新阶段——能够以平等的地位与全球顶级 IP 合作。

除了名创优品的旗舰业态与品牌，TOP TOY 也建立了自己的 IP 矩阵。其旗舰 IP Nomi 累计 GMV 已超过 3 亿元。可以看到，UU 在旗舰品牌内验证了方法论，而 Nomi、Yui、Duidui 在 TOP TOY Land 品牌下验证了不同风格。围绕自有 IP，我们已经积累了覆盖「艺术家签约—产品定义—设计开发—供应链排产—上市前 staging 与调试—渠道店内活动—粉丝运营」的全链路 SOP。

我们在今年年初设定的全集团 10 亿元自有 IP 销售目标，已于 7 月底提前达成。这充分证明我们「多 IP、多品类、全球化」战略的成功，也充分展示了名创优品独特的资源禀赋。在建设自有 IP 方面，我们拥有全品类覆盖、全渠道渗透、全球布局和全链路运营能力。放眼全球，名创优品在商品品类上拥有最大的灵活性与延展性，在渠道上具备强成本控制与创新能力，拥有覆盖最广、质量最高的全球门店网络。在运营层面，名创优品发挥从签约艺术家到设计、开发、营销、销售的全链路优势，在每个环节深度赋能艺术家，最大化每个 IP 的潜力。这些正是名创优品高度差异化且稀缺的资源，也是名创实现跨越式发展的关键。在自有 IP 上，有「四种力量」让我们能够比绝大多数公司更高效地完成从 IP 创意到上架的完整流程。

所以大家可以看到，UU 才刚刚开始。8 月 22 日，我们推出新的艺术家 IP Chocho，首发当日全部售罄，远超预期。我们已经签约了多位设计师玩具艺术家。可以看到，8 月 26 日晚直播中，5 万套 Chocho 在 1 秒内售出。同时，我们通过 IP Protégé 计划在全球范围内招募顶尖创意人才。

我们未来的愿景是：引领 100 个中国 IP 走向全球舞台。

三、CEO 叶国富：自有 IP 的产业判断与会员战略

叶国富（创始人兼 CEO）：当前，全球 IP 市场进入了前所未有的繁荣期。一个大国的崛起，必然伴随文化符号的诞生及其全球化上升。名创优品凭借世界领先的渠道、商品和 IP 运营能力，将在这场历史性机遇中占据头部位置。我们的愿景是成为全球领先的 IP 运营平台。

按渠道规模衡量，我们已经是全球最大的 IP 产品零售商，而我们的自有 IP 业务正在构建一个兼具独特性、爆发力和可复制性的新增长引擎。向自有 IP 的战略转型，是基于时代趋势的长期选择，我们将持续长期投入。即便从短期看，自有 IP 产品线也交出了出色的成绩单：不仅 UU 被验证成功，我们的第二个 IP Chocho 也是如此；上半年自有 IP 的利润率高于公司平均水平，库存周转控制在 30–40 天。自有 IP 战略没有对整体盈利能力造成压力，为我们继续构建 IP 生态奠定了坚实基础。

接下来我讲会员战略。去年我说过，会员将成为名创优品增长的另一个重要引擎。会员战略的价值正在稳步兑现。

会员规模与贡献持续创新高。上半年我们的中国会员数增长 31%，达到 1.3 亿，创历史新高。会员贡献销售占比从去年同期的 57%、去年全年的 60%、第一季度的 63%，进一步提升至当前的 77%。同时，会员也是名创优品增长从「机会驱动」转向「系统驱动」的最新证据。会员的价值体现在两个方面。

核心引擎是提升客单价。客单价增长 5%。在与全球 IP 合作方面，例如三丽鸥、迪士尼、哈利波特，以及 Chocho，叠加自有 IP 的爆款效应，大店已成为高价值会员的核心阵地。因此，中国会员的人均贡献是非会员的两倍；IP 会员的客单价是非 IP 会员的三倍以上。

第二，会员是通过精准触达和权益驱动的留存，进一步提升用户活跃生命周期的顶层引擎。精准识别会员的消费偏好与品类需求，能让新品高效触达目标消费者；而返现权益等升级后的会员权益，则把一次购买直接转化为下一次购买的动力。2025 年新增的 IP 会员，上半年留存率比非 IP 会员高 8 个百分点，购买频次是非 IP 会员的两倍。

使用返现权益的会员，复购频次比不使用者高 1.6 倍。IP 驱动获客、大店品质升级、复购延伸，是我们实现高度可持续会员价值的底层公式。当规模、结构与频次同时驱动时，就能支撑长期成功。

四、CEO 叶国富：海外业务——坦承不及预期，定调「盘整期」

叶国富（创始人兼 CEO）：接下来看看海外市场。今年上半年，海外收入增长 40.9%，达到 40.6 亿元。

门店数达到 3,644 家。坦率地说，海外表现不及我们的预期，并在一定程度上拖累了集团利润。海外对公司利润的贡献从 2023 年的 35%–40% 降至今年上半年的 10%–15%。影响来自两个因素：第一，分销商业务收入下滑；第二，北美以外的直营市场仍处于早期投入阶段，店型仍在打磨，尚未盈利。

我们也对这些问题做了内部复盘。在海外直营店扩张上，我们将更加聚焦、更加审慎，严格评估新店的 ROI，集中资源深耕优先市场。我要求团队放慢开店节奏，除非你有 100% 的信心。下半年，我们将首先专注于经营好现有的 800 家海外直营店，待单店模型跑通后再复制。

海外市场是我们的广阔天地，短期波动不会改变长期增长趋势。我们已经纠正了过去过度强调出货量和门店数的增长方式，让终端销售增长、库存周转与总部出货重新形成健康的闭环。现在也正是我们真正提升海外市场表现的时候。我们的海外业务目前处于盘整阶段（holding stage）。

我们需要打磨店型，更重要的是确保中国的转型能在国际市场成功验证。国际市场到了再一次升级的时候。我们已经做了重大的调整与变革。我想借这个机会鼓励海外团队。从 2015 年至今，我们的海外征程已走过 11 年。越往海外深处走，我越深切地体会到，一家中国公司要在海外真正站稳脚跟、获得可持续利润有多么困难。

这不仅是产品力和供应链的问题，还涉及组织能力、管控模式和本地化战略。名创优品的海外业务从第一天起就是盈利的。但我们必须认识到，今天海外的挑战恰恰标志着名创的全球化进入了深水区。随着直营业务占比上升，我们必须再次沉淀，追求精细化运营、本地化、更强的组织能力和全球化的管控模式。

在夯实管理基本功的同时，我们看到许多国际消费品牌过去十年在中国做得很好，但近几年开始亏损。所以，无论是国际品牌进入中国，还是中国品牌走向国际，都必须具备适应性，否则利润就无从谈起。这也是每一家走向国际化的公司都必须面对的「二次升级与转型」。

名创优品过去几年的中国转型取得了巨大成功，我们初步实现了品牌升级与商业模式迭代，中国业务开始迸发新的活力。海外业务今天面临的挑战，本质上与中国三年前相同：从规模优先转向质量优先。过去三年，中国交出了转型答卷——从跑马圈地，到 wonderland 式的升级，再到精细化运营。

002129 TCL中环 — 数据目录

DB 表

数据库文件: data/002129.db，共 9 张表（定义见 fetcher.py:_init_tables）。

revenue_structure 表

列 类型 说明
code TEXT (PK) 股票代码
year TEXT (PK) 财年
dim_type TEXT (PK) 拆分维度
dim_name TEXT (PK) 维度下的条目名
amount REAL 金额（亿元）
pct REAL 占比（%）

联合主键 = (code, year, dim_type, dim_name)

已存在的维度

dim_type 条数 年份 说明
by_product 21 2021-2025 产品拆分（光伏硅片/组件/半导体材料/电站/其他）

查询示例

-- 查某年全产品拆分
SELECT dim_name, amount, pct
FROM revenue_structure
WHERE code = '002129' AND year = '2025'
ORDER BY amount DESC;

-- 查某产品历年趋势
SELECT year, amount, pct
FROM revenue_structure
WHERE code = '002129' AND dim_name = '半导体材料'
ORDER BY year;

摘要

核心话题：大店与 IP 双引擎 · 会员化转型 · 印尼与美国市场 · 关税与通胀的对冲 · 自有 IP 进入收获期

一句话核心：收入 +28.5% 超指引上限、中国内地连续第五季加速，但毛利率 −0.9pp、调整后经营利润率 14.7%（去年 16.6%）；利润表上 +114% 的经营利润主要来自 MiniMax 投资的 8.7 亿元公允价值收益，剔除汇兑后的真实经营利润增速是 +14.3%。

关键数据：

  • 收入 56.88 亿元（+28.5%），GMV 101 亿元（+26%）；超原指引 +25%
  • 剔除汇兑的调整后净利 6.33 亿元（+8%）；经营现金流 +40%、自由现金流 +36%
  • 中国内地 32.3 亿元（+29.6%），连续第五个季度加速，近 9 个季度最高同比；同店高个位数增长
  • 海外 19.4 亿元（+22%）；TOP TOY 5.1 亿元（+51.4%）
  • 门店 8,500+：MINISO 8,210（净增 722；中国 +318、海外 +404 → 3,617）、TOP TOY 355（海外 39）
  • 主题店（LAND / SPACE / FRIEND）44 家，季末将达 61 家覆盖 32 城；主题店+旗舰+大店占门店数 12%，贡献销售 30%
  • 毛利率 43.3%（−0.9pp）；销售费用率 24.5%（+1.6pp），其中广告 +74%（占收入 3%）、物流 +43.5%、授权费 +42%（占 2.4–2.6%）
  • 调整后经营利润 8.4 亿元（+14.3%），利润率 14.7%（去年 16.6%）
  • 库存周转 101 天（去年 102）；中国 67 天（83）、海外 254 天（208）
  • 现金 70.5 亿元；累计股东回报 62.3 亿元，本期派息 1.16 亿美元
  • 指引：全年收入高双位数、2023–2026 CAGR ≥22%、净开店 450–500；H1 收入 +20~22%、净开店 210–230、中国同店中个位数、北美同店高个位数至低双位数

核心矛盾：

  1. 报表利润 vs 经营利润：经营利润 +114.3%、期内利润 +199.7%，但核心经营口径只 +14.3%——差额几乎全部来自 MiniMax 的 8.7 亿元未变现收益，管理层自己强调"不代表核心经营"
  2. 收入超预期 vs 利润率下滑：收入超指引 3.5pp，调整后经营利润率却降 1.9pp；直营收入 +50%、相关费用 +35%，"DTC 店层经济性在优化"与"集团利润率下降"并存
  3. 中国强 vs 海外弱：中国 +29.6% 且加速，海外只 +22%；印尼虽有会员创新但仍是"修修补补"，美国要靠涨价对冲关税
  4. 大店红利刚开始 vs 基数已抬高：管理层说渠道升级"才刚开始释放"，但华泰直接问"基数抬升后怎么持续"，叶国富只能拿五一数据（销售高双位数、进店率 +4.1%）应对

跟踪要点：

  1. MiniMax 收益的一次性：8.7 亿公允价值收益已剔除出调整口径，但市场容易误读 +114% 的经营利润；后续若股价回落会反向冲击
  2. 美国差异化提价：5 月起对高频高周转单品（如 T 恤）先行提价，管理层称 5 月毛利率已环比改善——这是关税对冲成色的直接检验
  3. 海外库存 254 天（去年 208）：管理层归因于开店备货与物流不稳，若 H2 去化不利，会压毛利
  4. 会员贡献 60%→73%：中国增长已转向会员复购驱动，需盯**新客首购占比 6%→11%**能否延续
  5. 欧洲 DTC 拐点：德国 10+ 店整体经营利润率已达双位数、波兰超预期，是"中国经验可复制"的第一个海外样本
  6. YOYO 的 IP 势能：6 个月销售破 1 亿、登上 Met Gala / 巴黎时装周 / 春晚，是自有 IP 从"卖货"转向"品牌资产"的首个证据

二、CEO 叶国富：战略执行、印尼与美国、下半年展望

叶国富（创始人兼 CEO）：大家好，欢迎参加名创优品 2026 年 3 月季度业绩电话会。本季度收入接近 57 亿元，同比增长 28.5%，超过我们此前指引的上限。剔除汇兑损益的调整后净利润为 6.3 亿元，同比增长 8%。经营现金流增长 40%，自由现金流增长 36%。

我不打算逐项念财务数据，Eason 会在 CFO 环节带大家看详细数字和展望。我想聚焦三个方面：第一，战略执行——我会在这里多花点时间，因为执行的细节才能真正说明一家公司要往哪里走；第二，大家最关心的两个海外市场：印尼和美国；第三，我对下半年的看法。

1. 战略执行：大店、IP 培训、渠道升级

先说战略执行。去年我提出了门店升级战略，我们走在这条路上。名创品牌在中国门店数增长 318 家，增长不到 10%，但线下门店 GMV 增长 25%。这两个数字最能说明问题。

第一，本季度加盟商的利润占比达到近几个季度的最高水平。加盟商是自己掏钱在干，所以他们的损益表是最诚实的信号。盈利能力创新高，说明大店模式不是在让加盟商承担风险，而是在帮他们赚钱。

第二，我们收到了数千份新店申请，其中一半要求开大店或旗舰店。过去是我们去说服加盟商开大店，现在是他们在抢这些机会。这种转变是市场对我们大店模式信心最直接的投票。

4 月 18 日，MINISO SPACE 和 MINISO LAND 在三亚免税城（CDF Mall）同时开业。免税城历来是奢侈品和美容品牌的地盘，客流密度与消费力在所有顶级零售场景里最高。我们能进去，本身就说明了品牌资产。更重要的是，我们带去的是别人给不了的东西——沉浸式 IP 体验，把潮流文化带进免税商场，为场所带来增量客流与停留时间。

经营大店真正的壁垒不是资本，是内容密度。在一个 1,000 平方米的空间里，你能不能让顾客愿意留下来、不想走？这取决于我们十年积累的三样东西：150 多个全球 IP 的授权、2,000 家全球供应商网络，以及每周都能换新的供应链。这三样才让我们真正脱颖而出。

同时，我们在系统性地关闭表现不佳的门店——那些开了很多年、面积不到 200 平方米的老店；同时升级加盟商结构，淘汰实力较弱的伙伴，引入更强的新伙伴。这就是我们门店与渠道战略的实质。

2. IP 运营是组织能力，不是一套 SOP

很多人想知道我们的 IP 战略是怎么落地的，这点很重要。今年一季度，我们在广州总部启动了 IP 运营培训项目，把区域经理、华南门店代表和各职能团队聚在一起。这不是课堂式培训——我们把 MINISO LAND 门店当作实战训练场，在真实门店环境里拆解运营。课程覆盖 IP 理解、故事讲述、运营执行和数据能力，从底层逻辑到实操体验全部走一遍。

为什么这很重要？因为 IP 运营是一种组织能力，不是一套 SOP。菜单写得再好，如果加盟商和店员只是机械照做，结果不会好。只有人们真正理解 IP 在哪里打动了消费者，战略才能落地。这能把 IP 运营从"总部的一个故事"变成整个网络的肌肉记忆。

3. 自有 IP：YOYO 进入收获期

4 月 8 日，我们结束了海外订货会。这次的主角是 YOYO，一个我们从零自建的自有 IP。自有 IP 站到 C 位本身就是一个信号——我们的自有 IP 已经能够在商业上独立行走。来自分销商和海外客户的强劲订单量，是对我们 IP 和产品信心最诚实的投票，比任何市场数据都更有说服力。

YOYO 上市 6 个月销售突破 1 亿元。4 月，它登上了 Met Gala——所谓时尚界的奥斯卡，这个舞台历来属于奢侈品牌和国际明星。一个中国的原创 TOP TOY IP，以配饰形式与国际明星同场出现，并被作为活动礼品呈现。这不是营销，YOYO 是靠自己的实力赢得全球时尚聚光灯下的位置。

从央视春晚，到巴黎时装周，再到纽约 Met Gala，YOYO 用 6 个月走完了很多 IP 十年都走不完的路。这是从孵化、设计、运营到全球落地的全链路 IP 能力。YOYO 的成功不是偶然，它是一个信号：自有 IP 战略正在进入收获期。

4. 组织能力建设：标准化、标杆复制、师徒制

本季度名创集团整体收入突破 200 亿元（累计口径），我们也有很好的业务延展方式。关键问题在于：组织能力能不能跟上。组织能力建设是我们在上一轮投入中做的事，它不会立刻体现在财务上，但会体现在长期发展上。

我们推进了三件事。第一，标准化：总部制定了运营与商品手册，通过视频案例和现场培训，确保各市场理解与执行一致；各市场也建立了区域管理培训，定期为店长和主管开课。第二，标杆与快速复制：选定关键试点项目，一旦验证成功就快速复制到其他市场。第三，师徒制：让有结果的资深运营者带新人，实现代际传递。

这套体系意味着，我们的海外能力不再依赖某一个个人，而是成为组织自身可以生长的东西。市场越多、门店越多，组织能力的复利效应可能越大。深度组织能力加上 IP 驱动的产品，这两点给了我们对海外长期增长的强烈信心。

5. 印尼：从流量驱动转向复购驱动

印尼和是美国是大家最关心的两个市场，我分别更新一下。

印尼一直是我们国际化进程中最引以为豪的市场之一，未来也必须如此。印尼不只是一个市场——它年轻的人口结构和活跃的消费环境，是我们会长期投资的市场，它也为全球团队树立了信心示范。我们必须把它做对。

当然，业务发展到一定规模后遇到一些波折是完全正常的。最困难的时候已经过去了，我们已经有了清晰的路径：

  • 渠道：总部成立了专门的谈判团队，主动争取核心位置，并筛选需要迁址的门店
  • 商品：放弃"一刀切"，做分层
  • 产品运营：总部直接支持，强化本地 IP 执行与定制化商品计划
  • 组织：明确职责分工——总部主导战略，本地团队聚焦日常运营
  • 会员：我们意识到必须真正把生意从流量驱动转为复购驱动

会员这块我多说两句。我们注意到印尼消费者在每月月底到店有明显高峰，与当地发薪周期吻合。于是我们做了"发薪日会员权益"活动。结果很清楚：参与会员活动的客流比普通会员日高 80.5%，复购率与购买频次都提升了。斋月期间参与度进一步攀升，说明这已经成为消费者的真实习惯。

全年来看，印尼贡献了稳健的利润。我相信随着我们对活动的调整，今年的盈利能力会明显好于去年。更重要的是，当会员与复购成为增长的主要引擎时，增长的质量会更高。我对印尼真的很有信心。

6. 美国：关税与通胀是我们的机会

再谈谈北美，这是另一个热点。之前我已经讲过店型与战略更新，今天我想回答两个问题：关税，以及通胀压力下的消费者行为。我认为这两件事对名创是机会。

第一，我们的价格带给了结构性优势。美国的核心价格区间大约是 5–25 美元。在这个区间里，驱动购买的是情感连接，是 IP——"我喜欢所以我买"；同时 5–25 美元本身很有吸引力；而一个专门来找某个 IP 商品的消费者，不会因为小幅涨价就走掉。关税和通胀确实会转化为价格弹性，但对我们来说，传导方式不一样。

第二，名创的供应链能力进一步升级。我们建立了本地化、专业化的商品团队，同时改善整条供应链，包括产品、战略和供应商开发。凭借强大的跨职能与供应链协同，我们推出了首个（本地直采）项目，帮助提升供应能力。

第三，我们的全球布局能真正支撑美国业务。我们在全球 120 个国家和地区经营。任何一个市场跑通的门店模型、验证过的 IP 打法，都可以快速复制到全球；同时，稳定的现金流与规模经济，也给了我们投资美国市场的信心和资源。这种全球互补的框架，我们的竞争对手没有。

第四，关税和通胀是周期性、短期变量，它们会来也会走；而消费者对 IP 情感体验的需求是结构性的，不会因为短期波动而消失。对强公司来说，扛住核心压力同时也是增长机会——这轮压力会加速行业洗牌，让真正有差异化的品牌站出来。在美国，我们就是那个有差异化的品牌。

7. TOP TOY

再说 TOP TOY。2026 年第一季度，TOP TOY 收入增长 51%，门店净增 21 家至 355 家，其中中国 316 家、海外 39 家。

本季度我们推出了新的自有 IP（转录不清）以及自有 IP 主题店，Nomi 领衔的 TOP TOY 自有 IP 组合表现突出。产品组合日趋成熟，自有 IP 正在被市场验证。

本月底，我们宣布赵露思出任 TOP TOY 全球品牌大使，她在年轻消费者中的影响力与认知度，将帮助我们加速触达更多年轻客群。

8. 下半年展望：四个驱动

接下来讲我对下半年的看法，有四个驱动。

第一，会员是同店增长最重要的杠杆。 数据说得很清楚：2026 全年口径，会员贡献了总销售的 60%；到 2026 年第一季度，这个数字升到 73%。换句话说，名创中国近四分之三的生意来自会员。背后有两个结构性变化：一是复购贡献持续提升，本季度复购已占会员销售的 60%；二是新客获取在加速，新会员的首购贡献从 6% 升到 11%——这说明我们把新消费者转成会员时，新会员的质量也在提高。当 70% 以上的生意来自你可以直接触达和互动的消费者，增长就从机会驱动转向系统驱动。这就是我们对下半年复购与扩张有信心的底层逻辑。

译者注：此处原文另有一句 "consumer accounted for 79% of the total sales for us"，与上文的 73% 口径冲突、语义不明（疑为 ASR 错录），未并入正文，存此待核。

第二，渠道升级的红利才刚开始释放。 全年我们计划新开接近 500 家大店，MINISO LAND 与旗舰店占比继续提升。

第三，北美与欧洲将在下半年进入收获期。 我们在美国和加拿大开的店质量很高，这一批店将进入成熟期，贡献高质量的同店增长和利润率改善。

第四，2026 年是 IP 密度最高的一年。 进入夏季旺季，我们排了一大批重磅 IP 产品。

9. AI：效率放大器

最后，本季度我们确实看到了此前在 AI 领域投资的一些回报。但我坚信，更大的奖品在于 AI 能给核心业务带来的效率提升。

强大的管理能力会被 AI 放大。AI 的技术红利会先流向那些已经具备高执行纪律和强学习能力的组织，我确信我们会继续借助 AI 支持这样的组织。对我和团队来说，我们正在加深对 AI 的理解，也在持续建设 AI 能力。

名创优品是什么？名创优品是一个高密度运营组织——每年推出数千个新 SKU，管理 8,000 多家门店，横跨 100 多个市场与地区。对这样的组织，效率是刻在 DNA 里的。

数据说得很清楚：会员的消费明显高于非会员，会员销售占比越高，整体业务的质量与生产力越高。过去几个月，我们的会员占比从 60% 提升到 70% 以上，主要由新客获取驱动。今年上半年我们主抓获客，下半年主抓复购，两者结合就能完成会员增长的飞轮。

看城市层级，我们观察到各层级都有正向的消费潜力释放，所有城市层级的同店都是正增长：省会城市由大店和顶级 IP 驱动；新一线城市由渗透率提升与获客驱动，增长相当健康。

春节期间我们推出了"潮玩下乡"策略，把名创的 IP 产品与主题店体验带到县域市场，帮助县域同店做到双位数增长。这说明对 IP 与潮玩的情感需求覆盖的人群远比想象中广——县城的年轻人也有同样的需求，只是过去没有足够的供给。这也说明名创品牌已经覆盖了不同的消费人群。中国市场的深度远超市场普遍认知。

Q5 同店基数抬升与持续增长策略（华泰证券 Huatai）

Shi Di（华泰证券）：能听到我说话吗？

叶国富：可以，很清楚。

Shi Di（华泰证券）：我是华泰证券的施迪。我有个关于中国同店销售的问题。我们看到本季度公司在同店上表现很好，但接下来几个季度基数在抬高。管理层如何评价基数上升后的单季表现？有哪些策略和手段可以维持同店增长？

叶国富：你说得对，基数确实在上升，但我们有清晰、系统化的策略。

先分享几个五一期间的数据：国内销售实现高双位数增长，跑赢主要竞争对手；单店日均销售创下节假日历史新高，甚至高于今年春节假期的日均水平。第三方数据显示，五一期间行业客流整体承压，但我们的进店率提升了 4.1 个百分点，单店客流也在增长——说明我们在逆风中拉到了客流。分品类看，玩具、数码配件和旅行品类增长 25%，这是很不容易的结果。

在维持同店增长上，我们有如下策略：

  • IP 联名：持续做差异化、高频率的发布。例如我们锁定了 F1 的全球独家授权，加上迪士尼联名；5 月到 6 月有多个礼赠节点——母亲节、儿童节、父亲节和 520
  • 我们已经根据礼赠数据搭建了专门的商品与活动方案，用来提升客单价
  • 运营：在门店层面开展客流竞赛，进一步赋能门店
  • 供应链：持续改善，即便在五一假期也能把握住销售窗口

所以即便基数在抬高，我们有多元化的工具箱，有信心继续交出强劲的同店表现。

Q6 自有 IP 的利润率与商业模式（中信证券 CITIC）

Xiaofang Xu（中信证券）：抱歉，我的线路有些技术问题。我有个关于自有 IP 的问题。过去半年，我们看到自有 IP 开始出现在中低线城市的门店里，设计相当有意思。能否分享一下你们的自有 IP 情况，例如 YOYO，以及（转录不清）和 Kumaru？

叶国富：这个问题问得很好，我展开讲。

第三方授权 IP 和自有 IP 看起来卖的是同一种商品，但底层逻辑不同。

从毛利率看，自有 IP 产品相比授权 IP 有更高毛利，但最关键的还是底层逻辑——自有 IP 最具排他性、绝对差异化。如果你想维持毛利率，就必须有自有 IP。定价权、运营的自主性，以及自有 IP 的整条价值链，完全掌握在我们手里。它也提供了长期的高毛利护城河。

但你还要思考如何多元化变现。一个成熟的自有 IP 不只是卖货：你可以把 IP 再授权给第三方，可以跨多种业态运营，还可以驱动内容生产、升级 IP 能力——这些都是极高毛利、且会随时间复利的商业模式。

YOYO 出现在 Met Gala、进入时装周，反映的是品牌价值的（提升），而不只是卖商品。 我们在建设自有 IP，也是在建立一个完全不同量级的商业模式——这是名创长期利润结构最重要的升级。

叶国富：谢谢。欧洲今年同店持续正增长，领先品类是潮玩（转录不清）。这也是我们做国际化的原因——我们不是把别人已经在卖的商品搬过去，而是把 IP 潮玩的消费场景带过去，创造新的需求。

渠道升级同步推进，Land 店型将在今年上半年落地。

盈利能力方面，波兰和德国是强有力的证明：这两个直营市场都超出预期，门店层面与市场层面的经营利润率都达到双位数；德国 10 多家门店的整体经营利润率已稳定在双位数，其他市场正在爬坡。

Q8 美国大店模型与会员复购（国泰海通 Guotai Haitong）

分析师（国泰海通）：我有个关于美国的问题。看起来你们在美国经营大店型已有一段时间。能否介绍一下运营细节与运营结果？另外，美国会员的购买频次如何？随着大店铺开，频次是否在提升？

叶国富：谢谢，吴女士。

正如我一再强调的，这就是我们正在做的事。过去两三年，名创持续在当地构建（中国以外）最大的日用品 DTC 网络。从 2024 年 1 月起，我们开始探索大店。在此之前，我们 2017 年进入美国市场，当时大部分门店开在购物中心里；从 2024 年 1 月开始，我们开出（新形态）门店，并逐步建立对（大店）的理解。

到今年年初，我到美国巡店，发现我们的（大店）已经进入 2.0 版本阶段。2.0 版本意味着什么？我们的 2.0 门店完全不挑商圈——在普通商圈里，好的大店单店销售与坪效依然表现良好。相比 1.0 版本门店，2.0 版本的盈利能力更好。

我们已经给过你们美国单店盈利模型：总体而言，美国单店回本约 1 年；2.0 版本门店的回本周期已控制在 1 年以内。 对名创来说，我们做长期生意、坚持长期投资。2.0 门店提供了超预期的同店表现，并且是可持续、持续改善的。换句话说，不久的将来，美国 2.0 门店可以复制到更多城市、更多商圈——它是被验证的成功，能帮我们继续释放美国市场的潜力。

第二个问题，关于会员销售数据。在中国，我们有非常成熟完善的 CRM 运营体系，因此可以把中国会员管理的成功经验延展到美国。过去一年，美国会员带来的销售增长非常显著。 中国从 2018 年开始做会员，到 2021 年会员销售超过总生意的一半，用了 5 年；而在美国，我们只用 1 年就做到了。你也可以看到，美国消费者的复购率不亚于中国会员。所以我们相信今年的门店效率会非常健康，我们对此有充分信心。

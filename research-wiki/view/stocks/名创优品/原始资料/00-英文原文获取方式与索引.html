二、两类来源的 URL 规律（便于补齐未来场次）

1. AlphaMadera（覆盖 17 场，主力来源）

https://alphamadera.com/stock/MNSO/transcripts/{财年}/{季度序号}/raw
  • {财年} = 该场所属财年的结束年，{季度序号} = 1–4
  • 财年错位注意：名创有一段时间以 12 月为财年结束（如 FY2023 Q1 是 2022-11 那场）， 后来改按自然年。所以 会议日期所在年 ≠ URL 里的财年，务必照上表核对
  • 页面为 raw transcript，需保留 [indiscernible] 等占位符才算完整

2. 公司官方 IR Full Script PDF（覆盖 2 场）

https://ir.miniso.com/image/FQ1%2721+Scripts.pdf          ← 早期命名（FY + 财季 + Scripts）
https://ir.miniso.com/image/MINISO+2024+Mar+Quarter+Transcript.pdf   ← 后期命名（MINISO + 年 + 月英文 + Quarter + Transcript）

命名规律随年份变化，两者都试；IR 站点会重定向到 filecache.investorroom.com。

3. Motley Fool（覆盖 2021 年 2 场）

https://www.fool.com/earnings/call-transcripts/{YYYY}/{MM}/{DD}/miniso-group-holding-limited-mnso-{q}{N}-{YYYY}-earnings

slug 里的 q1 / q4 用的是自然年季（例如 2021-05-19 那场在 slug 里是 q1-2021），与公司自己的 FY 编号不一致。

三、从 git 历史取回（无需联网）

英文原文最后一次存在于 commit 4834c96。

# 取单场（示例：2025-11-21）
git show 4834c96:"research-wiki/raw/research/名创优品/2025-11-21-Q32025业绩电话会逐字稿.md" \
  > 2025-11-21-Q32025业绩电话会逐字稿.md

# 一次性取回全部 23 份
git checkout 4834c96 -- research-wiki/raw/research/名创优品/

若将来仓库重写了历史导致该 hash 失效，先 git log --diff-filter=D -- "research-wiki/raw/research/名创优品/*逐字稿.md" 找到删除前那个 commit 再取。

四、引用这批材料时必读

  1. 全部为英文同传转录，管理层中文原话没有公开文本；所谓"引述"都是译自英文口译
  2. 2020-12-18、2024-05-14 两场是官方会前讲稿，不是逐字稿，文末止于 we are now ready to take questions，没有问答
  3. ASR 错词、数字串行普遍存在。引用数字前必须回业绩公告 / PPT / 6-K 对账； 本批译本中已标注的存疑点见各篇的译者注
  4. 2024-05-14 的问答部分由「天风海外」的交流纪要以中文补齐（另存同目录）

# 紫金矿业 (02899) — 有色金属矿业产业链全景

## 紫金矿业在产业链中的位置

紫金矿业处于**有色金属产业链最上游**——矿产资源勘查与开采，并向中游冶炼加工延伸。核心壁垒在于"找矿 + 采矿"的矿权和技术能力。

```
上游                              中游                              下游
──────────────────────────────────────────────────────────
勘探 & 开采                        冶炼 & 精炼                        终端应用
  │                                 │                                │
  ▼                                 ▼                                ▼
地质勘查(自主勘探)          ──▶  铜冶炼(电解铜)              ──▶  电力/电网(铜)
露天/地下开采                     黄金精炼(标准金锭)                 新能源汽车(铜/锂)
矿石破碎/浮选/堆浸                锌冶炼(锌锭)                       建筑/基建(铜/锌)
采矿权/探矿权                     锂盐加工(碳酸锂/氢氧化锂)           储能(锂)
                                                                     电子/光伏(银)
                                                                     央行储备/首饰(金)
```

**紫金矿业的独特性**：同时具备"找矿+采矿+冶炼"一体化能力，且以上游采矿为核心利润来源（冶炼利润薄）。对比同行：江西铜业强在冶炼（外购矿），紫金强在自有矿山（成本优势）。

## 一、上游：资源储量与勘探

### 全球矿山布局

| 矿种 | 主力矿山 | 地区 | 产能状态 |
|------|------|------|------|
| **铜** | 卡莫阿-卡库拉 | 刚果金 | 一期+二期满产，三期建设中 |
| **铜** | 巨龙铜矿 | 中国西藏 | 一期满产，二期扩产 |
| **铜** | 塞尔维亚铜矿 | 塞尔维亚 | 运营中 |
| **金** | 哥伦比亚金矿 | 哥伦比亚 | 南美最大金矿之一 |
| **金** | 巴布亚新几内亚 | 大洋洲 | 运营中 |
| **金** | 紫金山金铜矿 | 中国福建 | 成熟矿山 |
| **锂** | 阿根廷盐湖 | 阿根廷 | 一期投产爬坡 |
| **锂** | 湖南锂矿 | 中国湖南 | 在产/爬坡 |

### 核心竞争力：自主勘探能力

紫金的基因是"地质找矿"。与同行买成熟矿山不同，紫金偏好：
1. 低价收购被低估的矿权
2. 自主勘探增储（边采边探，储量越采越多）
3. "矿石流五环归一"工程管理模式 → 快速建成低成本矿山

卡莫阿铜矿收购时仅 200 万吨铜资源量，经紫金勘探后增至 4,300 万吨，堪称教科书级案例。

（来源：年报 MDA 文本、行业公开报道）

## 二、中游：冶炼与精炼

| 产品 | 冶炼方式 | 终端产品 | 交易所注册品牌 |
|------|------|------|------|
| 铜 | 火法冶炼 → 电解精炼 | 电解铜（99.99%） | SHFE + LME |
| 金 | 氰化浸出 / 堆浸 → 精炼 | 标准金锭 | SGE |
| 锌 | 湿法冶炼 → 电解 | 锌锭（99.995%） | SHFE + LME |
| 锂 | 盐湖提锂 / 锂矿提锂 | 碳酸锂 / 氢氧化锂 | — |

**冶炼利润远低于采矿**。紫金的冶炼产能主要配套自有矿山——把矿石变成可交易的标准金属产品。电解铜、锌锭均为 LME/SHFE 注册品牌，流通性高。

## 三、下游：终端需求

| 金属 | 核心需求 | 需求趋势 |
|------|------|------|
| **铜** | 电力电网（40%）+ 建筑（20%）+ 新能源车（10%+）| 📈 能源转型 = 铜需求结构性增长 |
| **金** | 首饰（50%）+ 央行储备（20%）+ 投资（15%）| 📈 央行购金创纪录 |
| **锌** | 镀锌钢（60%）+ 合金（15%）| ➡️ 成熟需求 |
| **锂** | 动力电池（60%）+ 储能（20%）+ 消费电子 | 📈 长期增长确定性高 |
| **银** | 光伏（15%）+ 电子 + 首饰 | 📈 光伏用银增长快 |

### 铜的需求叙事（最重要）
- 一辆电动车用铜 ~80kg（燃油车 ~23kg）
- 1GW 光伏用铜 ~5,000 吨
- 全球铜矿资本开支 2013 年见顶后持续不足 → 供给缺口扩大
- 铜矿从发现到投产平均 13 年 → 短期内新供给极为有限

（来源：行业公开数据、IEA 报告）

## 四、竞争格局

| 梯队 | 企业 | 特点 | 紫金对比 |
|------|------|------|------|
| **全球巨头** | BHP、力拓、Freeport-McMoRan | 百年老店，全球顶级矿山 | 规模较小但增速最快 |
| **中国龙头** | **紫金矿业** | 金铜为主 + 锂布局，成长性最强 | — |
| | 洛阳钼业 | 铜钴为主，刚果金布局 | 矿种侧重不同 |
| | 江西铜业 | 铜冶炼为主，自有矿山少 | 紫金在上游，江铜在中游 |
| | 山东黄金 | 纯金矿企 | 紫金多矿种分散风险 |
| **细分** | 天齐锂业、赣锋锂业 | 纯锂矿企 | 紫金锂板块较小但成长中 |

### 核心判断

**矿业是成本曲线决定胜负的行业**。紫金处于全球铜矿成本曲线最左端（前 25%），意味着：
- 铜价跌 30%，竞争对手亏损停产，紫金仍盈利 → 供给出清时紫金份额提升
- 铜价涨 30%，紫金利润弹性远超同行（低成本 × 高杠杆）

## 五、行业周期与关键变量

```
铜周期：  资本开支不足(2013-) → 供给缺口扩大 → 铜价上行 → 利润爆发
金周期：  去美元化 + 地缘风险 + 降息 → 金价上行结构性（非周期性）
锂周期：  过剩(2023-2024) → 出清(2025+) → 供需再平衡 → 价格反转
```

### 关键跟踪变量
- LME 铜价 / COMEX 黄金价格（核心变量）
- 全球铜矿 TC/RC 加工费（冶炼端供需信号）
- 卡莫阿、巨龙铜矿季度产量（产能兑现验证）
- 碳酸锂价格 + 阿根廷盐湖产量（锂板块拐点）
- 全球铜矿资本开支趋势（长期供给预判）
- 各国央行黄金储备变化（金价结构性支撑）

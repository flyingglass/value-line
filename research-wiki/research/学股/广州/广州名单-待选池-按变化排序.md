# 广州名单 · 待选池「按变化排序」（35 家）

> **来源**：对 [[学股/广州/广州名单-待选池跟踪表]] 既有定性的**重排**，不新增任何数据、不改行业分类。
> **排序维度**：里海 2444 的「**变化**」关——是否正在发生变化、变化力度如何、**变化是否已被市场定价**。
> **用途**：与按行业分组的原表互补。原表回答「同行业有哪些」，本页回答「哪个变化最值得先动手」。
> **重排日期**：2026-09-22

---

## 一、分档口径（变化维度）

| 档 | 含义 | 判定要点 |
|---|---|---|
| **A** | 变化可用 | 变化真实 + **尚未被定价**（位置仍在底部区或未被资金关注）→ 最值得优先核 |
| **B** | 变化大但**已被定价** | 变化力度确凿，但股价已在高位 / 估值已透支 / 机构已覆盖 → 等回撤到底部区再议 |
| **C** | 题材与基本面脱节 | 炒作主线在报表上找不到对应（收入占比极小或利润拐头向下）→ 变化存伪 |
| **D** | 变化在发生但**成色待验** | 变化方向对，但增收不增利 / 一次性成分 / 关键数据未复核 → 先补数据再定性 |
| **E** | **外生变量主导** | 利润由价格（钾价/锂价/运价）或政策（集采/医保）决定，不是公司自身变化 → 按周期位置而非「变化」处理 |
| **F** | **慢变量** | 提结构 / 降本增效 / 分红型，变化「不大、不远、全市场看得清」→ 变化关偏弱 |
| **G** | 未扫 / 变化未知 | 尚未扫描，无定性依据 → 先扫再定档 |

> 档内顺序沿用原表行业顺序（基础化工 → … → 媒体及娱乐），**行业归属一律不变**。
> 「定价状态」栏是本档位的核心判据：里海的变化关要求变化**尚未**被定价，故 A 与 B 的分界不在变化大小，而在位置与估值。

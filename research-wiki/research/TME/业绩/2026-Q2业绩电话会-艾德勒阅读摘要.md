# TME 2026Q2 业绩电话会 — 艾德勒四级阅读法摘要

## 第一级 · 检视阅读

- **文件性质**：一手资料（公司 IR 官网发布的业绩电话会议管理层陈述逐字稿），中文翻译版；**仅含 prepared remarks，无问答环节**
- **来源**：TME 投资者关系官网 PDF（`https://ir.tencentmusic.com/download/TME+Transcript+2Q26.pdf`），会议日期 2026-08-11
- **发言人**：彭迦信（执行董事长）、梁柱（CEO）、胡敏（CFO）、Millicent Tu（IR 负责人）
- **一句话定位**：喜马拉雅并表后的首份完整业绩叙事——TME 在广告逆风下靠"内容+平台"双引擎（音乐+音频）、IP 消费服务与 SVIP 会员维持增长，总收入 +6%
- **是否值得精读**：值得。喜马拉雅并表是战略转折点；广告承压与增速放缓（+6%，低于音乐相关服务 +11%）是关键信号，为后续季度对比建立基线

## 第二级 · 通读全书

**结构骨架**：三段式管理层陈述
1. Cussion（内容生态）：经典曲库增长 → 深度合作（梦想音乐、华策、儒意、浙江卫视）→ 自有内容 → 喜马拉雅自制能力 → 艺人经纪与演出周边（GAI、袁娅维、张新成、THE BLACK LABEL、SMTR25、TIMA）→ 版权保护与青少年模式
2. Ross（产品与生态）：内容发现与 3D丽音 → AI 代理 → 腾讯生态（微信视频号/微信支付/小微、车载、鸿蒙）→ 喜马拉雅整合 → SVIP 多维权益（数字专辑、小卡、NFC、星光卡、游戏 IP 联动）
3. Shirley（财务）：收入 +6% → 会员 +8% → 广告逆风 → 毛利率 44.2% → 费用率 14.5% → 利润与回购

**主线（因果链）**：广告逆风 + 竞争加剧 → 收入增长主要靠音乐相关服务（+11%）与 IP 消费服务对冲 → 喜马拉雅并表补充内容宽度、提供新增长点（含对广告的正贡献）→ SVIP 与腾讯生态是中长期抓手 → 短期利润率受并表摊销压制

## 第三级 · 分析阅读

**核心论点与逐条检验**：

1. **"喜马拉雅并表是内容+平台战略的里程碑，音乐+音频形成综合平台，潜力尚处早期"**
   - 证据：并表单季贡献收入约4亿元；自制网络小说前十占9席；对广告收入"正贡献"；SVIP 已开始接入音频内容
   - 检验：**部分有据**。收入贡献与自制能力有具体数据支撑；但"协同潜力"（广告交叉销售、SVIP 音频融合）均为定性前景陈述，无量化目标，无法独立验证

2. **"IP 相关消费服务（演出、周边）是第二增长引擎，两位数增长"**
   - 证据：SMTR25 三场澳门见面会、TIMA 迁启德容量+3倍、GAI 体育场巡演、周深/蔡徐坤/陈楚生/蒲熠星实体专辑、周杰伦《太阳之子》数字专辑、THE BLACK LABEL 投资
   - 检验：**方向可信，力度不可考**。案例丰富但**未披露营销与消费服务/线下演出的绝对收入**，而该分项内含承压的广告业务，需防"结构对冲"掩盖真实增速

3. **"SVIP 多维权益驱动用户基数、ARPPU、时长、留存增长"**
   - 证据：数字专辑+定制套餐（黄仁俊、张艺兴、aespa、RIIZE）、星光卡新增 THE BLACK LABEL 艺人、游戏 IP 联动
   - 检验：**弱证据**。全程无任何 SVIP 用户数/ARPPU/留存数字，仅有定性描述。此论点依赖公司未披露的内部数据，是本次逐字稿最大的信息盲区

4. **"广告业务承压，但正通过曝光、入口率、ECPM 和腾讯生态合作应对，喜马拉雅带来正贡献"**
   - 证据：管理层明确承认"广告支持模式面临逆风"；采取的措施为定性描述
   - 检验：**坦承但回避量化**。这是管理层主动承认的唯一负面点，但**未披露广告收入金额/下滑幅度**，无法判断逆风烈度与企稳时点

5. **"毛利率 44.2% 保持行业竞争力"**
   - 证据：毛利率微降归因于收入结构（线下演出占比上升）；喜马拉雅并表（含购买会计摊销）对毛利率"有利影响"；线下演出成本效率改善
   - 检验：**表述需谨慎**。毛利率口径下"并表有利"与费用率口径下"并表推高摊销"并存，说明喜马拉雅贡献主要在毛利率端，而摊销冲击落在费用端；44.2% 属微降，行业竞争力对比缺乏外部基准

**管理层坦承无法回答的问题**：广告何时企稳、喜马拉雅协同的量级——均未给出。

**本次逐字稿无法回答（需正式财报/其他来源补充）**：SVIP 用户数与 ARPPU、付费用户与 MAU、广告收入绝对值、喜马拉雅并表对价与摊销规模、竞争对手是谁。

## 第四级 · 比较阅读

**可比来源（建议，均需另行获取后核对）**：
- TME 2026Q2 正式财报 Press Release（含用户指标、分业务收入明细）
- TME 历史季度电话会议（对比广告业务逆风是否加剧、此前是否已提及）
- 行业背景：中国在线音乐市场竞争格局（网易云音乐）、短视频对广告预算与用户时长的分流、AI 音乐版权政策

**张力/矛盾/反向信号**：
1. **增长叙事结构性依赖**：总收入 +6% 而音乐相关服务 +11%，差额指向营销与消费服务几乎停滞或下滑（广告负贡献、靠线下演出对冲）——"第二增长引擎"内部其实两极分化
2. **利润率短期承压确认**：毛利率微降 + 费用率上升 0.8pct，且明确归因喜马拉雅摊销——并表是双刃剑，市场若只读"增长故事"易忽略短期利润稀释
3. **单点催化不可外推**：周杰伦《太阳之子》专辑、TIMA 单场演出均为脉冲式事件，逐字稿未给出其持续性论证
4. **股东回报信号偏弱**：Q2 回购 4亿美元，对比 442亿元 现金储备，回购强度有限（需对照历史季度方可判断趋势）
5. **全篇无用户数据**：业绩叙事从"用户增长"转向"收入结构与 IP 变现"，若 MAU 见顶，SVIP 是唯一付费增长引擎——这是后续最需要盯的信号

## 四个基本问题的回答

| 问题 | 回答 |
|---|---|
| 整体讲了什么 | TME 2026Q2 在广告逆风与竞争加剧下，依靠喜马拉雅并表、IP 消费服务和 SVIP 会员维持增长：总收入 +6%、会员 +8%、净利 25亿元，并描绘"音乐+音频综合平台"的前景 |
| 细部是怎样的 | 三发言人分别讲内容生态（深度合作+自有 IP+艺人经纪+演出周边）、产品与腾讯生态（AI、3D丽音、车载、鸿蒙、微信小微、SVIP 权益）、财务（收入 89亿元、会员 48亿元、毛利率 44.2%、EBITDA 33亿元+5%、回购 4亿美元） |
| 有道理吗 | 部分有道理。收入/利润/回购等硬数据可信（一手来源）；IP 与 SVIP 叙事有案例支撑但缺量化指标；广告逆风被坦承但未量化；喜马拉雅"早期阶段"是真实但无法验证的前景陈述 |
| 读它干什么 | 为 TME 建立 2Q26 基线：跟踪喜马拉雅协同落地（SVIP 音频、广告交叉销售）、广告企稳信号、SVIP 用户/ARPPU 数据、演出经济规模化与毛利率走势；与下一季度及正式财报对照验证 |

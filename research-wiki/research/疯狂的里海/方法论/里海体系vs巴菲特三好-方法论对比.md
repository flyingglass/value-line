# 里海体系 vs 巴菲特三好原则：方法论对比

> **一句话结论**：两者都源于格雷厄姆，但分属两套不同的推理结构——巴菲特是**正向演绎 + 优质样本归纳**（做对才赚钱，错由研究密度与生意质地兜底）；里海是**反向证伪 + 错误样本归纳**（先假设会看错，把"看错也不亏"变成买入前提）。分歧不在"要不要价值"，而在**远见型推理 vs 位置型推理**。
>
> 本页为 AI 对话产出的分析页（非里海原文）。里海引文均出自本 wiki 已入库页面，未新增外部数据；业绩口径均为作者自述、未独立核实。

## 〇、为什么需要这份对比

巴菲特的"好生意 + 好管理 + 好价格"是价值投资的中式传播最广的浓缩公式，里海自称"把格老四大准则融为一体"，又反复批判"中巴"（僵化理解巴菲特的中式价值投资者）。三好公式与里海体系的出入，直接决定了"里海是巴菲特的变体还是背离"这一判读。**注意：以下对比若只讲差异而丢"研究驱动"一腿，就会把里海误读成"反研究"——第三节专门处理此点。**

## 一、巴菲特"三好"的方法论结构

**推理链是正向演绎的**：

```
公理：买股票 = 买公司
  → 公司价值 = 未来自由现金流的折现
  → 超额收益 = 价格 < 内在价值（好价格）
  → 内在价值的长度与质量取决于生意能好多久（好生意 = 护城河持久性）
  → 护城河由谁维护（好管理）
```

成立条件是**远见**：护城河十年后还在不在、管理层十年后还理不理性，全是长周期命题。隐含支柱：

1. **归纳样本 = 伟大生意的共性**：对品牌消费品（喜诗、可口可乐一类）长期观察，归纳"提价权 + 低成本 + 稳定需求"组合能穿越周期。此样本隐含大前提——**存在几十年级的超长上升周期**（2001-2018 的 A 股黄金年代让中巴以为可以永远增长，正是同一结构的东方版本）。
2. **错误由深研压缩、由质地托底**：看错了怎么办？"生意足够好，时间会消化错误"。代价是**错误暴露慢**——高位买优质公司可能阴跌数年。
3. **价格是第三位的**：前两者是充分条件，价格只决定回报率高低、不决定生死，因为伟大公司"跌不死"。

## 二、里海体系的方法论结构

**推理起点是反向的**——这是最本质的区别：

```
公理：我会看错（弱者公理——散户在信息/研究/对手盘全面劣势）
  → 第一个问题不是"它能涨多少"，而是"什么位置让我看错了也不亏"
  → 由此倒推：必须在钟摆极限区域买（价格已充分反映悲观）
  → 必须在简单公司买（变量少，错误空间小）
  → 必须分仓（单次错误不可逆杀伤本金，3-5 只、单只 ≤40%）
```

1. **归纳样本不是"牛股的共性"，而是"亏损的结构"**：再升（研究最深却滑铁卢）、中巴两坑（高位买优质 + 左侧抄底）、腾讯朋友（弹药耗尽）、太极被抄作业者绑架——方法论从**错误解剖**里长出来，产出是"防御清单"，不是"伟大公司画像"。三大选股模型归纳的单位也不同：不是护城河特质，而是 **"价格形态（跌透横盘）+ 事件催化（变化）"的组合**。
2. **证伪主义设计**：不是因为"判断它会涨"而买，而是因为"结构性上我看错也伤不到我"而买（**"找看错了也很难亏钱，同时又存在向上弹性的标的"**）。错误被**前置暴露**——买在跌无可跌处，错了立刻知道（跌不下去），纠错成本极低。
3. **时间尺度被迫缩短**：拒绝十年期预测（**"这世界上就没有能长期持有的公司，谁知道五年后十年后长什么样"**），把判断周期压缩到"一个预期差被市场发现的周期"——战略股死拿几倍空间 vs 战术股一波流就走。**用更高精度的位置选择 + 交易纪律，替换巴菲特的远见。**
4. **信息劣势被转嫁为价格要求**：比机构谁知道得少，就让价格替自己说话——只买机构悲观到极致、筹码换手充分的位置。**用价格补偿信息，用赔率补偿概率。**

## 三、关键分歧总表

| 维度 | 巴菲特三好 | 里海体系 |
|---|---|---|
| 推理方向 | 正向演绎（公理 → "买什么"） | 反向证伪（"我会看错" → "什么位置安全"） |
| 归纳对象 | 伟大生意的共性（护城河样本） | 亏损的结构（错误清单）+ 价格-催化形态 |
| 第一性变量 | 生意质地（远见命题） | 买入位置（赔率命题） |
| 对优质公司的态度 | 买伟大公司本身就是目的，愿为护城河付溢价 | 好公司**被市场充分发现后即陷阱**（"中巴两坑"之首：榨菜 40→10 几）；只买"好还没被广泛看到"的 |
| 错误观 | 研究密度压错 + 质地扛错（暴露慢） | "看错不亏"成为买入前提（暴露前置、纠错廉价） |
| 时间尺度 | 十年计（护城河存续期） | 预期差兑现周期（战略/战术分层） |
| 研究定位 | 核心引擎 | **重划疆界**（见下），非废除 |
| 市场先生 | 提供报价的仆人，买点仍由价值决定 | 与基本面锚并列的利润来源（"低位信其有，高位信其无"） |

### ⚠️ 必须防的过度简化：里海不是"反研究"，是重划深研疆界

早期问答曾把里海概括为"反深研、用弱者体系替换研究"——**这是错的**。里海原文是**双模式**（《两大模式》2021.4.20）：

1. **研究驱动——但限定在极其狭小的能力圈内**：**"只有在一个非常非常狭小的能力圈范围内来做这个事情，散户才有可能在研究方面超越机构。"** 典型=医生投资人本职看清爱尔眼科赚数十倍（"比任何研究机构都熟悉爱尔眼科"）。散户在客场拼研究必输，在**主场**（本职行业/本地/极窄领域）可以反超机构——以地形换兵力。
2. **体系驱动——较广范围内按模型分类执行**（冯柳启发，后期以体系为主）：门槛压低到"能把公司解构清楚"，用模型替代深研。

**"重构"的准确表述 = 重新划定深研的疆界，不是宣布深研无效**：
- 客场深研（无边界、跟机构拼广度）→ 必输，放弃；
- 主场深研（极窄圈）→ 可以赢，保留；
- 体系驱动（模型分类）→ 补足主场之外的标的来源。

**为何后期仍以体系驱动为主？** 再升科技恰是**主场深研**的翻车案例（重庆本地 + 研究最深），研究对了也亏钱——败在边际筹码、市场先生、被外界绑架三个基本面之外的因素。结论：即便主场深研超越机构，"研究对"到"赚到钱"之间还隔着市场与人性的两道坎，须靠体系兜。

**另两个不可压平的细节**：
- 体系驱动也不完全排斥深研：三模型中"隐形冠军长期不涨"（英科/阳光电源）明确需深研、可遇不可求；
- 研究力量有组织化成分：2020.11.13"川渝 200 家强者视角全覆盖（有几个人帮研究）"——散户个体研究弱，但"散户 + 外援"组织可支撑强者式覆盖。

## 四、为什么里海体系"可行"（方法论内部论证）

可行性的论证不能停在"作者赚钱了"（业绩为自述口径、未独立核实），要从方法论内部找根据：

1. **构造非对称收益分布，而非高胜率预测**：亏损有下限（资产托底、跌无可跌），盈利无上限（变化引爆）。此结构下不需要单次高确定性，只需**赔率长期为正 + 偶尔大赚**即可复利——作者自述特征"高胜率、小亏损、偶尔大赚"正是印证（凯利框架的粗略版：概率可一般，赔率结构必须正确）。
2. **把问题从"难回答的"换成"可回答的"**：判断"公司十年后好不好"极难（信息依赖高）；判断"市场对它的悲观是否已到极端"相对容易（底部横盘、利空不跌、筹码换手=公开价格信息）。**弱者策略的本质是把认知要求从公司基本面迁移到市场情绪面**——情绪面极端状态恰是散户唯一可能比机构看得清的地方（机构受排名/仓位/流动性约束，无法在极端位置从容建仓冷门小票）。
3. **错误成本前置压低，复利不被单次击穿**：十年不踩大坑是小资金做大的唯一路径。巴菲特式错误（高位买优质）是慢变量、温水煮青蛙；里海把防错设计进买入条件（底部资产位置 + 简单 + 分仓），错误暴露快、代价小、可退出。
4. **"低位信其有"是存在性判断，不是预测**：底部横盘 = 卖方衰竭，此时只需一个"可能的"变化就能打破均衡。不需要预测变化何时来，只需确认"向上因子未被证伪"，然后用时间等——**以等待替代预测，以熬替代远见**。

### 可行性的边界（必须诚实标注）

- **高度依赖纪律**：作者把 2023-24 年 -45% 回撤归因于"被抄作业者绑架致操作失真"——"修行"不是玄学，是体系承重墙；
- **归纳样本受环境约束**：三模型与"底部博弈"来自 A 股 2016-2026（散户占比高、机构覆盖小票不足、情绪极端化）；作者自认"2001-2018 超大向上周期很难再有、轮动加快"。移植到高度机构化/指数化市场，底部博弈空间收窄；
- **业绩未经独立核实**："连续六年盈利、年化约 33.5%"为作者自述口径，是待验证假设，非已完成的外部验证。

## 五、相通处（防止对比失真）

里海对巴菲特/芒格的继承是显性的，差异集中在**操作层**而非**底座**：

- 格老四大准则（买股票=买公司 / 安全边际 / 市场先生 / 能力圈）——里海自称"融为一体"，批评的只是"只记第 1 条、忘后 3 条"的中巴；
- 复利思维、低换手（"价值投资是低频交易"）、不预测（"宏观是我们必须承受的"）、能力圈与消费股偏好、永续现金流补仓（"老巴平安打法"）；
- 他批判的"中巴" = 高位死拿优质公司 + 左侧抄底——即**丢了能力前提的巴菲特**，而非巴菲特本身。

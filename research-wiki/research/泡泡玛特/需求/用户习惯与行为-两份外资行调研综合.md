# 用户习惯与行为：两份外资行消费者调研的比较阅读

> 两份报告同期、同一家公司、**结论相反**（伯恩斯坦 Underperform/HK$225 vs 花旗 Buy/HK$415），但**测的是同一台机器的两端**：伯恩斯坦测"中国存量客群的留存深度"，花旗测"全球客群的扩张宽度"。
> 本篇把它们并到一张表上做比较阅读，并逐条标注**口径陷阱**——大部分表面矛盾来自口径，不来自事实；**不可比的两个数字拼在一起，比没有数字更危险**。

## 摘要

> 核心话题：留存深度 · 持有与支出天花板 · 收藏动机 · IP 集中度 · 渠道与二手 · 口径可比性

**一句话核心**：两份调研在**两个硬事实上完全一致**——**一年以上老客仅约 12%**（伯恩斯坦 11.70% vs 花旗 12%）、**LABUBU 是绝对第一获客 IP**（中国口径 37.94% vs 33%）；分歧只在于对同一事实的解读（渗透率仍在扩大 vs 留存证据不足）。**"二手 75.53%"与"二手 9%"不是矛盾**——前者问"是否用过"（多选），后者问"主渠道"（单选）；**"80% 持有不足 11 件"与"89% 持有 ≥2 件"同样不可比**——一个问当前持有、一个问累计购买。真正需要警惕的是**中国口径下 68.80% 年支出低于 ¥500**、**深度收藏者仅 5.56%**、**集齐系列动机在所有动机中垫底（1.88）**——三条同向证据指向"高频低额、审美驱动、非收藏品"的消费形态。

**关键数据（伯恩斯坦 2025-12 中国约 850 人 / 花旗 2026-01 五国 1,501 人）**：

- 留存：一年以上老客 **约 12%**（两家一致）；从未购买 **34.04%**（伯恩斯坦）；一年内首购 38.89%（伯恩斯坦，分母含非购买者）vs **76%**（花旗，分母为购买者）
- 持有：当前持有不足 11 件 **80.15%**（伯恩斯坦）；LABUBU 持有者中 ≥2 件 **88%**（花旗）
- 支出：年支出低于 ¥500 **68.80%**（伯恩斯坦，中国）≈ 6-7 件/年；人均支出 澳 **US$132** > 中 **US$130** > 美 US$110 > 英 US$108 > 日 US$95（花旗）
- 深度：深度收藏者（系统集齐 + 20 件以上）**5.56%**；到访动机中"集齐系列" **1.88**（5 分制垫底）
- 意向：继续购买 **93%**、更频繁 26%、未来不买 **7%**（花旗）；增加支出 61.28%、一年内完全停止 **13.24%**（伯恩斯坦）
- 单 IP：LABUBU 首因 **37.94%**（伯恩斯坦）/**49%**（花旗，中国 33%）；二级 IP 无一超过 12%

**核心矛盾**：

1. **留存缺口 vs 增长斜率**：一年以上老客 12% + 从未购买 34%（伯恩斯坦）↔ 76% 一年内首购 + 93% 计划继续购买（花旗）——同一现象，"漏桶"与"渗透"两种读法
2. **单 IP 依赖 vs 非 LABUBU 被低估**：伯恩斯坦视 37.94% 获客集中度为风险；花旗看到 Twinkle Twinkle/Skullpanda/Crybaby 在美英澳达 25-30%——分歧的实证基础是**中国 IP 结构最分散、海外更集中**
3. **稀缺策略的两难**：伯恩斯坦测出缺货时 18.32% 放弃、44.80% 生态内替代；花旗测出供给改善下二手占比降至 9%——供给放量是承接需求还是摧毁紧迫感，两家给的是同一问题的两侧
4. **价格敏感的方向相反**：中国"太贵"是减支第一因（29.57%），海外"降价"是提频第一因（美 46%/英 45%/澳 43%），而中国"降价"仅 19%

**推导方法与证据强度**：

- 🟢 **披露值**（可直接引用）：两份调研的图表明细均已逐格表格化入库；关键值经「正文锚点 + 加总 ≈100%」双重校验（伯恩斯坦 Ex3/5/6/7/13；花旗 Fig 1/3/4/5/8/10/13/18/27/30/32）
- 🟡 **本篇推算**（附算式）：伯恩斯坦购买者口径下的一年内首购 = 38.89 ÷ (100−34.04) = **58.9%**（用于与花旗 76% 对比）；花旗国别百分比抽样误差约 ±5-6pp（n≈300）
- 🔴 **不可识别**：① 花旗样本中"从未购买者"占比未披露（问了 Fig 23 却未给占比）→ "76% vs 38.89%" 只能定性比较；② 花旗"花了多少"（US$95-132）**周期口径未标注**（年 / 累计不明）；③ 伯恩斯坦 Exhibit 10/11 的 `0` 与 `1-10` 档配对存疑；④ 两家均为线上自选样本，非随机抽样

**跟踪要点**：

1. **一年以上老客占比**——两家唯一可裁决指标（当前 12%），下次调研是否抬升
2. **年支出 <¥500 主体能否上移**（68.80% → 中段 25.41%）与中国客群价格敏感度变化
3. **非 LABUBU IP 接力**：中国零交叉购买率（口径冲突，见 raw 备注）与海外 Twinkle/Skullpanda 持有曲线
4. **二手渗透率的两种口径同时跟踪**（是否用过 vs 主渠道），避免被单一数字误导
5. **礼品属性的地理差异**（花旗：海外 33-36% vs 中国 10%）——礼赠是海外增量还是文化差异

**原文与官方口径**：伯恩斯坦报告标题即问题本身——"Are its core consumers sustainable collectors or transient trend chasers?"，结论句为"the survey confirms concerns that Pop Mart's customer base is predominantly novelty-driven with temporary engagement rather than durable collector communities, and growth depends on continuous fresh releases"（raw 第 1 页）；花旗结论句为"Pop Mart's user base continues to grow globally as supply improves"（raw 第 1 页）。**两份原件的可靠性均已在 raw 逐处标注**：伯恩斯坦为纯图片 PDF + OCR（图表配对需逐图重建，Ex10/11 仍存疑）；花旗正文与图表有两处自相矛盾（Fig 26 美国/英国 59%、Fig 21 Tokidoki）。

## 第三级 · 分析阅读

### 3.1 两条论证链

**伯恩斯坦（看空链）**

```
新客占比高（一年内 38.89%）+ 从未购买 34.04%
  → 留存证据不足
  → 分型：68.09% 休闲/审美型，深度收藏者仅 5.56%
  → 行为：80.15% 持有不足 11 件、68.80% 年支出 <¥500
  → 心理："集齐系列"动机垫底（1.88）
  → 结论：客群以"短暂追潮者"为主，增长依赖持续上新
```

**花旗（看多链）**

```
76% 首购在一年内 + 45% 在三个月内 + 87% 未来 3 个月可能购买
  → 用户基数仍在扩张（渗透率提升）
  → 93% 计划继续购买、仅 7% 不买；海外 IP 结构比预期多元
  → 供给改善下二手占比降至 9%（稀缺溢价退潮 ≠ 需求退潮）
  → 结论：用户端未见流失证据，维持 Buy
```

**两条链的分歧点只有一个**：**"新客占比高"该读作渗透率提升（花旗）还是留存证据不足（伯恩斯坦）**——其余全是同一事实的不同侧面。

### 3.2 逐条检验

| 结论 | 强度 | 检验意见 |
|---|---|---|
| 一年以上老客约 12% | 🟢 **强** | 两家独立样本同值，本篇唯一"可裁决事实" |
| 收藏深度浅（非收藏品形态） | 🟢 **强** | 三条独立证据同向：分型（深度收藏者 5.56%）、持有（<11 件 80.15%）、动机（集齐系列 1.88 垫底）；花旗"收藏爱好"虽为第二主因但仅 26% |
| LABUBU 主导获客 | 🟢 **强** | 中国口径两家接近（37.94% vs 33%）；海外更高（日 62%、英 59%） |
| 支出天花板低 | 🟡 **中** | 伯恩斯坦"年支出 <¥500"口径清晰；花旗"人均 $95-132"周期未标注，无法互证 |
| 留存不足（伯恩斯坦核心结论） | 🟡 **中** | 依赖两个存疑点：Ex10/11 配对存疑；且"零交叉购买 29.08%"与"从未购买 34.04%"逻辑上不能同时成立 |
| 基数继续扩张（花旗核心结论） | 🟡 **中** | 依赖"新客占比"单点，且分母未披露；花旗自身有两处正文-图表矛盾 |
| 二手市场活跃（稀缺策略有效） | 🔴 **弱** | 75.53% 与 9% 口径不可比，无法判断真实渗透 |

### 3.3 证伪存档

1. **两家都是线上自选样本** → 活跃用户偏差：把"愿意填问卷的人"当作"客群"，**流失者与沉默者未被采样**。这意味着"一年以上老客 12%"可能是**幸存者口径下的上限**，而非全量真实值
2. **时间差 8 周不可忽视**：伯恩斯坦（2025-12）测到缺货与稀缺摩擦，花旗（2026-01）明确写 "as supply improves" → 两家差异中可能有一部分只是**供给状态变化**（🟡 本篇推断）
3. **伯恩斯坦的换算跳跃**：以"5,900 万会员 × 5.56% = 320 万深度收藏者"把**账户数当人数**，会员定义未披露 → 🔴
4. **花旗的国别精度**：每国约 300 人，国别百分比抽样误差约 ±5-6pp → 差距小于 6pp 的国别结论都不稳健（🟡 统计推断）
5. **反向信号（两家共同记录）**：盲盒"热爱"仅 17.85%（伯恩斯坦）、中性 26%；集齐动机垫底 → **若收藏属性确实不存在，"持续上新"就是唯一增长引擎**——这既是伯恩斯坦看空的落点，也是花旗"依赖执行"的落点，两家在此其实同向

### 3.4 识别性边界（不可识别项）

- 花旗样本中"从未购买者"占比 🔴（问了 Fig 23 却未披露占比）
- 花旗"花了多少"的时间周期 🔴（年？累计？图内未标）
- 跨市场可比的年支出口径 🔴（人民币分布 vs 美元均值）
- 会员数 → 实际人数 🔴
- 中国"每月+购买"的两家差异（16.55% vs 44%）🔴 无法归因（口径？时点？样本渠道？）

## 第四级 · 比较阅读

### 4.1 共识（可裁决的事实层）

| 共识 | 伯恩斯坦 | 花旗 |
|---|---|---|
| 一年以上老客 ≈ 12% | 11.70% | 12% |
| LABUBU 绝对第一 | 首因 37.94% | 首因 49%（中国 33%） |
| 收藏动机弱 / 非收藏品形态 | 深度收藏者 5.56%、集齐 1.88 | 系列集齐非主要驱动；LABUBU 持有者以 2-5 件为主 |
| 审美/设计 > 机制 | 艺术设计 4.38 最高 | 设计类因素居首（Fig 15/16） |
| 增长依赖持续上新 | "growth depends on continuous fresh releases" | 新品发布是下次购买第一驱动（41%） |
| 中国 IP 结构最分散 | （单一市场样本） | 中国 LABUBU 首因 33%、持有 31%，六国最低 |

**说人话（本项目归纳，非数据行）**：**这不是"收藏品"生意，是靠不断出新款往前推的快消上新生意——习惯还没养成的那一半是"持续买"，不是"买"；增长的推力在产品。** 对应关系：老客仅 12%（R1）+ 收藏动机垫底（R3）→ 留存端尚未形成习惯；审美/设计 > 机制（R4）+ 增长依赖持续上新（R5）→ 推力来自"产品"，而非"IP 情感黏性"。

> 三处不能省（都是把这句话读歪的入口）：
> 1. **"习惯未养成"只指持续购买**——"买"的习惯已经养成（最近一次购买在 3 个月内 86%、认为盲盒重要 80%），不可读成"这个品类还没被接受"。
> 2. **"推力"是中性化改写**——伯恩斯坦原口径是 "growth **depends on** continuous fresh releases"（依赖＝风险口吻），其落点比"重要推力"重得多（见 3.3 第 5 条："若收藏属性确实不存在，持续上新就是**唯一**增长引擎"）。
> 3. **本句未覆盖 R2 / R6**——单 IP 依赖（LABUBU 首因 37.94%/49%）与中国 IP 结构最分散，而这两条才是通向 [[../投资论点]]"断代风险"的那条腿。

### 4.2 分歧与根源

| 分歧 | 伯恩斯坦读法 | 花旗读法 | 根源 |
|---|---|---|---|
| 新客占比高说明什么 | 缺乏留存证据 | 渗透率仍在提升 | **解读分歧，非事实分歧** |
| IP 集中度 | 单 IP 依赖 = 风险 | 非 LABUBU 被低估（Twinkle/Skullpanda/Crybaby 美英 25-30%） | **样本地域**：中国集中度低 vs 海外集中度高 |
| 价格 | "太贵"为减支第一因（29.57%） | "降价"为海外提频第一因（46/45/43%），中国仅 19% | **市场定价差**：海外定价更高 |
| 稀缺策略 | 缺货致 18.32% 放弃 + 44.80% 替代 | 供给改善、二手占比仅 9% | **时点差 8 周** + 供给状态变化 |
| 二手市场 | 75.53% 用过（活跃） | 9% 主渠道（不活跃） | **问法口径**（是否用过 vs 主渠道） |

### 4.3 与本库其它页面的三向对照

- **[[情绪需求持续性跟踪]]（行业 beta 框架）**：该页第四层的三个高频信号在此有了**基线值**（2025-12 / 2026-01）——二手溢价容忍（64.54% ≤50%）、退坑/入坑（仅一次购买 20.92% + 一年内完全停止 13.24%）、支出占比（年支出 <¥500 占 68.80%）。🟡 建议把本页登记为该框架的**基线快照**（时间戳：伯恩斯坦 2025-12-02 / 花旗 2026-01-27）
- **[[../运营指标]]（公司经营口径）**：公司口径 2026H1 会员 8,244 万、复购率 51.6%、会员销售占比 92.9%（见该页与 [[../业绩/经营重点关注]]）——与调研口径形成张力：**"复购率 51.6%"（公司）与"深度收藏者 5.56% / 一年以上老客 12%"（调研）不是同一维度，但同样指向"复购 ≠ 深度"**
- **[[../投资论点]]**：本页为需求端提供**行为基线**（不是结论）。投资论点里的"断代风险"在本页对应的正是"新客源源不断 vs 老客留存不足"的张力

### 4.4 张力与反向信号（不和谐处保留）

1. 中国"每月+购买"16.55%（伯恩斯坦）vs 44%（花旗）——**同为中国人差 2.7 倍**，无法用样本渠道完全解释；在两处澄清之前，对外引用"消费频次"必须**同时标出双口径**
2. "93% 计划继续购买"与"13.24% 一年内完全停止"——问法不同但可能指同一群体（"继续购买"含"减少"），引用时须成对出现
3. 伯恩斯坦的看空结论**踩在其最不可靠的两张图上**（Ex10/11 配对存疑）；花旗的看多结论**踩在单点（新客占比）上**——两家核心论证都落在自己的薄弱处，这本身是风险提示

## 四个基本问题的回答

1. **整体谈什么？** 同一个问题——泡泡玛特客群的行为质量（深度、黏性、可持续性），但用两套样本测同一台机器的两端：中国存量（伯恩斯坦）与全球增量（花旗）
2. **细部说了什么、怎么说的？** 逐题交叉表：留存 / 分型 / 持有 / 频次 / 支出 / 动机 / IP / 渠道 / 二手 / 意向。方式上伯恩斯坦单市场纵深、花旗六国横切
3. **说得有道理吗？** 部分有道理：**一致的事实**（12% 老客、LABUBU 主导、收藏动机弱）证据强；**两家各自的核心结论**证据中等（都踩在薄弱数据上）；**二手与频次的跨报告数字**目前不可比，不应合并使用
4. **与我何干？** 三条：① 需求端基线（供 [[情绪需求持续性跟踪]] 用）；② **口径警戒清单**（五项陷阱，防止把不同口径拼成"趋势"）；③ 跟踪回到"一年以上老客占比"这一唯一可裁决指标

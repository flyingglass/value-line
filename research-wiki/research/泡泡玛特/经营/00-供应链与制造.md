# 泡泡玛特 (09992) — 供应链与制造链条

> 从 [[../产业链]] 独立出来的**制造价值链**。与 IP 产业链（上游内容 → 中游产品化 → 下游渠道）是两套框架：**本文件只讲成本结构与运营风险，不替代商业模式定位**。逐环节结构性限制评估另立文件：[[../评估/01-结构性限制评估]]。

## 链条总览（2020 → 2026 时间线）

> 招股书（2020-12-01 全球发售）时代泡泡玛特以盲盒/手办为主，**"搪胶毛绒"（Labubu VINYLicious）2023 年底才推出，招股书无该品类披露**。全文无 "vinyl plush"；唯一一次"搪胶"出现在 p.160，是描述 KAWS 的 Companion（搪胶米奇老鼠玩偶，行业背景，非本公司产品）。以下为当时的盲盒口径链条，但"设计→OEM→质控→物流→渠道"的结构沿用至今。
>
> （2020 基线来源：`data/pdfs/09992/09992_2020_招股书_中文_官网.pdf`，632 页，页码为 PDF 页；财务口径：渠道跟踪表 19H1–25A + 各环节文件）

```
IP/设计      →  OEM制造     →  质控         →  仓储物流          →  渠道销售
(111名设计师)   (18家第三方)    (18人+第三方检测)  (自营+外包仓/7物流商)   (零售店/机器人店/线上/经销商)
```

### 2020 · 基线快照（招股书口径）

| 环节 | 基线 | 环节级评估 |
|------|------|-----------|
| 设计/IP | 111 内部设计师；IP 池 85 个（12 自有 / 22 独家 / 51 非独家）；原型与模具设计公司负责 | [[01-设计IP环节]] |
| 制造 | 18 家中国第三方制造商、全外包；模具归公司、可在制造商间转让；五大制造商采购占 2020H1 50.8%（最大 15.8%） | [[02-制造与质控环节]] |
| 质控 | 18 人团队、季度现场检查；第三方年检（VOC / 重金属 / 玩具安全 GB 6675） | [[02-制造与质控环节]] |
| 仓储物流 | 2 中央仓 + 172 地方仓 + 2 外包仓；7 物流商；物流费 3,930 万（2019）；周转 46 天（2019） | [[03-仓储物流环节]] |
| 渠道销售 | 零售店 136 + 机器人商店 1,001 + 线上 + 经销商 47 家；五大客户占 2020H1 4.7% | [[04-渠道销售环节]] |

财务基线：营收 **16.8 亿**（2019）→ **25.1 亿**（2020）；存货 2.25 亿；销售成本 9.19 亿（外包货款口径）

### 2021 · 供应链重构元年

- **制造**：前孩之宝供应链负责人袁俊杰主导"柔化"重构——长约 3–10 年 / 成本透明（可查工厂财务系统）/ KPI / 飞行检查+罚单；主力厂贡献 >70% 产能，收缩至十家主力供应链
- **制造**：工程与工艺开发部成立（2021-09，东莞）——设计师与工厂之间的"翻译器"；SRM 系统 + 产线数据直连
- **设计**：自有 IP 收入占比 57.6% 创新高；员工 4,053
- **渠道**：线上 41.4% 首超零售店 37.5%
- 财务：营收 **44.9 亿**（+79%）；存货 7.9 亿（+251%）；外包货款 14.5 亿

### 2022 · 口径切换与低谷

- **设计**：披露口径改"艺术家 IP"（自有+独家合并），占收入 78.9%
- **渠道**：批发及其他占比升至 17.0%（经销商扩张）；抽盒机占线上 52.2%
- 财务：营收 **46.2 亿**（+2.8%，疫情低谷）；存货 8.7 亿；外包货款 16.9 亿

### 2023 · 新品类破局

- **制造**：年底推出**搪胶毛绒 Labubu VINYLicious**（布料共用既有供应链——原材料清单中"布料"在列）
- **渠道**：线上占比 23A 处谷底（全集团线上 18.66 亿 / 占 29.6%；中国线上按 2024 年报重述口径 15.25 亿）；抖音独立披露并放量（23A 2.83 亿）；批发占比 23A 12.2%（此前误记 28.9%，官方 2023 年报 Note 6 全集团批发 7.67 亿）
- 财务：营收 **63.0 亿**（+36%）；存货 9.1 亿；周转 133 天；外包货款 20.4 亿

### 2024 · 出海元年

- **设计**：星星人 2024-08 上线；4 IP 破 10 亿（THE MONSTERS 30.4 亿）；员工 6,702
- **仓储**：海外仓 600 → 47,000㎡（畅联股份）；物流费 5.43 亿（占营收 4.2%）
- **渠道**：零售店占收益 **51.9%** / 线上 **31.9%** / 机器人 6.4% / 批发及其他 9.9%（2025 年报重述口径；此前误记"零售店 45.3% 反超线上 34.7%"系用户表 Old 口径残留，2026-08-27 校正）；门店 521 家
- 财务：营收 **130.4 亿**（+107%）；存货 15.3 亿（+69%）；外包货款 34.7 亿

### 2025 · 全球爆发（营收 371 亿）

- **设计**：艺术家 IP 收入 334 亿、占约 90%；THE MONSTERS 141.6 亿；17 IP 破亿；员工 10,879（设计开发 2,194）
- **制造**：外包货款 **85.1 亿**（占销售成本 82%）；质控成绩单＝存货减值率 0.39%
- **仓储**：物流费 **20.43 亿**（+276%，占营收 5.5%）；海外仓峰值单月 2,020 万件、SKU 超 1 万、覆盖 40+ 国
- **渠道**：门店 630（海外净增 89）；会员 7,258 万（贡献 93.7%、复购 55.7%）；DTC 95.3%
- 财务：营收 **371.2 亿**（+185%）；存货 54.7 亿；周转 123 天

### 2026H1 · 调整年（消化高水位）

- **设计**：艺术家 IP 152.9 亿、占 89%；6 IP 破 10 亿；星星人 26.5 亿（+580.6%）
- **制造**：**海外工厂加入供货**（优先海外工厂向海外市场供货，对冲头程费用）；供应链信息化为未来 1–2 年核心重点
- **仓储**：库存 **61.0 亿**、周转 **201 天**（结构性高水位 + 预测偏差）；全球 10+ 国家仓储体系；海运 40–60 天仍是主要瓶颈（新品无法按时上市）
- **渠道**：门店 676；机器人商店 2,827；海外收入 -11.1%（线上高基数回落）；抽盒机 +83.3%（私域逆势加速）
- 财务：H1 营收 138.8 亿；库存 61.0 亿；周转 201 天

> **链条演化一句话：骨架没变（设计→OEM→质控→物流→渠道），肌肉全换（全球制造、全球仓网、多式联运、DTC 渠道）**——2020 的 25 亿国内生意，2025 变 371 亿全球生意；代价是存货周转从 46 天拉长到 201 天。

# 泡泡玛特 (09992) — 供应链与制造链条

> 从 [[产业链]] 独立出来的**制造价值链**。与 IP 产业链（上游内容 → 中游产品化 → 下游渠道）是两套框架：**本文件只讲成本结构与运营风险，不替代商业模式定位**。逐环节结构性限制评估另立文件（见文末入口）。

## 链条总览（招股书 2020 披露口径）

> 说明：招股书（2020-12-01 全球发售）时代泡泡玛特以盲盒/手办为主，**"搪胶毛绒"（Labubu VINYLicious）2023 年底才推出，招股书无该品类披露**。全文无 "vinyl plush"；唯一一次"搪胶"出现在 p.160，是描述 KAWS 的 Companion（搪胶米奇老鼠玩偶，行业背景，非本公司产品）。以下为当时的盲盒口径链条，但"设计→OEM→质控→物流→渠道"的结构沿用至今。
>
> （来源：`data/pdfs/09992/09992_2020_招股书_中文_官网.pdf`，632 页；页码为 PDF 页）

```
IP/设计      →  OEM制造     →  质控         →  仓储物流          →  渠道销售
(111名设计师)   (18家第三方)    (18人+第三方检测)  (自营+外包仓/7物流商)   (零售店/机器人店/线上/经销商)
```

### 1. 设计 / IP 环节（p.245）
- 111 名内部设计师组成"内部创意设计及工业开发团队"，深入参与产品开发过程
- 截至 2020-06-30 已创作 9 个自有 IP（BOBO&COCO、Yuki、BUNNY 等）；授权 IP 支付特许权使用费
- 产品原型和模具设计由泡泡玛特负责（标准营运程序 + 原型 + 模具）

### 2. OEM 制造环节（p.285-287）→ [[制造与质控环节]]
- **全外包**：18 家中国境内第三方制造商，公司不自产
- **模具是公司核心资产**：公司拥有制造用模具，可在制造商间转让（对供应链保持控制权）
- 协议要点（一年期）：产品+模具 IP 归公司；产品责任与索赔由制造商承担；公司可委派 QC 现场抽检
- 供应商集中度：五大制造商采购占比 2019 年 40.8%（最大 15.0%）→ 2020H1 50.8%（最大 15.8%）
- **供应商 K（2020H1 第二大供应商，占 13.4%）**：从事"塑料玩具、电子玩具及**毛绒电子玩具**制造"——招股书中与毛绒最相关的供应商
- **环节级评估见 [[制造与质控环节]]**（OEM+质控合并）：轻资产外包+重管控内核、八步验厂、长约+KPI+飞行检查罚单、S'OP 分批下单、模具资产、三层质控（减值率 0.39%）

### 3. 质控环节（p.289-290）→ [[制造与质控环节]]
- 18 名质控团队成员；每季度对全部制造商现场临时检查
- 原材料清单：ABS、PVC、涂料和油墨、**布料**、五金（布料在列 → 毛绒类产品共用此供应链）
- 第三方检测机构年检：VOC 17 项限值（GB 38507-2020）、包装重金属（GB/T 16716.1-2018）、玩具安全（GB 6675-2014）
- 三层防线：工厂内控（回炉重造/大娃全检）→ 公司介入（季度→飞行检查+罚单/PPM）→ 第三方年检；质控成绩单=存货减值率（2025 仅 0.39%）

### 4. 仓储物流环节（p.287-288）→ [[仓储物流环节]]
- 2 个自营中央仓（北京+南京，共 4,310㎡）+ 172 个自营地方仓（10,739㎡）+ 2 家外包仓（嘉兴-线上 / 东莞-华南）
- 2 家仓储派递 + 7 家物流服务商；2019 年物流费用 3,930 万元
- 存货周转天数：2017 49 → 2018 45 → 2019 46 → 2020H1 126（COVID 扰动）
- **环节级评估见 [[仓储物流环节]]**：库存放大=**高**（周转 201 天）、物流费率=中（2025 占营收 5.5%）、海外物流时效=中、货值密度=低

### 5. 渠道销售环节（p.280-281）→ [[渠道销售环节]]
- 零售店 + 机器人商店 + 线上 + 经销商；五大客户均为经销商
- 南京金鹰泡泡玛特（与金鹰国际合营）2020H1 占经销商渠道 3.0%
- **环节级评估见 [[渠道销售环节]]**：私域依赖=**低**、经销依赖=**低**（2025 批发仅 4.7%）、海外单店效率=中、海外线上获客=中

## 与 2026 年对照（链条演化）

| 维度 | 招股书 (2020) | 2026 中报业绩会口径 |
|------|--------------|--------------------|
| 制造 | 18 家中国第三方制造商 | 海外工厂加入供货（对冲头程费用） |
| 仓储 | 中国境内 2 中央仓 + 172 地方仓 | 全球 10+ 仓储体系 |
| 物流 | 7 家物流商、汽运为主 | 海运/空运/铁路多式联运（货值密度决定容错空间） |
| 存货周转 | 46 天 (2019) | 201 天 (2026H1) |

## 财务科目对应（2025 年报口径）

> 以上业务环节在财报上的落点。金额为人民币千元（2025 年报，`data/pdfs/09992/09992_2025_年报.pdf`，370 页）。三大费用行（销售成本 / 经销及销售开支 / 一般及行政开支）在 **Note 7 统一按性质列示**；收益按渠道在 **Note 6** 拆分。

| 链条环节 | 损益表科目（2025） | 资产负债表科目 | 附注 |
|---------|------------------|--------------|------|
| **1. 设计 / IP** | 授权费 **833,481**（按销量提成）；设计服务费 **86,446**；内部设计师薪酬⊂雇员福利开支 2,252,340 | 无形资产：授权 IP / IP 产权 / 软件；2025 添置授权 IP **117,623**（买断授权金资本化） | Note 7 / 15 |
| **2. OEM 制造** | 销售成本 **10,355,136**，其中计入销售成本的存货成本 **8,507,015**（占 82%）；≤1 年模具成本 **22,697**（费用化） | 存货 **5,472,839**；固定资产"模具"科目（>1 年资本化）；应付贸易款项（欠制造商货款） | Note 7 / 14 / 22 |
| **3. 质控** | 无独立科目（质控团队薪酬⊂雇员福利开支；检测费⊂其他） | 间接反映：存货减值 **21,183**（质检不合格/滞销损失） | Note 7 |
| **4. 仓储物流** | 运输及物流开支 **2,043,181**（2024 为 543,180，+276%） | 使用权资产-办公室及仓库 **237,223**（仓库租金资本化）；短期及可变租赁开支 1,338,240（费用化） | Note 7 / 16 |
| **5. 渠道销售** | 收益 **37,120,052**（零售店 17,254,326 / 线上 16,433,829 / 机器人商店 1,689,446 / 批发及其他 1,742,451）；经销及销售开支 **8,082,433**（含佣金及电商平台服务费 1,438,036 + 广告营销 1,194,368） | 使用权资产-零售店 **2,483,182**（门店租金资本化）；贸易应收 921,240（经销商欠款）；合约负债 393,119（预收/充值卡） | Note 6 / 16 / 20 / 32 |

**会计处理要点**：

- **OEM 制造成本不入"采购"科目**：外包货款先入存货，卖出后转入"计入销售成本的存货成本"。跟踪制造环节看三条线：存货规模（5,472,839）+ 存货减值（21,183）+ 应付贸易款（欠供应商）——与存货三维跟踪一致。
- **模具双轨制**（招股书"公司持有模具"的账面对应）：使用年限 >1 年 → 资本化进 PP&E"模具"科目；≤1 年 → 费用化（2025: 22,697）。
- **IP 费用双轨**：按销量提成的授权费费用化（833,481）；一次性买断的授权金资本化为无形资产（2025 添置 117,623），再按无形资产摊销（127,050）。

（来源：`data/pdfs/09992/09992_2025_年报.pdf` p.218-221 损益表/资产负债表、p.283-285 Note 6/7、p.294-300 Note 14/15/16）

## 结构性限制评估（环节级）

> 逐环节独立成文、逐一验证。**未经数据验证的限制不列**。

- [[设计IP环节]] — 设计/IP 环节（已验证）：分成制=**低**（授权费占营收 7 年 1.8–3.0%，2025 为 2.25%，无恶化趋势）、IP 生命周期=**高**、设计师产能=待验证
- [[制造与质控环节]] — OEM 制造 + 质控环节（已验证）：轻资产外包+重管控内核（模具所有权/验厂准入/长约+KPI+罚单/S'OP 分批下单/三层质控）；质控成绩单=存货减值率 0.39%（2025）运行良好
- [[仓储物流环节]] — 仓储物流环节（已验证）：库存放大=**高**（周转 46→123→201 天，出海铺货+海运长周期）、物流费率=中（2025 占营收 5.5%，+276%）、海外物流时效=中（海运 40–60 天）、货值密度=低
- [[渠道销售环节]] — 渠道销售环节（已验证）：私域依赖=**低**（抽盒机占线上 40%+ 且 2026H1 加速）、经销依赖=**低**（2025 批发及其他仅 4.7%）、海外单店效率=中（海外收入 -11.2% vs 门店 +105 家）、海外线上获客=中（"获客能力仍在建设阶段"）

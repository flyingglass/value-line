# 《泡泡玛特2020年年度业绩发布会纪要》— 艾德勒四级阅读法摘要

## 摘要

> 核心话题：上市首年 · 全产业链平台 · 心向大海 · 供应链缺货 · 利润率指引 · Pucky 预测落空

**一句话核心**：上市首年收入 **25.13 亿元（+49.3%）**、经调整净利润 **5.91 亿元（净利率 23.5%）**，王宁定调 **"心向大海，不恋沟渠"**（盲盒占比会降、长期走向乐园/内容/游戏）；暗线是**供应链缺货**（王宁自认疫情下单保守）与 **Pucky 停滞**——后者"2021 小幅增长"的预期随后落空（实际 **-39.3%**），是全序列第一次 IP 预测失败。

**关键数据（2020A）**：

- 收入 **25.13 亿元（+49.3%）**；毛利率 **63.4%**（64.8% → 63.4%，工艺+环保投入）；经调整净利润 **5.91 亿元**（净利率 23.5%）
- 四大头部 IP（Molly/Dimoo/Pucky/The Monsters）均超 **2 亿元**；Molly 3.15 亿、Skullpanda 首系列 3,900 万（上市首日 27 万个）
- 渠道：门店 **187 家**（+76）、机器人商店 **1,351 台**；线上占比 **38%**；海外 **+176%**
- 会员 **740 万（+236%）**、复购率 46%+；存货周转 **78 天**；派息率 **40%**
- 长期指引：利润率 **22%-27%**（IPO 路演口径重申）

**核心矛盾**：

1. **销售超预期 vs 供应链缺货** —— 王宁自认"对三四季度下单略有保守"，供需错配是自身决策而非单纯疫情
2. **"IP 公司"定位 vs 盲盒模式依赖** —— 自主产品 85%、但市场认知仍系于盲盒；MEGA/乐园尚未出现
3. **Pucky"符合预期" vs 单一 IP 预测失效** —— 管理层称各 IP 表现符合规划，当年 Pucky 3 亿与上年持平，次年即 -39.3%

**管理层应对**：缺货靠 3 月底供应链复工缓解、承诺 Q2 头部 IP 密集上新且备货更充分；不控股工厂、不做饥饿营销；会员运营从纯拉新转向分层精细化（ARPU/复购）；海外 2021 年底目标 20+ 门店、机器人商店 100+，亚洲占比降至 60%。

**跟踪要点**：

1. Skullpanda 能否成为新头部 IP（后验证：2021 年 5.95 亿，兑现）
2. Pucky 生命周期（后验证：-39.3%，落空）
3. 利润率 22-27% 区间（后验证：2021 年 22.3% 贴线、2022 年破位）
4. 乐园/内容/游戏"海"的落地节奏（乐园 2023-09 开业）

**王宁原话**：心向大海，不恋沟渠。

## 第一级 · 检视阅读

- **文件性质**：业绩发布会要点纪要（公众号「永恒的价值」依据 B 站回放整理，问答含原话，颗粒度约 80-90%），非官方逐字稿
- **发言人**：王宁（董事会主席兼CEO）、司德（COO）、杨镜冰（CFO）、文德一（海外总裁）
- **一句话定位**：全序列起点——上市后的第一次年度答卷，"IP 平台"叙事的奠基场次
- **是否值得精读**：是。多数承诺（利润率区间、IP 矩阵、乐园）在其后三年被逐一验证或证伪，是检验管理层口径可信度的基准场

## 第二级 · 通读全书

**结构骨架**：王宁开场 → 司德业务回顾（IP/渠道/会员）→ 杨镜冰财务回顾（IP/渠道/费用三维拆解）→ 8 组问答（会员与缺货/内外部 IP/门店与 IP 周期/Pucky 与内容化/PDC 与三线城市/IP 一体化与衍生品/渠道定位/营销与二手）

**主线（一句话因果链）**：
上市融资 + 疫情下高增长 → 全产业链平台叙事（四板块）→ 但保守下单导致缺货、利润率首降 → 用"心向大海"把估值锚从盲盒切换到 IP 生态

## 第三级 · 分析阅读

**核心论点**（管理层立场）：

1. 四大 IP 均超 2 亿、占比更均衡，平台能力被验证
2. 缺货是需求超预期+供应链疫情，3 月底已缓解
3. 利润率下滑是质量/环保投入+疫情期间的固定投入，长期维持 22-27%
4. 内外部 IP 利润率仅差 2-3 个点，不做刻意区分
5. 头部 IP 每年 3-4 个系列、销售周期 12-18 个月
6. 衍生品克制，核心仍放潮玩

**逐条检验**：

1. "Pucky 表现符合规划"——**与后续事实冲突**：2021 年实际 1.81 亿（-39.3%），原文笔者注已点破"准确预测某一个 IP 的销售情况可能很难"。管理层对单一 IP 的预测能力自此场起应打折扣
2. 缺货归因中"我们下单保守"是罕见的自我归因（王宁主动补充），可信度较高；但"Q2 重磅 IP 备货更充分"的承诺需后续验证（2021 年 Skullpanda 确实爆发）
3. 利润率 22-27% 区间：2021 年 22.3% 贴下限达成，2022 年 16%（经调整 19%）破位——区间在疫情冲击下失效，但方向上 2023 年后回到 20%+ 重新贴线
4. "衍生品不做激进投入"与"潮玩占比核心"当时可信；但与后来毛绒占比过半的路径完全无法从本场推出——本场的品类视野仍局限于潮玩

**坦承无法回答的问题**：未给 2021 年收入指引（仅定性"更好表现"）；乐园/游戏只有方向无时间表。

## 第四级 · 比较阅读

- **与 21H1（2021-08）对照**：本场存货 78 天已"上升"，半年后 74 天（新低）→ 再半年 128 天（恶化）——库存周期的真正拐点在本场与 21H1 之间埋下，当时无人视为风险
- **与指引兑现追踪表**：本场是全序列中少数"把长期区间讲清楚"的场次；Pucky 预测落空 + 22A 指引落空 + 23A-25A 连续超额 + 26 年保守，构成完整的管理层预测能力曲线
- **与投资论点护城河对照**：IP 矩阵（四大 IP 均衡）本场已有数据支撑；品类转换/地理对冲本场完全缺席——护城河是逐步"长"出来的，不是设计出来的
- **被忽略的信号**：王宁提及乐园"已经在进行当中"、游戏"在考虑的方向"、动画《哪吒重生》投资——"海"的种子 2021 年 3 月就已埋下，比市场认知早两年

## 四个基本问题的回答

| 问题 | 回答 |
|---|---|
| 整体讲了什么 | 上市首年高增长（25.13 亿/+49.3%），四大 IP 均衡验证平台能力；缺货与利润率下滑是暗线；"心向大海"定调长期 IP 生态 |
| 细部是怎样的 | 业务（IP/渠道/会员）→ 财务三维拆解 → 8 组问答：缺货归因、利润率区间 22-27%、IP 周期 12-18 个月、海外扩张计划 |
| 有道理吗 | 平台叙事与后续兑现大体成立；但 Pucky"符合预期"被次年 -39.3% 证伪，单一 IP 预测不可信；22-27% 利润率区间在疫情冲击下失效过 |
| 读它干什么 | 作为全序列基准场：校准管理层口径起点、记录"海"战略的最早时间戳、建立 IP 预测不可信的第一证据 |

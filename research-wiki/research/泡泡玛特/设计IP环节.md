# 泡泡玛特 (09992) — 供应链环节：设计 / IP

> 供应链五环节之一的环节级独立分析，承接 [[供应链与制造]]。结构性限制逐项验证 + 权重评估；**未经数据验证的限制不列**。

## 环节运行机制

- **111 名内部设计师**组成"内部创意设计及工业开发团队"，深入参与产品开发（招股书 p.245，2020-06-30 口径）
- 截至 2020-06-30 已创作 **9 个自有 IP**（BOBO&COCO、Yuki、BUNNY 等）；授权 IP 支付特许权使用费
- **产品原型和模具设计由公司负责**（标准营运程序 + 原型 + 模具），模具归公司所有、可转让
- 三种模式：**签约分成**（外部艺术家，独家）+ **内部孵化**（Pop Design Center）+ **联名**（迪士尼/三丽鸥等，引流为主）
- 财务落点（2025 年报）：按销量提成的授权费 **833,481**（费用化）+ 设计服务费 **86,446**（费用化）；买断授权金资本化为无形资产（2025 添置 **117,623**）后按摊销进损益（127,050）

## 结构性限制与权重

| 限制 | 权重 | 量级证据 | 判定 |
|------|:---:|---------|------|
| **分成制（授权费按销量提成）** | **低** | 授权费占营收 7 年稳定在 **1.8%–3.0%**（2019 2.9% → 2022 1.8% 谷 → 2024 3.0% 峰 → 2025 2.25%）；2025 授权费 833,481 = 营收 2.25% / 毛利 3.1% / **行政开支 47%** | 量级小、占比无恶化趋势；2025 单年显著摊薄（3.0%→2.25%，营收 +185% 快于授权费 +112%）。不构成压毛利的结构性力量 |
| **IP 生命周期（单一 IP 3-5 年一轮）** | **高** | 见 [[产业链]] 第六章；前三大 IP 占比目标 <50% 意味着现状 >50% | 影响营收规模本身而非成本，是核心风险 |
| **设计师产能上限** | **低** | 设计/开发人员：2020 793 → 2021 1,617 → 2022 1,584 → 2023 1,110* → 2024 1,435 → 2025 2,194 → 2026H1 2,322（*2023 销售口径重划分）；纯设计岗 111 人（2020 招股书） | 产能瓶颈被签约艺术家网络（200+，二手口径）缓解；内部团队主责产品化而非爆款原创；2025 起科目改"行政及设计开发"，扩张显著但仍属规模内生变量，非结构性限制 |

### 团队结构与职能

- **PDC（泡泡设计中心）**：把艺术家原画转化为可量产、可系列化的产品，令 IP 孵化从偶然爆款转向有节奏的持续输出（爱建证券 2026-08-12 深度报告）；也承担内部原创 IP 孵化（如 2019 年自有 IP BOBO&COCO，百度百科标注 PDC 内部开发）
- 全球 20+ 国家/地区本地办公室，设计力量本地化（2026 中报逐字稿）
- 官方只披露"设计/开发人员"总盘子；**PDC 孵化 IP 名单口径混乱**（自媒体将 SKULLPANDA、DIMOO 等签约 IP 误归 PDC），可确证内部 IP 仅 BOBO&COCO 等少数

### 人才吸收（"发现"与"招聘"）

**官方一手**（年报"与持份者关系"章节，历年同句）：主要通过 **校园招聘会、招聘代理、公司网站及社交网络平台** 招聘雇员；有健全的内部培训政策。

**二手报道**（未经官方证实）：
- 超 20 人**艺术家发掘团队**（雪球 2025-09-24）
- 自办 **PTS 潮流玩具展**（2024 上海/2025 北京"全球数百位艺术家"）、国际艺术展、顶级院校合作、设计比赛（界面/中国日报）
- **大数据筛选**艺术家，王宁自比"赛马机制"（搜狐号 2025-06-21）
- 全员共创"**灵感盲盒池**"（东财财富号 2026-06-01，锦鲤小福案例）
- 签约规模（均二手口径，官方不披露）："全球 300+ 艺术家合作、运营自有/独家 IP 约 50 个"（雪球 2026-06-06）；"签约 200+ 顶级艺术家 IP"（搜狐号 2025-06-21）；"深度合作/签约艺术家超 200 位"（雪球 2026-08-05）

### 激励机制

**对内部设计师**（东财财富号 2026-06-01，自媒体、未经官方证实）：
- 不考核销量，考核市场反馈、设计创新性、工艺难度；品控权（改动须艺术家+公司双重同意，交付不达标可叫停）
- "IP 合伙人计划"：爆款 IP 衍生品持续分成三年；"年度潮玩造物主"称号；灵感盲盒池全员共创

**对签约艺术家**：
- 销售分成：官方未披露比例，第三方估算 5–10%；雪球传闻 Labubu 龙家升为利润 8%；自媒体称头部 10–15%（均未证实）
- 招股书锚点：**设计费年度上限"个位数水平"**——分成有封顶
- **艺术家股东化唯一案例**（官方可查）：王信明（Molly）2019-06 独家买断版权+获 2% 股权（作价 345.32 万），IPO 后持约 1.49%（2025-09 市值约 46 亿元）
- 收入组合：销售分成+联名授权+买断/股权+拍卖版税；乐园自营不分成（新浪财经·YOUNG财经 2025-09-17）
- 财务落点：设计及授权费 2025 年 **8.33 亿**（占营收 2.25%）随销量线性分成

## 结论（修正 2026-08-21 前稿"分成制长期压毛利·确定"）

- 授权费是**随销量线性的费用**，但占比稳定在 ~2–3%，**不存在"长期压毛利"的结构性恶化**；2024→2025 反而显著摊薄。
- 真正决定毛利的是销售成本（27.9%）；决定净利率的主要费用是经销及销售开支（80.8 亿，占营收 21.8%）——授权费（8.3 亿）不足其 1/10。
- 分成制的真实风险不在"比例高"，而在**分成协议重签时被调高**（一年期协议）与**单一 IP 分成基数大**——权重最终取决于议价地位，而非当下占比。

# 泡泡玛特周期对抗：芒格多元思维模型检视

> 对照：Chason《泡泡的过去、现在、未来》× 芒格心智模型格栅
> 原始资料：[[../../raw/research/泡泡玛特/2026-06-17-popmart-past-present-future]]

## 芒格格栅总览

芒格说：**"手里只有锤子的人，看什么都是钉子。"** 一个严肃的投资判断，必须动用多个学科的思维模型，交叉验证。以下是我们用来检视泡泡玛特周期问题的模型格栅：

| 模型 | 学科来源 | 在泡泡玛特分析中的映射 |
|------|---------|---------------------|
| 🔄 **反演** | 数学/雅可比 | 不问"怎么赢"，问"怎么死" |
| 🔒 **护城河** | 商业/巴菲特 | 竞争优势是否可持久、可加深 |
| 📐 **安全边际** | 工程学/格雷厄姆 | 估值 vs 内在价值的缓冲空间 |
| 🔗 **复利** | 数学 | IP积累、用户心智沉淀、组织学习是否复利增长 |
| 🧲 **激励** | 心理学 | 创始人、设计师、渠道的激励机制是否对齐长期利益 |
| 📊 **概率思维** | 统计学 | 每层防御是"确定性"还是"概率性"？多因素收敛还是发散？ |
| ⚡ **多因素协同** | 物理学 | 多个正向因素同时叠加→非线性的极端结果 |
| 🌐 **生态系统** | 生物学 | 平台化网络效应 vs 线性 IP 公司 |
| 🔍 **二阶效应** | 经济学 | 一阶看得见（收入增长），二阶才致命（用户流失的滞后效应）|
| 🧪 **能力圈** | 认知心理学 | 哪些我们知道，哪些我们不知道 |

> **核心问题**：泡泡玛特的周期防御系统，经得起芒格思维模型格栅的交叉拷问吗？

## 一、反演（Inversion）— 先想怎么死

> Jacobi: "Invert, always invert."
> 芒格："反过来想，总是反过来想。什么会导致失败？然后坚决避开。"

### 泡泡玛特怎么死？

**第一死法：IP 断档**

当前顶流是 LABUBU（~150 亿体量）。如果 LABUBU 衰退速度超过新 IP 崛起速度，收入出现硬缺口。

- Chason 的判断：平台化运营可以加速新 IP 孵化，降低断档概率 → **概率有改善，但非零**
- 芒格的视角：这不是"会不会"的问题，是"什么时候"的问题。IP 一定会衰退，问题是你有没有在衰退前长出足够多的新东西。

**第二死法：用户断代**

Chason 提出"3 年高活跃后流失"定律。这意味着：

```
每 3 年，存量用户洗牌一次。
公司必须像西西弗斯一样，不断把新用户推上山。
```

- 反演的结论：如果获客成本（CAC）持续攀升而 LTV 不变，模型早晚崩溃。
- 芒格会问：**"当获客变贵时，你有定价权吗？"** 潮玩本质上是可选消费——没有定价权。

**第三死法：品类厌倦**

毛绒→？。如果下一代年轻人不玩潮玩了，而是集体转向某种新品类（AR 宠物？数字藏品？），泡泡玛特的"IP 换品类"策略是否有效？

- Chason 的回答：强 IP 可以跨品类迁移。LABUBU 做成毛绒成功了 → 下一个载体也会成功。
- 芒格的质疑：**"你这个推理里有没有幸存者偏差？"** 我们看到的 LABUBU+毛绒是成功案例，但 SKULLPANDA+毛绒呢？MOLLY+毛绒呢？只有一个 LABUBU 跨品类成功了，这是规律，还是运气？

**第四死法：组织熵增**

芒格特别警惕成功之后的管理层退化：**"大部分聪明人不知道自己什么时候变成了蠢人。"**

泡泡玛特的防御本质上依赖"组织持续做正确决策"——IP 选择、设计师管理、渠道扩张、品类切换……任何一环出错都可能导致连锁反应。这是一个**决策密集型**而非**惯性驱动**的生意。

- 可口可乐不需要天才 CEO，系统自己运转。
- 泡泡玛特需要王宁和团队不断做出正确的判断。
- 芒格的原则：**"把大量钱投在我们不用再做决策的地方。"** 泡泡玛特显然不是这种生意。

## 二、护城河（Moat）— 五层检视

芒格的护城河标准极其苛刻：**"必须宽到连白痴都能经营。"** 用这个标准来量泡泡玛特：

| 护城河层次 | 是否存在 | 宽度 | 加深趋势 | 芒格式质疑 |
|-----------|---------|------|---------|-----------|
| 品牌/IP | ✅ 有 | 中等 | ↑ 加深中 | LABUBU 150 亿体量是真实品牌力，但单个 IP 的护城河 ≠ 公司的护城河 |
| 规模/渠道 | ✅ 有 | 中等 | ↑ 海外扩张 | 门店数量是规模经济，但潮玩门店不是基础设施——没有转换成本 |
| 网络效应 | ❌ 无 | — | — | 用户之间没有互动价值。多一个用户不会让你手里的 LABUBU 更值钱（二手市场有些微效应，但不形成壁垒）|
| 转换成本 | ❌ 无 | — | — | 消费者明天可以不买泡泡玛特。品牌的转换成本远低于银行/软件/数据库 |
| 成本优势 | ❌ 无 | — | — | 潮玩生产壁垒低，中国供应链成熟，对手可以找到同样的工厂 |

**芒格的结论**：泡泡玛特的护城河**真实存在但很窄**。它的竞争优势主要来自两个东西：

1. **先发优势 + 规模** — 最大的 IP 库、最多门店、最强设计师关系网。这是在"跑马圈地"阶段积累的，窗口期正在关闭，但还没有完全关上。
2. **组织的 IP 运营 know-how** — 这是隐性的、难以复制的。Chason 说的"平台化效率"（签约→产品化→验证→分发）正是这种 know-how 的外显。

**但芒格会追问**：这两个优势，哪一个能挡住一个拿着 50 亿现金、挖走你头部设计师的竞争对手？

答案是：**第一个挡不住，第二个也许能。** 这就是为什么泡泡玛特的安全边际必须要足够大——护城河不够宽，估值不能给溢价。

## 三、安全边际（Margin of Safety）— 工程学视角

格雷厄姆的安全边际是"1 美元的资产用 0.4 美元买"。但这在现代消费品牌上不适用。芒格版本的安全边际 = **"即使最坏情况发生，你也不会永久损失资本。"**

### 泡泡玛特的"最坏情况"是什么？

```
情景 A（可接受）：
  LABUBU 正常衰减（-20% CAGR），新 IP 补上 → 收入增长放缓但不崩

情景 B（危险）：
  LABUBU 快速衰退 + 海外扩张受阻 + 毛绒热潮退去 + 无新顶流 IP
  → 三重叠加 → 收入 -30%～-50%

情景 C（致命）：
  情景 B + 管理层内部分裂 / 王宁离开 / 财务造假
```

- Chason 的框架认为情景 A 概率最高，情景 B 概率低但不可忽略。
- 芒格会说：**"我不需要精确知道情景 B 的概率。我只要确认，即使情景 B 发生了，我也不至于血本无归。"**

### 安全边际的量化解构

泡泡玛特目前的核心业务可以拆成：

- LABUBU 相关收入：~150 亿（含授权、衍生品、乐园等）
- 其他 IP 收入：剩余部分
- 海外收入：~44%

如果 LABUBU 收入腰斩 → 总盘缩水 ~30%。这是一个真实存在的下行风险。

**芒格式结论**：泡泡玛特不是一个可以"买了就忘"的生意。它需要你**持续跟踪** IP 表现、用户数据、管理层动向。这种生意天然需要**更大的安全边际**——因为你无法用"长期确定性"来补偿短期的高估值。

## 四、复利（Compounding）— 什么在积累，什么在消耗？

芒格投资的核心信仰是复利：**"理解复利的人能得到它，不理解的人会付出它。"**

### 泡泡玛特有哪些复利？

| 维度 | 是否复利 | 说明 |
|------|---------|------|
| IP 库 | 🟡 半复利 | IP 可以积累但会折旧。LABUBU 和 MOLLY 是资产，但不是永久资产。不像可口可乐的配方——1920 年的配方 2026 年还在卖。|
| 设计师关系网 | 🟢 正复利 | 越多成功案例，越能吸引新设计师。设计师规模 = 新 IP 概率 ↑ |
| 渠道/门店 | 🟢 正复利 | 越多店 = 越强谈租金的能力 = 越好的位置 = 越多客流 |
| 供应链效率 | 🟢 正复利 | 平台化效率每跑一轮都在提升（Chason 的观点）|
| 组织学习 | 🟢 正复利 | IP 运营 know-how 在积累。2026 年的泡泡玛特比 2020 年更懂怎么做 IP |
| 用户忠诚度 | 🔴 负复利 | 用户 3 年后流失！积累的用户会消失——这是反复利 |

**关键洞察**：泡泡玛特最大的结构性缺陷 = **用户端是反复利**。

芒格热爱的生意——See's Candies、可口可乐——用户不会因为买了 3 年巧克力就不买了。恰恰相反，老用户是利润最高的用户（零获客成本）。

泡泡玛特的"3 年流失定律"意味着：
- 收入增长 = 老用户自然流失 - 新用户获客 + 客单价提升
- 如果新用户获客速度 < 老用户流失速度 → 负增长
- 获客成本如果持续上升 → 单用户经济不可持续

**这是泡泡玛特最被低估的脆弱点。** 不是 IP 会衰退（大家都知道），而是**用户基础不可积累**——这直接否定了复利效应的基础假设。

## 五、激励（Incentives）— 谁在为什么工作？

> 芒格："告诉我激励是什么，我就告诉你结果是什么。"

### 多利益主体的激励对齐分析

| 角色 | 激励 | 与长期股东利益是否对齐 |
|------|------|---------------------|
| 王宁（创始人）| 大股东 + 个人声誉 + 做成伟大公司 | 🟢 高度对齐 |
| 设计师 | 分成 + 名气 + IP 归属感 | 🟡 部分对齐。顶级设计师可能自立门户（参考 KAWS）|
| 经销商/加盟商 | 短期销售额 → 提成 | 🔴 可能错位。为冲量可能过度铺货、损害品牌调性 |
| 内部产品经理 | KPI = 新品销售额 | 🔴 可能错位。追求短期爆款而非 IP 长期健康 |
| 海外团队 | 扩张速度 → 预算/晋升 | 🟡 可能追求速度 > 质量 |

**Chason 未充分讨论的维度**：

泡泡玛特的生意本质是**设计师经济**。设计师 = 内容创造者，等于影视公司的导演/编剧。如果激励设计不当，会出现：

1. **设计师外流**：顶级设计师发现 IP 价值大部分被公司拿走 → 自己单干 / 签约竞品
2. **短期主义**：设计师为追求短期内多出系列 → IP 审美疲劳加速
3. **人才断层**：过度依赖少数头部设计师（如 Kenny Wong / 龙家升）→ 关键人风险

芒格会问：**"泡泡玛特的 IP 到底是公司的资产，还是向设计师'租'来的？"**

如果是租的——租约到期（设计师离开 / 过气），资产归零。如果是公司的——换设计师也能维护 IP 热度（迪士尼模式），才是真资产。

**泡泡玛特目前处于两者之间**。LABUBU 正在从"龙家升的 LABUBU"变成"泡泡玛特的 LABUBU"（电影、乐园、游戏——这需要公司而非个人投入）。这是正确的方向，但过程充满不确定性。

## 六、概率思维 — 多因素收敛还是发散？

> 芒格："如果一件事太复杂，我会把它放进'太难'的箱子里。"

### 泡泡玛特的防御体系 = 多因素概率叠加

```
P（成功防御周期）= P（IP 矩阵不塌）× P（用户迭代不断）× P（品类持续适应）× P（组织不衰退）× P（全球化不失控）
```

如果这 5 个因子相互独立，且每个概率 80%：
- P（成功）= 0.8⁵ = 32.8%

如果相互关联（不好的事倾向于一起发生）：
- P（成功）可能更低

### 多因素协同效应（Lollapalooza Effect）— 上行可能

反过来，如果这些因素形成正反馈：

```
LABUBU 内容化成功 → 海外知名度↑ → 吸引更多国际设计师 → IP 库更丰富 → 
平台化效率再提升 → 更多品类 → 用户触达频率↑ → 单用户 LTV↑ → 
打破"3 年定律" → 商业模式从"反复利"变成"正复利"
```

这是泡泡玛特最性感的叙事——**多个因素同时朝好的方向收敛，产生非线性的极端结果**。

但芒格会冷静地指出：**Lollapalooza Effect 在两个方向上都有效。** 如果 LABUBU 电影失败、海外扩张受阻、毛绒热潮退去、关键设计师离开——这些因素也会同时朝坏的方向收敛，产生**负向的 Lollapalooza Effect**。

**概率思维的结论**：泡泡玛特是一个**高方差**的投资。结果分布很宽——可能非常好，也可能非常差。中间值不被保证。

## 七、生态系统 vs 线性公司

### 生物学视角：泡泡玛特是"物种"还是"生态系统"？

| | 线性 IP 公司 | 生态系统公司 |
|------|------------|------------|
| 典型 | Sanrio（Hello Kitty）| 迪士尼 |
| 动力 | 少数 IP 的兴衰 | 多 IP × 多媒体 × 多变现渠道 |
| 韧性 | 低。一个 IP 不行了 = 公司不行了 | 高。系统自我修复 |
| 复利 | 线性的 | 指数的 |

泡泡玛特正在从"线性 IP 公司"向"生态系统"转型的路上——但还远没到。

Chason 的"平台化"叙事本质上是说泡泡玛特正在构建生态系统的基础设施。但基础设施 ≠ 生态系统。一个有完善高速公路网的城市 ≠ 有繁荣经济的城市——还需要内容、文化、用户参与。

**芒格会问的问题**：泡泡玛特的平台化，到底是（a）让新 IP 更容易跑出来，还是（b）只是在用同一个方法论反复复制？如果是（b），那只是工业化的线性扩展，不是生态系统的指数增长。

## 八、二阶效应 — 看得见的和看不见的

> 巴斯夏："好经济学家看得到看不见的东西。"

### 泡泡玛特的二阶效应清单

| 一阶效应（看得见）| 二阶效应（需要推演）|
|-----------------|-------------------|
| LABUBU 电影上映 → 票房收入 | 电影如果口碑崩了 → IP 价值折损 → 连带盲盒销售下滑 |
| 海外扩张开店 → 海外收入增长 | 过快扩张 → 管理稀释 → 海外门店亏损 → 拖累整体利润率 |
| 更多IP上线 → 矩阵更丰富 | 资源分散 → 单个 IP 投入不足 → 没有 IP 能突破阈值成为顶流 |
| 毛绒品类爆发 → 收入超预期 | 过度依赖毛绒 → 品类单一化 → 品类退潮时缺乏替代方案 |
| 乐园开业 → 新收入来源 | 乐园是重资产 → 如果客流不达预期 → 固定成本变成亏损黑洞 |
| 用户 3 年流失 → 不断获新客 | 如果人口结构变化（少子化）→ 潜在新用户池缩小 → 获客越来越难 |

**Chason 的文章偏重一阶分析**（IP 运营手段、品类切换、内容化方向）。芒格会要求我们把**二阶效应**写满一页纸，尤其是那些会反转一阶判断的效应。

最危险的二阶效应：**The Monster 化（内容化）如果失败**——不只损失投入的资金，而且反噬 IP 本身。一个失败的 LABUBU 电影，会降低 LABUBU 的品牌价值，进而拖累盲盒销售。这就是为什么"内容化"不是免费的午餐，而是一把双刃剑。

## 九、能力圈 — 我们知道什么，不知道什么

> 芒格："知道自己会在哪里死，就永远不要去那里。"

### 我们知道的

1. 泡泡玛特的 IP 矩阵是目前中国最强的（没有之一）
2. 平台化效率在提升（单位时间内能跑更多 IP）
3. LABUBU 正在从"潮玩 IP"向"文化 IP"升级（电影/游戏/乐园）
4. 海外市场提供了第二增长曲线，且与中国市场存在时间差
5. 创始人王宁是核心资产，能力圈匹配

### 我们不知道的

1. **LABUBU 电影能不能成功？** 潮玩 IP 跨媒体是全新品类，没有先例可参考。不能类比漫威（漫画→电影）或宝可梦（游戏→动画→一切）。
2. **3 年流失定律能不能被打破？** 如果 LABUBU 内容化成功，有没有可能让用户从"潮玩消费者"变成"文化粉丝"？还是说潮玩消费本质上就是阶段性的？
3. **毛绒之后是什么？** 下一代品类是随机的还是可以主动设计的？Chason 说是概率问题——我们同意。
4. **海外竞争格局会如何演变？** 泡泡玛特在海外目前是降维打击（中国供应链+运营效率 vs 本地慢速对手），但如果迪士尼、万代、三丽鸥认真反击呢？
5. **王宁能否持续做出正确决策？** 创始人驱动的公司，最大的变量就是创始人本人。

### 能力圈判断

芒格对能力圈的定义是：**"如果你不能在一张纸上用几句话解释清楚为什么一个生意能持续赚钱，你就不在能力圈内。"**

泡泡玛特的赚钱逻辑不复杂：IP 吸引用户 → 盲盒 / 毛绒 / 联名变现 → 新品推动复购。但"持续"二字是分歧所在。

**我们的结论**：泡泡玛特的核心商业模式在能力圈内，但其**长期确定性**不在任何人的能力圈内。它是一个"好生意 + 不确定的持久性"的组合——这种组合在芒格的世界里需要极大的安全边际。

## 十、芒格格栅整合判断

### 多模型交叉评分

| 思维模型 | 评估 | 评级 |
|---------|------|------|
| 反演 | 识别出 4 种死亡路径，其中"用户反复利"最被低估 | 🟡 有脆弱点 |
| 护城河 | 真实但不宽。先发优势 + 组织 know-how，无网络效应、无转换成本 | 🟡 中等护城河 |
| 安全边际 | 需要更大安全边际——高方差生意不适合溢价买入 | 🔴 当下估值的核心挑战 |
| 复利 | 运营端正复利（IP/渠道/效率），用户端负复利（流失）| 🟡 结构性矛盾 |
| 激励 | 创始人对齐，设计师/经销商可能错位。IP 所有权是关键 | 🟡 需持续关注 |
| 概率 | 多因素叠加 → 高方差 → 结果分布宽 | 🔴 不确定性强 |
| 多因素协同 | 上行有 Lollapalooza 潜力，下行同样有 | 🟡 双刃剑 |
| 生态系统 | 在路上但还没到。平台化 ≠ 生态化 | 🟡 需要验证 |
| 二阶效应 | 内容化失败会反噬 IP。海外扩张过快有管理稀释风险 | 🟡 不可忽视 |
| 能力圈 | 商业模式清晰，长期确定性模糊 | 🟡 在边缘 |

### 芒格的终极问题

**"如果你知道自己将在 10 年后持有这只股票，你必须能回答一个问题：10 年后，为什么还会有用户为泡泡玛特的 IP 买单？"**

Chason 的回答是：内容化（The Monster 化）——把 LABUBU 从潮玩升级为有故事、有情感连接的文化 IP。

我们的回答是什么？

- 如果 LABUBU 电影成功 → IP 跨入迪士尼级别 → 品牌寿命可能是 50 年 → **泡泡玛特值得高估值**
- 如果 LABUBU 电影一般 → IP 停留在潮玩层级 → 品牌寿命 5-10 年 → **需要更宽的 IP 矩阵来补偿**
- 如果 LABUBU 电影失败 → IP 受损 → 下一轮周期无顶流接棒 → **估值需大幅打折**

**而这三条路径的概率，今天没有人知道。** 这不是信息不足的问题——是未来本身尚未确定的问题。

**芒格会怎么做？**

他不会赌。他会说：**"如果我不确定，我就不做。投资不是奥运会跳水——没有难度加分。"**

他会把泡泡玛特放进两个箱子之一：
- **"太难"的箱子**：如果他认为内容化的不确定性太大，直接放弃。
- **"有安全边际的箱子"**：如果价格跌到即使 LABUBU 衰退 50% 也能保本的价位，他会买。

**后者才是芒格精神的真正体现**——不是判断对或错，而是**只在你拥有不对称优势的时候下注。**

## 与 Chason 框架的对话

Chason 做了一件有价值的事：把泡泡玛特的周期防御从"能不能"的二元问题细化成"在什么条件下能/不能"的多因素分析。

芒格的思维模型格栅让我们更进一步：

1. **Chason 的"平台化" ≈ 芒格的"复利效应在运营端的体现"** — 但用户端的反复利（3 年流失）是 Chason 自己发现但未充分重视的结构性缺陷
2. **Chason 的"The Monster 化" ≈ 芒格的"二阶效应 + Lollapalooza 效应"** — 内容化成功 = 正向多因素收敛；失败 = 不只损失投入，还反噬 IP 本体
3. **Chason 强调了"创始人"** — 芒格的框架补上了"激励机制"的维度：IP 是公司的资产还是租来的？设计师的长期利益是否与股东一致？
4. **Chason 未充分讨论安全边际** — 芒格要求我们明确计算"最坏情况"下还能不能保本，而不是仅仅判断"大概率会好"

**最核心的分歧**：Chason 的框架聚焦在"泡泡玛特能不能做好"，芒格的框架要求我们同时考虑"如果我们判断错了会怎么样"——这是防御性投资者与进取性分析师的本质区别。

## 投资启示

泡泡玛特是芒格式投资者会**高度关注但大概率不买**的股票：

- 商业模式有趣（有趣的挑战）
- 管理层优秀（好马）
- 行业有结构性增长（顺风）
- 但长期确定性不足（核心缺陷）
- 护城河不够宽（安全边际不足）

它完美诠释了芒格的另一句名言：**"我们有很多公司我们很喜欢但我们不会买——因为价格不对。"**

如果一定要持有，芒格的应对策略是：
1. **小仓位** — 对不确定性的补偿
2. **持续跟踪** — 不是"买了就忘"的生意
3. **关键观察指标**：LABUBU 电影口碑 / 新 IP 孵化速度 / 用户留存率变化 / 海外单店模型 / 设计师留存率
4. **退出条件**：任何一个"死亡路径"上出现实质恶化信号 → 立即退出

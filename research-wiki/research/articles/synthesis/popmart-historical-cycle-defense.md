# 泡泡玛特历史上如何对抗IP/品类周期——归纳法 × 演绎法 × 芒格模型

> 方法论：从历史事实中归纳模式 → 演绎推演机制 → 芒格多元模型映射
> 数据来源：泡泡玛特2016-2025年年报 + 公开IR数据

---

## 一、历史事实：泡泡玛特的三个关键转折

### 2016-2021：Molly 单IP驱动 + 盲盒爆发

```
2016: 签约 Molly → 首个盲盒系列 → 现象级爆款
2017-2019: 营收从1.6亿→16.8亿（年复合~220%），几乎全由 Molly 驱动
2020: 港股上市，市值破千亿
2021: 营收44.9亿，Molly 占比仍超30%
```

**归纳**：这是典型的"单IP爆款驱动"阶段。增长极度依赖一个IP，品类认知=盲盒。

### 2022：第一次IP周期危机

```
2022: 营收46.2亿，增速从220%断崖跌至2.8%
      — Molly 审美疲劳
      — 疫情封控（门店关闭）
      — 消费者对盲盒的新鲜感消退
```

**这是一次真实的"IP+品类双重周期"测试。** Molly 在过气，盲盒作为品类也在被质疑。

### 2023-2025：三条防线同时激活

泡泡玛特没有坐等 Molly 回归，而是做了三件事：

| 防线 | 动作 | 效果 |
|------|------|------|
| **IP矩阵扩建** | SKULLPANDA突破10亿（+27%），小野+191%，DIMOO+21% | Molly占比从30%+降至~15% |
| **品类形态创新** | 搪胶毛绒（LABUBU毛绒爆款）、MEGA高端线 | 从"盲盒公司"变为"IP运营平台" |
| **地理空间扩张** | 海外收入从几乎为零→2025年占比43.8% | 全球化打开新增量 |

**结果**：2024年营收130亿（+107%），2025年营收371亿（+185%），毛利率从58%→72%。

## 二、归纳法：从历史中提取的四个防御模式

### 模式一：IP矩阵 → 熨平个体IP的生命周期

```
历史事实：
  2019: Molly 贡献 >40% 营收
  2022: Molly 衰退，但 SKULLPANDA + DIMOO + 小野 顶上
  2025: 10个IP收入过亿，LABUBU 成为首个百亿级IP，Molly 占比 ~15%
```

**归纳规律**：单一IP的衰退不等于收入的衰退——只要多IP矩阵足够深。泡泡玛特在 Molly 衰退前就已经在储备新IP（2019年签约 DIMOO、2020年签约 SKULLPANDA）。这不是运气，是有意识的战略。

### 模式二：品类形态转换 → 从载体到需求

```
历史事实：
  2016-2021: 盲盒 = 泡泡玛特（品类=公司）
  2023: 搪胶毛绒 LABUBU 爆款，打开新品类
  2024: MEGA 系列（1000-5000元收藏级），打开新价格带
  2025: 毛绒+手办+MEGA+衍生品 多品类并行
```

**归纳规律**：泡泡玛特成功的品类转换遵循同一个公式：**IP不变，载体变**。LABUBU 作为毛绒卖爆了——不是因为消费者突然喜欢毛绒了，而是因为他们已经喜欢 LABUBU。IP 是"锚"，品类是"帆"——锚不动，帆可以换。

### 模式三：地理扩张 → 从存量到增量

```
历史事实：
  2020前: 99% 收入来自中国
  2023: 海外开始起量
  2024: 海外收入50亿（占比~38%）
  2025: 海外收入~163亿（占比43.8%）
```

**归纳规律**：当国内市场遭遇品类质疑时，海外市场提供了全新的增长曲线。海外消费者对泡泡玛特的认知是"中国潮玩IP"——他们不需要经历"盲盒疲劳"周期，因为他们才刚刚开始接触。

### 模式四：价格带拉宽 → 从冲动消费到收藏投资

```
历史事实：
  2016-21: 主力价格 59-79元（冲动消费）
  2023: MEGA 1000-5000元（收藏投资）
  2025: 毛利率 72.1%（品类多元化 + 高端化推升）
```

**归纳规律**：从"59元冲动消费"到"5000元收藏投资"——价格带的拉宽，本质上是对冲了品类周期。当"随便买一个玩玩"的需求下降时，"收藏全套"或"投资隐藏款"的需求仍然存在。

## 三、演绎法：三条防线的运作机制

### 3.1 IP矩阵为什么能防住Molly的衰退？

演绎前提：
```
P1: 泡泡玛特的核心能力不是"创造一个超级IP"，而是"签约-孵化-产品化-分发"
P2: 这个能力不依赖任何单个设计师——它是一个标准化的工业流程
P3: 中国有足够多的优秀插画师/设计师可供签约
P4: 渠道触达效率（门店+抽盒机+抖音）决定了新IP的冷启动速度
──────────────────────────────
C: 只要签约-孵化-分发这个链条不断，旧IP衰退就只是给新IP腾出渠道资源
```

泡泡玛特在2022年已经验证了这个逻辑：当 Molly 增长停滞时，SKULLPANDA + 小野 + DIMOO + HACIPUPU 同时发力，新IP合计增长覆盖了 Molly 的下滑。

### 3.2 品类转换为什么能成功？

演绎前提：
```
P1: 消费者的忠诚是对IP的，不是对"盲盒"这个商品形态的
P2: IP可以附着在任何物理载体上（PVC手办/毛绒/金属/陶瓷/数字）
P3: 不同载体的生产成本和受众不同，天然形成价格带
──────────────────────────────
C: 品类转换 = 同一个IP用不同的载体触达不同消费力的用户
```

演绎验证：LABUBU 毛绒的成功不是因为毛绒这个品类突然火，而是 LABUBU 这个IP火。如果是先做毛绒再做IP，大概率失败。**顺序是：IP先行，品类跟随。**

### 3.3 全球化的真正意义是什么？

演绎前提：
```
P1: 国内市场的品类周期与海外市场不同步
P2: Z世代是全球化的——日本、韩国、东南亚、美国、欧洲的年轻人有相似的消费心理
P3: 泡泡玛特在海外的品牌定位是"中国潮流IP"，不是"盲盒"
──────────────────────────────
C: 全球化 = 品类周期的地理对冲 + 品牌定位的重新定义
```

海外消费者对泡泡玛特的第一印象不是"卖盲盒的"，而是"来自中国的潮流玩具品牌"。这意味着他们在海外天然地跳过了中国消费者经历过的"盲盒疲劳"阶段。

## 四、芒格多元模型映射

| 芒格模型 | 历史验证 |
|---------|---------|
| **数学/复利** | IP矩阵不是加法效应——10个IP不是1个IP的10倍。IP之间存在交叉引流（买Molly的人顺便发现SKULLPANDA）→ 网络效应 |
| **生物学/生态位** | 泡泡玛特占据的生态位不是"盲盒"，是"Z世代情感消费"。盲盒只是进入这个生态位的第一个入口——毛绒、MEGA是从入口出发的生态位扩张 |
| **工程学/冗余备份** | 2019-2021年签约的多个IP不是"多余的"，是冗余备份。当 Molly 这条主线断裂时，备份IP立刻接管。没有冗余=没有2023-25年的复苏 |
| **心理学/可变奖励** | 斯金纳箱解释"为什么盲盒机制有效"，但不解释"为什么品类可以转换"。品类转换=（IP不变 × 载体变 × 可变奖励保持不变）→ 行为迁移零成本 |
| **Lollapalooza正向** | 2024-25年的爆发 = IP矩阵成熟 + 毛绒品类突破 + 海外渠道铺开 + MEGA拉高均价 + 社交媒体放大 → 五力共振 |
| **反过来想** | "泡泡玛特2021年就该死了"——一个依赖单一IP、单一品类、单一市场的公司确实该死。但他们在2022年的危机中完成了三条防线的同时激活。这不是运气，是冗余备份的工程学思维在商业中的应用 |
| **微观经济学/冲浪模型** | 泡泡玛特冲上的是"Z世代情感消费"这个浪潮，而不是"盲盒"这个浪。浪潮还在，载体变了——类比：冲浪者在同一片海上换了一块板 |
| **心理学/近因偏差** | 2025年370亿营收容易让人忘记2022年增速仅2.8%。芒格会说："看看历史——它曾经几乎停下来。" |

## 五、芒格的终极判断

> "优秀的公司拥有很深的护城河，这些护城河不断加宽。"

泡泡玛特的护城河在**2022年之前**并不存在——一个靠单个IP赚钱的公司没有护城河（Molly可以被复制）。

护城河是在**2022-2023年**被建造的——IP矩阵、品类转换能力、全球渠道网络。这三个要素不是"护城河"本身，而是**挖护城河的铲子**。

**历史上泡泡玛特如何对抗IP/品类周期？**

不是"对抗"——是对抗不了。
单一IP必然有周期，单一品类必然有疲劳。

泡泡玛特做的是：**接受周期存在，构建一个系统，使得在任何一个时刻至少有一条增长曲线在向上走。**

```
2022: Molly ↓   /   SKULLPANDA ↑   /   海外 →     /   品类：盲盒 →
2023: Molly →   /   SKULLPANDA ↑   /   海外 ↑     /   品类：毛绒 ↑↑
2024: Molly →   /   LABUBU ↑↑↑     /   海外 ↑↑    /   品类：MEGA ↑
2025: All ↑     /   LABUBU 百亿     /   海外 ↑↑↑   /   品类：全面开花
```

**这个系统的名字叫做"冗余"——工程学最重要的思维模型。**

## 六、演绎法：从历史模式推演未来（3-5年展望）

### 6.1 核心前提——从表面模式到第一性原理

演绎的前提必须来自归纳，但归纳不能停留在"看到A→B就推演A→B"。**真正可靠的推演需要从历史中提炼出第一性原理——那些跨时间、跨场景仍然成立的底层机制。**

#### 6.1.1 模式一：IP交替——第一性原理

**表面模式**：Molly衰退→SKULLPANDA顶上→LABUBU顶上。已发生两次。

**归纳洞察**：为什么IP能够交替成功？不是运气——是泡泡玛特构建了一个**"情感需求的分布式满足系统"**。

```
第一性原理拆解：

人类的情感需求是分布式的，不是单一维度的：
  Molly 满足："傲娇·可爱·金发碧眼"  → 甜美系
  SKULLPANDA 满足："暗黑·酷·独立"     → 叛逆系
  LABUBU 满足："搞怪·精灵·邪魅"       → 怪趣系
  CRYBABY 满足："哭包·脆弱·治愈"      → 治愈系

每一类情感需求的受众不同，不是"Molly过时了—大家转向SKULLPANDA"
而是"SKULLPANDA触达了Molly从未触达的受众"
```

**芒格模型：生态位理论（生物学）**

```
森林生态学：同一片森林里，不同树种占据不同的生态位
  喜阳树种占据林冠层
  耐阴树种占据林下层
  攀缘植物占据垂直空间

泡泡玛特的IP矩阵 = 情感消费的生态位分化
  Molly → 甜美生态位
  SKULLPANDA → 叛逆生态位
  LABUBU → 怪趣生态位
  CRYBABY → 治愈生态位
```

**核心演绎规则**：

人类的情绪类型是有限的（喜怒哀乐+几种复合情绪），但**足够多**。只要泡泡玛特持续签约不同风格的设计师，就能覆盖越来越多的情感生态位。这是结构性的可重复能力，不是随机运气。

**芒格检验：如果这个原理成立，我们能观测到什么？**
- ✅ 不同IP的买家画像应该有差异（年龄/性别/消费场景）
- ✅ 同一个消费者可能会购买多个IP（因为同一个人有多种情绪）
- ❓ 是否还有未被覆盖的情感生态位？（愤怒？恐惧？怀旧？）→ 是的，这是增量空间

#### 6.1.2 模式二：品类转换——第一性原理

**表面模式**：盲盒→毛绒→MEGA。公式：IP不变，载体变。

**归纳洞察**：这个公式为什么有效？因为**IP和载体遵守不同的供需法则**。

```
第一性原理拆解：

IP = 情感符号（供给端决定，不可替代）
  供给：设计师创造 → 唯一
  需求弹性：低（喜欢LABUBU的人不会因为买不起毛绒就"不喜欢LABUBU了"）

载体 = 物理形态（需求端决定，可替代）
  供给：工厂量产 → 无限
  需求弹性：高（价格翻倍，买的人减少）

品类转换 = 在不触及"IP不可替代性"的前提下，切换载体以适应不同需求弹性
```

**芒格模型：微观经济学——替代品与互补品**

```
Molly PVC手办（59元）= 低价格 · 低单价利润 · 大受众
Molly 毛绒（99元）= 中价格 · 中利润 · 中受众
Molly MEGA（4999元）= 高价格 · 高利润 · 小受众

同一IP，不同载体 = 价格歧视的完美实现
不是"消费者升级了"，是"不同消费力的消费者找到了各自的入口"
```

**核心演绎规则**：

只要IP的情感价值不归零，品类转换就可以无限进行。关键约束不是"能找到几个新载体"，而是**载体本身的物理极限**（PVC→毛绒→金属→陶瓷→数字→？）——而这个极限对于泡泡玛特来说还很远。

**芒格检验：如果这个原理成立，我们能观测到什么？**
- ✅ LABUBU 毛绒成功了，有没有失败的载体？有——积木未爆发
- ✅ 失败 ≠ 原理不成立。积木失败说明"载体需要与IP调性匹配"，不是"载体转换不可行"

#### 6.1.3 模式三：全球化——第一性原理

**表面模式**：中国→东南亚→欧美。公式：文化近邻优先。

**归纳洞察**：这不是"复制中国模式到海外"，这是**同一代际的全球同步消费**。

```
第一性原理拆解：

代际 > 国界：
  北京25岁的Z世代  vs  首尔25岁的Z世代  → 高共鸣
  北京25岁的Z世代  vs  北京45岁的X世代  → 低共鸣

Z世代的全球共性：
  - Instagram/TikTok上的视觉消费
  - "买得起的奢侈品"（affordable luxury）
  - 身份表达通过"拥有什么"而非"做什么工作"
  - 情绪驱动的即时满足
```

**芒格模型：社会学——代际分层的优先级高于地理分层**

```
归纳观察：
  星巴克 → 先征服美国，再全球化（地理优先）
  iPhone → 同时引爆全球（代际优先）
  泡泡玛特 → 中国→东南亚→欧美（地理与代际混合）

泡泡玛特的位置：比星巴克更"代际驱动"（年轻人有更强的全球共性），
比iPhone更"地理渐进"（文化产品需要本地化适配）
```

**核心演绎规则**：

全球化的可持续性取决于Z世代是否继续作为全球消费主力（他们在未来10-15年会进入收入高峰期）。这个变量几乎确定（人口结构不可逆）。

**芒格检验**：
- 如果Z世代=全球同步消费为真 → 泡泡玛特每进入一个新市场，启动速度应快于传统消费品
- ✅ 历史验证：东南亚12个月内从0到规模化的速度远超传统零售品牌
- 未来验证：欧美如果能复制东南亚速度，则原理成立

#### 6.1.4 模式四：LABUBU 150亿级爆发——第一性原理

**表面模式**：不可复制（后疫情·Lisa·工艺突破）。

**归纳洞察**：虽然"天时地利人和"不可复制，但**"大规模爆发的结构性条件"是可以被复制的**。

```
第一性原理拆解：

LABUBU爆发 = f（IP积累 × 载体突破 × 社交引爆 × 全球同步）

拆开来看：
  IP积累（可复制）：LABUBU在PVC手办阶段已积累5年粉丝基础
  载体突破（不可精确复制但可尝试）：搪胶毛绒 = 特定工艺 + 特定时机
  社交引爆（不可精确复制但概率可知）：Lisa佩戴 = 随机事件，但IP足够多 → 概率提高
  全球同步（可复制）：海外渠道已在运行
```

**芒格模型：工程学——Poisson过程（随机事件的发生率）**

```
核心洞察：
  "中彩票"的概率 = 买彩票的频率 × 单次中奖概率

泡泡玛特的"LABUBU级别爆发"：
  频率 = 每年签约+孵化N个IP → 每次发布都是"买一张彩票"
  概率 = 单次发布的病毒传播概率（未知，但非零）
  
  → 随着IP池扩大 + 发布频率提高 → "再中一次"是时间问题
```

**核心演绎规则**：

LABUBU级别的爆发不需要被精确预测——芒格从不要求预测精确数字。他要求的只是：**"这件事是否可能再次发生？如果是，概率是否不为零？"**

如果答案是"概率不为零，且举办'抽奖'的次数在增加"→ 那么下一次爆发是统计意义上的必然。

#### 6.1.5 归纳总结：五条第一性原理

| 表面模式 | 第一性原理 | 芒格模型 |
|---------|----------|---------|
| IP交替 | 情感需求是分布式生态位，不是线性替代 | 生物学生态位 |
| 品类转换 | IP价值与载体价值解耦——前者不变后者可变 | 微观经济学/价格歧视 |
| 全球化 | 代际分层 > 地理分层 | 社会学/代际共性 |
| 价格带拉宽 | 同一情感需求在不同消费力下有不同载体 | 工程学/冗余设计 |
| 超级爆发 | Poisson过程：尝试次数↑→命中概率↑ | 概率论/大数定律 |

**推演规则**：以第一性原理为演绎前提，而非以"历史是否发生过几次"为判断标准。

### 6.2 演绎一：LABUBU 的下半场——从生态位第一性原理推演

**不再问"LABUBU还能增长多久"，改问"LABUBU的情感生态位是否仍在"？**

```
第一性原理：IP价值取决于情感生态位的稳定性，而非单个载体的热度。

P1: LABUBU 占据的情感生态位 = "搞怪·精灵·邪魅"（设计师Kasing Lung的独特表达）
P2: 这个生态位是否有替代者？→ 目前没有（CRYBABY=治愈、星星人=天真——不同生态位）
P3: 单个载体的生命周期（毛绒~3-5年）≠ IP的生命周期（生态位可维持数十年）
P4: LABUBU 的品类矩阵正在扩展：毛绒 → MEGA → 积木 → 内容化（电影/乐园/游戏）
   → 这是从"单一载体IP"升级到"跨载体IP"——类比迪士尼从动画片到乐园
──────────────────────────────
C: LABUBU 作为"情感生态位"的价值不会因为毛绒退潮而崩塌
   最可能路径：150亿→180亿平台→200亿+（内容化成功）
   保守路径：150亿→120亿→100亿稳定（内容化平淡，但品类矩阵对冲）
   "归零"概率：趋近于零——因为替代这个生态位的IP尚未出现
```

**芒格的反转检验**：什么情况下 LABUBU 会归零？不是毛绒退潮，而是**出现了一个更强大的"搞怪·精灵·邪魅"IP**——目前没有，且 Kasing Lung 的设计语言难以被模仿。

### 6.3 演绎二：下一个超级IP——Poisson过程的第一性原理

**不再问"什么时候出现"，改问"系统每年买多少次彩票，命中概率是否非零"？**

```
第一性原理：超级IP的出现 = 尝试次数 × 单次命中概率（Poisson过程）

P1: 泡泡年签约+孵化 ~10-20个新设计师（即每年10-20次独立"抽奖"）
P2: 历史命中频率：2016-2025（10年），出现3个超级IP（Molly/SP/LABUBU）
    → 频率 ~0.3次/年，即平均3年一次
P3: 随着IP池扩大（600+设计师库）和产品化能力提升 → 单次命中概率可能提高
    （更好的筛选 + 更强的冷启动 = 更高的成功率）
P4: Poisson过程的特性：即使概率不变，只要尝试次数不降 → 下一次命中是统计必然
──────────────────────────────
C: 3-5年内出现下一个50-100亿IP = 高概率（统计频率 ~0.3次/年支撑）
   3-5年内出现下一个150亿+IP = 中低概率（需要载体突破+社交引爆的"天时地利"共振）
```

**芒格的关键区分**：
```
对投资者重要的不是"预测下一个LABUBU是谁"
而是"系统是否能持续产生新IP" → 这是一个结构性问题，不是预测问题

类比：你不会预测下一手牌是什么
但你知道赌场长期赚钱——因为规则对它有利
泡泡玛特的"规则"（签约-孵化-分发系统）长期对泡泡有利
```

### 6.4 演绎三：全球化的加速条件——代际 > 地理

**不再问"欧美能否成功"，改问"欧美Z世代与亚洲Z世代有没有消费心理共性"？**

```
第一性原理：代际共性 > 文化差异（社会学的核心洞察）

P1: 东南亚验证：Z世代对"中国潮玩IP"的接受度与本地化运营正相关
P2: 欧美Z世代同样存在"affordable luxury"消费缺口
    （传统可负担身份消费：球鞋 → 新的选项：设计师盲盒/毛绒）
P3: 泡泡海外品牌定位 = "来自中国的潮流IP"（非"盲盒公司"）
    → 跳过了国内"盲盒疲劳"的品牌包袱
P4: TikTok/Instagram = 全球化加速器（LABUBU在海外开店前已被全球用户通过社媒认知）
──────────────────────────────
C: 海外占比43%→60%+ = 大概率事件（5年内）
   增速可能非线性：每进入一个新市场，增速先陡升后趋稳（东南亚已完成陡升段，欧美在初期）
   2027年海外收入预估：200-250亿（基准情景）
```

**芒格"反过来想"**：全球化最大的风险不是"海外会不会接受"（会，代际共性支持），而是**管理半径——跨国多业态运营对组织的挑战。** Chason正确指出了这一点，但它"可被逐渐消化"。

## 七、概率路线图：四种情景

### 情景构建方法

不预测单一未来，而是枚举四种情景，分配概率。每个情景由三个关键变量的组合决定：

```
变量A: LABUBU 能否维持在100亿+？
变量B: 3年内是否出现新的50-100亿IP？
变量C: 海外能否维持30%+增速？
```

### 情景一：黄金路径（概率：20%）

2027年营收推演：LABUBU 180亿 + 新超级IP 80亿 + 现有梯队 100亿 + 海外230亿 ≈ 590亿，利润 ~200亿。

**触发条件**：LABUBU 电影/乐园成功 → IP升级 + 新IP撞上风口 + 欧美市场爆发。三者同向共振 = Lollapalooza 正向。

### 情景二：稳健增长（概率：45%）**← 基准**

2027年营收推演：LABUBU 130亿 + 梯队IP 150亿 + 海外200亿 ≈ 480亿，利润 ~160亿。

**这是基准情景——历史模式的可重复部分。** 不需要奇迹，只需要系统继续运行。

### 情景三：周期震荡（概率：25%）

2027年营收推演：LABUBU 80亿 + 梯队IP 120亿 + 海外180亿 ≈ 380亿，利润 ~120亿。

**触发条件**：毛绒品类退烧 + 新IP未能接棒 + 海外增速回归均值。三重变量同向收缩 = Lollapalooza 负向。

### 情景四：危机重现（概率：10%）

2027年营收推演：LABUBU 40亿 + 梯队IP 90亿 + 海外100亿 ≈ 230亿，利润 ~70亿。

**触发条件**：此时泡泡玛特面临的不是周期，是系统性崩溃——与2022年那次同构，但体量大了5倍，摔得更重。

### 概率加权预期

| 情景 | 概率 | 2027E利润 | 权重 |
|------|:----:|----------|------|
| 黄金 | 20% | 200亿 | 40亿 |
| 稳健 | 45% | 160亿 | 72亿 |
| 震荡 | 25% | 120亿 | 30亿 |
| 危机 | 10% | 70亿 | 7亿 |
| **加权** | **100%** | **~149亿** | **—** |

> 概率加权利润 ~149亿。当前市值如对应15x加权利润 = 2235亿人民币≈2400亿港币。若市场给20x = 2980亿人民币≈3200亿港币。

## 九、最终判断

### 归纳法的结论

从泡泡玛特的历史中提取的四个模式（IP矩阵、品类转换、地理扩张、价格带拉宽）构成了一个**日益加厚的冗余系统**。2022年经受住了真实周期的压力测试。

### 演绎法的结论

如果历史模式可重复，泡泡玛特在3-5年内维持 **"稳健增长"情景（概率45%）** 的可能性最高。核心变量是**LABUBU 的内容化**——成功了可能触发黄金路径，失败了也不致命（三条其他防线仍在）。

### 芒格的终极判断

> "在长期内，一只股票的投资回报率，大致等于这家企业的ROE。"

泡泡玛特当前ROE极高（2025年约50%+）。即使未来ROE下降到30%（保守假设），如果买入PE在15-20x之间，长期回报仍然可观。

**关键不是"预测2027年营收是多少"，而是"在任何一个情景下，泡泡玛特是否仍然是一个优质企业"。** 即使在情景三（周期震荡），泡泡玛特仍然拥有IP矩阵 + 全球渠道 + 品类转换能力 + 127亿现金。

> "好公司 + 合理价格"比"精准预测未来"重要得多。

# 期权 Wheel 策略（卖出期权收保费模式）

> 收录日期：2026-08-19
> 来源：AI 与用户投研对话（泡泡玛特期权参数示例），原始资料见 `raw/research/articles/2026-08-19-期权wheel策略-泡泡玛特分析.md`

---

## 定义

**Wheel 策略（轮动策略）** 是期权卖方的一种循环打法：

1. 卖出 put 收权利金（现金担保 put / cash-secured put），愿意在行权价买入股票
2. 若被 assign → 以行权价买入股票，持有
3. 再卖出 call 收权利金（covered call），愿意在行权价卖出股票
4. 若被 assign → 以行权价卖出股票，回到现金状态，循环重新开始

本质是**卖保护收保费**：站在承保人（seller）一侧，赚波动率钱（theta + 隐含波动率溢价），承担价格波动风险。

## 完整循环机制

在"持有现金"和"持有股票"两种状态之间循环，每一步都卖出期权收权利金，被行权才切换状态：

```
状态：现金 ──卖 put──> 收权利金
  │                      │
  │ put 到期作废         │ put 被行权（股价跌到行权价）
  │ 股价没跌到行权价      ▼
  │                状态：持股（以行权价买入）
  │                      │
  │                      │ 卖 call 收权利金
  │                      ▼
  │                 call 到期作废（股价没涨到）
  │                 → 继续持有，再卖一张 call（提高收益率）
  │
  │                 call 被行权（股价涨回行权价）
  │                 → 以行权价卖出，回到现金
  └──────────────────── 循环重新开始
```

### 阶段 1 — 现金状态：卖 put（现金担保 put）

- 手上有现金（或愿意买股票），卖出 K 的 put，收权利金
- 本质："我愿意在 K 以下买股票，而且现在就开始收钱等它跌下来"
- 两种结局：
  - 到期股价 ≥ K → put 作废，白赚权利金，但没买到股票（踏空风险）
  - 到期股价 < K → 被行权，以 K 买入（实际成本 = K − put 权利金，打折买入）

### 阶段 2 — 持股状态：卖 call（covered call）

- 手里有股票，卖出 K 的 call，再收一笔权利金
- 本质："我愿意在 K 以上卖掉，但卖出之前先把未来卖价的权利金收掉"
- 两种结局：
  - 到期股价 ≤ K → call 作废，白赚权利金，继续持有（可再卖下一张 call）
  - 到期股价 > K → 被行权，以 K 卖出，回到现金

### 阶段 3 — 循环

回到现金 → 再卖 put → ……。收益不依赖股价涨跌：**只要股价在两腿之间横盘或温和波动，至少一个期权到期作废，就收满权利金**。赚的是波动率的钱（卖方向），不是方向的钱（买方）。

## 收益来源拆解

| 来源 | 说明 |
|---|---|
| θ（时间价值） | 期权每天都在贬值，卖方赚流逝的价值 |
| 隐含波动率溢价 | 市场恐慌时 IV 高、权利金贵，卖方高价卖出"保险" |
| 行权价折扣 | put 被行权 = 打折买入；call 被行权 = 高位卖出 |

## 泡泡玛特参数示例（用户案例）

参数：行权价 145 × 200 股；put 权利金 6.88/股；call 权利金 5.00/股。

### 现金流

| 步骤 | 现金流 |
|---|---|
| 卖 2 张 145 PUT @6.88 | +1,376 |
| PUT 被行权，$145 买入 200 股 | −29,000 |
| 卖 2 张 145 CALL @5.00 | +1,000 |
| CALL 被行权，$145 卖出 200 股 | +29,000 |
| **净结果** | **+2,376 权利金，股票进出相抵** |

实际占用资金 = 29,000 − 1,376（先收的 put 权利金）= **27,624**

### 收益率

- 按净投入：2,376 / 27,624 ≈ **8.6%**
- 按名义本金：2,376 / 29,000 ≈ **8.2%**
- 每股验证：总权利金 11.88 / 净成本 138.12 ≈ 8.6%，一致

**年化依赖周期**：若 put + call 各约 1 个月（共约 2 个月），单利年化 ≈ 51%；3 个月期限则约 17%。纸面年化，未计佣金/滑点/交易所费/波动风险。

## 与保险公司的关系

**是同类逻辑**：收保费、承风险、小赚频繁、尾部大亏靠纪律控制。

- 卖 PUT = 提供"下跌保护"保险，收保费；跌破行权价即"理赔"（接货）
- 卖 CALL = 提供"上涨封顶"期权，收保费；涨过行权价即"交出货"

**两点本质区别**：

1. **风险可分散性**：保险承保的是相互独立的个体风险（可精算、可大数定律摊薄）；卖 put 承保的是**市场系统性风险**，暴跌时所有卖方一起亏，无法分散
2. **定价依据**：保险靠精算赔付率；期权卖方靠波动率。波动率低时"保费"便宜但赔付概率未必低

## 风险路径（不止"打满"一条）

- **大幅下跌**：PUT 行权接货后股价续跌，CALL 不行权，持有浮亏仓位。综合下行保护 = 行权价 − 总权利金 = 145 − 11.88 = **133.12**；跌破后整体亏损且无下限（除非止损）
- **大涨踏空**：CALL 被行权，仅赚固定权利金，超额收益全部让出
- **PUT 未行权**：股价上涨、PUT 作废，只赚 put 权利金但踏空建仓

收益期望 = 满额收益 − 尾部亏损 × 发生概率。前提：对标的的价值判断够硬，愿意在盈亏平衡点以下继续持有。

## 适用场景

适合：**本来就打算长期持有某标的、对估值有判断、愿意在低价位接货的人**——用期权把"等待买入/等待卖出"的闲置时间也变成现金流。

一句话总结：**Wheel = 用"愿意在 K 买入、愿意在 K 卖出"的承诺反复卖保险收保费；横盘赚满、温和波动赚一半、暴跌兜底接货、暴涨锁定卖价。** 收益期望是"权利金收入 − 尾部亏损概率"，不是无风险套利。

## 伯克希尔先例（已核实）

伯克希尔 2004–2008 年间分批卖出四大股指长期看跌期权（S&P 500 / FTSE 100 / Euro Stoxx 50 / Nikkei 225），2008 年致股东信披露：名义本金 $37.1B，已收保费 $4.9B。巴菲特用 premium（保费）与 insurance float（保险浮存金）框架论述卖 put，CDS 直接定性为"credit insurance"（信用保险）。

⚠️ **转述边界**：巴菲特无"卖 put = 卖保险"的原话，此为对原文框架的合理转述，引用时不可当作逐字引语。

# 芒格多元思维模型 — 第二讲精要

> 来源：《穷查理宝典》第二讲（1994年南加州大学）
> 原始资料：[[../../raw/research/articles/2026-06-27-munger-poor-charlie-lecture2]]

## 核心框架

**多元思维模型** — 用重要学科的重要理论组成认知复式框架（latticework），而非孤立使用单一模型。

> "在手里拿着铁锤的人看来，世界就像一颗钉子。"

## 七大学科模型

| 学科 | 关键模型 |
|------|---------|
| 数学 | 复利、排列组合/概率论、决策树、高斯分布 |
| 会计学 | 理解其局限——仅仅是粗略估算 |
| 工程学 | 冗余备份（安全边际）、断裂点理论、临界质量 |
| 生物学 | 达尔文进化论、竞争性毁灭 |
| 心理学 | 误判心理学约20原则、双轨分析 |
| 微观经济学 | 规模优势/劣势、冲浪模型、提价能力、竞争性毁灭 |
| 历史学 | "一本30美元的历史书里藏着价值数十亿美元的答案" |

## 投资应用

1. **能力圈**：可以 / 不行 / 太难 —— 三种分类
2. **护城河**：竞争性毁灭 → 持久的竞争优势
3. **安全边际**：工程学冗余备份思维
4. **下重注 + 长期持有**："极度的耐心 + 极度的决心"
5. **20次打卡**：一生只有20次机会，慎重对待每次决策

## 五大超级观念

1. 先解决答案显而易见的大问题
2. 数学运算能力
3. 反面思考——"反过来想，总是反过来想"
4. 跨学科思考
5. **Lollapalooza效应**——多种因素同向共振产生巨大效应

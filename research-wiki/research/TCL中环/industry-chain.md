# TCL中环 (002129) — 产业链全景

## TCL中环在产业链中的位置

TCL中环处于光伏产业链的 **中游偏上游（硅片环节）**，同时横向切入半导体硅片领域。

---

## 一、光伏产业链

```
上游                        中游                          下游
──────────────────────────────────────────────────────────────────
硅矿/石英矿                   硅片（TCL中环主战场）           电池片
  │                            │                              │
  ▼                            ▼                              ▼
多晶硅/工业硅  ────────▶  单晶拉棒 ──▶  切片  ──▶  PERC/TOPCon/HJT 电池
（通威、大全、协鑫）         （TCL中环核心能力）               （通威、爱旭、隆基）
                                │                              │
                                │                              ▼
                           硅片工费同比降超40%              组件封装
                           210mm G12 占比持续提升            （隆基、晶科、天合、
                           N 型硅片出货领先                  晶澳、TCL中环自产 → 15.1GW）
                                │                              │
                                ▼                              ▼
                           BC 专利体系                      光伏电站
                           Maxeon 授权爱旭                   （集中式 + 分布式）
                           收取 16.5 亿授权费

```

### 各环节说明

| 环节 | TCL中环参与度 | 说明 |
|------|------------|------|
| 上游多晶硅 | 不参与 | 外购硅料，供应商集中（通威、协鑫），硅料价格下跌有利成本 |
| 中游硅片 | **核心主业** | 全球市占率第一（23.5%），210mm G12 大尺寸 + N 型领先 |
| 中游电池 | 通过并购切入 | 拟收购一道新能源，BC 电池技术专利布局 |
| 下游组件 | **第二增长** | 2025 年出货 15.1GW，同比增长超 80%，营收 +60.45% |
| 下游电站 | 少量参与 | 自持电站运营，占比 4% |

## 二、半导体硅片产业链

```
上游硅材料 ──▶ 半导体硅片（中环领先） ──▶ 晶圆代工 ──▶ 芯片设计/封测
（SUMCO、      4-6-8-12 英寸               台积电、中芯国际、  高通、英伟达、
 信越化学）     抛光片 / 外延片              华虹、英飞凌        海思等
```

TCL中环通过子公司 **中环领先** 切入半导体硅片赛道：

| 能力 | 说明 |
|------|------|
| 产品覆盖 | 4-12 英寸全系列，国内唯一 |
| 客户认证 | 已通过台积电、英飞凌认证 → 国际一线标准 |
| 出货规模 | 2025 年出货超 1200MSI，营收 57.07 亿（+21.75%） |
| 扩产方向 | 12 英寸大硅片扩产中，资本开支持续投入 |
| 国产替代 | 国内半导体硅片自给率低，中环领先是最大国产供应商之一 |

## 三、商业模式演进：从纯硅片到"适度一体化"

```
2021-2023: 纯硅片龙头             2024-2025: 适度一体化
─────────────────────       ────────────────────────────
硅片 74-77% 营收            硅片 42%（龙头，亏损）
组件 15-16%（小规模）        组件 32%（出货 15.1GW，+60%）
半导体 5%（起步）            半导体 20%（+21.8%，第二曲线）
                            并购一道新能源（BC 电池）
                            海外 GW 级突破
```

**战略逻辑**：
- 周期底部通过并购（一道新能源）向下游延伸，补齐电池组件短板
- 利用 BC 专利体系构建差异化竞争壁垒（打破同质化价格战）
- 半导体业务逆周期增长，提供利润缓冲
- 沙特 10GW 海外建厂，规避贸易壁垒

（来源：`raw/research/TCL中环/2026-03-25-证券之星-2025年报分析.md` 第二、五节）

## 四、竞争格局

### 光伏硅片

| 公司 | 地位 | 差异化 |
|------|------|--------|
| TCL中环 | 全球第一（23.5%） | 210mm G12 大尺寸、N 型 |

| 公司 | 能力 |
|------|------|
| 中环领先（TCL中环） | 4-12 英寸全系列，已通过台积电认证 |
| 沪硅产业 | 12 英寸 SOI 硅片 |
| 立昂微 | 6-8 英寸抛光片 |

## 五、行业周期判断

| 阶段 | 特征 | TCL中环位置 |
|------|------|-----------|
| 2021-2022 | 光伏超级景气周期，量价齐升 | 营收 411→670 亿，归母 39→65 亿 |
| 2023 | 产能过剩开始，价格松动 | 营收降至 592 亿，归母降至 25.8 亿 |
| 2024 | 全产业链价格暴跌 | 营收腰斩至 284 亿，归母 -109 亿 |
| 2025 | 行业深度调整，亏损收窄 | 营收企稳 290 亿，净利率修复 4pcts |
| 2026E-2027E | 产能出清 → 供需再平衡 | 预计 2027 年扭亏为盈 |

# 002129 TCL中环 — 数据目录

## DB 表

数据库文件: `data/002129.db`，共 9 张表（定义见 `fetcher.py:_init_tables`）。

## `revenue_structure` 表

| 列 | 类型 | 说明 |
|----|------|------|
| code | TEXT (PK) | 股票代码 |
| year | TEXT (PK) | 财年 |
| dim_type | TEXT (PK) | 拆分维度 |
| dim_name | TEXT (PK) | 维度下的条目名 |
| amount | REAL | 金额（亿元） |
| pct | REAL | 占比（%） |

**联合主键 = (code, year, dim_type, dim_name)**

### 已存在的维度

| dim_type | 条数 | 年份 | 说明 |
|----------|------|------|------|
| by_product | 21 | 2021-2025 | 产品拆分（光伏硅片/组件/半导体材料/电站/其他） |

### 查询示例

```sql
-- 查某年全产品拆分
SELECT dim_name, amount, pct
FROM revenue_structure
WHERE code = '002129' AND year = '2025'
ORDER BY amount DESC;

-- 查某产品历年趋势
SELECT year, amount, pct
FROM revenue_structure
WHERE code = '002129' AND dim_name = '半导体材料'
ORDER BY year;
```

### 营收占比演变 (%)

| 年份 | 光伏硅片 | 光伏组件 | 半导体材料 | 电站及其他 |
|------|----------|----------|------------|------------|
| 2021 | 77.4% | 14.9% | 5.2% | 2.6% |
| 2022 | 76.0% | 16.2% | 4.5% | 3.4% |
| 2023 | 74.0% | 15.7% | 5.5% | 4.7% |
| 2024 | 58.6% | 20.4% | 16.5% | 4.5% |
| 2025 | 42.1% | 32.1% | 19.6% | 6.1% |

**趋势**: 光伏硅片占比持续下降（77%→42%），半导体材料逆势增长（5%→20%），组件占比受策略调整波动。

# 腾讯控股 — 互联网科技产业链

## 业务矩阵
```
社交平台(微信/QQ) ──流量入口──▶ 游戏(自研+发行) ──内容变现
                    │            │
                    ├────────────▶ 广告(朋友圈/视频号/公众号)
                    │
                    ├────────────▶ 金融科技(微信支付/理财通)
                    │
                    └────────────▶ 企业服务(腾讯云/企业微信/腾讯会议)
```
## 竞争格局
- 社交: 护城河最深，微信 = 中国移动互联网基础设施
- 游戏: 腾讯 + 网易双寡头 + 米哈游等挑战者
- 云: 阿里云 > 华为云 > 腾讯云（第三）
- 广告: 字节跳动 / 腾讯 / 百度 三强

## 行业周期
- 游戏版号周期 + 宏观经济影响广告/金融业务
- AI 大模型（混元）为下一增长点

# 建滔集团 — 电子材料产业链全景

> 最后更新：2026-08-06

## 产业链位置

```
上游原材料          中游核心          下游应用
─────────────────────────────────────────────────
铜矿 → 电解铜箔 ─┐
硅砂 → 电子玻纤布 ─┤
石油 → 环氧树脂  ─┼→ 覆铜板(CCL) → PCB → 终端产品
                   │                    │
                   └ 建滔积层板(01888)  │
                         ↑              │
                   建滔集团自供          │
                   (铜箔/玻纤布/树脂)    │
                                        ↓
                              AI服务器/数据中心
                              汽车电子/ADAS
                              5G基站/通信设备
                              消费电子/手机
                              工业控制/医疗
```

## 建滔集团的垂直整合

| 环节 | 产品 | 自供率 | 说明 |
|------|------|:--:|------|
| 上游 | 电解铜箔 | 高 | 自有铜箔产能 |
| 上游 | 电子级玻纤布 | 中高 | LDK一代纱自供 |
| 上游 | 环氧树脂 | 高 | 化工分部生产 |
| 中游 | 覆铜板(CCL) | - | 建滔积层板(01888)，全球第一 |
| 下游 | 印刷线路板(PCB) | - | 依利安达等子公司 |

## 竞争格局

### 全球覆铜板 Top 5
1. 建滔积层板 (01888) — 连续20年第一
2. 生益科技 (600183)
3. 南亚塑胶
4. 松下电工
5. 台光电子

### 建滔的核心优势
- 唯一实现铜箔→玻纤布→树脂→CCL→PCB全链条的厂商
- 规模优势：原材料大批量采购议价力
- 高端突破：M6/M7级高速材料少数供应商

## 行业周期特征
- 铜价是覆铜板定价锚（铜箔占CCL成本30-40%）
- 下游需求周期：AI基建（上行）vs 消费电子（波动）
- 2021年峰值 → 2023年谷底 → 2025年复苏上行

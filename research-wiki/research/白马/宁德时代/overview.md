# 300750 宁德时代 — 数据目录

## DB 表

数据库文件: `data/300750.db`，共 9 张表（定义见 `fetcher.py:_init_tables`）。

## `revenue_structure` 表

| 列 | 类型 | 说明 |
|----|------|------|
| code | TEXT (PK) | 股票代码 |
| year | TEXT (PK) | 财年 |
| dim_type | TEXT (PK) | 拆分维度 |
| dim_name | TEXT (PK) | 维度下的条目名 |
| amount | REAL | 金额（百万元） |
| pct | REAL | 占比（%） |

**联合主键 = (code, year, dim_type, dim_name)**

### 已存在的维度

| dim_type | 条数 | 年份 | 说明 |
|----------|------|------|------|
| by_product | 4 | 2025 | 产品分类（动力电池/储能电池/电池材料/其他） |

### 查询示例

```sql
-- 查产品拆分
SELECT year, dim_name, amount, pct
FROM revenue_structure
WHERE dim_type = 'by_product'
ORDER BY year, amount DESC;

-- 查某年全维度
SELECT dim_type, dim_name, amount, pct
FROM revenue_structure
WHERE year = '2025'
ORDER BY dim_type, amount DESC;
```

## 数据可用性边界

| 指标 | 粒度 | 来源 | 边界 |
|------|------|------|------|
| 产品拆分 | 年度 (2025 仅 by_product) | 年报 → DB | 历史年份仅一个维度 |
| 地区拆分 | 不可得 | — | 年报披露定性描述，未录入 DB |
| 客户拆分 | 不可得 | — | 年报披露前五大客户集中度 |
| 毛利率 | 年度 | DB | 季度可通过 Q 报表推算 |
| 装机市占率 | 月度 | SNE Research/动力电池联盟 | 需外部获取 |

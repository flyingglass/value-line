# 02899 紫金矿业 — 数据目录

## DB 表

数据库文件: `data/02899.db`，共 9 张表（定义见 `fetcher.py:_init_tables`）。

## `revenue_structure` 表

| 列 | 类型 | 说明 |
|----|------|------|
| code | TEXT (PK) | 股票代码 |
| year | TEXT (PK) | 财年 |
| dim_type | TEXT (PK) | 拆分维度 |
| dim_name | TEXT (PK) | 维度下的条目名 |
| amount | REAL | 金额（百万元） |
| pct | REAL | 占比（%） |

**联合主键 = (code, year, dim_type, dim_name)**

### 已存在的维度

| dim_type | 条数 | 年份 | 说明 |
|----------|------|------|------|
| by_product | 5 | 2025 | 产品分类（铜/金/锌铅/锂/银及其他） |

### 查询示例

```sql
-- 查产品拆分
SELECT year, dim_name, amount, pct
FROM revenue_structure
WHERE dim_type = 'by_product'
ORDER BY year, amount DESC;
```

## 数据可用性边界

| 指标 | 粒度 | 来源 | 边界 |
|------|------|------|------|
| 产品拆分 | 年度 (2025 仅 by_product) | 年报 → DB | 历史年份只有一维 |
| 矿山产量 | 年度 | 年报 | 铜/金/锌/锂各矿产量需手动从年报提取 |
| 地区拆分 | 不可得 | — | 年报披露海外占比但未录入 DB |
| 资源储量 | 年报披露 | 年报 | 未录入 DB |
| 成本(C1/C3) | 年度/半年度 | 年报 | 矿业关键指标，未录入 DB |

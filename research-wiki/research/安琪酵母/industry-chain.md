# 安琪酵母 (600298) — 产业链全景

## 安琪酵母在产业链中的位置

安琪酵母处于 **发酵制造中游**，上游对接农业原料（糖蜜），下游覆盖食品工业多个应用领域。

---

## 一、酵母产业链

```
上游                        中游                          下游
──────────────────────────────────────────────────────────
原材料                    发酵制造（安琪主战场）           应用领域
  │                         │                              │
  ▼                         ▼                              ▼
糖蜜（占成本40%+）  ──▶  菌种选育 + 发酵工艺  ──▶  烘焙（面包酵母）
  制糖工业副产品           核心壁垒：技术Know-how          调味品（YE 替代味精）
  价格波动大，安琪         规模优势：全球49万吨产能         酿酒（酿酒酵母）
  凭规模优势议价           自动化：一次合格率99.6%         营养健康（酵母蛋白）
  │                        品牌：170+国、6海外基地          动物营养（饲料酵母）
  ▼                         │
能源、包材等                ▼
                        下游延伸
                        制糖（自产糖蜜配套，8%营收）
                        包装（配套包装，2%营收）
```

### 各环节说明

| 环节 | 安琪参与度 | 说明 |
|------|----------|------|
| 上游糖蜜 | 部分自产 + 外购 | 糖蜜占成本 40%+，价格波动是毛利率核心变量；制糖业务（8%营收）提供部分糖蜜自给 |
| 中游发酵 | **核心主业** | 全球第二、亚洲第一酵母产能（49万吨），菌种选育+发酵工艺Know-how（四十年积累） |
| 下游烘焙 | 主力市场 | 面包酵母传统基本盘，国内市场增速放缓 |
| 下游调味品 | 结构性增长 | YE（酵母抽提物）替代味精趋势，国内 YE 市占率 60%+ |
| 下游营养健康 | 新增长极 | 酵母蛋白替代植物蛋白，食品原料板块 +54.4% |
| 下游酿酒 | 认证突破 | 酿酒酵母通过美国 FDA 认证 |
| 下游动物营养 | 稳定需求 | 饲料酵母，畜牧养殖刚需 |

## 五、行业周期与催化

### 毛利率周期

```
2017-2020  高位平台期    毛利率 34-38%
2021       糖蜜暴涨冲击  毛利率暴跌至 27.3%
2022-2024  持续下行      毛利率 24.8% → 23.5%
2025       首次企稳回升  毛利率 24.7%（+1.2pp）✅ 利润率反转信号触发
```

### 核心催化剂

1. **海外产能释放** → 埃及/俄罗斯工厂扩产，海外高毛利占比提升
2. **酵母蛋白新品类** → 食品原料 +54.4%，替代植物蛋白趋势
3. **YE 渗透率提升** → 酵母抽提物替代味精空间大，毛利率高于传统酵母
4. **糖蜜价格回落** → 若回归历史均值，毛利率可修复 2-3pp

### 核心风险

1. 糖蜜价格若重回高位 → 压缩毛利 2-3pp
2. 国内烘焙需求增速放缓
3. 海外地缘政治风险（俄罗斯工厂）
4. 制糖业务持续亏损拖累利润（毛利率 -4.9%）

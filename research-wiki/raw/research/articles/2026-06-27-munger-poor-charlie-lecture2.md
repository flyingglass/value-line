## 一、核心理念

**"你必须知道重要学科的重要理论，并经常使用它们——要全部都用上，而不是只用几种。"**

> "在手里拿着铁锤的人看来，世界就像一颗钉子。" —— 这是处理问题的一种笨办法。

芒格将自己评估商业和投资的方法称为 **"多元思维模型"（Multidisciplinary Thinking Model）**。它是一个收集和处理信息、并依照信息行动的框架，借用并完美地糅合了许多来自各个传统学科的分析工具、方法和公式。

涉及的学科：历史学、心理学、生理学、数学、工程学、生物学、物理学、化学、统计学、经济学等。

### 为什么需要？

1. **单一模型会扭曲现实** —— 如果你只能使用一两个模型，你将会扭曲现实，直到它符合你的思维模型
2. **世界是相互联系的** —— "如果我们试图理解一样看似独立存在的东西，我们将会发现它和宇宙间的其他一切都有联系。"（约翰·缪尔）
3. **几乎每个系统都受到多种因素的影响** —— 所以必须熟练运用来自不同学科的多元思维模式

### 需要多少模型？

> "掌握八九十个模型就差不多能让你成为拥有普世智慧的人。而在这八九十个模型里面，非常重要的只有几个。"

芒格估计他大约使用 **100种** 思维模型。

## 二、思维模型的复式框架

> "长久以来，我坚信存在某个系统——几乎所有聪明人都能掌握的系统，它比绝大多数人用的系统管用。你需要的是在你的头脑里形成一种思维模型的复式框架。"

### 框架原则

1. **不能死记硬背孤立事实** —— "如果你们只是记得一些孤立的事物，试图把它们硬凑起来，那么你们无法真正地理解任何东西。如果这些事物不在一个理论框架中相互联系，你们就无法把它们派上用场。"
2. **把经验挂在模型框架上** —— "你必须把经验悬挂在头脑中的一个由许多思维模型组成的框架上。"
3. **不断地追问"为什么"** —— "如果你想要变得聪明，你必须不停地追问的问题是'为什么，为什么，为什么'。"
4. **愿意改变想法** —— "哪年你没有破坏一个你最爱的观念，那么你这年就白过了。"

## 三、核心思维模型（第二讲芒格亲述）

### 1. 数学 — 最基础的学科

| 模型 | 芒格原文要点 |
|------|-------------|
| **复利原理** | 最基本的模型，"理解复利的魔力和获得它的困难是理解许多事情的核心和灵魂" |
| **排列组合原理（概率论）** | 费马-帕斯卡系统；巴菲特"能够自动地根据决策树理论和基本的排列组合原理来思考问题" |
| **高斯分布（钟形曲线）** | 理解大致分布形态即可，不需要精通统计学；"我就像一个虽然不懂帕斯卡可是打牌打得很好的扑克牌手" |
| **决策树理论** | 哈佛商学院一年级必修，"他们所做的只是把高中代数拿过来，用它来解决现实生活中的问题" |

> **关键认知**：人类大脑的神经系统经过长期的基因和文化进化而来，它并不是费马-帕斯卡的系统，使用的是非常粗略而便捷的估算。你必须刻意训练才能克服。

> "如果你没有把这个基本的概率方法变成你生活的一部分，那么在漫长的人生中，你们将会像一个踢屁股比赛中的独腿人。这等于将巨大的优势拱手送给了他人。"

### 2. 会计学

| 要点 | 原文 |
|------|------|
| **商业活动的语言** | "会计是从事商业活动的语言。它是对人类文明的一大贡献。复式簿记真是一种了不起的发明。" |
| **必须理解其局限** | "你必须对会计有足够的理解，才能明白它的局限——因为会计虽然是商业活动的出发点，但它只是一种粗略的估算。" |
| **布劳恩案例** | C. F. 布劳恩看了标准会计报表说"这是狗屁"，召集工程师自建会计系统 |
| **五何原则** | 布劳恩公司所有交流必须说明"何人因何故在何时何地做了何事"；犯两次就被解雇 |

### 3. 硬科学和工程学 — 最可靠的思维模型

> "哪些思维模型最可靠呢？答案很明显，那些来自硬科学和工程学的思维模型是地球上最可靠的思维模型。"

| 模型 | 应用 |
|------|------|
| **工程学后备系统（冗余备份）** | 投资中的安全边际——"工程师设计桥梁时，会给它一个后备支撑系统以及额外的保护性力量，以防倒塌——投资策略也应该如此" |
| **断裂点理论** | 识别系统的临界失效点 |
| **物理学临界质量** | 事物在达到某个临界点后发生质变 |

### 4. 生物学/生理学

| 模型 | 应用 |
|------|------|
| **现代达尔文综合模型** | 商业世界的生态竞争、适者生存 |
| **竞争性毁灭** | 1911年纽交所成交最活跃的50家公司，至今仅剩通用电气一家独立企业 |

### 5. 心理学 — "太过重要"

> "如果你想拥有任何普世的智慧，心理学是太过重要了。"

**核心：误判心理学（约20个小原则）**
- 人类的感知器官有时会短路
- 认知功能比感知功能更容易受误导
- 大脑缺乏足够的神经线路 → 自动短路
- 激励机制造成的偏见
- 社会认同倾向
- "铁锤人倾向"
- 巴甫洛夫联想（听不得逆耳忠言 → 生活在谎言中）

> "聪明人一个星期就能被教会"的基本心理学知识，芒格说他在加州理工和哈佛法学院从未被教授过。"我不得不自己在后来的生活中一点一点地学习。那可是相当辛苦的。"

**帕斯卡名言**："人类的头脑既是宇宙的光荣，也是宇宙的耻辱。"

**双轨分析法**：
- **理性分析**：哪些因素真正控制了涉及的利益？（打桥牌的方法）
- **潜意识分析**：当大脑处于潜意识状态时，会自动形成哪些潜意识因素？（大多数情况下是错误的结论）

### 6. 微观经济学

| 模型 | 核心洞见 |
|------|----------|
| **生态系统思维** | "我发现把自由的市场经济当作某种生态系统是很有用的思维方式。动物在合适的地方能够繁衍，同样地，人只要在社会上找到了专属于自己的位置，也能够做得很成功。" |
| **规模优势** | 几何学优势（油罐：表面平方增长，容量立方增长）、信息优势（品牌认知=绿箭vs格罗兹口香糖）、社会认同、赢家通吃（日报模式） |
| **专业化的力量** | "大未必就是好" —— 缩小规模、加强专业化也能带来巨大优势。《越野摩托》杂志利润率"会让你们流口水" |
| **规模劣势** | 官僚主义、敷衍塞责、激励机制失灵、腐败——"苏联工人的经典感叹：他们假装给薪水，我们假装在工作。" |
| **竞争性毁灭** | 马鞭厂 → 汽车；技术变革消灭旧行业 |
| **冲浪模型** | 先行者优势：冲上浪尖→停留很久（微软/英特尔/NCR）；没冲上去→被吞没 |
| **技术第二步分析** | "改善生产带来的所有好处都流向消费者"——纺织业的教训。芒格："我从来没有见到有哪个人提出过这第二步分析。" |
| **提价能力** | 迪士尼、喜诗糖果、可口可乐——尚未利用的提价能力是极佳投资机会 |
| **赢家通吃 vs 无利润竞争** | 麦片行业大家都赚钱（品牌认同），航空业股东净收益为负（纯粹商品、竞争性毁灭） |

> "微观经济学的伟大意义在于让人能够辨别什么时候技术将会帮助你，什么时候它将会摧毁你。"

## 四、投资应用框架

### 能力圈原则

> "如果你确有能力，你就会非常清楚能力圈的边界在哪里。如果你问起（你是否超出了能力圈），那就意味着你已经在圈子之外了。"

- 投资选项三分法：**可以投资 / 不能投资 / 太难理解**
- 能力圈难以扩大，"要扩大那个能力圈是非常困难的"
- "如果你们要玩那些别人玩得很好而你们一窍不通的游戏，那么你们注定会一败涂地。"

### 投资筛选流程

1. **先确定不该做什么** —— "我只想知道我将来会死在什么地方，这样我就可以永远不去那里。"
2. **选简单且好理解的备选项目** —— 制药业和高科技 → "太难理解"
3. **用重要学科的重要理论评估** —— 多元思维模型全面分析
4. **企业内部 + 外部 + 行业情况** —— 护城河分析
5. **护城河的宽度和持久性** —— "优秀的公司拥有很深的护城河，这些护城河不断加宽"
6. **管理层评估** —— 能干、可靠、为股东考虑（现金分配方式尤为关键）
7. **计算整个企业的真正价值** —— 考虑未来股权稀释
8. **安全边际** —— 工程学冗余备份思维模型的应用

### 投资核心原则

> "（购买）股价公道的伟大企业比（购买）股价超低的普通企业好。"

> "我们偏向于把大量的钱投放在我们不用再另外作决策的地方。"

- **耐心等待，重注出击** —— "赚大钱的诀窍不在于买进卖出……而在于等待。"
- **20次打卡** —— 巴菲特说一生只能有20次投资机会，"慎重考虑你做的事情"
- **坐等投资法** —— 长期持有，少交易，税务系统每年给1%-3%额外回报
- **极度的耐心 + 极度的决心**
- **彩池投注系统类比** —— 寻找定错价格的赌注，碰到好机会就下重注，其他时间按兵不动

### 市场的本质

> "市场既是部分有效的，也是部分低效的。"

"生活的铁律就是，只有20%的人能够取得比其他80%的人优秀的成绩。"

"成为赢家的方法是工作，工作，工作，再工作，并期待能够看准几次机会。"

"上天并没有赐予人类在所有时刻掌握所有事情的本领。但如果人们努力在世界上寻找定错价格的赌注，上天有时会让他们找得到。"

## 五、五大超级观念（第四讲）

1. **先解决答案显而易见的大问题** —— 简化任务的最佳方法
2. **数学运算能力** —— "如果缺乏数学运算能力，你将会像一个参加踢屁股比赛的独腿人"
3. **反面思考** —— "反过来想，总是反过来想"（卡尔·雅可比）。知道死亡地点就永远不去那里
4. **跨学科思考** —— 最好的、最具实践性的智慧是基本的学术智慧，前提是跨学科
5. **Lollapalooza效应** —— 真正的巨大效应通常在几种因素的共同作用下才会出现（如肺结核需三种药同时服用）

## 六、投资原则检查清单

| 类别 | 核心要点 |
|------|----------|
| **风险** | 测量风险（尤其是信用风险）、合适的安全边际、避免和道德有问题的人交易、永远记住通胀和利率风险、避免资本金持续亏损 |
| **独立** | 客观和理性需要独立思考，对错不取决于别人同意与否，"随大流只会让你往平均值靠近" |
| **准备** | 广泛阅读→终身自学、熟练掌握各大学科的思维模型、追问"为什么为什么为什么"、"比求胜的意愿更重要的是做好准备的意愿" |
| **谦虚** | 只在能力圈内行事、辨认和核查否定性证据、抵制虚假精确和错误确定性的欲望、"别愚弄你自己，记住，你是最容易被自己愚弄的人" |
| **严格分析** | 使用科学方法和检查清单、区分价值和价格/过程和行动/财富和规模、"反过来想，总是反过来想"、关注二阶效应和更高层次影响 |
| **配置** | "好主意特别少——当时机对你有利时，狠狠地下赌注吧"、最好的用途由第二好的用途衡量（机会成本）、别"爱上"投资项目 |
| **耐心** | "复利是世界第八大奇迹"（爱因斯坦）、不到必要时别打断它、避免多余交易税和摩擦成本、享受结果也享受过程 |
| **决心** | "当别人贪婪时，要害怕；当别人害怕时，要贪婪"、机会来临的次数不多所以抓住它、"机会只眷顾有准备的人" |
| **改变** | 认识和适应世界的真实本质、不断挑战和修正"最爱的观念"、"正视现实，即使你并不喜欢它——尤其当你不喜欢它的时候" |
| **专注** | "别把事情搞复杂，记住你原来要做的事"、声誉和正直是最有价值的财产且能瞬间化为乌有、"直面你的大问题，别把它们藏起来" |

## 七、关键语录

> "如果说伯克希尔取得了不错的发展，那主要是因为沃伦和我非常善于破坏我们自己最爱的观念。哪年你没有破坏一个你最爱的观念，那么你这年就白过了。"

> "迅速歼灭不该做的事情，接着对该做的事情发起熟练的、跨学科的攻击，然后，当合适的机会来临——只有当合适的机会来临——就采取果断的行动。"

> "如果你把自己训练得更加客观，拥有更多学科的知识，那么你在考虑事情的时候，就能够超越那些比你聪明得多的人，我觉得这是很好玩的。再说了，那样还能赚到很多钱，我本人就是个活生生的证据。"

> "就确定未来而言，没有比历史更好的老师……一本30美元的历史书里隐藏着价值数十亿美元的答案。"

> "生活就是两种力量之间无休无止的斗争：一边是获得上面提到的那些规模优势，另一边是变得像美国农业部那样人浮于事。"

> "在拿着铁锤的人看来，每个问题都像钉子。"

> "我问他：'天哪，你这些鱼钩居然是绿色和紫色的。鱼真的会上钩吗？'他说：'先生，我又不是卖给鱼的。'"

> "决定行为的是决策者的激励机制，这是人之常情。"

> "能够生存下来的物种不是最强的，也不是最聪明的，而是最能适应变化的。" —— 查尔斯·达尔文

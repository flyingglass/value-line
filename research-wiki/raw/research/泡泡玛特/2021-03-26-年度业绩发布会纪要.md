## 摘要

> 核心话题：IP矩阵 · 渠道扩张 · 会员运营 · 供应链缺货 · 利润率指引 · 海外扩张 · 心向大海

**一句话核心**：上市首年（2020）收入 **25.13亿元**（+49.3%）、经调整净利润 **5.91亿元**，王宁定调 **"心向大海，不恋沟渠"**——长期从潮玩走向乐园、内容、游戏；短期痛点是供应链缺货，管理层明确利润率长期指引 **22%-27%**。

**关键数据（2020年）**：

- 收入 **25.13亿元**（+49.3%）；毛利 15.94亿元（+46.2%），毛利率 64.8% → **63.4%**
- 经营利润 **7.2亿元**（+20%）；经调整净利润 **5.91亿元**（净利率 23.5%），上市开支约 4,400万元
- 头部四大 IP（Molly、Dimoo、Pucky、The Monsters）年销售额均超 **2亿元**；Molly 3.15亿元、Pucky 3亿元、The Monsters 2.05亿元（+90%）、Skullpanda 首系列 3,900万元
- 渠道：门店 **187家**（+76家）、机器人商店 **1,351台**（+526台）；线上收入占比 **38%**（+76.5%），抽盒机小程序 4.7亿元（+72%）、天猫 4.1亿元（+61.5%）
- 海外收入 **7,417万元**（**+176%**）；注册会员 **740万**（**+236%**），会员贡献 88.8%，复购率 46%+
- 自主产品占比 **85%**；存货 2.25亿元、周转天数 **78天**；派息率 40%（2.09亿元）

**问答要点**：

1. 会员：2021年注册会员预期再增 **80%-100%**，运营重心从纯拉新转向分层精细化（ARPU、复购率）
2. 缺货：疫情复工慢 + 二月销售超预期（历史第二），三月底大幅缓解；不做饥饿营销、不控股工厂
3. 利润率：疫情期固定投入（库位、人才、办公）压制当年利润率，若无疫情维持 **22%-27%** 指引
4. IP：头部 IP 每年 **3-4个系列**，销售周期 **12-18个月**；内外部 IP 利润率仅差 2-3 个点，不做刻意区分
5. 海外：2021年底预计 **20多家** 门店、机器人商店 100+，亚洲/东南亚占比降至 60%、西方提至 20%+
6. 品类：盲盒占比会逐渐下降，核心仍是潮玩；衍生品仅小范围试水，服务乐园与旗舰店

**跟踪要点**：

1. Skullpanda 2021 年能否成为新头部 IP
2. Pucky 能否如管理层预期实现小幅增长（笔者注：实际 2021 年 1.8 亿元，大幅低于 2020 年的 3 亿元，预测落空）
3. 供应链柔性化改造与二季度头部 IP 新品备货
4. 乐园、内容、游戏等"海"的业务落地节奏

### 开场致辞与业绩回顾

**王宁**：

各位投资人朋友大家好，非常开心大家能够参加我们泡泡玛特 2020 年的年度业绩发布会。

2020 年对于泡泡玛特而言，是一个非常不平凡的一年。伴随着我们的上市，我们也收到了很多资本市场对我们的关注。特别是在疫情的大背景下，我们的收入和利润也保持了非常好的一个增长。

我们的全产业链平台也进一步发挥了作用。我们在 IP 的孵化运营、渠道的扩张，包括会员的增长，都表现出了非常亮眼的成绩。我也非常开心地今天在这里跟大家做一个交流。

下面有请司德和杨镜冰，为大家回顾一下我们 2020 年的一些业务表现和财务表现。

**司德**（业务回顾）：

大家好，我简单介绍一下公司的情况。泡泡玛特成立于 2010 年，刚过去的 2020 年是我们的第十年。公司的 slogan 是"创造潮流，传递美好"。我们的愿景是希望可以成为全球领先的潮流文化娱乐公司。我们现在是中国最大的潮流玩具公司。

在 2020 年，我们继续通过 **全球的艺术家挖掘、IP 运营、消费者触达，以及潮流玩具文化推广** 这四个大的业务板块，发展我们以 IP 运营为核心、覆盖潮流玩具全产业链的能力，引领整个中国潮流玩具行业的发展。

在 2020 年，我们实现了 **25.1 亿元** 的营业收入，同比增长达到了 **49%**。经调整后的净利润达到了 **5.9 亿元** 人民币。

#### 业务情况介绍

**IP 孵化与运营能力持续被证明**：

- 我们在过去一年继续在全球范围挖掘最顶级、最有潜力的潮流艺术家，帮助他们进行 IP 的孵化和运营。
- 2020 年，我们运营的 **前四大 IP：Molly、Dimoo、Pucky** 还有 **The Monsters**，他们的年销售额分别都超过了 **2 亿元** 人民币。这四个头部 IP 的收入占比更加均衡。
- 我们在 2020 年推出了两个新系列：**Molly 的一天** 和 **Dimoo 太空系列**。这两个系列单系列销售额分别都超过了 **1 亿元** 人民币，取得了非常好的成绩。

**新 IP 培养与突破**：

- 我们内部的设计师团队 **PDC** 持续推出了多个受到市场欢迎的 IP 形象，比如说 **Bobo & Coco、小甜豆、YUKI** 等。2020 年，他们的累计销售额超过了 **1 亿元** 人民币。
- 2020 年下半年推出了重磅 IP **Skullpanda**。它这种非常新潮前卫的审美风格，使得整个系列上市的第一天销售就超过了 **27 万个**，打破了我们所有新 IP 首个系列上市的销售记录。我们也相信 **Skullpanda** 在 2021 年也会取得一个非常好的表现。
- 我们继续加强与全球知名 IP 的合作，比如说 **迪士尼、华纳、环球** 等，推出了多个市场表现出色的产品。
- 我们也在尝试很多新类型 IP，比如说去年推出了二次元风格的 **火影忍者、初音未来**；去年年底也在跟周杰伦合作，推出了首个明星形象的 IP。这些新的尝试都取得了非常好的市场反馈。我们也会在 2021 年继续加强这些新品类 IP 的合作。
- 在整个 2020 年，我们自主开发的产品销售收入占比达到了整体的 **85%**。

**IP 商业化拓展**：

- 我们的 IP 凭借在年轻消费者中巨大的影响力，受到了非常多行业的青睐。
- 我们在 2020 年与多个世界知名品牌合作，也跟非常多的中国领先的购物中心合作，开展了多项授权合作业务，拓展了更多 IP 商业化的可能性。

**消费者触达与渠道布局**：

- 去年虽然受到了疫情的影响，但我们依然加快了整个线下零售的布局。
- **门店**：2020 年新增门店数 **76 家**，总计 **187 家** 门店。门店收入同比增长 **35.5%**。
- **机器人商店**：新增了 **526 台** 机器人商店，总数是 **1,351 台**。收入同比增长 **32.2%**。
- **线上收入**：2020 年线上收入增长非常迅速，整个线上收入占比达到了整体业务的 **38%**，同比增长达到了 **76.5%**。
- 我们的天猫旗舰店在 2020 年的双十一期间，GMV 达到了 **1.42 亿元**，超过了众多的国际品牌，成为了天猫玩具类目的首个双十一销售过亿的品牌。
- **海外市场**：2020 年在海外市场虽然受到了非常严重的疫情影响，但我们依然取得了 **176%** 的收入同比增长。目前在全球超过 **20 个** 国家和地区都可以购买到我们的产品。
- 2020 年 9 月我们在韩国的首尔开出了泡泡玛特第一家海外门店。我们新加坡和加拿大的首家门店也分别在今年（2021 年）1 月份和 3 月份开业，销售表现也都非常好。

**会员体系建设与行业推广**：

- 在 2020 年，我们继续加强整体的会员体系建立。
- 截止到 2020 年底，我们的注册会员达到了 **740 万** 人，同比增长 **236%**。
- 会员的消费占比达到了 **88.8%**，会员的复购率也超过了 **46%**。我们希望通过会员体系的不断加强，可以给粉丝提供更好的服务和体验。
- 2020 年 11 月份，我们举办了 **上海国际潮流玩具展**，吸引了超过 **10 万** 人次的粉丝前来观展。
- 同期我们举办了首届潮流玩具产业论坛，并发布了潮流玩具行业发展趋势的白皮书。我们也希望通过努力，去引领整个行业，得到一个更加健康快速的发展。

#### 2020 年主要经营指标

- 我们在去年运营了 **125 个 IP**，头部四大 IP 的销售额分别都超过了 2 亿元人民币。
- 我们有 **85%** 的收入来自于自主产品。
- 线上收入占比达到 **38%**，海外业务增长达到了 **176%** 的同比增长。
- 截止到去年底，门店数量是 **187 家**，机器人商店数量是 **1,351 台**。
- 会员数量有了较高增长，达到了 **740 万**，同比增长数字是 **236%**。
- 营业收入是 **25.1 亿元** 人民币，收入同比增长达到了 **49%**。
- 调整后的净利润达到了 **5.9 亿元** 人民币。

#### 2021 年及未来展望

- **2021 年**：我们希望依旧发挥整个全产业链平台的优势。
- 继续挖掘和培养更多优秀的艺术家和 IP，拓宽 IP 商业化的可能性。
- 继续加强整个供应链的优势，进一步健康快速地进行渠道建设，包括继续加快门店的开设。
- 线上除了现在的天猫店，我们的微信抽盒机小程序之外，也会继续增加可能类似于京东还有其他的一些电商平台的运营。
- 会更加注重会员和数字化的建设。我们预期在明年，会员各方面的表现也会取得一个更好的表现。
- 我们希望通过这样一番努力，可以提升我们整体的服务体验和运营效率。
- **更远的未来**：我们希望泡泡玛特可以继续以 IP 为核心，围绕着 IP 探索整个 IP 产业上下游的产业链条，在未来真的成为 **全球领先的潮流文化娱乐公司**。

### 杨镜冰（首席财务官）财务回顾

**杨镜冰**：

大家好，在 2020 年虽然有新冠疫情的影响，但我们的财务表现依然强劲。

**收入及利润概览**：

- 收入：从 2019 年的 16.83 亿元人民币上升到了 2020 年的 **25.13 亿元** 人民币，年增长率达到 **49.3%**。
- 自主产品占比：泡泡玛特品牌自主开发的产品的占比由 2019 年的 82.2% 上升到了 2020 年的 **85%**，达到 21.36 亿元人民币。外采的第三方产品的占比下降到了 15%。
- 毛利：由 2019 年的 10.9 亿元人民币上升到了 2020 年的 **15.94 亿元** 人民币，年增长率达 **46.2%**。
- 毛利率：由 2019 年的 64.8% 略微下降到 **63.4%**，主要由于我们进一步提高了产品的质量，优化了产品的工艺，增加了环保投入所致。
- 经营利润：达到了 **7.2 亿元** 人民币，比 2019 年增长了 **20%**，经营利润率为 **28.6%**。
- 经调整后的净利润：达到了 **5.91 亿元** 人民币，利润率为 **23.5%**。
- 主要调整项目包括我们上市开支约 4,400 万元人民币，以及优先股转为普通股的公允价值变动 2,300 万元人民币。

**销售增长驱动因素：按 IP 划分**：

- 公司持续增加泡泡玛特品牌产品的销售占比，从 2019 年的 82% 上升到了 2020 年的 85%。
- **自有 IP**：
  - 自有 IP 数量：截至 2019 年底共拥有 **12 个**，2020 年底共拥有 **14 个**。
  - 收入由 2019 年的 6.3 亿元人民币增加到了 2020 年的 **9.8 亿元** 人民币。
  - 收入占比从 2019 年的 37% 上升到了 2020 年的 **39%**。
  - 主要得益于来自 **Molly** 的收入由 2019 年的 1 亿元人民币增加到了 2020 年的 **3.15 亿元** 人民币。
  - 2019 年推出的 BOBO&COCO 在 2020 年实现了营业收入 6,700 万元人民币。
  - **Skullpanda 在 2020 年 10 月推出第一个系列，实现了营收 3,900 万元人民币。**
- **独家 IP**：
  - 独家 IP 数量：截至 2019 年底共拥有 **22 个**，2020 年底共拥有 **30 个**。
  - 收入从 2019 年的 6 亿元人民币增加至了 2020 年的 **7.12 亿元** 人民币。
  - Pucky：2020 年收入为 3 亿元人民币，与 2019 年的 3.15 亿元人民币基本持平。
  - The Monsters：在 2020 年收入达到了 2.05 亿元人民币，比 2019 年的 1.08 亿元人民币增长了 90%。
- **非独家 IP**：
  - 非独家 IP 的数量：2019 年为 **51 个**，2020 年达到了 **81 个**。
  - 由于我们的 IP 运营能力得到了市场的广泛认可，吸引了国际 IP 供应商与我们合作。2019 年我们与迪士尼、环球建立了合作。
  - 得益于 **迪士尼系列、哈利波特系列、火影忍者** 等的销售，非独家 IP 的收入由 2019 年的 1.6 亿元人民币大幅增至 2020 年的 **4.44 亿元** 人民币。
  - 收入占比从 2019 年的 9.5% 增加到了 2020 年的 **17.7%**。

**销售增长驱动因素：按渠道划分**：

- 收入增长主要来自于线下零售店和机器人商店的网络扩张，以及线上渠道增长。
- **线下零售店**：
  - 收入从 2019 年的 7.4 亿元人民币上升到了 2020 年的 **10 亿元** 人民币。
  - 门店数量由 2019 年底的 114 家增加到了 2020 年底的 **187 家**。
  - 187 家门店中，81 家在一线城市（主要是北上广深），56 家在新一线城市，50 家在二线及其他城市。
  - 2021 年，我们的零售店开店速度也会继续高于 2020 年的开店速度。
- **机器人商店**：
  - 收入从 2019 年的 2.5 亿元人民币上升到了 2020 年的 **3.3 亿元** 人民币。
  - 数量由 2019 年的 825 个增加到了 **1,351 个**。
  - 1,351 台其中在一线城市有 447 个，新一线城市 453 个，二线及其他城市达到了 451 个。
  - 我们会继续利用机器人商店作为我们的雷达，在二线及以下城市增加我们的渗透。
- **批发及其他业务收入**：
  - 收入从 2019 年的 1.56 亿元人民币增长到了 2020 年的 **2.3 亿元** 人民币，收入占比约为 9.1%。
  - 中国大陆的批发业务（2020 年收入 1.57 亿元人民币），主要来自南京金鹰泡泡玛特公司（我们持股 52% 的合营公司）的收入增长。
  - 海外市场也在加速扩张，已在韩国、日本、新加坡设立了合资公司。
  - 海外销售收入从 2019 年的 2,689 万元人民币增长到了 2020 年的 **7,417 万元** 人民币，增长率高达 **176%**。
  - 长期来看，我们会通过海外经销商扩展我们的海外市场，国内经销商不是我们的主要发展方向。
- **潮玩展收入**：
  - 收入由 2019 年的 4,500 万元人民币下降到了 2020 年的 **2,350 万元** 人民币。
  - 这主要是由于新冠疫情的影响，公司取消了北京潮玩展，仅在 11 月举办了上海展。
- **线上方面**：
  - 收入由 2019 年的 5.4 亿元人民币大幅增长至 2020 年的 **9.5 亿元** 人民币。
  - 增长主要由于 2020 年新冠疫情的影响，尤其 2020 年上半年大量的销售在线上进行；线上购买用户增加、泡泡玛特品牌产品的增加、以及我们品牌的知名度的上升，也提升了线上渠道的销售。
  - 天猫旗舰店 2020 年营业收入为 **4.1 亿元** 人民币，比 2019 年 2.5 亿元人民币增长了 **61.5%**。
  - 泡泡玛特抽盒机小程序 2020 年营业收入为 **4.7 亿元** 人民币，比 2019 年 2.7 亿元人民币增长了 **72%**。
  - 此外，我们在京东以及其他的电商平台，2020 年也贡献了 **7,900 万元** 的销售收入。

**成本与费用分析**：

- **销售成本**：
  - 从 2019 年的 5.93 亿元人民币上升到了 2020 年的 **9.19 亿元** 人民币，增长了 **55%**，与业务扩张及收入的增长一致。
  - 商品成本主要为我们支付的第三方制造商的商品成本，以及我们采购的第三方产品的成本。
  - 其他成本主要为支付艺术家及 IP 供应商的设计费、授权费、税金以及折旧摊销的成本。
- **毛利及毛利率**：

**分析师提问（中金公司）**：

我有两个问题。第一个的话，也是关于咱们的 IP 的。我们看到咱们自主产品销售占比是在提升，发展势头也很好。但这里面要看到独家 IP 这个占比是在下降的，尤其是咱们的 **Pucky** 这块的销售额也是在下降的。这块能不能问一下 **Pucky** 销售下降的原因。还有就是后续咱们在新的 IP 的储备情况和后续的推出的新系列的规划是什么样的？

第二个问题的话，其实也是关于咱们 IP 的。因为现在咱们很多的像 **Molly** 和 **Labubu** 这样的一些非常好的 IP，它其实只是一个非常可爱的形象。我们想了解一下，这些已经成为一个大 IP 之后，大家准备给这个 IP 一个什么样的比较好的形象，就像迪士尼里面可能有些唐老鸭或者米老鼠这种的内涵。那这块公司是一个什么样的规划？在 IP 内容化这块，咱们是怎么考虑的？

**司德**（Pucky 表现与 IP 内容化）：

我先说第一个问题，关于去年我们的 IP 表现。去年的整个 IP 表现其实还是在我们整个的规划预期里面。我们每一年会提前差不多六个月左右去做接下来一年整个 IP 的规划，包括它一年会推出多少个，每一个系列的预计销售额是怎么样的。其实包括 **Pucky**，包括我们其他的 **Dimoo** 这些 IP，他们在去年的表现其实跟我们的预期差不太多。

当然会有一些个别比较亮眼的表现，比如说 "**Dimoo** 的太空系列"，还有 "**Molly** 的一天"这个系列，他们都取得了单系列过亿的销售额表现。

对于 **Pucky**，它本身的定位是一个比较精准的定位，它是针对特定的人群。我们在它的每个系列的规划里面，其实也是差不多会在目前的这么一个销售额。我们预期在 2021 年它会有一个小幅的增长，但大概还是在目前的这个状态里边。它也符合我们整体的预期。

同时我们也会在每年去努力推出更多针对整个市场的审美优化，或者针对大众的一些喜欢的方向，去引领大家喜欢的一个东西。去年年底的时候我们推出了 **Skullpanda** 这个新的 IP 形象。我们也认为它会是今年我们整体表现非常好的一个新的头部 IP。

第二个关于 IP 的内容化，我们自己其实首先会认为潮流玩具本身它的兴起到整个的发展的趋势，未来其实它跟内容本身并不能说是完全一一对应的。因为手办艺术设计本身在我们理解里面，它其实也是内容的一部分。

我们认为 IP 从长远来看，运营 IP 要持续投入。这些持续的投入会包括从设计的角度，也许从内容的角度，或者从营销活动、市场营销预算等等各个方面去做。这样的话可以让每一个 IP 产生出更大的生命力、更长久的生命力、更大的影响力。这是我们对于运营 IP 的理解。

因为泡泡玛特本身也是一个多 IP 运营的公司，我们也会去针对每一个 IP、每一个艺术家不同的特点，去做未来长远的规划。可能对于未来我们有一些 IP 背后的艺术家，他在艺术方面可能会走得更远，我们会帮助他们在艺术方面去做更多尝试。有一些 IP 它天然地可能会具有一些世界观和内容属性，我们不排除未来去帮助它赋予更深度的内容，通过内容去打动更多的消费者。可能对于另外的一些 IP，我们可能会在潮流玩具这个方向上面去进行一个更深度的探索。所以这是我们长远对这个事情的考虑。

**王宁**（IP 策略补充）：

我再补充一下刚才第一个问题，关于 IP。虽然大家比较关注某一个 IP 的上升，或者某一个 IP 的下降，或者说它单一 IP 的一个表现。但是我还是希望大家能够从我们财报中看得出来。就拿 **Molly** 举例子，虽然它的整个绝对值是在上涨的，销售额是在上涨，但是它在我们的占比其实是逐年下降了。我们过去从一个单一的 **Molly** 作为一个主打，现在大家也可以看出来，我们已经跑出来了很多个头部 IP。而且除了现在已经跑出来的四五个 IP 以外，我们还有很多个非常有潜力的 IP，即使是在 2020 年只推出了一个系列或两个系列，它的销售表现也非常好，包括我们的 PDC，我们自有的一些 IP 他们的表现也非常好。

所以我希望大家可以从我们财报中看得出来，我们整个 IP 的运营能力以及我们现在平台的优势，其实在更加凸显。我们相当于整个平台的价值链也在慢慢完善。我们也会根据这么多 IP 的运营表现，把更多的平台的这种核心资源，向我们认为非常有价值的 IP 上面聚集。这是我们未来的一个方向。

「笔者注：从财报上看，Pucky 在 2021 年的销售收入为 1.8 亿元，大幅低于 2020 年的 3 亿元，没有实现预期中的小幅增长。另一方面，公司有些 IP 产品的销售也会超预期的增长。这也许说明准确预测某一个 IP 的销售情况可能很难」

**分析师追问（中金公司）**：

刚才其实大家都在问这个供应链，我们也确实看到咱们有些门店一些潮玩的产品出现了缺货。那这块我们想问一下公司在定一系列的生产的产量的这块是什么样的一个规划。然后如何决定咱们生产的这个量在不同渠道之间的分配，包括不同区域的门店的分配？

**司德**（供应链与分配）：

从供应链的角度，我们经历了去年整个疫情的反复，我们也在算是下定决心，去做整个供应链的改造。我们去跟我们的团队，还有我们合作的工厂，去花了很长的心思去做整个供应链的柔性化的管理。我们也希望可以通过我们这样的一些不断优化，包括去做一些信息系统的一些优化等等，去做到我们供应链的快速反应。

同时对于定量的阶段的话，我们也会针对不同的渠道，它会有一个不同的特征。比如线上渠道，它可能在新品上市的刚开始的第一周会有一个更快速的爆发。可能对于线下的渠道，它的销售相对更长久更平稳。针对不同渠道的特征，我们也会去做整个的资源的调配。

**王宁**（供应链总结）：

我再补充一句，一方面，在去年疫情发生的时候，我们对于整体全年表现稍微保守了一些。但是另一方面，其实因为去年疫情的反复，让供应链整个它的招工，包括疫情的一些管控政策，包括一些回乡政策，也让它整个用工的相对稳定性受到一些影响。我相信在未来的一年，随着疫情的逐渐控制，包括我们对未来预期的更加明朗，会有一个比较好的表现。

**Q5 PDC 设计团队规模、三线城市门店效率（广发证券）**

**分析师提问（广发证券）**：

我这边有两个问题想问一下管理层。第一个刚才管理层提到咱们的 PDC。从年报来看的话，目前 PDC 的设计师团队已经超过了百人。我们往后看的话，会大概到一个什么样的团队规模。后续来看的话，整个我们内部的一个设计怎么样的一个合作或者协调的一个机制，我们在 IP 的一个分配方面是特殊的一个划分？这是第一个关于设计师的问题。

第二个我想问一下关于咱们的渠道结构的问题。因为目前咱们门店主要是开在一线和二线城市。但我们看到也有开店在三线或者以下的城市，想问一下在三线城市的门店，它的一个运营效率如何？

**司德**（PDC 团队）：

我先解释一下关于 PDC，其实 PDC 在我们内部包含了不同的团队。比如说刚才提到的原创团队，他们会去原创一些 IP，像我们推出的 **Bobo & Coco、小甜豆** 这些是 PDC 的原创团队。

同时 PDC 也会有其他的部门，比如说可能更偏 3D 设计、工业设计或者平面设计等等这些团队。这些团队是对我们现有的所有的 IP 去做一个支持和日常的一些工作，这是有一个区分的。

我们长期来看，我们的设计团队其实也在不断扩充中。因为我们运营的 IP、推出的产品，从 IP 的风格、品类各个方面其实都在不断扩充。所以我们的设计人员也在不断扩充。泡泡玛特本身是一个非常推崇艺术、推崇设计的公司。所以设计的人才在我们这里，它也会有一个相对更好的长远发展。

**王宁**（门店效率）：

我说一下关于门店的表现。对于我们来讲的话，一线城市和二三线城市，它的店的效率，我们现在来看的话，一定程度上不会有特别大的改变。当然因为一线城市它的门店数量比较多，北京可以开到 40 多家 50 家的门店。那可能有些二线城市也许它的承载是十家门店，那可能也许三线城市它是一家到三家门店。但它单店的表现可能不比一线城市差，甚至可能还优于很多一线城市的门店表现，其实它的效率并没有说下降。当然它可能因为它的城市级别，现阶段可以承载门店的数量可能跟一线城市、二线城市有所区别。

**Q6 IP 一体化与虚拟形象、衍生品 SKU 扩展、设计人才培养体系（中信证券）**

**分析师提问（中信证券）**：

我这边有几个问题想请教一下。第一个就是我们会看到，刚才王总也提到我们的 IP **"心向大海"** 这个点。确实我们能感受到，泡泡玛特的 IP 整个来讲，它的一个影响力也在扩大。对于整个这个 IP，刚才也提到不限于内容和游戏各方面的一个拓展。那您再讲一下，包括我们现在像一些数字形象以及虚拟形象，或者是在这个 IP 的一体化发展上，现在有哪些更多的一些布局和策划呢？

第二个问题是，我们会看到现在很多泡泡玛特的店里面，其实现在已经不只是销售潮玩的或者是盲盒类产品，会有一些相应的衍生品。我们也看到很多手机壳，销售看起来都好的，包括一些礼品。这一块我们对于人像 IP 类的，刚才你也提到，我们其实以后会不只是一个潮玩，可能还有一些品牌性的建设。这边关于一些 SKU 的扩展计划，以及我们现在这个 SKU 扩展的一个定价战略。还有甚至我们现在供应链的一个准备情况大概是怎么样的？

第三个问题就是我们看到刚才很多投资人也提到一些供应链问题。但是我们会发现，包括其实泡泡玛特和一些其他的一些潮玩品牌上来讲，泡泡玛特的 IP 设计的审美窗口是主要的一些地方。那这样一个 IP 的设计流程，以及我们在这个艺术团队和艺术家的一些团队和人才培养和管理体系上，能帮我们再进行一些分享吗？

**王宁**（IP 拓展、衍生品与设计体系）：

我们去年其实已经有开始去进行一些整个 IP 产业链的一些投入。包括今年春节档大家也可以看到我们有参与投资的一个动画片《哪吒重生》，也有比较好的一个表现。当然这只是我们的一个开始。

关于一个 IP 的上下游，我们现在都会进行一些考虑。因为我觉得 IP 这个产业是一个先天的有很强的扩展性，而且我们现在也有很强的一个优势。我们内部孵化出了非常多优秀的 IP，也有很多优秀的一些艺术家。我们相信它在往上延展和往下延展的时候，都应该会有不错的表现。包括我们去年整个对 IP 的授权业务合作，其实也有一个非常好的表现，也可以间接看到它们的非常好的一个价值。

我们从上游上来讲的话，我们现在也在积极考虑，不管是它的 **内容** 和它的一些 **虚拟形象** 的建设，包括它的 **游戏业务**，是我们在考虑的一个方向。下游的话，比如说它的 **乐园**，乐园我们现在已经在进行当中了。我们也希望尽快的能够跟大家去见面，我们还是对这个业务充满信心的。

我觉得关于衍生品，首先我们核心还是会放在 **潮玩** 这个类目上。因为我们觉得潮玩类目本身这个品类还处于一个非常快的增长通道。那我们也在这个品类当中占据了非常重要的用户心智。所以在这个品类上，还是非常核心的一个重点。当然我们在衍生品上，虽然大家可以看到一些衍生品，但是我们并没有非常多地去推我们的衍生品。我们现在衍生品只是在我们限定的一些 IP 和限定的一些少量品类上做尝试。

当然这些衍生品主要是去服务我们后期的 **乐园业务** 和我们将来 **旗舰店业务**，去丰富整个 IP 线、为更好的用户体验来做一些筹备。当然我们也相信很多好的 IP 其实在衍生品上也会有一个很好的表现。

关于设计，我想说的是首先我们今年已经创业十年了。我觉得这十年除了对我们自身运营的积累，不管是团队的积累，还有我们运营细节的积累。这都让我们一点点对这个行业会有更深的理解和更深的行业认知。

除了这些经营的积累以外，关于 IP 和艺术家孵化，也是每一年都会有我们对这个行业新的认知和判断，以及对这个行业不断的迭代。所以对我们来讲的话，产品的诞生基本上都需要 **5 到 8 个月** 的时间。我们很多的产品都是提前对设计、对审美、对艺术家进行一些预判和沟通，来不断地完善和规划我们未来的系列。

所以这也是我们一个非常重要的门槛，也是一个非常核心的竞争力。也就是说，我们永远在推出一些**引领这个市场的设计方向**、**优秀艺术家的方向**、**产品系列规划的方向**。我觉得未来很长的时间会成为一个非常强的壁垒。

**Q7 各渠道定位与毛利差异（线上主持人）**

**分析师提问（线上主持人）**：

我们公司有门店、线上、机器人销售等多渠道进行销售。哪一个渠道的成本毛利最高？未来会主要扩张哪一个销售渠道？

**司德**：

我先解释一下我们的四个渠道，它本身会有一些不同的定位。从我们整个公司经营的策略上面来讲：

- **线下门店**：除了是好的销售渠道之外，它其实是我们非常重要的一个 **品牌宣传** 渠道。大家可以通过我们的门店更好地去了解我们的品牌文化，以及它也是我们 **会员拉新** 的非常重要的一个地方。
- **机器人商店**：它有两层的作用，一层是它可以提供一个更加 **便利化的购买**。同时它也是一个非常好的 **会员拉新** 渠道，可以更快速地到达更多的点位，帮助我们去让更多的潜在消费者成功转化为我们的用户。同时机器人商店本身还有一个非常好的 **雷达作用**，根据它的销售表现，我们可以去考虑是不是在这里去新增门店。
- **线上（天猫旗舰店和传统电商）**：它更多的是以 **拉新** 作为我们的一个核心目标。像我们整个天猫团队，他们的经营指标里边，除了销售额、利润之外，**新会员的销售业务占比** 是他们非常重要的 KPI 考核标准。
- **微信小程序（抽盒机）**：它更多的是我们 **核心用户聚集** 的地方。因为我们会在里面推出更多变化的玩法，让我们的用户在里面产生更多的购买乐趣。

**王宁**：

我补充一下，大家可以看到我们有四个渠道，而且相对来讲，每个渠道它都有它一定的份额，表现也非常的出色。这一定程度上可以反映我们其实在不管是线上、线下和新的销售模式上，都有一个比较好的表现。

我们并不是说公司只有线上的基因，或只有线下的基因，一定程度上说明我们在各个环节我们都有一个比较好的运营能力。我觉得这是我们积累下来的一个非常好的体系。未来，我们也希望能够把这样一个更加综合的运营体系和综合的运营能力做一个更好的提升。

**Q8 线上营销规划、二手市场影响（方正证券）**

**分析师提问（方正证券）**：

第一个问题是线上营销的规划，也陆续看到朋友圈的一些广告投放，未来线上的销售额会加大。去年跟快手合作的"潮玩新计划"等合作新闻稿中也提到了泡泡玛特自己的 MCN，未来的规划是什么？

第二个问题是咸鱼、潮玩族等二手平台发展非常快，交易量也很大。虽然泡泡玛特的二手价格比较高，但盲盒类产品还是有折扣的。怎么看待二手市场影响一手市场销量的情况？

**司德**：

从营销的角度，市场营销其实不会是我们特别重要的一块。我们的营销更多的是借助我们强势 IP 的能力，去做更多 **联合营销** 活动。比如说我们今年春节跟快手的合作，跟支付宝的合作。包括我们过去众多的商场大型展览和授权业务的合作。我们是通过这样的合作，跟第三方品牌联合一起进行营销活动，这是我们更重要的一些营销方式。

像朋友圈广告或者天猫的一些常规广告，这些都是常规的运营方式。从营销费用占比上面来讲的话，**不会有一个显著的增加**。

我们是在做一手市场的销售、运营，所以我们自己不会去做二手市场。我们可能会去通过二手市场的表现，去反馈我们的一些产品推出情况、市场口碑等等。我们会去做一些关注，但不会自己参与。

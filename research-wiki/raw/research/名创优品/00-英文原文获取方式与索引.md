## 二、两类来源的 URL 规律（便于补齐未来场次）

### 1. AlphaMadera（覆盖 17 场，主力来源）

```
https://alphamadera.com/stock/MNSO/transcripts/{财年}/{季度序号}/raw
```

- `{财年}` = 该场所属**财年**的结束年，`{季度序号}` = 1–4
- **财年错位注意**：名创有一段时间以 **12 月为财年结束**（如 FY2023 Q1 是 2022-11 那场），
  后来改按自然年。所以 *会议日期所在年 ≠ URL 里的财年*，务必照上表核对
- 页面为 raw transcript，需保留 `[indiscernible]` 等占位符才算完整

### 2. 公司官方 IR Full Script PDF（覆盖 2 场）

```
https://ir.miniso.com/image/FQ1%2721+Scripts.pdf          ← 早期命名（FY + 财季 + Scripts）
https://ir.miniso.com/image/MINISO+2024+Mar+Quarter+Transcript.pdf   ← 后期命名（MINISO + 年 + 月英文 + Quarter + Transcript）
```

命名规律随年份变化，两者都试；IR 站点会重定向到 `filecache.investorroom.com`。

### 3. Motley Fool（覆盖 2021 年 2 场）

```
https://www.fool.com/earnings/call-transcripts/{YYYY}/{MM}/{DD}/miniso-group-holding-limited-mnso-{q}{N}-{YYYY}-earnings
```

slug 里的 `q1 / q4` 用的是**自然年季**（例如 2021-05-19 那场在 slug 里是 `q1-2021`），与公司自己的 FY 编号不一致。

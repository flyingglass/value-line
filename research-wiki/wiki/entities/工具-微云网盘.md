# 工具：微云网盘

## 概述

腾讯微云网盘，通过 MCP 协议接入。用于备份项目关键文件（`.env` token、Skill 安装包、年报 PDF 等），实现跨电脑迁移自动化。

## 关键属性

| 属性 | 值 |
|------|-----|
| 接入方式 | CodeBuddy Skill (`~/.codebuddy/skills/weiyun/`) |
| 认证 | `WEIYUN_MCP_TOKEN` 环境变量 |
| Token 获取 | https://www.weiyun.com/act/openclaw |
| 上传脚本 | `scripts/upload_to_weiyun.py` |

## 能力

| 功能 | 命令 |
|------|------|
| 上传文件 | `python upload_to_weiyun.py <文件路径> --token <TOKEN>` |
| 分片上传 | 自动处理大文件分片 + SHA1 计算 |
| 秒传 | 相同文件自动跳过 |

## 备份清单

微云上存储的迁移文件：

| 文件名 | 用途 |
|------|------|
| `codebuddy-migration.zip` | IMA + TDX + Weiyun 全套迁移包 + setup.cmd |
| `weiyun_fixed.zip` | 修复后的微云 Skill 安装包 |
| `.env` | 项目所有 API Token (TDX/Weiyun/IMA) |

## 涉及模块

- 属于开发工具链，不直接参与 build 流水线
- 与 `.env` gitignore 配合实现密钥云备份

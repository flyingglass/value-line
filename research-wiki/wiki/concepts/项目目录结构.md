# 项目目录结构

## 总览

```
value-line/
├── scripts/              ← 全部 Python 源码
│   ├── build.py          ← 主入口，8步流水线
│   ├── config.py         ← 标的配置 + 市场定义 + VL 指标
│   ├── engine.py         ← 指标计算引擎 (~2600行)
│   ├── fetcher.py        ← 数据拉取 (AKShare + TDX)
│   ├── tdx_client.py     ← TDX HTTP API
│   ├── pdf_downloader.py ← 年报 PDF 下载
│   ├── extract_mda.py    ← MD&A 文本提取
│   ├── generate_report.py   ← HTML 报告生成
│   ├── generate_reading.py  ← 阅读报告 (MD + HTML)
│   ├── generate_index.py    ← 索引页
│   ├── list_refs.py         ← 历史PE/PB参考
│   └── <code>/              ← 每只标的的定制脚本
│       ├── business_commentary.py
│       ├── insert_revenue.py
│       ├── metric_adjustment.py
│       └── extract_business.py
│
├── data/                  ← 数据 (共享)
│   ├── <code>.db          ← 每只标的 9 表 SQLite
│   ├── pdfs/<code>/       ← 年报 PDF (500+)
│   └── fx_rates.db        ← HKD/CNY 汇率
│
├── report/                ← VL 报告输出
│   ├── <Name>.html        ← VL 单页 HTML
│   ├── reading/           ← 阅读报告
│   └── index.html         ← 索引页
│
├── research-wiki/         ← 知识库 (双轨)
│   ├── raw/               ← 原始资料，只进不改
│   ├── wiki/              ← VL 项目文档 (模块/概念/实体)
│   └── research/          ← 投研 wiki (标的/主题)
│
├── .codebuddy/            ← 项目宪法 + 自动化
├── .venv/                 ← Python 虚拟环境
├── requirements.txt
└── .env                   ← 密钥 (gitignored)
```

## 路径规则

所有脚本统一使用以下模式：

```python
# 项目根目录 (用于 data/ report/ report_data.json 等)
PROJECT_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))

# 模块互导入 (所有 .py 都在 scripts/ 下)
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
```

## 使用方式

```bash
# VL 报告生成
python scripts/build.py 09992 --cf 15.0

# 阅读报告
python scripts/generate_reading.py 09992

# 索引页
python scripts/generate_index.py
```

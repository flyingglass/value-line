# 跨电脑迁移与云备份

## 定义

项目依赖 3 个外部服务认证（TDX/Weiyun/IMA），所有 token 统一存储在 `.env` 中（gitignore）。通过微云网盘实现密钥和 Skill 安装包的云端备份，新电脑一键迁移。

## 关键要点

- **`.env` 是唯一真相源**：包含 TDX/Weiyun/IMA 全部 token，通常 8 行
- **微云是传输通道**：`.env` + Skill zip 包统一上传，新电脑下载后 `setup.cmd` 一键初始化
- **setup 脚本自动处理**：从 `project.env` 读取 token 设置环境变量
- **不依赖 CodeBuddy 云同步**：mcp.json 和 skills 都通过微云手动迁移

## 迁移流程

```
本机                                    微云                           新电脑
───                                    ───                           ───
.env + skills 打包 ──upload──→ weiyun ──download──→ setup.cmd 解包
                                                          ├─ mcp.json
                                                          ├─ ima-mcp (创建venv)
                                                          └─ project.env → .env
```

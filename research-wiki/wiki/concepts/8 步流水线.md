# 8 步流水线

## 概述

`build.py` 是系统主入口，编排 8 步强制流水线。任何一步失败 = 阻断 = 不生成报告。不存在 `--force`。

```
python build.py <代码> [--cf N | --pb N] [--years N]
```

## 流水线步骤

| Step | 操作 | 脚本 | 缺则 | 自愈 |
|------|------|------|------|------|
| 0 | config 完整性检查 | — | **BLOCK** | 缺 name_en 阻断 |
| 1 | 数据拉取 | fetcher.py | **BLOCK** | 自动下载 |
| 2 | 年报 PDF 下载 | pdf_downloader.py | **BLOCK** | 自动下载 (≥3 年) |
| 3 | MD&A 提取 | extract_mda.py | **BLOCK** | 自动提取 → mda_text |
| 4 | 营收拆分入库 | insert_revenue.py | **BLOCK** | **手动补** |
| 5 | config final 切回 | — | **BLOCK** | — |
| 6 | 指标计算 + 交叉验证 | engine.py | **BLOCK** | 自动 |
| 7 | HTML 生成 | generate_report.py | **BLOCK** | 自动 |
| 8 | 72 项数据完整性验证 | build.py | **WARNING** | 失败降级，报告仍生成 |

## Step 0: 确认页

估值倍数确定优先级：
```
CLI --cf/--pb > DB meta 已确认值 > 用户交互输入
```

确认页必须出现才进入流水线。显示：企业名/代码/市场/行业/币种/数据年份/估值方法/历史参考。

## Step 4: 营收拆分（唯一需手动的步骤）

每只标的需要 `scripts/<code>/insert_revenue.py`。营收结构写入 `revenue_structure` 表。

## 阻断诊断

```
BUILD FAILED →
  ├─ Step 0: 补 config.py
  ├─ Step 1: 检查 AKShare 网络
  ├─ Step 2: PDF < 3 → HKEX 搜索参数
  ├─ Step 3: mda_text 提取失败
  ├─ Step 4: revenue_structure 空 → 手动 insert_revenue.py
  ├─ Step 6: engine 字段映射兼容
  └─ Step 8: validation.mismatches > 0
```

# 开发环境配置

## 虚拟环境

本项目使用本地虚拟环境 `.venv`，**严禁**使用系统全局 Python 环境。

```cmd
# 创建
python -m venv .venv

# 安装依赖
.venv\Scripts\pip.exe install -r requirements.txt

# 运行脚本
.venv\Scripts\python.exe <script.py>
```

## 依赖

| 包 | 最低版本 | 用途 |
|----|----------|------|
| akshare | >=1.18.0 | 金融数据获取 |
| pdfplumber | >=0.11.0 | PDF 解析 |
| requests | >=2.34.0 | HTTP 请求 |
| pandas | >=2.3.0 | 数据处理 |

## 全局环境规则

`requirements.txt` 中的包不得存在于全局 Python。pymysql 是系统预装包，不要动。

新增依赖必须同步更新 `requirements.txt`。

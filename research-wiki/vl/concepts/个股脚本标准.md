# 个股脚本标准 (09992 模板)

每只股票必须在 `scripts/<code>/` 下拥有 4 件脚本，与 09992 (泡泡玛特) 对齐。

## 1. business_commentary.py — 动态 Business + AI Commentary

**接口**：
```python
def build(stock, metrics, revenue_structure, years, cagr, spot):
    return {"business": "...", "commentary": [p1, p2, p3, p4, p5]}
```

**参数说明**：
- `stock`: config 中的股票配置 `{"name":"...", "market":"hk", "business_desc":"..."}`
- `metrics`: engine 计算后的全部指标 `{"2025": {"OPERATE_INCOME":7200, "BASIC_EPS":24.15, ...}, ...}`
- `revenue_structure`: dict 格式 `{"by_product": [{"name":"...","pct":82.4}]}` (⚠ 非 list)
- `years`: 年份列表 `["2018",...,"2025"]`
- `cagr`: 增长率 `{"sales": {"1yr":10.2, "3yr":..., "5yr":...}, ...}`
- `spot`: 现值 `{"pe":15.9, "pb":2.96, "div_yield":1.19}`

**设计原则**：
- 所有数字通过 `ly.get("FIELD")` 从指标实时获取，无硬编码
- 每年拉完新财报自动同步更新
- 5 段 Commentary 模板：P1 业绩快照 / P2 每股资金流向 / P3 竞争壁垒 / P4 估值 / P5 催化剂

## 2. insert_revenue.py — 营收拆分入库

**格式**：
```python
data = [
    (code, '2025', 'by_business', '业务A', 10000, 50.0),
    (code, '2025', 'by_business', '业务B', 10000, 50.0),
]
conn.executemany(
    'INSERT OR REPLACE INTO revenue_structure (code, year, dim_type, dim_name, amount, pct) VALUES (?,?,?,?,?,?)',
    data)
```

**维度**：`by_business` / `by_channel` / `by_region` / `by_product` 等，按年报披露。数据手动维护。运行 `build.py` 时 step 4 自动调用。

## 3. metric_adjustment.py — EPS 非经常性调整

**接口**：
```python
def adjust_metrics(reader, rd, np_val, tax_rate, stock_cfg):
    return adj_np, footnotes_list
```

**分市场策略**：

| 市场 | 策略 | 脚注格式 |
|------|------|---------|
| A股 | CAS 扣非净利润 (`*扣除非经常性损益后的净利润`) | `EPS adj: CD {val}` |
| 港股 | 探 FV + FX + GS + IM + OG 子项，逐个排除 | `EPS adj: FV -1.6 GS +1.5` |
| 美股 | 直通，无调整 | 无脚注 |

**缩写表**：
- GS = 政府补贴
- FV = 公允价值变动
- FX = 汇兑收益
- II = 投资收益
- IM = 资产减值
- EL = 权益法亏损
- OG = 其他收益
- CD = A股扣非

## 4. extract_business.py — PDF 信息提取

**用途**：从最新年报 PDF 中搜索员工人数、产能、门店数等补充数据。

**实现**：`pdfplumber` 遍历页面，按关键词 (`["雇员","员工","人数",...]`) 匹配，打印上下文。

**注意**：此脚本为辅助工具，非流水线必需步骤。报告生成不依赖其输出。

## 新增股票检查清单

```
scripts/<code>/
  ├── business_commentary.py   ← 必须，动态业务+评论
  ├── insert_revenue.py        ← 必须，营收拆分
  ├── metric_adjustment.py     ← 必须，EPS调整
  └── extract_business.py      ← 必须，PDF辅助提取
```

## 新增股票完整流程

1. `config.py`：添加 STOCKS 条目（name / name_en / market / exchange / currency / industry / shares 等）
2. `scripts/<code>/`：创建 4 件脚本
3. `python build.py <code> --cf N --fetch`：首次拉数据 + 生成报告
4. `python generate_index.py`：**重新生成 `report/index.html`**
5. `python build.py <code> --cf N`：确认页验证（历史 PE/PB 参考正常显示）

## BUSINESS 与 Revenue 职责分离

| 区域 | 负责脚本 | 内容 |
|------|---------|------|
| **BUSINESS** | `business_commentary.py` | 公司描述 + 品类/模式 + 财务快照（全权控制） |
| **Revenue Structure** | `insert_revenue.py` | IP/渠道/地域/产品占比（独立展示，不重复） |

模板 `generate_report.py` 仅附加折旧率、员工数、CEO/注册地/网站等通用信息。

## 涉及模块

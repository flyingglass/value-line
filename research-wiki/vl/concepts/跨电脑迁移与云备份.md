# 跨电脑迁移与云备份

## 定义

项目依赖 2 个外部服务认证（TDX / IMA），所有 token 统一存储在 `.env` 中（gitignore）。新电脑需手动配置 token 和 Skill。

> 微云已于 2026-06-13 移除 — API 配额不足，用户改为手动同步。

## 关键要点

- **`.env` 是唯一真相源**：包含 TDX / IMA 全部 token，通常 6 行
- **新电脑需手动配置**：复制 `.env` 到项目根目录，安装 Skill zip 包
- **不依赖 CodeBuddy 云同步**：mcp.json 和 skills 通过手动迁移

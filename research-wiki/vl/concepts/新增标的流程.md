# 新增标的流程

## 标准步骤（2026-06-23 简化版）

1. `config.py` 添加 STOCKS 配置（name / name_en / market / exchange / currency / shares / industry 等）
   - 🔴 **industry 必须用中文**（如 `"光伏"`、`"消费"`、`"半导体"`，不用 `"Photovoltaic"` 等英文）。
2. `build.py <code> --cf 15.0 --fetch` 首次拉取 + 生成
   - 🔴 **必须前台交互运行**（不可 `start /b` 后台），因为 build.py 会弹出 `input()` 提示输入 CF/PB 倍数。
   - 首次 DB 无缓存时，优先级：CLI `--cf`/`--pb` 参数 > DB 已确认值 > **用户交互输入**。
3. 若 Step 2 PDF 下载失败 → 检查 org_id
4. 若 Step 4 营收结构为空 → 创建 `scripts/<code>/insert_revenue.py`
5. **🆕 Step 4.5 自动生成 `business_commentary.py`** — 无需手动创建！
   - 基于 config + DB 数据自动生成 5 段 Commentary
   - 14 行业专属壁垒模板 + 9 行业催化剂模板
   - 后续可选精调 P3/P5 段落
6. 阅读报告：`generate_reading.py <code>`
7. 索引页：`generate_index.py` 重建 `report/index.html`

## org_id 获取（A 股）

**不可盲写 `gssz` 前缀**。部分 SZSE 股票使用纯数字 org_id（如美的集团 `9900005965`）。

```python
import requests, json
r = requests.get("http://www.cninfo.com.cn/new/data/szse_stock.json", timeout=15)
data = json.loads(r.text.lstrip("\ufeff"))
cache = {s["code"]: s["orgId"] for s in data.get("stockList", data)}
print(cache.get("000333"))
```

## 常见故障

| 症状 | 根因 | 修复 |
|------|------|------|
| "REFUSED: 未提供有效CF倍数" | build.py 后台运行无 stdin，`input()` 收到 EOFError | **必须前台运行**，不可 `start /b` 或管道重定向 |
| Step 1: "数据拉取失败" | 子进程编码乱码 | `fetcher.py` 已加 `FETCH_OK` ASCII 标记 |
| Step 2: 下载 0 份 PDF | org_id 错误 | cninfo API 查询正确 org_id |
| Step 4: revenue_structure 为空 | 无 insert_revenue.py | 创建对应脚本 |
| Step 4.5: 生成失败 | 生成器异常 | 不阻断，回退 engine 通用模板 |
| index.html 无新标的 | 未重新生成 index | `generate_index.py` 重建 |
| AI 评论质量差 | 行业模板不匹配 | 手动精调 `business_commentary.py` P3/P5 |

## business_commentary.py 自动生成

`generate_business_commentary.py <code>` 或 build.py Step 4.5 自动调用。
生成的脚本 `build()` 返回：
```python
{
    "business": "业务概述...（来自 config.business_desc + 营收结构）",
    "commentary": [
        p1,  # 业绩概览（营收/利润增速 + 地区拆分）
        p2,  # 每股现金流四大去向（资本支出/营运资金/分红/净留存）
        p3,  # 盈利质量 + 行业专属壁垒 + 风险
        p4,  # 估值分析（PE/PB/CF 估值区间）
        p5,  # 行业专属催化剂/展望
    ]
}
```
已存在不覆盖，可后续手动精调任意段落。

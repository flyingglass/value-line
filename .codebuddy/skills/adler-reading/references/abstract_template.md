# 头部速读摘要模板（先写摘要，再写四级结构）

## 一、为什么必须先写摘要

1. `scripts/generate_wiki_index.py` 的 `extract_summary()` 取**第一个非空、非标题、非 `---`、非 `|`、非列表**的段落，作为 Wiki 浏览器列表页的摘要
2. 🔴 **该函数会跳过 `>` 开头的行** —— 若把核心结论写成 `> 一句话结论：…` 引用块，列表页抓不到，只能抓到后面的次要内容（如"证据等级说明"）
3. 摘要放在 frontmatter 之后、四级结构之前，列表页可扫性最好

> 2026-08-30 教训：茅台《非标价格体系与吨价分解》原先把结论写成 `> 一句话结论：` blockquote，Wiki 列表页抓到的是"证据等级（全文适用）：🟢 观测…"，核心数字完全不可见。

## 二、模板（7 字段）

````markdown
## 摘要

> 核心话题：A · B · C · D

**一句话核心**：<最关键信息，核心结论加粗>

**关键数据（<期间>）**：

- <指标> **<数值>**（<同比>）
- <指标> **<数值>**（<同比>）

**核心矛盾**：

1. <矛盾1>
2. <矛盾2>

**<适配字段一>**：<一段话>

**跟踪要点**：

1. <要点1>
2. <要点2>

**<适配字段二>**：<引语>
````

## 三、字段规范

| 字段 | 要求 |
|---|---|
| **核心话题** | 4–6 个关键词，`·` 分隔 |
| **一句话核心** | 🔴 **必须写成普通段落，不能用 `>` 引用块**，否则列表页抓不到。核心结论加粗；一句话说完，须同时包含**最重要的数字**与**最重要的边界** |
| **关键数据** | 3–6 条，每条带同比或对照；关键数字加粗；期间标注在标题括号里 |
| **核心矛盾** | 3–4 条，每条是「X 与 Y 的张力」，不是流水账 |
| **跟踪要点** | 4–5 条，与正文「待验证清单」一一对应 |
| **适配字段一 / 二** | 见下表 |

## 四、字段适配（按读物类型）

| 读物类型 | 字段一（原「管理层应对」） | 字段二（原「XX原话」） |
|---|---|---|
| 业绩会逐字稿 | **管理层应对** | **XX原话**（发言人真实姓名） |
| 券商研报 | **分析师逻辑** | **研报原文** |
| 调研纪要 | **调研结论** | **受访者原话** |
| **自有分析 / 推导笔记** | **推导方法与证据强度** | **原文与官方口径** |

**自有分析的两处适配（照搬逐字稿字段会失真）**：

- `管理层应对` → **`推导方法与证据强度`**：没有管理层，对应的是"结论怎么来的 + 证据落在哪一级"。必须写明哪些是披露值（🟢）、哪些是推算（🟡）、哪些不可识别（🔴）
- `XX原话` → **`原文与官方口径`**：引年报/公告原文 + 管理层原话，**标注出处**（如"2025 年报 P9"、"业绩说明会 Q5"）

## 五、与四级结构的位置关系

```
frontmatter（topic / category / structure / created / sources）
    ↓
## 摘要                    ← 3 分钟速读，独立成块
    ↓
## 第一级 · 检视阅读
## 第二级 · 通读
## 第三级 · 分析阅读
## 第四级 · 比较阅读
## 四个基本问题的回答
```

- 摘要答「**得出什么**」，第一级表格里的「一句话定位」答「**本文在做什么**」——层次不同，不重复，两者都保留
- 摘要的「一句话核心」须覆盖正文最关键的数字与最重要的边界（含 🔴 不可识别项），不能只报好消息

## 六、生成后必须校验

复现 `generate_wiki_index.py` 的抓取逻辑，确认列表页抓到的是「一句话核心」：

```python
import re
def extract_summary(body):
    summary = ''
    for line in body.strip().split('\n'):
        s = line.strip()
        if not s or s == '---' or s.startswith('#') or s.startswith('>') \
           or s.startswith('|') or s.startswith('- ') or s.startswith('* '):
            if summary: break
            continue
        s = re.sub(r'\[([^\]]+)\]\([^)]+\)', r'\1', s)
        s = re.sub(r'\[\[([^\]]+)\]\]', r'\1', s)
        s = re.sub(r'\*\*([^*]+)\*\*', r'\1', s)
        summary += s + ' '
    return summary.strip()
```

同时校验正文与源文件字节级一致（body 在 HTML 中 base64 存储，需解码后比对）。

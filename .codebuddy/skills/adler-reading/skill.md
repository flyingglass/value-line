# 艾德勒四级阅读法

## 方法论来源

莫提默·J. 艾德勒 & 查尔斯·范多伦《如何阅读一本书》（1940 / 1972 修订版）。

项目内完整方法论页：`research-wiki/research/articles/concepts/艾德勒-四级阅读法.md`

## 流程

1. 通读原文全文
2. **先写头部速读摘要**（见 `references/abstract_template.md`）
   - 放在 frontmatter 之后、四级结构**之前**，7 字段，3 分钟读完核心
   - 🔴 「一句话核心」必须写成**普通段落**，不能用 `>` 引用块——`generate_wiki_index.py` 的 `extract_summary()` 会跳过 `>` 开头的行，列表页将抓不到核心结论
   - 字段按读物类型适配：逐字稿用「管理层应对 / XX原话」，自有分析改用「推导方法与证据强度 / 原文与官方口径」
3. 按四级阅读层次生成正文（见 `references/reading_levels.md`）
4. 回答四个基本问题
5. 保存到 wiki 对应位置（注意：摘要属于 research/，不进 raw/）：

   - **业绩会逐字稿** → `research-wiki/research/<code>/业绩/<时间>-<业绩会名称>-艾德勒阅读摘要.md`
     - 参照标杆：`research/拼多多/业绩/2026-Q2业绩电话会-艾德勒阅读摘要.md`、`research/泡泡玛特/业绩/2026-中报业绩发布会-艾德勒阅读摘要.md`
   - 其他资料（研报/文章/书籍）→ `research-wiki/research/<code>/` 或 `research/articles/` 对应子目录
   - 头部加 frontmatter：`topic`（标题）/ `category`（如"投研-资料摘要"）/ `structure`（如"艾德勒四级阅读法（检视 → 通读 → 分析 → 比较）"）/ `created`（日期）/ `source`（指向 raw 原文相对路径，如 `raw/research/拼多多/2026-08-24-xxx.md`）
   - 自有分析笔记用 `sources` 复数（可列 PDF 页码、调研链接等多源）
6. **校验**：复现 `extract_summary()` 确认列表页抓到「一句话核心」；解码 index.html 的 base64 body，确认与源文件字节级一致

## 核心原则

- 尊重原文，不编造不推理，不确定的标注"原文未明确说明"
- 区分事实与观点，作者的立场评价标注"XX 认为/评价"
- 证伪式检验：主动寻找论证的薄弱点、反向信号、被遗漏的风险
- 不简化论证力量：保留原文关键转折、反证、限定条件
- **摘要先于正文**：结论前置，不淹没在长文中；边界与不可识别项必须在摘要里就点明

## 适用对象

说明性读物（业绩会逐字稿、券商研报、书籍、文章）。想象类读物不适用。

亦适用于**自有分析/推导笔记**的结构化重组——此时四级结构的分工是：

| 层级 | 自有分析中的对应内容 |
|---|---|
| 第一级 · 检视阅读 | 文件性质、要回答的问题、证据等级约定、**是否值得精读 / 怎么用** |
| 第二级 · 通读 | 观测事实清单（全部可引用，集中一处，不散落） |
| 第三级 · 分析阅读 | 论证链 + 逐条检验 + 证伪存档 + 识别性边界 |
| 第四级 · 比较阅读 | 与他页 / 管理层叙述 / 外部调研三向对照 + 张力与反向信号 |

# 深度阅读摘要 — 补充质量标准

本文件是 `summary_structure.md` 的补充，当用户未提供参考文档时，AI 在生成摘要后应自查以下质量标准。

## 自查清单

### 结构完整性
- [ ] 元信息块包含：原文全长、入库日期、作者、译者、出版社、结构
- [ ] 有"全书核心命题"（根本问题 / 作者答案 / 核心洞见）
- [ ] 导读/序/导言（如有）分层展开，保留原文叙事节奏
- [ ] 逐章摘要每章以"核心主题"开头，按原文论证结构分层
- [ ] 有"全书关键概念表"（章节 / 概念 / 意义 三列）
- [ ] 有"笔记"（元洞见 + 实践概念 + 交叉点 + 论证策略 + 不完整性）

### 内容准确性
- [ ] 所有引述可回溯到原文
- [ ] 不添加原文没有的数据/数字
- [ ] 不将推测当作事实，不编造引语
- [ ] 作者的立场评价明确标注为"XX 认为/评价"

### 论证完整性
- [ ] 每章核心论证链完整
- [ ] 保留原文的关键转折、反证和限定条件
- [ ] 段落之间保持因果/递进关系

### 适度性
- [ ] 不逐句翻译，也不过度压缩
- [ ] 全文字数通常为原文的 5%-15%
- [ ] 关键概念的定义完整保留

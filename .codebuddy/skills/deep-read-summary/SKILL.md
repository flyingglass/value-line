# 深度阅读摘要生成

## 概述

读取 epub 电子书全文 → 保存原始资料到 raw/ 目录 → 深度阅读全书 → 按参考文档的结构生成结构化摘要。
所有参数均可替换：书名、epub 路径、参考文档路径、输出路径。

## 工作流

### 第 1 步：提取 epub 全文

使用 `scripts/extract_epub.py` 将 epub 提取为纯文本：

```bash
python scripts/extract_epub.py "<epub_path>" --output "<output_txt_path>"
```

- `<epub_path>`：用户提供的 epub 文件绝对路径
- `<output_txt_path>`：临时 txt 输出路径（建议放在项目临时目录）

脚本输出：提取的字符数、行数。

### 第 2 步：保存原文到 raw/

将提取的全文保存到 `research-wiki/raw/research/articles/` 目录。

文件命名规则：`作者_年份_书名.md`

**关键原则：raw/ 目录只进不改。** 必须保存完整的原文全文，不做任何删减。不可用 AI 总结替代原文。

### 第 3 步：深度阅读原文

从头到尾通读提取的全文。

在阅读过程中注意：
- 全书试图回答的核心问题是什么？
- 作者的答案和论证路径是什么？
- 每章的核心主题和分层论点是什么？
- 关键概念的定义是什么？
- 作者与其他学派的论争点在哪里？

### 第 4 步：读取参考文档

参考文档决定摘要的输出格式。AI 必须**模仿参考文档的结构、层级、段落组织方式**来生成摘要。

**优先级：**
1. 用户指定的参考文档路径（最高优先级）
2. 项目中的 `research-wiki/raw/research/articles/哈格斯特朗_2023_查理芒格的智慧-投资的格栅理论.md`（默认参考文档，是一份已完成的摘要实例）

读取参考文档后，提取以下信息：
- 元信息块的字段列表和格式
- 导读/序/导言的分层方式和子标题风格
- 逐章摘要的层级深度（几级标题）和段落密度
- 总结层的具体模块（概念表、公式、思维导图等）
- 笔记的条目数量和内容风格

**补充质量参考**：生成摘要后，可用 `references/quality_checklist.md` 自查完整性、准确性、论证完整性和适度性。

### 第 5 步：生成摘要

按照参考文档的结构模板，生成完整的结构化摘要。严格遵循：

**核心原则：**

1. **尊重原文**：所有关键概念、论证链条、核心引语均直接来自原文。不使用过度推理、自我发挥或"笔者认为"。不确定的标注"原文未明确说明"。

2. **区分事实与评价**：原文的论证用陈述句呈现。作者的立场评价明确标注为"XX 认为/评价"。不混淆作者的论证和作者的立场。

3. **不简化论证力量**：不为简洁而牺牲论证的递进逻辑。保留原文的关键转折、反证和限定条件。段落之间保持因果/递进关系。

**输出格式**：严格模仿参考文档的实例格式。不要套用固定模板——每本书的结构不同，参考文档只是示范了"一个摘要应该有的样子"。

### 第 6 步：保存摘要

将生成的摘要保存到 `research-wiki/raw/research/articles/` 目录（与原文同目录）。

文件命名规则：`作者_年份_书名.md`（与原文同名，因为原文保存的也是完整全文，摘要覆盖写入）。

## 可替换参数

用户可以在请求中替换以下参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| epub 路径 | 要阅读的电子书文件 | `C:\Users\xxx\Downloads\盲眼钟表匠.epub` |
| 参考文档 | 摘要结构对齐的模板文档 | `哈格斯特朗_2023_查理芒格的智慧-投资的格栅理论.md` |
| 输出目录 | raw/ 下的子目录 | `research-wiki/raw/research/articles/` |
| 文件命名 | 摘要文件的命名规则 | `作者_年份_书名.md` |

**默认行为**：如果用户只提供 epub 路径，使用项目中的 `哈格斯特朗_2023_查理芒格的智慧-投资的格栅理论.md` 作为默认参考文档，输出到 `research-wiki/raw/research/articles/`。

## 资源

### scripts/extract_epub.py
从 epub 文件中提取全部文本内容。epub 本质是 ZIP 压缩包，脚本解析其中的 XHTML 文件，剥离标签，输出纯文本。

用法：
```bash
python scripts/extract_epub.py <epub_path> [--output <output_path>]
```

### references/summary_structure.md
摘要结构的方法论指南。说明摘要应有的层次、分层逻辑和质量标准。**不作为格式模板**——实际格式由参考文档（用户指定或默认的哈格斯特朗实例）决定。

### references/quality_checklist.md
生成摘要后的自查清单。用于验证摘要的完整性、准确性、论证完整性和适度性。

# raw 入库结构模板

来源：`research-wiki/raw/research/泡泡玛特/2026-08-20-中期业绩发布会完整逐字稿.md`（2026-08-22 确立，作为格式标杆）。

## 模板

```markdown
# <标题>（<资料类型，如：完整逐字稿 / 调研纪要 / 文章>）

> 来源：<平台>「<公众号/账号名>」\
> 原文链接：<url>\
> 作者：<作者/整理者>\
> 发布时间：YYYY-MM-DD HH:MM（修改于YYYY-MM-DD）\
> 会议信息：<公司名称> <业绩类型>，YYYY-MM-DD，约N分钟\
> 参会管理层：<姓名（职务）>、<姓名（职务）>\
> 原始来源：<材料来源，如：投资者关系材料、长桥证券公开回放>

---

## 摘要

> 核心话题：<话题A> · <话题B> · <话题C>

**一句话核心**：<这场资料最关键的信息，核心结论加粗>

**关键数据**：

- <指标> **<数值>**（<同比>）
- <指标> **<数值>**（<同比>）

**核心矛盾**：

1. <矛盾1>
2. <矛盾2>

**跟踪要点**：

1. <要点1>
2. <要点2>

## 正文

一、管理层陈述

**发言人**：<原话>

二、问答环节

**Q1 <主题>（<机构>）**

**提问人（机构）**：<问题原话>

**发言人**：<回答原话>
```

## 格式规范（突出重点）

1. **摘要禁用大段平铺**：一律分点列表。一句话核心 / 关键数据 / 核心矛盾 / 跟踪要点四项为固定骨架，核心结论加粗。
2. **发言人一律加粗**：`**王宁**：`。长段落中靠加粗名字快速定位谁在说话。
3. **问答加导航小标题**：每个问题前加 `**Q1 主题（机构）**`。主题从原文提炼（如"全年指引与拉布布运营"），不加编造内容。
4. **关键数字加粗**：收入、利润、毛利率、增速等重点数字用 `**数值**` 突出。
5. **演示页/页码提示弱化**：逐字稿中的 PPT 页码（如"官方演示第X/26页"）保留但独立成行，不干扰正文阅读。
6. **元数据行尾加 `\`（硬换行，强制）**：头部元数据除最后一行外，每行末尾加反斜杠。原因：同一 blockquote 内连续行属 Markdown 软换行，渲染时会被合并成一段（"来源：… 原文链接：… 作者：…"挤成一行）；行尾双空格是标准写法但会被编辑器"删除行尾空白"设置 trim 掉，故统一用 `\`（Obsidian / Typora / GitHub 均支持）。摘要区的 `> 核心话题：` 为单行，无需加。
7. **图表数值一律表格化（强制，研报类尤其）**：不得写成行内散文（如「（图表数值：a% / b%…对应 X / Y / Z）」）。
   - 横纵按可读性择一：选项为行/分组为列（调研交叉表默认）、单行横表（档位 ≤6 且标签短）、左右分栏横表（档位 ≥7 且标签长）、纵表（标签为完整句子 / 需带定义列 / 档位 ≥9）
   - **每张表下用 `> ` 引用块写「校验」或「存疑」注**，表体只留「选项 | 数值」；能加「合计」的都加
   - 提取方法与七个坑见 `pdf-chart-extraction.md`；无法提取的图**逐图标注原因**，不硬凑
   - **文章配图默认不落盘**：转写为表格即达标，只在 raw 里记「原文链接 + 原图 CDN 链接」；仅"无法转写且内容关键"的图才存 `research/<专题>/assets/`（见 `pdf-chart-extraction.md` 第五节）
   - 摘要需与表格同步重生成，关键数据每条标注来源图号/页号

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 来源 | 是 | 平台 + 公众号/账号名 |
| 原文链接 | 是 | 宪法强制，禁止只记名称不记链接 |
| 作者 | 是 | 作者或整理者 |
| 发布时间 | 是 | 含修改时间（如有） |
| 会议信息 | 条件 | 业绩会/纪要类必填（公司、类型、日期、时长） |
| 参会管理层 | 条件 | 业绩会类必填，姓名（职务） |
| 原始来源 | 条件 | 内容转载自其他材料时必填 |
| 摘要 | 是 | 一句话核心 + 关键数据 + 核心矛盾 + 跟踪要点，分点 + 加粗；含图表的资料需加「图表数据状态」条 |
| 正文 | 是 | 完整原文，不删减，发言人加粗，问答带 Q 标题；**图表数值一律表格化 + 表下校验注** |

## 与宪法关系

- 链接强制保留：`CODEBUDDY.md` → `## 🔴 入库规范`
- 三段式结构 + 突出重点格式强制：`CODEBUDDY.md` → `### 🔴 raw 入库结构模板`

# 里海2444体系 × 标的两期变化对照分析

## 目的

把一次「里海2444视角的标的两期对照分析」标准化：数据可回溯、引语有出处、判定可复现、产出结论先行。

## 数据来源（硬约束：只准用以下三类，逐处标注出处）

1. **体系与案例层**（`research-wiki/research/疯狂的里海/`）：
   - 体系页：`里海-2444投资体系.md`（总纲+三模型+弱者视角）、`方法论/里海-变化论.md`（六类变化+兑现端风险+双左侧）、`方法论/里海-双左侧.md`（**下跌/横盘/高位标的必读**：双左侧定义、老登股/杀估值/高位情绪三档、买入端「最好股价先到右侧」）、`里海体系-总览.md`
   - 案例页：`案例/里海案例-涪陵榨菜.md`（杀业绩+预期定价+老登股完整生命周期样本）、`案例/里海案例-再升科技.md`（双左侧铁案）、`案例/里海案例-太极集团.md`（回撤不砍对照组）等
   - **引语必须逐字来自这些页并标注日期出处；wiki 未收录的里海观点一律不引用、不凭印象补**
2. **标的基本面层**（`research-wiki/research/<标的>/`）：
   - `业绩/经营时间序列（YYYY-YYYY）.md`（收入/毛利/净利/存货/渠道/IP/复购半年度序列）
   - `业绩/YYYY-年度(中期)业绩发布会-艾德勒阅读摘要.md`（两期各自的业绩会口径）
   - `跟踪/`、`投资论点.md` 等按需
3. **股价层**（`data/<code>.db` 的 `kline` 表，前复权）：
   - 用 `.venv/Scripts/python.exe` 查：年度 high/low/年末收盘、极值日期、月度收盘序列（画图用）
   - 注意检查 `MIN(date)`/`MAX(date)` 覆盖范围，有数据缺口时如实标注（002507 曾有三段缺口）
   - 现价结论必须注明「数据截至 YYYY-MM-DD」

**禁止**：引用 wiki 与 DB 之外的实时行情/新闻数字；对 wiki 未覆盖的指标标「待查」而非估算；先画靶再找证据（AI行为准则优先）。

## 分析流程

1. **读体系页 + 变化论 + 对标案例页**（如涪陵榨菜），把 2444 判定框架装进上下文。
2. **读标的 wiki 时间序列 + 两期业绩会摘要**，抽取两期的关键数据（收入/净利/毛利率/存货/复购/渠道结构/管理层定性）。
3. **查 kline**：两期各自的顶/底/现价、涨跌幅、月度收盘序列。
4. **2444 逐项打分**（每项给 ✓/✗/⚠️ + 证据）：
   - 术四字：简单（业务+财务一句话能否说完）/ 底部（是否「走出来的」长期横盘，高位回撤≠底部）/ 变化（六类变化归类、方向混合则拆正负两面、「大·近·未被看清」三性检验）/ 分仓+赔率（当前市值 vs 盈利体量的粗略 PE，判断是否钟摆极限区域）
   - 归类三个选股模型（白马杀业绩 / 隐形冠军长期不涨 / 困境反转），明确判定：构成买点 / 不构成 / 观察区
5. **案例镜像对照**：同构处逐条列，差异处**必须**单列（禁止机械套用对标案例的结局）；对照「你认市场不认 / 双左侧 / 预期清算」等兑现端风险模式。
6. **产出**（结构固定，**顺序不可颠倒：先逻辑后图形**）：
   - ① 结论先行一句话（两期各是什么、当前是否买点）
   - ② 两期对照：各期基本面变化数据表 + 2444 逐项判定表（逻辑与证据全部在这两段）
   - ③ 案例镜像段（同构 + 差异）
   - ④ 操作含义 + 风险分级（如「中风险观察区」）+ 跟踪清单（按变化论捕获动作具体化：横盘形态/存货去化/复购率/IP生命周期验证等）
   - ⑤ **最后**才给 SVG 对照图（月收盘折线 + 区间底色标注：杀业绩段/底部横盘段/调整段 + 顶底与关键事件点），仅作「一眼看位置」的辅助，不承担新信息
   - 坐标用脚本算，X 从左到右为时间升序，明暗主题用浅色底+深色字
7. **落库**：默认只对话产出；用户确认后才写 wiki 页（放 `research/<标的>/跟踪/` 或 `research/疯狂的里海/案例/`），并按落库四件套执行（新页+index条目+log条目+重建index.html）。

## 已验证样例

- 泡泡玛特 09992「2022 vs 2026」（2026-09-13）：2022=模型1完整演绎（-91%→横盘18个月→2023指引全兑现=变化确认）；2026=榨菜2021-22「预期清算段」镜像但不构成双左侧（星星人接棒/回购/管理层信用记录三处差异），判定非买点、中风险观察区。
- **变体：多标的横向对照（腾讯 00700 vs 茅台 600519，2026-09-13）**。同框架跑两个标的时：
  - 逐项判定表拆两个小表（每标的一行一要件），末尾加「档位」行（老登股 / 临界偏左 / 双左侧 / 高位情绪），档位词直接取自 `里海-双左侧.md` §四；
  - **必须回查体系页对这两个标的的原话时点，并检查它是否已被后续价格推翻**——实测：里海 2026.5.1 判"茅台走平不再新低=右侧萌芽"，而 2026.6.29 茅台盘中 1151.01 破 2024 低点 1155.58（名义新低 -0.4%），需据此把档位从"临界"下调为"临界偏左"；
  - 赔率用 `meta.total_shares` × 收盘价算市值，港股按 `data/fx_rates.db` 的 `hkd_cny`（单位：100 港元兑人民币）折 CNY，勿硬编码汇率；
  - 股息率必须注明口径：`dividend` 表只有年度分红，含中期的真实全年需手工相加（600519 2025 年度口径 28.02 元→2.16%，含中期约 52 元→约 4.0%）。

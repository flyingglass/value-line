## 一、报告概览

### 1.1 Value Line Investment Survey 三部分架构

Value Line 每周发布三个部分，覆盖约 **1700 只股票** + 约 **100 个行业**（约占美国市场总市值的 90%）：

## 二、三大评级与独特评分体系

### 2.1 Timeliness Rank (时效性排名)

**定义:** 预期未来 **6-12 个月**相对约 1700 只股票的价格表现排名。

| 排名 | 数量 | 含义 |
|------|------|------|
| **1 (Highest)** | 100 只 | 预期表现最佳 |
| **2 (Above Average)** | 300 只 | 预期表现优于平均 |
| **3 (Average)** | ~900 只 | 预期表现平均 |
| **4 (Below Average)** | 300 只 | 预期表现低于平均 |
| **5 (Lowest)** | 100 只 | 预期表现最差 |

**决定因素（按重要性排列）:**

1. **盈利增长** — 过去 10 年盈利增长 > 股价涨幅的股票，排名倾向有利。这是最重要的因子。
2. **相对价格表现** — 近期股价相对所有约 1700 只股票的表现
3. **季度盈利表现** — 近期季度盈利的绝对水平和变化趋势
4. **盈利惊喜** — 报告结果显著好于或差于预期时的影响

> ⚠️ Rank 1 股票通常波动性更高、市值偏小。保守投资者应同时关注 Safety 排名。

### 2.2 Safety Rank (安全性排名)

**定义:** 衡量个股相对约 1700 只股票的**总风险**水平。由两个等权重因子组成（位于报告右下角 ⑲ 区域）：

| 因子 | 刻度 | 含义 |
|------|------|------|
| **Financial Strength** | A++ (最高) → C (最低) | 公司财务状况。大公司 + 强资产负债表得分最高 |
| **Price Stability** | 100 (最高) → 5 (最低)，步长 5 | 过去 5 年每周价格变化百分比的标准差排名 |

**附加参考**（不直接参与 Safety 计算，但同样展示在 ⑲ 区）：

| 指标 | 刻度 | 含义 |
|------|------|------|
| **Price Growth Persistence** | 100 → 5 | 过去 10 年相对价格增长的**一致性** |
| **Earnings Predictability** | 100 → 5 | 盈利预测的**可靠性**，衡量历史盈利的可预测程度 |

> 保守投资者应选择 Safety Rank **1 或 2** 的股票。Financial Strength 建议至少 **B+** 以上才适合保守策略。

### 2.3 Technical Rank (技术排名)

**定义:** 预测未来 **3-6 个月**的短期相对价格变化。

**基于：** 专有模型，考察过去一年不同时间段的 **10 种相对价格趋势**，以及每只股票的价格波动率。

分布与 Timeliness 相同：100 / 300 / 900 / 300 / 100。

### 2.4 Beta 系数

**定义:** 衡量个股相对整体市场（NYSE Index）的波动性，由 VL 计算。

| Beta 值 | 含义 |
|---------|------|
| **1.0** | 与市场同步：市场涨/跌 10%，个股约涨/跌 10% |
| **> 1.0** | 比市场更波动：Beta 1.5 → 市场涨 10%，个股涨 15% |
| **< 1.0** | 比市场更稳定：Beta 0.65 → 市场涨 10%，个股涨 6.5% |

### 2.5 Industry Timeliness (行业时效性)

VL 同时发布约 **90+ 个行业**的时效性排名。行业排名 = 该行业内所有有时效性评级的股票的 Timeliness 平均值。

- 每周更新，发布在 Summary & Index 封面和第 24 页
- 也出现在 Ratings & Reports 中每个行业报告的顶部

## 三、市盈率的五种口径

VL 在同一页面展示 5 种不同计算方式的 P/E，是最丰富的估值参考：

### 3.1 VL P/E（报告顶部，item ⑥）

```
公式: 最近股价 ÷ (过去6个月EPS + 未来6个月预估EPS)
```

**特点:** VL 独有，兼顾历史和未来，最具前瞻性。VL 认为同时使用过去和未来盈利能提供最现实的图景。

### 3.2 Trailing P/E（item ⑦）

```
公式: 最近股价 ÷ 过去12个月实际报告EPS
```

**特点:** 报纸和财经网站最常用的口径，仅用已报告数据。报纸只用这个数因为他们不做预测。

### 3.3 Median P/E（item ⑦）

**定义:** 过去 10 年 P/E 的**中位数**（经特定统计调整，剔除异常值）。

**特点:** 显示该股票的历史估值中枢，是重要的估值锚点。投资者无法自行精确计算（因为 VL 使用专有统计调整）。

### 3.4 Average Annual P/E（Statistical Array 第8行，items ⑮ & ㉖）

```
公式: 每年均价 ÷ 当年实际报告EPS（逐年计算）
```

**特点:** 逐年展示，直观看到估值倍数在 10-17 年间的变化趋势，判断当前处于历史估值区间的什么位置。

### 3.5 Relative P/E（item ⑧ + Statistical Array 第9行）

```
公式: 个股 VL P/E (item ⑥) ÷ VL 全样本(~1700只) P/E 中位数
```

**解读:**
| 相对 P/E | 含义 |
|----------|------|
| **> 1.0** | 比市场整体贵 |
| **= 1.0** | 与市场持平 |
| **< 1.0** | 比市场整体便宜 |

> VL 全样本 P/E 中位数每周更新在 Summary & Index 封面框 A。

## 四、价格图与估值工具

### 4.1 月线价格区间（竖线，③）

每月最高价和最低价（已针对后续分拆和股息调整）。直观展现长期走势和波动范围。

### 4.2 现金流基准线（实线，④）— VL 独门发明

这是 VL 最具特色的工具，有时直接被称为 "Value Line"。

**核心理论:** 股价倾向于围绕现金流线波动——高于则倾向回落，低于则倾向回升。但部分股票可能长期偏离。

**绘制方法:**
```
每股"现金流" = (净利润 + 折旧摊销 - 优先股股息) ÷ 期末流通股数
现金流线位置 = 每股"现金流" × 分析师确定的乘数
```

**乘数确定方法:** 分析师通过历史拟合确定——使现金流线与历史股价最接近，同时与 3-5 年目标价格区间相呼应的一组数值。乘数可以且经常随时间变化。

**与 P/E 乘数的区别:**
```
P/E 乘数 = 股价 ÷ 盈利
现金流乘数 = 股价 ÷ (盈利 + 折旧)
```
因此现金流乘数始终**小于** P/E 乘数。JNJ 的现金流乘数为 12.0。

**虚线延伸段:** 现金流线的虚线部分是 VL 对未来年份的预测延伸。

### 4.3 相对价格强度线（虚线，⑫）

与 VL Arithmetic Index（基于约 1700 只股票的综合指数）比较：
- **上升** = 跑赢大盘（动量强）
- **下降** = 跑输大盘（动量弱）

### 4.4 % Total Return（⑬）

展示过去 1 年、3 年、5 年个股和 VL Arithmetic Index 的总回报（价格升值 + 股息），不取平均值或复合值。

### 4.5 目标价格区间（Target Price Range，⑪）

图表右上角的虚线区间，表示 VL 分析师认为 **3-5 年后股价最可能落入的价格区间**。

```
计算方法:
预测的 3-5 年后 EPS × 统计数组中对应时期的预估 P/E = 目标价格区间

区间宽度取决于 Safety Rank:
- Safety 高 → 区间窄（确定性高）
- Safety 低 → 区间宽（不确定性大）
```

### 4.6 3-5 年预测框（Projections，㉙）

位于 Beta 下方的框，与 Target Price Range 数值对应，额外提供：

| 内容 | 说明 |
|------|------|
| High / Low Price | 对应 Target Price Range |
| % Gain (High) / (Low) | 高位和低位的升值百分比 |
| Ann'l Total Return | 年化总回报（升值 + 股息） |

**参照基准:** Summary & Index 封面框 C 每周公布全市场约 1700 只股票的预估中位数升值潜力。

### 4.7 图例框（Legends，②）

包含：
- 现金流乘数值
- 股票分拆记录
- 是否有期权交易
- 阴影区域 = 经济衰退期

## 五、统计数组 (Statistical Array) — 24 行核心指标

统计数组是 VL 报告的**核心区域**。左侧常规字体 = 历史实际数据（最多 17 年），右侧粗斜体 = 预测数据（今年、明年、3-5 年后）。

### 5.1 每股指标区 (#1-#6)

---

#### #1 每股营收 (Revenues per sh)

**VL 定义:** 公司通过主营业务产生的收入，除以发行在外的普通股股数。

**解读:** 当 EPS 因利润率低而受压时，高水平的每股营收暗示盈利恢复潜力。但若每股营收与 EPS 同时下降则是危险信号。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `营业总收入 ÷ 期末总股本` | 利润表 + 资产负债表 |
| H 股 | `营业额 ÷ 期末总股本` | 利润表 + 资产负债表 |

---

#### #2 每股现金流 ("Cash Flow" per sh)

**VL 定义:** "分析师通常使用的现金流，等于报告净利润加上折旧，减去优先股股息，以每股为基础计算。它是衡量公司内部现金生成能力的指标——公司可用于扩建或更换厂房设备、提供营运资金、支付股利或回购股票的现金量。"

> ⚠️ **关键区分:** VL 的 "Cash Flow" **不是**财务报表中的"经营活动现金流 (CFO)"。它是 VL 独创口径，强调账面内生现金留存能力。2020 版注明该指标现已包含股票期权费用。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `(扣非归母净利润 + 折旧及摊销总额) ÷ 期末总股本` | 利润表 + 现金流量表(补充资料) |
| H 股 | `(Non-IFRS 经调整净利润 + 折旧及摊销总额) ÷ 期末总股本` | 利润表 + 财报附注 |

**解读:** 每股现金流应该大于每股收益（因为加了折旧）。两者差距越大 → 资产折旧负担越重 / 资本密集度越高。每股现金流是价格图中现金流基准线的数据来源。

---

#### #3 每股收益 (Earnings per sh)

**VL 定义:** "向股东报告的每股收益，剔除非经常性项目，并已针对后续的股票分拆或股票股利进行调整。Value Line 通常使用稀释每股收益，包含期权或权证等摊薄因素。脚注 (B) 明确标注使用的是基本还是稀释 EPS（几乎总是稀释）。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `扣除非经常性损益后的归母净利润 ÷ 稀释后总股本` | 利润表附注 / AKShare 分析指标 |
| H 股 | `Non-IFRS 经调整稀释每股收益` | 业绩公告 / 年报附注 |

**解读:** 非经常性损益（如一次性资产出售收益）会扭曲真实盈利能力。扣非 EPS 更能反映主营业务持续经营状况。H 股科技公司需关注 Non-IFRS vs IFRS 的差异——股份酬金和投资公允价值变动常导致两者相差巨大。

---

#### #4 每股股息 (Div'ds Decl'd per sh)

**VL 定义:** 董事会在该年度宣告的每股现金股利总和。增长型公司通常支付较少或"象征性"股利，将利润再投资于业务。脚注 (C) 列出历史支付月份。

**VL 基准:** 大型成熟公司的典型支付率为 **25%-30%** 的利润。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `当年宣告分红总额(含税) ÷ 期末总股本` | 分红公告 + AKShare 股息数据 |
| H 股 | `当年宣告派息总额 ÷ 期末总股本` | 业绩公告 + AKShare 股息数据 |

**解读:** 股息持续增长是积极信号。需警惕脱离自由现金流的过度派息。保守投资者应确保公司 Financial Strength 至少 B+。

---

#### #5 每股资本支出 (Cap'l Spending per sh)

**VL 定义:** "公司在新建厂房和设备上的支出（包括用于收购其他公司的资金，大多数分析师不会将收购支出纳入预测预算），除以发行在外股数。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `(购建固定资产、无形资产和其他长期资产支付的现金 + 取得子公司及其他营业单位支付的现金净额) ÷ 期末总股本` | 现金流量表 |
| H 股 | `(购买PP&E + 收购附属公司净额) ÷ 期末总股本` | 现金流量表 |

**解读:** CAPEX 高不一定好——需检查 ROIC 是否 > WACC。CAPEX vs 折旧：CAPEX > 折旧 → 扩张；CAPEX < 折旧 → 收缩。

---

#### #6 每股账面价值 (Book Value per sh)

**VL 定义:** "普通股股东权益以每股为基础计算，包括有形资产（工厂、应收账款、存货）和无形资产（专利、品牌价值即'商誉'）。如果有重大无形资产，通常会在脚注 (D) 中注明具体金额。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `归属于母公司所有者权益合计 ÷ 期末总股本` | 资产负债表 |
| H 股 | `归属于公司权益持有人权益总额 ÷ 期末总股本` | 资产负债表 |

**解读:** 账面价值是"清算价值"的代理变量——按账面值变卖所有资产、偿还所有债务、补偿优先股股东后，每股账面价值就是普通股股东剩下的金额。商誉占比过高的公司，权益"含金量"需警惕。PB < 1 的股票通常被认为低估。

### 5.2 股本与历史估值区 (#7-#10)

---

#### #7 发行在外股数 (Common Shs Outst'g)

**VL 定义:** 期末发行在外的普通股总数（扣除库藏股）。脚注 (E) 标注百万股单位及分拆调整。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `期末总股本 (百万股)` | 资产负债表 / 公司公告 |
| H 股 | `已发行普通股总数 (百万股)` | 年报 / 港交所披露 |

**解读:** 总利润增长但每股收益不增，通常因股数增加（增发/并购换股/期权行权）。反之，回购减少股数会推高每股指标。销售和利润可能飙升，而每股指标滞后——这是"摊薄效应"。

---

#### #8 平均年化市盈率 (Avg Ann'l P/E Ratio)

**VL 定义:** 逐年计算：每年均价 ÷ 当年实际 EPS。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `Σ(每日收盘总市值 ÷ 滚动四季扣非归母净利润) ÷ 交易天数` | 日K线 + 利润表滚动 |
| H 股 | `Σ(每日收盘总市值 ÷ 滚动四季 Non-IFRS 净利润) ÷ 交易天数` | 日K线 + 利润表滚动 |

**注:** 当前实现使用月度均价近似: `年度均价 ÷ 年度 EPS`。后续升级为日线精确计算。

**解读:** 历史平均 PE 提供估值中枢。VL 用 10 年 PE 中位数（见 3.3）作为最重要的估值锚。

---

#### #9 相对市盈率 (Relative P/E Ratio)

**VL 定义:** 逐年计算：个股 Avg Annual P/E ÷ VL 全样本（~1700只）Avg Annual P/E。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `个股平均 PE ÷ 沪深300 PE` | K线 + config 市场PE表 |
| H 股 | `个股平均 PE ÷ 恒生指数 PE` | K线 + config 市场PE表 |

**解读:** 相对 PE > 1 表示比大盘贵，< 1 表示比大盘便宜。低 PE 可能意味着低估，但也有可能是基本面将大幅恶化的先兆。

---

#### #10 平均年化股息率 (Avg Ann'l Div'd Yield)

**VL 定义:** 逐年计算：当年每股股息 ÷ 年均价。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `Σ(当年每股派息 ÷ 每日收盘价) ÷ 交易天数` | 股息 + 日K线 |
| H 股 | 同左 | 股息 + 日K线 |

**注:** 当前实现使用月均价近似: `DPS ÷ 年度均价 × 100%`。

**解读:** 高股息率可能意味着高回报，但也可能意味着股价暴跌。需结合股息支付率和自由现金流判断可持续性。收入导向投资者应选择股息率高于 Summary & Index 封面框 B 中位数的股票。

---

### 5.3 利润表指标区 (#11-#17)

---

#### #11 总营收 (Revenues / Sales)

**VL 定义:** 公司全年营业总收入，是衡量公司规模的**最常用指标**。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `营业总收入 (亿元)` | 利润表 |
| H 股 | `营业额 (亿元)` | 利润表 |

---

#### #12 毛利率 (Gross Margin)

> VL 官方 23 行中不包含此指标，本系统新增于 Revenues 和 Operating Margin 之间以增强利润分层分析。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `(营业总收入 - 营业成本) ÷ 营业总收入 × 100%` | 利润表 |
| H 股 | `(营业额 - 销售成本) ÷ 营业额 × 100%` | 利润表 |

**解读:** 毛利率反映产品定价权和成本控制能力。与营业利润率对比可揭示"费用负担"：高毛利 + 低营业利润率 = 销售管理费用过高。

---

#### #13 营业利润率 (Operating Margin)

**VL 定义:** "营业利润率显示多高比例的销售额转化为营业利润。营业利润等于总销售额减去销售成本以及销售和一般管理费用。也被称为 EBITDA（息税折旧摊销前利润）。"

> ⚠️ **关键区分:** VL 的 Operating Margin = EBITDA 利润率，**不是** A 股财报中"营业利润率"科目。EBITDA 排除了折旧政策和资本结构的影响。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `(经营溢利 + 折旧摊销) ÷ 营业总收入 × 100%` | 利润表 + 现金流表 |
| H 股 | `(经营溢利 + 折旧及摊销) ÷ 营业额 × 100%` | 利润表 + 现金流表 |

**解读:** VL 建议将营业利润率与净利润率对比。两者通常同步变化，如果不一致（如营业利润率上升但净利率下降），说明折旧、利息或税率正在发生重大变化，值得深究。

---

#### #14 折旧摊销 (Depreciation)

**VL 定义:** "折旧反映公司资产价值的降低，体现厂房设备的老化程度。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `固定资产折旧 + 无形资产摊销 + 长期待摊费用摊销 (亿元)` | 现金流量表补充资料 |
| H 股 | `折旧及摊销总额 (亿元)` | 财报附注 |

---

#### #15 净利润 (Net Profit)

**VL 定义:** "公司在扣除所有费用（含税）后赚取的利润，**不包括**非经常性损益和已终止业务的结果。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `扣非归母净利润 (亿元)` | 利润表 |
| H 股 | `Non-IFRS 经调整净利润 (亿元)` | 业绩公告 / 附注 |

---

#### #16 所得税率 (Income Tax Rate)

**VL 定义:** 所得税费用占税前利润的百分比。通常稳定，除非联邦税率变化或公司海外业务比例大幅变动。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `所得税费用 ÷ 利润总额 × 100%` | 利润表 |
| H 股 | `所得税开支 ÷ 除税前溢利 × 100%` | 利润表 |

**解读:** 高新技术企业、西部大开发等税收优惠会显著降低实际税率。

---

#### #17 净利润率 (Net Profit Margin)

**VL 定义:** 净利润占销售额（或营收）的百分比。**趋势比绝对值更重要。**

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `扣非归母净利润 ÷ 营业总收入 × 100%` | 利润表 |
| H 股 | `Non-IFRS 经调整净利润 ÷ 营业额 × 100%` | 利润表 |

**解读:** VL 建议将净利润率与营业利润率对比。两者通常同步，偏离时需追查折旧、利息支出或税率的异常变化。

---

### 5.4 资产负债指标区 (#18-#20)

---

#### #18 营运资金 (Working Cap'l)

**VL 定义:** "流动资产减去流动负债，反映企业日常运营的可用流动性资产。销售额越高，通常需要越多营运资金。**但我们提醒:** 许多稳定收入流的大型公司不再需要大量营运资金，负营运资金可能完全可接受——因为公司可以通过持续现金收款满足正常运营支出。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `流动资产合计 - 流动负债合计 (亿元)` | 资产负债表 |
| H 股 | `流动资产总额 - 流动负债总额 (亿元)` | 资产负债表 |

**解读:** 负营运资金对零售、消费品行业常见（快收慢付模式）。但若负营运资金伴随营收下降，可能是流动性危机的信号。

---

#### #19 长期债务 (Long-Term Debt)

**VL 定义:** "一年以上到期的债务义务。"

> ⚠️ VL 的长期债务指有息金融负债，不含租赁负债、递延税项等经营性负债。

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `长期借款 + 应付债券 (亿元)` | 资产负债表附注 |
| H 股 | `非流动银行借款 + 应付票据及债券 (亿元)` | 资产负债表附注 |

**解读:** 将长期债务与股东权益比较。如果债务占比快速上升但 ROIC 没有同步提升，说明借债没有为股东创造额外价值。若公司借债成本高于 ROIC，从长期看借贷不值得。

---

#### #20 股东权益 (Shr. Equity)

**VL 定义:** "也称为净资产，是扣除所有负债后公司总资产中的股东权益总额（含优先股和普通股）。所有无形资产（如商誉、专利、递延费用）都包含在内。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `归属于母公司所有者权益合计 (亿元)` | 资产负债表 |
| H 股 | `权益总额 - 非控股权益 (亿元)` | 资产负债表 |

**解读:** 商誉占比过高的公司，权益"含金量"需要警惕——商誉减值会一次性冲击净资产。

---

### 5.5 回报率指标区 (#21-#24)

---

#### #21 投入资本回报率 (Return on Total Cap'l)

**VL 定义:** "衡量公司从股东权益和长期债务中赚取的回报百分比。当 ROIC 上升时，ROE 也应该上升。如果没有，说明公司在借更多钱并支付利息，但没有为股东的权益赚取更多回报。除非公司长期赚取超过债务利息成本的回报，否则借贷风险不值得承担。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `息税前利润(EBIT) ÷ (长期借款 + 应付债券 + 归母权益) × 100%` | 利润表 + 资产负债表 |
| H 股 | `经调整 EBIT ÷ (非流动有息负债 + 归母权益) × 100%` | 利润表 + 资产负债表 |

**解读:** ROIC 是最全面的盈利衡量指标，同时考虑股权和债权回报。ROIC > WACC 表示公司创造价值。

---

#### #22 股东权益回报率 (Return on Shr. Equity)

**VL 定义:** "揭示每年为股东（普通股和优先股）赚取的回报百分比。**较高的数字通常更理想，表明更高的生产力和效率。** ROE 和 ROIC 的趋势——两个衡量企业表现的关键指标——能充分说明管理层的水平。"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `扣除非经常性损益后的归母净利润 ÷ 加权平均归母净资产 × 100%` | 利润表 + 资产负债表 |
| H 股 | `Non-IFRS 经调整净利润 ÷ 归母净资产平均值 × 100%` | 利润表 + 资产负债表 |

**解读:** ROE 可拆解为杜邦分析：净利润率 × 资产周转率 × 杠杆倍数。ROE 很高但主要靠高杠杆驱动时需警惕。

---

#### #23 留存利润再投比 (Retained to Com Eq)

**VL 定义:** "也称为'留存率 (Plowback Ratio)'，等于净利润减去所有股息（普通股和优先股），除以普通股股东权益，以百分比表示。它衡量公司有多少内部生成的资源可用于投资未来增长。**高留存率和快速增长的账面价值是积极的投资特征。**"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `(扣非归母净利润 - 全部股息) ÷ 归母权益 × 100%` | 利润表 + 资产负债表 |
| H 股 | `(Non-IFRS 经调整净利润 - 全部派息) ÷ 归母权益 × 100%` | 利润表 + 资产负债表 |

**解读:** 留存率 + 股息支付率 ≈ 100%。高速增长公司留存率高，成熟公司留存率低。留存资金能否产生足够回报（ROE）是关键——ROE 低时把钱分给股东更合理。

---

#### #24 股利支付率 (All Div'ds to Net Prof)

**VL 定义:** "'支付率 (Payout Ratio)'，衡量公司利润中以股息形式分配给所有股东（普通股和优先股）的比例。年轻快速成长的公司通常将大部分利润再投资，成熟公司通常支付较大比例的利润。**大型股公司通常支付 25%-30% 的利润作为股息。**"

| 市场 | 公式 | 数据来源 |
|------|------|----------|
| A 股 | `当年现金分红总额(含税) ÷ 扣非归母净利润 × 100%` | 分红公告 + 利润表 |
| H 股 | `当年派息总额 ÷ Non-IFRS 经调整净利润 × 100%` | 业绩公告 + 利润表 |

**解读:** 支付率过高 (>80%) 可能不可持续。支付率 + 留存率 ≈ 100%。

---

## 六、关键交叉诊断框架

### 6.1 ROIC vs ROE 四象限（VL 官方最强调）

```
ROIC↑ + ROE↑ → 真实盈利改善 ✅
ROIC→ + ROE↑ → 杠杆增加推高 ROE（中性，需持续监控）
ROIC↓ + ROE↑ → 危险杠杆游戏 🔴
ROIC↓ + ROE↓ → 盈利全面恶化 🔴
```

### 6.2 三层利润率裂缝分析

```
毛利率 (#12)
  ↓ 裂缝1 = SG&A 费用负担（销售、管理和一般费用）
营业利润率 (#13) — VL 口径 = EBITDA 率
  ↓ 裂缝2 = 折旧(#14) + 利息 + 税费(#16)
净利润率 (#17)

裂缝1 缩小 → 规模效应发挥 / 费用控制改善 ✅
裂缝1 扩大 → SG&A 侵蚀利润 ⚠️
裂缝2 缩小 → 折旧/利息/税负减轻 ✅
裂缝2 扩大 → 资产老化加速或杠杆成本上升 ⚠️
```

### 6.3 现金流 vs 收益验证

```
#2 每股现金流 必须 > #3 每股收益（永远！）
差值 = #2 - #3 = 每股折旧摊销

差值越大 → 资本密集度越高（重资产模式）
差值缩小 → 轻资产转型 或 折旧完成
差值突然扩大 → 有大额资产购建（检查 #5 CAPEX 是否同步上升）
```

### 6.4 销售 vs 每股销售（摊薄检测）

```
总销售增长 > 每股销售增长 → 股本摊薄（增发/并购换股/期权行权）
总销售增长 < 每股销售增长 → 公司回购（股本减少）
总销售增长 = 每股销售增长 → 纯内生增长（最佳）
```

### 6.5 留存 vs 分红四象限

| | 留存率高 (#23) | 留存率低 (#23) |
|---|---|---|
| **ROE 高 (#22)** | ✅ 复利机器（利润再投产生高回报） | ✅ 成熟现金牛（分红回馈股东） |
| **ROE 低 (#22)** | ❌ 价值毁灭（再投资效率低，应分红） | ⚠️ 吃老本（低回报 + 高分红的不可持续） |

### 6.6 CAPEX vs 折旧（投资效率）

```
CAPEX (#5 × 股数) > 折旧 (#14) → 净投资扩张
CAPEX < 折旧 → 资产基础收缩（可能是好事，如果旧资产回报低）
关键在于：新增 CAPEX 是否产生了足够的 ROIC？
```


|------|------|

### 8.4 季度数据（㉑ ㉒）

- 过去 2 年 + 当前年的季度/半年数据
- 销售额列 (㉑) + EPS 列 (㉒)
- 每列有"全年合计"列
- 可用于同比季度增速分析（如 JNJ：2012年6月 vs 2013年6月销售增长 8.5%）

### 8.5 脚注系统（⑳）

脚注是 VL 报告的重要补充信息，包含：

| 脚注 | 典型内容 |
|------|----------|
| **(A)** | 财年结束日期 |
| **(B)** | 基本 EPS 或稀释 EPS（几乎总是稀释） |
| **(C)** | 历史股息支付月份 |
| **(D)** | 无形资产明细（总额 + 每股金额） |
| **(E)** | 股数单位（百万股）及分拆调整 |
| ■ | 是否有 DRIP (股息再投资计划) |

## 九、A股 / H股适配差异

### 9.1 美股 ↔ A股/H股的关键差异

| 概念 | 美股 (US GAAP) | A 股 (CAS) | H 股 (HKFRS ≈ IFRS) |
|------|---------------|-----------|---------------------|
| 每股收益 | Diluted EPS (剔除一次性) | 扣非稀释 EPS | Non-IFRS 稀释 EPS |
| 营业利润率 | EBITDA 率 | 需从经营溢利+D&A 计算 | 同左 |
| 营业成本 | COGS | 营业成本 | 销售成本 (Cost of Sales) |
| 现金流 | Net Income + D&A | 同左 | 同左 (非 CFO) |
| 无形资产 | 含商誉 | 含商誉 | 含商誉 |
| 优先股 | 普遍存在 | 极少 | 极少 |

### 9.2 当前实现说明

- 扣非 EPS (#3) 和 Non-IFRS 净利润 (#15) 当前使用归母口径，后续升级为扣非/Non-IFRS
- 平均 PE (#8) 和股息率 (#10) 当前使用月线均价近似，后续升级日线
- 资本支出 (#5) 含收购支出，与 VL 口径一致
- VL P/E (item ⑥) = (过去6个月EPS + 未来6个月预估EPS) 的 P/E，当前尚未实现（需盈利预测数据）
- Median P/E (item ⑦) = 10年P/E中位数，当前用历史均值近似

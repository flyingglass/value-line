## 一、入门：Value Line Investment Survey 三大板块

Value Line Investment Survey 每周向订阅者提供三个部分，覆盖约 1700 只股票和约 100 个行业。这只股票池约占美国市场总市值的 **90%**，因此具有极高的市场代表性。

### Part 1 — Summary & Index (摘要与索引)

首页包含三个关键市场统计框：

| 框 | 内容 | 含义 |
|----|------|------|
| **框 A** | 全部有盈利股票的预估 P/E 中位数 | 当前市场整体估值水平 |
| **框 B** | 全部有分红股票的预估股息率中位数 | 市场整体分红回报水平 |
| **框 C** | 预估 3-5 年价格升值潜力中位数 | VL 假设的经济环境下的市场整体预期回报 |

首页还按字母顺序列出所有行业及其 **当前行业排名**，右侧标注该行业报告的页码。从第 2 页开始是按字母排序的全部股票列表，标注每只股票在 Part 3 中的页码。左侧列若出现 **HH** (双星)，表示当前期有该股票的 **补充报告**。

**股票筛选器 (Stock Screens)**：在 Summary & Index 的后半部分（第 24 页起），提供多种每周更新的股票筛选列表，如：
- 及时行业中的及时股票
- 保守型股票
- 最高收益率股票
- 最高 3-5 年升值潜力股票

### Part 2 — Selection & Opinion (选股与观点)

这是 VL 的最新经济和市场评论、投资想法的核心来源，包括：

- **经济与市场评论** — VL 对宏观经济的展望
- **四个模型投资组合**：
  | 组合 | 特点 |
  |------|------|
  | **Portfolio I** | 年度价格潜力高于平均的股票 |
  | **Portfolio II** | 收益 + 价格升值兼顾 |
  | **Portfolio III** | 长期价格成长潜力 |
  | **Portfolio IV** | 股息率高于平均的股票 |
- **精选股票深度评论 (Stock Highlights)**
- **特殊股票筛选器** — 与 Part 1 不同的独特视角

### Part 3 — Ratings & Reports (评级与报告)

这是 VL 的核心产品：**约 1700 份公司单页报告 + 约 100 份行业单页报告**。

- 公司报告包含：Timeliness / Safety / Technical 排名、3-5 年预测、最多 17 年历史财务数据、价格图、分析师评论
- 每份报告每 **13 周**更新一次
- 每周约 130 份公司报告更新，按行业分组
- 行业报告排在对应行业公司报告之前
- 重大事件发生时可发布 **补充报告**（标为 HH）

## 五、Value Line 三大排名详解

### 5.1 Timeliness Rank (时效性排名)

**定义:** 预期未来 6-12 个月相对约 1700 只股票的价格表现排名。

| 排名 | 数量 | 含义 |
|------|------|------|
| **1 (Highest)** | 100 只 | 预期表现最佳 |
| **2 (Above Average)** | 300 只 | 预期表现优于平均 |
| **3 (Average)** | ~900 只 | 预期表现平均 |
| **4 (Below Average)** | 300 只 | 预期表现低于平均 |
| **5 (Lowest)** | 100 只 | 预期表现最差 |

**决定因素（按权重排序）：**
1. **盈利增长** — 过去 10 年盈利增长 > 股价涨幅的，排名倾向有利
2. **相对价格动量** — 近期股价相对表现
3. **季度盈利表现** — 近期是否超预期或低于预期
4. **盈利惊喜** — 报告结果显著好于或差于预期

> ⚠️ **注意:** Rank 1 股票通常波动性更高、市值偏小。保守投资者应同时关注 Safety 排名。

### 5.2 Safety Rank (安全性排名)

**定义:** 衡量个股相对约 1700 只股票的总风险水平。与 Timeliness 不同，每个排名的股票数量可能不固定。

**由两个等权重因素组成**（位于报告右下角 29 号区域）：

| 因素 | 刻度 | 含义 |
|------|------|------|
| **Financial Strength** (财务实力) | A++ (最高) → C (最低) | 公司财务状况，大公司 + 强资产负债表得分最高 |
| **Price Stability** (价格稳定性) | 100 (最高) → 5 (最低)，步长 5 | 过去 5 年每周价格变化百分比的标准差排名 |

**附加参考（不直接参与 Safety 计算）：**
- **Price Growth Persistence** — 过去 10 年相对价格增长的持续性
- **Earnings Predictability** — 盈利预测的可靠性

> 保守投资者应选择 Safety Rank 1 或 2 的股票。

### 5.3 Technical Rank (技术排名)

**定义:** 预测未来 3-6 个月的短期相对价格变化。

**基于：**
- 专有模型，考察过去一年不同时间段的 **10 种相对价格趋势**
- 每只股票的 **价格波动率**

分布与 Timeliness 相同：100/300/900/300/100。

## 六、Beta 系数

**定义:** 衡量个股相对整体市场的波动性（由 Value Line 计算）。

| Beta 值 | 含义 |
|---------|------|
| **1.0** | 与市场同步波动，市场涨/跌 3%，个股约涨/跌 3% |
| **> 1.0** | 比市场更波动（激进型） |
| **< 1.0** | 比市场更稳定（防守型） |

> JNJ 的 Beta 为 0.65，意味着市场涨 10% 时 JNJ 约涨 6.5%，适合追求稳定的保守投资者。

## 七、市盈率的五种形式

这是 VL 报告中最丰富的部分之一，同一页面展示 **5 种不同口径的 P/E**：

### 7.1 VL P/E (报告顶部，item 6)
```
公式: 最近股价 ÷ (过去6个月EPS + 未来6个月预估EPS)
```
**特点:** VL 独有，兼顾历史和未来，最具前瞻性。

### 7.2 Trailing P/E (item 7)
```
公式: 最近股价 ÷ 过去12个月实际EPS
```
**特点:** 报纸和财经网站最常用的口径，仅用已报告数据。

### 7.3 Median P/E (item 7)
```
定义: 过去10年P/E的中位数（经统计调整）
```
**特点:** 显示该股票的历史估值中枢，是重要估值锚。

### 7.4 Average Annual P/E (Statistical Array 第8行，items 15 & 26)
```
公式: 每年均价 ÷ 当年实际EPS
```
**特点:** 逐年对比，展示估值变化趋势。

### 7.5 Relative P/E (item 8 + Statistical Array 第9行)
```
公式: 个股P/E ÷ VL全样本(~1700只)P/E中位数
```
**解读:**
- **> 1.0** — 比市场整体贵
- **< 1.0** — 比市场整体便宜
- JNJ 相对 PE = 0.95，长期低于市场平均

## 八、价格图深度解读

VL 的价格图（图表区域）包含**三条线 + 多个辅助元素**：

### 8.1 月线价格范围（竖线，item 3）
- 显示每月最高价和最低价
- 已针对后续股票分拆和股息调整
- 用来看长期价格走势和波动范围

### 8.2 现金流基准线（实线，item 4）
**"Value Line" — VL 最著名的发明之一。**

```
绘制方法:
每股"现金流" × 分析师确定的乘数

其中每股"现金流" = (净利润 + 折旧摊销 - 优先股股息) ÷ 期末股数
```

**核心理论：**
- 股价倾向于围绕现金流线波动
- 股价高于现金流线 → 倾向回落
- 股价低于现金流线 → 倾向回升
- 部分股票可能长期高于或低于该线

**乘数设定：** 分析师通过历史拟合确定，使现金流线与历史股价最接近，同时与 3-5 年目标价格区间呼应。JNJ 当前的现金流乘数为 12.0。

> **与 P/E 乘数的区别:** P/E = 股价 ÷ 盈利；现金流乘数 = 股价 ÷ (盈利 + 折旧)，因此通常小于 P/E 乘数。

### 8.3 相对价格强度线（虚线，item 12）
- 与 VL Arithmetic Index（约 1700 只股票的综合指数）比较
- 上升 = 跑赢大盘（动量强）
- 下降 = 跑输大盘（动量弱）

### 8.4 图例框 (Legends Box, item 2)
包含：
- 现金流倍数值
- 股票分拆记录
- 是否有期权交易
- 阴影区域 = 衰退期

### 8.5 图表上的其他元素

| 元素 | 位置 | 说明 |
|------|------|------|
| 年度最高/最低价 (item 9) | 图表顶部 | 每日历年的价格范围 |
| 成交量 (item 14) | 图表底部 | 每月成交量占流通股百分比 |
| % Total Return (item 13) | 图表区域 | 过去1/3/5年个股 vs VL 指数总回报 |

---
### 8.5 目标价格区间 (Target Price Range，item 11)

图表右上角的虚线区间，表示 VL 分析师认为 **3-5 年后股价最可能落入的价格区间**。

```
计算方法:
预测的 3-5 年后 EPS × 预估 P/E = 目标价格区间

区间宽度取决于 Safety Rank:
- Safety 高 → 区间窄（确定性高）
- Safety 低 → 区间宽（不确定性大）
```

JNJ 的目标区间为 90-110，较当前价格有 40%-65% 的潜在空间。

## 九、统计数组 (Statistical Array) 逐行拆解

这是 VL 报告**最核心的区域**，包含 **上下两部分**：
- **上半部分** = 每股数据（per share）
- **下半部分** = 总量数据（百万美元）

**字体含义：**
- 左侧常规字体 = 历史实际数据（最多 17 年）
- 右侧粗斜体 = 预测数据（今年、明年、3-5 年后）

### 9.1 上半部分 — 每股指标

| 行 | 指标 | 英文原文 | 核心解读 |
|----|------|----------|----------|
| **1** | 每股营收 | Sales per sh | 业务扩张能力；股数增加会摊薄此指标 |
| **2** | 每股"现金流" | "Cash Flow" per sh | 净利润+折旧（非 CFO）；衡量内生现金生成能力 |
| **3** | 每股收益 | Earnings per sh (B) | 稀释 EPS，剔除非经常性项目（脚注 B 标明） |
| **4** | 每股宣告股息 | Div'ds Decl'd per sh (C) | 成熟公司 25-30% 利润用于分红 |
| **5** | 每股资本支出 | Cap'l Spending per sh | 厂房设备新支出+收购支出 |
| **6** | 每股账面价值 | Book Value per sh (D) | 含商誉等无形资产（脚注 D 披露） |
| **7** | 发行在外股数 | Common Shs Outst'g (E) | 百万股；股数变化直接影响每股指标 |
| **8** | 平均年化 P/E | Avg Ann'l P/E Ratio | 逐年计算，展示估值趋势 |
| **9** | 相对 P/E | Relative P/E Ratio | 个股 P/E ÷ VL 全样本 P/E |
| **10** | 平均年化股息率 | Avg Ann'l Div'd Yield | 逐年股息率变化 |

### 9.2 下半部分 — 总量指标

| 行 | 指标 | 英文原文 | 核心解读 |
|----|------|----------|----------|
| **11** | 销售额(百万美元) | Sales ($mill) | 衡量公司规模的最常用指标 |
| **12** | 营业利润率 | Operating Margin | VL 口径 = EBITDA 率 = (营收-COGS-SG&A) / 营收 |
| **13** | 折旧(百万美元) | Depreciation ($mill) | 反映厂房设备老化程度 |
| **14** | 净利润(百万美元) | Net Profit ($mill) | 扣除所有费用含税，不含非经常性和终止业务 |
| **15** | 所得税率 | Income Tax Rate | 通常稳定；海外业务比例变化会影响 |
| **16** | 净利润率 | Net Profit Margin | 净利润 ÷ 销售额；趋势比绝对值更重要 |
| **17** | 营运资金(百万美元) | Working Cap'l ($mill) | 流动资产-流动负债；大型稳定企业可为负 |
| **18** | 长期债务(百万美元) | Long-Term Debt ($mill) | 一年以上到期的有息负债 |
| **19** | 股东权益(百万美元) | Shr. Equity ($mill) | 含优先股+普通股、含无形资产 |
| **20** | 投入资本回报率 | Return on Total Cap'l | (股东权益+长期债务) 的综合回报 |
| **21** | 股东权益回报率 | Return on Shr. Equity | 反映管理层的盈利效率 |
| **22** | 留存利润再投比 | Retained to Com Eq | 利润再投资比例 = (净利润-全部股息)/普通股权益 |
| **23** | 全部分红与净利润比 | All Div'ds to Net Prof | 支付率；大型成熟公司通常 25-30% |

### 9.3 关键交叉诊断

**每股现金流 vs 每股收益的差值：**
```
差值 = #2 - #3 = 折旧/股
差值越大 → 资本密集度越高
差值缩小 → 轻资产化或折旧完毕
```

**三层利润率裂缝分析（VL 最核心的诊断方法）：**
```
毛利率
  ↓ 裂缝1 = SG&A 费用负担
营业利润率 (#12)
  ↓ 裂缝2 = 折旧 + 利息 + 税负
净利润率 (#16)

裂缝缩小 → 规模效应/效率提升 ✅
裂缝扩大 → 费用侵蚀/负担加重 ⚠️
```

**ROIC vs ROE 诊断（VL 官方最强调）：**
```
ROIC↑ + ROE↑ → 真实改善 ✅
ROIC→ + ROE↑ → 杠杆增加（中性）
ROIC↓ + ROE↑ → 危险杠杆游戏 🔴
ROIC↓ + ROE↓ → 全面恶化 🔴
```

**销售 vs 每股销售：**
- 总销售增长 + 每股销售不增 = 股本摊薄
- 总销售不增 + 每股销售增长 = 公司回购

### Analyst Commentary (分析师评论，item 17)

**VL 官方认为这是页面中最重要的部分之一。**

**阅读建议：**
1. **先看硬数据**，形成自己的初步判断
2. **再读评论**，看分析师如何解读
3. **找矛盾点** — 数据与评论不一致的地方往往是最大的机会或陷阱
4. **关注变化** — 分析师解释为什么趋势正在或即将转向

**JNJ 评论要点示例：**
- JNJ 是优质蓝筹股，适合持有而非追涨
- 第二季度全面超预期（三大业务部门均有贡献）
- 管理层谨慎引导，仅小幅上调全年指引
- 股息优质（A++ 财务实力 + 100 盈利可预测性）
- 近期大涨已压缩 3-5 年升值空间，建议保守投资者观望

## 核心要点回顾

1. **三部分架构** — Summary & Index (筛选) → Selection & Opinion (观点) → Ratings & Reports (深度)
2. **三大排名** — Timeliness (6-12月) → Safety (总风险) → Technical (3-6月动量)
3. **五层 P/E** — VL P/E / Trailing / Median / Avg Annual / Relative
4. **三条图线** — 月线价格 / 现金流基准线 / 相对强度线
5. **24 行统计数组** — 每股指标(上) + 总量指标(下)，历史(左) + 预测(右)
6. **阅读顺序** — 排名 → 分析评论 → 预测 → 增长率 → 目标价 → 历史趋势
7. **核心交叉诊断** — ROIC vs ROE、现金流 vs 收益、三层利润率裂缝、留存 vs 分红
